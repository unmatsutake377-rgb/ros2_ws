C-median 필터 검증

물보라가 raw-min 감속을 유발하는가 / 공간 median(커널5)이 고치는가. 시드 20개.

결론: 채택. 물보라가 가짜 감속을 실제로 유발하고(전진 시간의 최대 37%), median 필터가 그걸 완전히 제거하면서 접촉은 그대로 0입니다. 순수 이득입니다.

측정 결과

물보라방식접촉 합전진 평균가짜 감속 시간비율
0%raw min033.7m8.9%
0%median033.7m8.9%
15%raw min034.9m22.5%
15%median033.8m8.9%
30%raw min036.1m36.8%
30%median033.8m8.9%

"가짜 감속 시간비율" = 전진 명령 중 순항속도 미달로 감속된 시간 비율. 8.9%는 실제 부표 앞 정상 감속(기준선).

왜 temporal 필터와 다른가

temporal (폐기)C-median (채택)
막는 것프레임 간 깜빡이는 오탐한 프레임 안 고립 스파이크
닿는 곳회피 마스크 (효과 0이었음)감속 신호(_closest_obstacle)
20시드 효과차이 없음가짜감속 22~37% → 9%
접촉 영향—0 유지 (회피 안 건드림)
왜 접촉이 안 변하나 (핵심): median 은 _closest_obstacle(감속 신호)에만 적용됩니다. 회피 조향은 _compute 의 별도 경로(마스크→dilate→갭)를 씁니다. 즉 감속 오탐만 고치고 회피는 손대지 않습니다. 그래서 접촉 0 그대로. 가장 외과적인 수정입니다.

권고

  • 채택하되 파라미터화 — obst_median_kernel (기본 5, 0이면 raw min)
  • 기본 ON 권장 — temporal 은 효과 0이라 OFF였지만, 이건 명확한 이득 + 무해라 ON
  • 적용 위치: _closest_obstacle. 회피 마스크는 건드리지 말 것
  • ⚠️ 시뮬 물보라는 '고립 단일점' 모델 — 실제 물보라가 작은 군집이면 커널5가 부족할 수 있음. 배 뜬 뒤 블랙박스 obst_min_dist 로 실측 확인
