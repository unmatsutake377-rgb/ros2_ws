우선순위 재확인

채점표가 우선순위를 확정해줍니다:
  1. 위치유지 — 배점은 낮아도(10) 가장 쉬운 만점. 득점한 7팀 전원 만점. 반드시 확보.
  2. 장애물회피 — 배점 최고(20)이고 우리가 가장 잘함. 여기가 점수의 기둥.
  3. 도킹 — 희소(2팀)라 성공 시 순위가 크게 오름. 위험하지만 고배점.
  4. 탐색·항로추종 — 되면 보너스. 무리하지 말 것.
