# KABOAT 2025 상위권 팀 총정리 → Claude Code 가능성 평가 요청

> 채점표(정답지) + 8개 팀 기술보고서를 대조 분석한 결과.
> 우리 시스템: RPLIDAR A3 + OAK-1(단안, 뎁스 없음) + ZED-F9P RTK.
> 회피=갭팔로잉 / 도킹=카메라방위+LiDAR전방최소거리+정면접근FSM / 위치유지=LiDAR거리 bang-bang / 선회=orbit / 게이트=빨강초록 쌍제약.

---

## 0. 가장 큰 결론 (먼저)

**도킹 만점 팀(인하대 252·251)은 우리와 하드웨어가 판박이**다 — RPLIDAR A3 + 단안 카메라 + ZED-F9P RTK.
그들이 **우리와 같은 방법**(정면접근 FSM + 카메라 방위 + LiDAR 거리)으로 성공했다. **우리 6a 설계가 옳았다.**

그리고 **딥러닝은 함정**이었다 — 정교한 YOLO+3D LiDAR 팀(부경대)은 도킹 0점, 담백한 OpenCV 팀(인하대)이 만점.

## 1. 미션별 "상위권 표준" (우리 방식 대비)

### 위치유지 — 🚨 우리 방식이 소수파일 수 있다
- **우리:** LiDAR로 부표까지 거리 유지 (bang-bang)
- **상위권 표준: RTK-GPS 절대좌표 홀드 + PD.** 서울대 MSGA(만점):
  > "GPS 위치 + θ PD 제어. Waypoint 3m 반경 진입 시 전면/후면 판별하여 그 점 위에 계속 머무름"
- 부산대 두 팀도 "목표 반경 감속 + 도착 판정" RTK 홀드형.
- **평가 필요: 우리 LiDAR 거리 방식 vs RTK 좌표 홀드. 어느 게 나은가? RTK 있으면 좌표 홀드가 부표 없이도 되니 더 견고할 수 있다.**

### 장애물 회피 — 우리 갭팔로잉이 맞는 방향, 강화 여지 있음
- **부산대 해미르 (우리와 동일 하드웨어의 완성형):**
  > "미디언필터(커널5)로 해수면 반사 제거 → DBSCAN 클러스터링 → 선폭 고려 **0.6m 이상 갭만 유효** → **목표방위각 오차 최소 갭의 중심각** 선택"
- **부산대 날샘 (ISV_J 유력, 회피 16):** **장애물+목표+헤딩 3항 코스트 최소화** (VFH*/DWA식). 갭팔로잉을 비용함수로 일반화.
- **창원대 ECOCEAN (회피 만점):** VFH+ (목표각·회피각 가중합).
- **동아대 OpenDEP (회피 18):** 갭 후보를 "통과 소요시간" 비용으로 스코어링.
- **인하대 251:** obstacle_detector + MOT-LiDAR ROS 패키지 (거리 급변 세그먼트 + 원근사 + 트래킹).
- **공통 패턴:** 단순 "최대 갭"이 아니라 **목표 방향 가중치를 더한 갭 선택**이 고득점 열쇠.

### 선회(탐색) — 우리 orbit 골격은 맞음, 부표 잠금 정밀화 여지
- **인하대 251 / 부산대 날샘:** **YOLO 색분류 bbox ∩ LiDAR 클러스터 매칭** → "초록부표 = 전방 7m, 15도" 융합 → 그 점 기준 Circling.
- 우리도 **OAK-1 bbox 각도 ∩ RPLIDAR A3 스캔 각도 매칭**으로 orbit 중심 잠금 가능 (뎁스 없어도 됨).
- 부산대 날샘: 선회 정량값 — **0.45m/s에서 좌우 ΔPWM 33, 요레이트 3.0°/s.**

### 게이트 — 특이 기법 발견
- **서울대 MSGA:** **복소 유체 속도장** — 빨강 +Γ / 초록 -Γ 소용돌이 → 게이트 중앙으로 빨려드는 유동장 자동 생성. 우리 "쌍제약" 로직을 수식으로 대체 가능.

### 항로추종 — 기본기
- **한국해양대 새울 (만점):** 화려하지 않은 GPS 웨이포인트 FSM + PID. 대신 **GAZEBO 가상검증 + 실해역 반복 테스트**로 신뢰성. → "정교함보다 검증"

## 3. Claude Code 에 물어볼 것 (가능성·실용성 평가)

```
위 8개 아이디어(A~H)를 우리 시스템에 적용 가능한지, 실용적인지 평가해줘.
우리 원칙을 유지하면서: RPLIDAR A3 2D + OAK-1 단안(뎁스없음) + ZED-F9P RTK,
하드코딩 금지(파라미터화), 토픽 계약 유지, 대회 직전 위험한 큰 리팩터링 회피.

각 아이디어에 대해:
1. 우리 하드웨어/구조로 구현 가능한가? (특히 OAK-1 뎁스 없음, 2D LiDAR 제약)
2. 노력 대비 효과 (점수 미션에 닿는가? 채점표상 위치유지·회피·도킹이 고배점)
3. 위험 (기존 검증된 것을 깨뜨리나? 대회 직전 도입 위험?)
4. 순서 (지금? 배 뜬 뒤? 아예 하지 말 것?)

특히 이 둘은 판단이 갈릴 수 있으니 자세히:
- [D] 위치유지: 우리 LiDAR bang-bang vs 서울대 RTK 좌표 홀드.
  상위권은 RTK 홀드가 표준인데, 우리 방식을 바꿔야 하나 유지해야 하나?
  (RTK 홀드는 부표 없이도 되지만, GPS 정밀도/드리프트에 의존)
- [G] 게이트 복소 유체 속도장: 우아하지만 우리 쌍제약이 이미 검증됨.
  바꿀 가치가 있나, 아니면 과설계인가?

그리고 A~H 를 '지금 넣을 것 / 배 뜬 뒤 판단 / 안 할 것' 3분류로 정리해줘.
근거는 '채점표 배점(위치유지10·회피20·도킹15가 핵심)'과 '우리 하드웨어 제약'에 두고.
```

## 4. 반면교사 (하지 말 것)

- **YOLO / 3D LiDAR 고정밀 도킹** — 부경대(0점). 우리 단안+2D엔 OpenCV가 정답.
- **Velocity Obstacle 회피** — 서울대, 이론 최고급이나 실전 회피 0점.
- **딥러닝 표식 인식** — 야외 조도·연산부하로 인하대도 버림.
- **교훈: 정교함 < 실전 검증.** 만점 팀들의 공통점은 "단순 + 반복 검증".
