간이 수조 테스트 계획

야외 · 3~6m · GPS 됨(RTK). 미션 하나씩 검증 + 회전 관성 측정.

핵심: 수조는 작지만 정확히 GPS가 필요 없는 부분 = 미션 동작을 검증합니다. 미션 노드는 서로 독립이라 하나씩 켤 수 있고, 야외라 GPS가 되니 회전 관성 + (6m면) 전진 관성까지 뽑힙니다.

수조에서 되는 것 / 야외 코스로 미루는 것

테스트수조(3~6m)비고
조향 부호 (좌/우)✅ 됨제자리 선회 30초, 공간 거의 안 씀
회전 관성 (tau_w, k_w)✅ 됨자이로(gyro_z)로 측정, 공간 무관

미션 하나만 켜는 법

수조엔 코스가 없어 north_goal_angle(GPS 웨이포인트)을 안 씁니다. 대신 /wp_mode를 손으로 쏴서 원하는 미션만 깨웁니다:

ros2 topic pub /wp_mode std_msgs/msg/Int32 "{data: 1}"
#   1 = 게이트    2 = 위치유지    3 = 선회    7 = 도킹

그 미션 노드가 카메라·라이다로 동작 → /candidate_angle 발행 → ship_direction + motor_control이 배를 움직입니다. GPS 불필요.

🚨 수조 벽 문제 — 미션별 대응

3~6m 수조면 라이다에 벽이 1.5~3m에 사방으로 잡힙니다. ship_direction이 벽을 장애물로 보고 피하려다 배가 맴돌 수 있습니다. 미션별로 다르게 처리하세요.
테스트벽 처리
모터 응답·조향 부호ship_direction을 끄고 motor_control에 명령 직접 (/desired_angle 수동 발행). 벽과 무관.
위치유지벽이 오히려 거리 기준물. 작은 공간이 딱. 그대로 진행.
게이트·도킹·선회부표/도크를 수조 중앙, 벽에서 최대한 떨어뜨려 배치. detection_distance를 짧게(예: 1.0m) → 벽 전에 목표물만 본다.

순서 — 이렇게 도세요 (반나절)

1벤치 (물 밖, 30분) — 물 넣기 전에

· 헬스체크: 라이다·IMU·GPS·카메라 다 살아있나 (ros2 launch ... healthcheck)
· 포트 확인: /dev/ttyLiDAR, /dev/IMU, /dev/ttyGPS, /dev/ttyMCU 다 잡혔나
· IMU 정북 확인: 뱃머리 정북 → /imu/yaw 가 0 근처인가
· 모터: 프로펠러 손으로 막고, 전진 명령 → 양쪽 다 도는가

2수조: 조향 부호 (5분)

제자리 우선회 명령 → 오른쪽으로 돌면 정상.
왼쪽으로 돌면 → config 의 steer_invert: true 로 바꾸고 재확인.
★ 이게 맞아야 나머지 전부 의미 있음. 제일 먼저.

3수조: 회전 관성 (5분)

정지 → 한쪽 조향 확 넣고 6초 → 중립.  좌우 각 2~3회.
블랙박스가 gyro_z 로 기록. 공간 거의 안 씀.

4수조: 전진 관성 (6m면, 5분)

정지 → 순항 PWM 확 넣고 벽 닿기 전까지 → 중립.  2~3회.
gps_vel(RTK) 로 기록. ★ RTK fix 품질 확인 필수(아래).

5수조: 미션 하나씩 (각 10분)

위치유지 → 선회 → 근접 게이트 → 근접 도킹 순.
각각 /wp_mode 로 켜고, 부표/도크는 벽에서 떨어뜨려.

6CSV 를 채팅에 올리기

~/ssf_logs/blackbox_날짜.csv 를 이 채팅에 드래그.
→ 내가 회전 관성·(전진 관성)·조향 검증 + 시뮬 보정값 산출.

⚠️ 야외 RTK — 데이터 오염 방지

건물·구조물 옆이면 GPS 신호가 반사(멀티패스)되어 RTK가 튑니다.
  • 수조를 트인 곳에 두세요 (하늘이 넓게 보이게)
  • 블랙박스에서 RTK fix 상태를 확인 — fix가 'RTK Fixed'가 아니면 그 전진 데이터는 못 씁니다
  • 회전 관성은 GPS 안 쓰니(자이로) 이 문제와 무관 — RTK 나빠도 회전은 유효

정리

수조에서 확정: 조향 부호, 회전 관성, 위치유지, 센서 생존, 근접 미션 동작.
(6m면 추가): 전진 관성, 시뮬 보정 대부분.
야외 코스로 미룸: GPS 항법, geofence, 전체 코스, 모터 불균형 정밀.

수조 테스트는 헛수고가 아닙니다. 점수의 핵심인 미션 동작과 시뮬 보정에 필요한 물리 계수를 대부분 여기서 뽑습니다.
