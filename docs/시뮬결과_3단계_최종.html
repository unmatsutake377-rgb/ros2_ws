권고: 기본값을 OFF로

temporal_frames: 1 (필터 끔). 코드는 남겨두되 기본값을 끄세요. 실제 물 위 물보라의 시간적 특성이 제 시뮬과 다를 수 있으니, 필요하면 켤 수 있게 남겨둡니다.

TTC 때와 같은 원칙입니다: 효과가 측정되지 않으면 기본값으로 넣지 않습니다. 다만 TTC는 해로웠으므로 삭제했고, 이건 무해하지만 무익하므로 기본값 OFF입니다.

6. 검증 도구 자체의 결함 — 4건 발견

도구가 틀리면 결론도 틀립니다. 이번에 제 하네스에서 결함 4개를 찾았습니다.
  • 정지 레벨을 문자열 'L3'로 찾고 있었습니다. 새 코드가 레벨을 0/1/2로 바꾸자 시나리오 2·5·9를 오판했습니다 → /failsafe_level 직접 구독으로 수정
  • mock Logger가 throttle_duration_sec을 못 받았습니다. 실제 rclpy는 받습니다 → 수정
  • 패키지 내부 import를 못 살렸습니다. from ship_direction.failsafe import ...가 실패했습니다. 실제 ROS에선 colcon이 해주는 일 → 시뮬 로더에 경로 주입으로 수정
  • 🚨 시나리오 6을 단일 시드로 판단했습니다. 이것 때문에 시간 필터라는 잘못된 처방을 내렸습니다. 20시드로 재보니 효과 0 → 다중 시드가 기본이어야 합니다
