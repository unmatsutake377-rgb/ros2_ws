# docs — 분석·프롬프트·시뮬결과 문서

작년 코드 재활용 프로젝트의 분석 보고서, 단계별 작업 프롬프트, 시뮬 결과 뷰어(HTML)를 모아둔 곳.
원래 `~/Desktop/SSF 노드 파일/` 에 흩어져 있던 것을 저장소로 옮겨 여러 컴퓨터에서 공유한다.

- **작업 지침의 단일 출처는 저장소 루트의 `CLAUDE.md`** 다. 여기 문서들은 그 근거·이력이다.
- `*_프롬프트.md` : 단계별로 Claude Code 에 준 작업 지시.
- `*보고*.md`, `*분석*.md` : 버그·설계 분석.
- `시뮬결과_*.html`, `*채점분석*.html` : 시뮬레이션 결과 뷰어.
- **`소프트파트_전체설명_쉬운버전.md`** : 회로·기구 등 **다른 파트가 읽는** 전체 설명(용어 풀이 포함).
- `boat_launch_checklist.md`, `tank_test_plan.html`, `배뜨면_할일_*.md` : 배 완성 후 벤치/실측 절차.

> ⚠️ 코드 복사본 폴더·zip·바이너리·이미지는 옮기지 않았다(저장소가 지저분해진다).
> 실제 노드 코드는 `src/` 에 있고, 이 문서들은 그것의 '왜'를 설명한다.
