# 케이블 출구 맵 — 장치별 선 나오는 면 → 마스트 구멍 → 방수박스 (2026-09-16)

> 목적: 마스트·갑판에 **선이 실제로 나오는 자리**에 구멍을 내고, 한 다발로 박스 앞면까지 보내기.
> 근거: 각 제조사 문서를 직접 열어 도면을 봤다(아래 출처). 도면에 없는 값은 "실측" 으로 남김. 추측 없음.
> 도면 원본 캡처: `docs/전달용/도면참고/` (D455·A3·ANN-MB·iAHRS·OAK-1 PoE)
> 반영할 곳: `tools/cad/mast.py`(v3), `하드웨어_배치_요구사항.md` §2·§6, 회로 박스 앞면 구멍.

## 0. 결론 먼저 — 설계를 바꿔야 하는 것 2개

| # | 발견 | 지금 설계 | 바꿀 것 |
|---|---|---|---|
| 1 | **D455 USB-C 는 바닥면**(¼-20 과 같은 면, 중심에서 37mm 옆). 선반에 얹으면 커넥터가 선반을 뚫고 내려감 | 선반 + 벨크로 + ¼-20 | **뒷면 M4×2(95mm 간격) 판 마운트**로 변경 — OAK 와 같은 방식. USB-C 가 아래로 자유롭게 나오고, Intel 케이블 고정용 M2×2 로 커넥터 잠금 가능. 선반 삭제 |
| 2 | **iAHRS 커넥터(micro-USB + 4핀)는 X축 화살표 기준 −Y 면**(오른쪽). 포켓이 베이스 우현(+X)에 있으면 케이블이 바깥쪽으로 나감 | 포켓 +X, 터널 −X | 포켓을 **좌현(−X)** 으로 옮기고 터널 방향 `+X`(관 쪽) — 또는 보드를 180° 돌리고 `mount_offset_deg` 로 보정. 전자 권장(소프트 무변경). 포켓에 **커넥터 쪽 +20mm 여유**(micro-USB 플러그 머리 ≈12×7 + 굽힘) |

## 1. 장치별 출구

### OAK-1 PoE (마스트 꼭대기)
- 출처: Luxonis `OAK-1-PoE_Datasheet.pdf`(oak-hardware repo, 2022-01) p1 사진·§1.
- 외형 81.9×81.9×31. 뒷면 M4×4 (가로 45 / 세로 37.5). 바닥 ¼-20.
- **케이블 그랜드는 측면 한 면에서 돌출**(사진: 렌즈 아래쪽 면). 데이터시트에 치수 도면 없음 → **그랜드 중심의 면 내 오프셋·돌출 길이 실측**(도착일). 지금 CAD 가정 35mm 돌출·중앙.
- 마스트: 그랜드가 **아래**를 보게 장착(v2 결정, 220 상한). 케이블은 관 앞면 슬롯(18×14)으로 관 안 → 베이스 Ø22.
- 실측 전 슬롯을 **가로 40mm 로 넓혀** 오프셋 불확실성 흡수.

### RealSense D455 (마스트 아래단)
- 출처: Intel D400 Series Datasheet 337029-017 p149–150 Figure 10-11 (기계 도면).
- 외형 124×26×29. **뒷면(로고 면) M4×2, 간격 95, 삽입 깊이 ≤4mm**, 토크 0.4Nm.
- **바닥면: ¼-20 중앙(삽입 ≤9mm) + USB-C 가 중심에서 37.01mm 옆 + 케이블 잠금 M2×2**. 즉 USB 플러그는 **아래로** 꽂힌다.
- 마스트: **뒷면 M4×2 판**(폭 ≥110, 구멍 95, M4 관통 4.4). 판 아래는 비워 USB-C 플러그(길이 ≈25 + 굽힘 R≥20)가 내려오게. 케이블은 관 앞면 슬롯(v2 의 D455 슬롯 위치 유지) → 관 안.
- USB 3.0 케이블 굽힘 반경 ≥ 20mm(케이블 외경 ×5). 슬롯 하단은 플러그 끝에서 25mm 이상 아래.

### iAHRS RB-SDA-v1 (마스트 베이스 포켓)
- 출처: `IAHRS_manual_rb_sda_ob_v_dn_2.0.1_210607.pdf` p3(사양)·p6(도면)·p5(구성)·p7(설치).
- 케이스 **35×35×10**, 상단 Ø2 관통 ×4 (모서리에서 3mm, 29 간격). 무게 미기재.
- 커넥터: **micro-USB + 4핀 1.25mm(Molex 53048-0450)**, 둘 다 **같은 측면**. 도면 좌표계: X 화살표(앞) 기준 그 면은 **−Y(오른쪽)**.
- 동봉 케이블: 4핀 30cm, micro-USB to USB(길이 미기재 — 실측). 통신: USB(가상 COM) 또는 4핀 UART/RS-232.
- 마스트 포켓: 실측치 35×35×10 → `IMU_L/W/H = 35,35,10` (지금 가정 50×50×20 → 베이스가 190×28 로 커져 있음, **160×20 으로 돌아옴**). 커넥터 면 쪽 **+20mm 포켓 연장**. 뚜껑 나사는 케이스 Ø2 홀과 무관(뚜껑으로 누름) — 또는 케이스 홀 이용 M2 ×4 로 포켓 바닥에 고정(더 확실).
- **권장 통신: 4핀 UART → 박스 안 USB2TTL**(매뉴얼 §3.1). micro-USB 는 진동에 약하고 플러그가 커서 터널 Ø8 을 못 지남. 4핀 케이블은 지름 ≈3mm 로 터널 통과. 드라이버는 시리얼이라 동일(포트만 USB2TTL 로).
- 설치 주의(매뉴얼): 회전중심·무게중심 권장, 진동 심하면 방진패드, 모터·자성체·금속체 가까이 ✗. 베이스 포켓 바닥에 **2mm 고무 패드**.

### RPLIDAR A3 (선수 갑판)
- 출처: `LD310_SLAMTEC_rplidar_datasheet_A3M1_v1.0_en.pdf` p16 Figure 5-1.
- Ø76 × 41. 바닥 **M3×4, PCD R29.5, 90° 등간격, 나사 길이 ≤4mm(내부 손상)**, 위치결정 Ø3 홀.
- **커넥터 XH2.54-5P 가 베이스 측면(평면 컷 부분)에서 수평으로** 나옴 → 케이블은 갑판 위를 수평으로 기다 그로밋으로 내려감. 회전면 높이는 도면상 19.6~31 사이 창(6mm) — **실측**.
- 케이블: 5핀 하네스 → **USB 어댑터 보드**(키트) → micro-USB → 노트북. 하네스는 짧다(≈30cm 급, 실측). 선수(1470)→박스 앞(1160) 31cm + 낙차 → **모자람**. 해결: USB 어댑터 보드를 **선수 갑판 밑 작은 케이스**에 두고 USB 케이블(1m)로 박스까지. 어댑터에 5V 가 필요하면 그 케이스까지 5V 한 가닥.
- 갑판 구멍: LiDAR 바로 뒤 Ø10 그로밋 1개 (5핀 하네스 + 5V).

### GPS 안테나 (ANN-MB 급, 갑판 x=535)
- 출처: u-blox `ANN-MB_DataSheet_UBX-18049862.pdf` p5 Figure 1.
- 82×60×22.5, 173g. **M4 ×2 구멍이 82mm 축 양끝(귀)**, **케이블은 60mm 면에서 옆으로** 나옴(귀 축과 직각). 케이블 RG174 5m SMA(팀 것은 짧음 — 실측).
- 배치: 케이블을 선미 쪽으로 보내려면 **귀(M4)를 좌우 방향으로**, 케이블 면이 선미를 보게. 그로밋 x≈515.
- A배 C94 키트 안테나는 별도 도면 없음 — 실측.

### 마스트 밖 (참고)
- 표시등 3색: 신호 3 + GND → 마스트 기둥 안으로 같이.
- 비상버튼: 박스 뚜껑 위 → 박스 안 직결(관통 없음).
- RC 수신기·LTE: 선미, 별도 그로밋 1개씩.

## 2. 합류 경로

```
[OAK 그랜드↓] ─슬롯(관 앞면, 위)─┐
[D455 USB-C↓] ─슬롯(관 앞면, 아래)─┤ 40×40 각관 속(내경 30)
[표시등 4선] ─────────────────────┘
        ↓ 베이스 Ø22 (플러그 안쪽 구멍 ≥ 20)
[IMU 4핀] ─포켓 터널 Ø8→ 베이스 Ø22 합류
        ↓ 갑판 그로밋 A (마스트 베이스 바로 옆, Ø25)
[LiDAR 5핀+5V] ─ 갑판 그로밋 B (선수, Ø10) ─┐
[GPS SMA] ───── 갑판 그로밋 C (x≈515, Ø8) ──┤
        ↓ 갑판 밑 다발 ──────────────────────┘
[박스 앞면 구멍] ≥ Ø22 (RJ45 헤드 13×16 통과) — 실란트 마감. 위쪽, 드립 루프.
```
- 각관 내경 30×30 에 들어가는 것: Cat5e(Ø6) + USB3(Ø5) + 표시등 4선 + (IMU 는 베이스에서 합류) → 여유 충분.
- 베이스 플러그 안쪽 구멍 = plug − 2·TUBE_WALL ≈ 19 → **RJ45 헤드(13×16)가 못 지날 수 있음** → 카메라 케이블은 **위에서 아래로 넣는다**(헤드가 위) 또는 안쪽 구멍 22 로 확대. CAD 확인 항목.

## 3. mast.py 반영 상태 (v4 에서 완료 — 2026-09-16)
| 항목 | 값 |
|---|---|
| `IMU_L, IMU_W, IMU_H` | ✅ 35, 35, 10 + 케이블 공간 `IMU_CABLE_SPACE=14` |
| IMU 포켓 위치 | ✅ **중심선(X=0) 선미쪽**(팀 피드백 — 좌현보다 중심). 터널 +Y Ø8 @x10 → 중앙 구멍 합류 |
| D455 | ✅ 선반 삭제 → **U자 크레들**(뒷판 M4×2 간격 95 + 바닥턱 + 좌우턱), 바닥턱 USB 노치 ±37 |
| OAK | ✅ 슬롯 40 + **U자 크레들**, 바닥턱 그랜드 노치 35(Ø27+여유) |
| 플러그 안쪽 구멍 | ✅ 22 |
| 갑판 그로밋 | A Ø25(마스트 옆) / B Ø10(선수) / C Ø8(x≈515) → 배치 요구사항 §6 #4 |
