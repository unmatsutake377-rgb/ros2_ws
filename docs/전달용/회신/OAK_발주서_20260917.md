## 발주 직전 체크 (결제 버튼 누르기 전)

- [ ] 리얼리 옵션 — FIXED-FOCUS 맞나 / 32MP 빠졌나 / **US Cord 인젝터 빠졌나**(AC 플러그라 배에서 못 씀)
- [ ] 인젝터 리스팅 상세에 **"IEEE 802.3af/at" 또는 "Active PoE"** 문구가 있나 (passive 면 중단)
- [ ] 인젝터 출력이 **30W** 인가 (10W 짜리 아님 — Class 3 는 PSE 예산 15.4W 요구)
- [ ] 어댑터가 **1000Mbps** 이고 칩셋이 **AX88179** 인가 (100M 이면 프레임 끊김)

## 먼저 해야 할 것

🚨 **리얼리스토어에 재고·발송일 문의.** 아직 안 했다. 카메라가 132만원으로 금액이 제일 크고,
국내 대리점이라 재고만 있으면 제일 빠른데 그걸 모르는 채로 일정을 세우고 있다.

- **인젝터**: 딘레일 클립 유무 / DC 입력이 5.5×2.1 배럴잭인지 적·흑 리드선인지 / 박스(400×300×200) 안 자리
- **카메라**: `docs/절차/oak_arrival_runbook.md` 실행 (고정 IP 169.254.1.222, hfov 실측, 각도·부호 검증, yaml 교체)
- **전원 분기점**: 인젝터 DC 입력은 **접촉기 앞**에서 딴다 (`회로_신규설계.md` §4-2). 비상정지는 추진만 끊는다.
