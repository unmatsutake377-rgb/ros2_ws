## 3. 기억 — 처음에 메모리로 저장해 둘 것 (이전 세션의 기억 3건)

1. **역할**: 이 세션은 위 [역할] 의 배 담당이다. 그 배의 실물 결정은 이 세션이 실측 기준으로 내리고 `docs/기준/<배>_구성.md` 에 확정한다. **공용 코드의 기본값·계약 결정(예: `boat` 필수)은 바꾸지 않는다.** 다른 배 결정은 하지 않는다. 계약서·구현은 Mac 세션 몫, 실물 검증은 Ubuntu 몫.
2. **1번배 스러스터 배선(10-26 최종)**: 좌 = 접촉기 1번(배터리 B)·ESC↔T200 3상 **초↔파 교차**, 우 = 6번(배터리 A)·**색 동일**. 방향 판정은 `tools/hold.py 1600 1600 10` **대칭 명령으로만** — 수동 모드 육안 판정 금지(조종기 중심이 60 µs 만 밀려도 좌우에 반대 명령이 가서 한쪽만 틀려 보인다). 스러스터·ESC·프로펠러를 바꾸면 다시 판정.
3. **조종기 수동 이상 진단 순서**: 상태줄 `S,…` 로 스틱 배정을 판정하지 말 것(10-27 에 "채널선이 옮겨졌다" 오진 두 번). ① 상태줄 mode 필드(WAIT/MANUAL/AUTO) ② 배정·중심은 `RC_DEBUG=1` 빌드 원시 펄스로 **한 축씩 15 초** ③ 조종기 OFF 로 다른 송신기 배제 ④ 끝나면 대회 펌웨어 복원. 1번배 배정: 핀2=CH2 오른쪽 상하(스로틀), 핀3=CH4 왼쪽 좌우(조향), 핀19=CH6 SwD(모드). 중심값이 세션마다 ±100 µs 밀린 원인 1순위는 조종기 AA 전압(4.6 V).

## 4. 일하는 방식 (이전 세션에서 굳은 것)

- 커밋 서명 줄은 그 세션의 안내를 따른다. 커밋 메시지에 **무엇을 왜** 를 적고, 끝나면 `git pull --rebase` 후 push — Mac 세션이 계속 올린다.
- 팀장 명칭은 **Davidson**(문서상). 사람은 they/them 으로.
- 동작이 바뀌는 코드 변경은 **팀 모드**(CLAUDE.md §1-9) — Ubuntu 는 주로 실물 검증과 결과표 채우기.
- 🚨 `pkill -f` 금지(자기 셸까지 잡는다). 프로세스 정리는 PID 로, 찾을 땐 `pgrep -fa "[r]plidar_node"` 처럼 첫 글자를 대괄호로.
- 라이다는 반드시 SIGINT(Ctrl+C)로 끈다. SIGKILL 이면 다음 실행 `SL_RESULT_OPERATION_TIMEOUT`(USB 뽑았다 꽂아야 복구).
- 시험은 별도 `ROS_DOMAIN_ID`(78·79)로 — 배 스택과 섞이지 않게.
- 이 노트북 DDS 기본 설정에서 640×480 가짜 영상은 전달 안 됨 → 160×120 (`tools/repro/fake_cam.py`). 실제 카메라 fps 는 `camera_info` 로 잰다(파이썬 이미지 구독은 느림).
- yaml 숫자는 **소수점**: 실수형 파라미터에 정수(`37`, `[120, 90]`)면 노드가 부팅 즉시 죽고, 섞인 배열(`[120.0, 90]`)은 params 파일 전체 파싱 실패(10-29 실측). params 파일 두 개면 뒤가 이기고 앞 파일 키는 병합.
- `-p 이름:=값` 은 yaml 의 **노드별 절에 밀린다** — 노드 파라미터를 바꿔 시험할 땐 yaml 복사본을 `--params-file` 로.
- 아두이노 포트를 열면 리셋 → ESC 15~25 s 재시동. 98 규칙 설치 후엔 다시 열어도 리셋 안 됨(10-28 실측). 경기 중 포트 직접 열기 금지, 상태는 `/boat_*` 토픽으로.
- 배터리: B(1·2번) 먼저 → A(5·6번). ROS 를 띄운 상태면 **수동**에서 꽂는다(자율이면 시동 순간 출발). 벤치(ROS 없음)는 자율에서.
- 사실과 다른 걸 말했으면 바로 정정하고 문서에도 "오진" 으로 남긴다.
