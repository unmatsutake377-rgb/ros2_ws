## 0. 한 장 요약

| # | 무엇이 | 그대로 두면 | 심각도 |
|---|---|---|---|
| 1 | **신호 GND 가 공통이 아님** | **ESC 가 신호를 못 읽는다 → 모터가 안 돌거나 제멋대로 돈다** | 🚨 즉시 |
| 2 | MD-30A 가 추진 경로에 있음 | 30A 한계 < 필요 50A → **경기 중 추진 끊김** | 🚨 |

## 1. 🚨 신호 GND — **이게 제일 급합니다**

문서 §13-⑤ 에 이렇게 적혀 있습니다:

> *"좌우 전원선을 서로 연결해서는 안 된다"*

**전원선(굵은 +/− 선)은 그 말이 맞습니다.** 분리 유지가 좋습니다.
그런데 **신호 GND 는 반대로 반드시 이어야 합니다.**

### 왜 그런가

아두이노가 ESC 에 보내는 것은 **PWM 펄스** 입니다. 그런데 "전압" 은 **혼자 존재하지 않습니다** —
항상 **어떤 기준점에 대해 몇 V** 입니다. 그 기준점이 GND 입니다.

```
아두이노가 "5V 펄스" 를 보낸다
        ↓
좌측 ESC 는 "자기 GND 기준으로" 그 전압을 읽는다
        ↓
두 GND 가 안 이어져 있으면 → 기준이 다르다 → **읽은 값이 의미가 없다**
```

전압계 한쪽 탐침을 아무 데도 안 대고 전압을 재는 것과 같습니다. 숫자가 안 나옵니다.

### 어떻게 연결하나

```
                    ┌──────────────┐
   배터리A (+) ━━━━━┥ 좌 ESC ×2    ┝━━━ 좌 스러스터 2개
   배터리A (−) ━━━━━┥              │
                    └──────┬───────┘
                           │ 신호선 + 신호GND
                           │
                    ┌──────┴───────┐
                    │   아두이노   │   ← GND 가 여기서 만난다
                    └──────┬───────┘
                           │ 신호선 + 신호GND
                    ┌──────┴───────┐
   배터리B (+) ━━━━━┥ 우 ESC ×2    ┝━━━ 우 스러스터 2개
   배터리B (−) ━━━━━┥              │
                    └──────────────┘

  ━━━  굵은 전원선 : 좌우 **분리 유지**  ✅
  ───  가는 신호선 : GND **공통**        ✅ 반드시
```

**ESC 의 3핀 커넥터(신호/＋/GND) 중 GND 를 아두이노 GND 에 연결**하면 됩니다.
전류가 흐르는 굵은 선을 잇는 게 아니라, **가는 신호선 한 가닥**입니다.

⚠️ 문서 §13-⑤ 의 경고를 **"굵은 전원선에 한정"** 으로 고쳐 적어주십시오.
   지금 문장 그대로면 조립하는 사람이 신호 GND 도 안 잇습니다.

## 2. 🚨 MD-30A 가 추진 경로에 있으면 전류가 못 지나갑니다

### 숫자

| | |
|---|---|
| MD-30A 허용 전류 | **30 A** |
| T200 개당 순간 전류 (14.8V) | 약 **25 A** |
| 계통당 스러스터 | **2개** (문서엔 1개로 적힘 — §5 참고) |
| **계통당 필요 전류** | **약 50 A** |

**필요량이 한계의 1.7배입니다.** 풀스로틀에서 컨버터가 전류 제한에 걸리거나
보호 차단됩니다. 그게 **경기 중에** 일어납니다.

### 애초에 컨버터가 필요 없습니다

**T200 + ESC 는 배터리 14.8V 직결이 정상**입니다.
속도 조절은 **ESC 가** 합니다 — 전압을 낮춰서 조절하는 방식이 아닙니다.
아두이노가 ESC 에 `1100~1900µs` 펄스를 보내면 ESC 가 알아서 출력을 만듭니다.

**컨버터가 실제로 필요한 곳은 아두이노·수신기의 5V** 입니다. 거긴 전류가 작아
MD-30A 로 충분합니다.

### 고치는 법

```
지금 : 배터리 → EC5 → 릴레이 → MD-30A → 스러스터        🚨 컨버터가 병목
바꿈 : 배터리 → EC5 → 릴레이 → ESC → T200               ✅ 직결
                          └→ MD-30A → 아두이노·수신기 5V
```

**MD-30A 를 추진 경로에서 빼서 제어부 5V 로 옮기는 것** — 이게 전부입니다.

## 3. 🚨 무선 비상정지가 없습니다 (규정)

문서는 **버튼식만** 다룹니다. 룰북 §8 은 **버튼식 + 무선식 둘 다 의무**입니다.

이건 성능 문제가 아니라 **출전 자격** 문제입니다.

### 구성

```
FS-i6 여유 채널 → RC 스위치 모듈 → 고전류 릴레이 → 추진 전원 차단
```

🚨 **아두이노를 거치지 않아야 합니다.** 제어기가 죽어도 작동해야 하기 때문입니다.
아두이노는 **릴레이 상태를 감지만** 합니다(핀 38) — 차단은 회로가 직접 합니다.

부품은 `docs/전달용/부품_추천목록.md` §3 참고.

---

## 4. 🚨 비상정지 버튼 하나가 **양쪽을 동시에** 끊어야 합니다

릴레이가 좌·우 계통에 하나씩 있습니다. 문서에 **동시 차단**이 명시돼 있지 않습니다.

**한쪽만 끊기면 살아있는 쪽 추력만 남아 배가 제자리에서 돕니다.**
비상정지가 오히려 위험을 만드는 상황입니다.

→ 버튼 1개(그리고 무선 1채널)가 **좌·우 릴레이를 함께** 열도록 배선해야 합니다.

---

## 5. ⚠️ 스러스터 개수 — 문서와 실제가 다릅니다

| | |
|---|---|
| 문서 §2-⑤ | *"왼쪽 스러스터, 오른쪽 스러스터 **두 개**를 사용하며"* |
| 실제 | 좌 **2개** + 우 **2개** = **4개** (기판 L/R 이 각각 2개씩 제어) |

이 차이 때문에 §2 의 전류 계산이 **두 배** 달라집니다. 문서를 4개 기준으로 고쳐야
전원 용량·배선 굵기·커넥터 정격이 맞습니다.

---

## 6. ⚠️ ESC 가 전원 사슬에 없습니다

T200 은 **브러시리스 모터**라 ESC 없이는 아예 돌지 않습니다.
문서의 `컨버터 → 스러스터` 사이에 ESC 가 들어가야 합니다.

기판에는 이미 자리가 있습니다 — **L / R 커넥터가 ESC 신호선** 입니다.
문서에만 빠져 있으니 그림과 조립 순서에 추가해 주십시오.

## 7. 수정된 전원 사슬

```
배터리 A (14.8V 4S)
   │
  EC5
   │
  릴레이  ←── 비상정지 버튼 ─┐
   │                          ├─ 둘 다 **좌·우 릴레이를 동시에** 연다
   ├─────────────┐    무선 E-Stop ─┘
   │             │
 좌 ESC ×2    (분기)
   │             │
 좌 스러스터 2개  └→ MD-30A → 아두이노·수신기 5V
                              (⚠️ 이쪽으로 이동)

배터리 B — 위와 대칭

  ━━ 굵은 전원선 : 좌우 분리 유지
  ── 신호 GND    : 아두이노에서 좌·우 공통  🚨 §1
```

## 8. 결정이 필요한 것 (회로팀 회신 요청)

| # | 질문 | 왜 필요한가 |
|---|---|---|
| 1 | **신호 GND 공통 배선을 넣을 수 있나** | 안 되면 ESC 제어 자체가 불가 |
| 2 | **MD-30A 를 추진 경로에서 뺄 수 있나** | 못 빼면 풀스로틀에서 차단됨 |
| 3 | 무선 E-Stop 부품을 확보했나 | 규정 항목 |
| 4 | 버튼 1개 → 양 릴레이 동시 차단 배선인가 | 폭주 방지 |
| 5 | **M(핀18) 커넥터의 용도를 유지할 것인가** | ②가 해결되면 **불필요해짐** |

### 🚨 5번 보충 — M 커넥터

현재 기판의 **M 커넥터(아두이노 핀 18)** 가 MD-30A 에 신호를 보내 스러스터 전압을
조절하는 용도로 배선돼 있습니다.

**②가 해결되면(컨버터를 추진 경로에서 빼면) 이 기능은 필요가 없어집니다.**
속도 조절은 ESC 가 하기 때문입니다.

그래서 **소프트팀은 M 제어 기능을 펌웨어에 넣지 않았습니다.** 지금 넣으면
바꿔야 할 구조를 코드로 굳히게 됩니다. ②의 답이 나온 뒤에 정하겠습니다.

## 9. 펌웨어 쪽 현재 상태 (참고)

실물 아두이노로 확인한 배선입니다. **문서 핀표와 다릅니다.**

| 아두이노 핀 | 기판 실제 | 펌웨어 문서 핀표 |
|---|---|---|
| 2, 3 | RC 수신기 | RC (일치) |
| 4, 5 | RC 수신기 | 🚨 **핀 5 는 ESC 출력** — 출력끼리 충돌 |
| 10 | ESC 우(R) | — |
| 13 | ESC 좌(L) | — |
| 18 | M (컨버터) | RC 조향 |
| 6, 7, 8 | 없음 | ESC 출력 |

🚨 **핀 4·5 는 RC 입력으로 쓸 수 없습니다.** 아두이노 Mega 에서 인터럽트로 펄스 폭을
   잴 수 있는 핀은 **2, 3, 18, 19, 20, 21 뿐**입니다. 다른 핀은 코드가 읽을 방법이 없습니다.

→ RC 3채널(스로틀·조향·모드)이 **전부 저 6개 안에** 있어야 합니다.
   ESC 출력은 아무 핀이나 되므로 **펌웨어를 기판에 맞추는 쪽이 작업이 적습니다.**
   핀표 확정은 위 8장의 답이 나온 뒤에 한 번에 하겠습니다.
