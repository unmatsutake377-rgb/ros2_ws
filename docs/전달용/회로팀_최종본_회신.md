## 0. ✅ 먼저 — 해결된 것

| 이전 지적 | 블록도에서 |
|---|---|
| MD-30A 가 추진 경로에 있음 (30A < 필요 50A) | ✅ **빠졌습니다.** `4s Lipo → 전원차단회로 → ESC 14.6V` 직결 |
| ESC 가 전원 사슬에 없음 | ✅ `ESC × 4` 명시 |
| 스러스터를 2개로 적음 | ✅ `T200 × 4` |
| LED 전원 | ✅ `AA×3 → 4.5V` 로 **분리** — 좋은 판단입니다 |

특히 **`모터 제어 PWM × 2` → `ESC × 4`** 가 정확합니다.
펌웨어의 **좌/우 페어 제어**(좌 명령 → 좌측 2개, 우 명령 → 우측 2개)와 정확히 맞습니다.

## 1. 🚨 신호 GND — 남은 것 중 제일 급합니다

배터리가 **2개(좌우 독립)** 이므로 이 항목은 그대로 유효합니다.

문서 §13-⑤:
> *"좌우 전원선을 서로 연결해서는 안 된다"*

**굵은 전원선은 그 말이 맞습니다.** 그런데 **신호 GND 는 반대로 반드시 이어야 합니다.**

### 왜

아두이노가 ESC 에 보내는 건 **PWM 펄스**입니다. 그런데 "전압" 은 혼자 존재하지 않습니다 —
항상 **어떤 기준점에 대해 몇 V** 이고, 그 기준점이 GND 입니다.

```
아두이노가 "5V 펄스" 를 보낸다
   ↓
좌측 ESC 는 "자기 GND 기준으로" 그 전압을 읽는다
   ↓
두 GND 가 안 이어져 있으면 → 기준이 다르다 → 읽은 값이 의미 없다
```

전압계 탐침 한쪽을 아무 데도 안 대고 재는 것과 같습니다.

### 배선

```
   배터리A (+) ━━━━━━┓
                     ┃   ┌──────────┐
   배터리A (−) ━━━━━━┻━━━┥ 좌 ESC ×2 ┝━━━ 좌 스러스터 2개
                         └────┬─────┘
                              │ 신호선 ─── + 신호GND ───┐
                                                        │
                                              ┌─────────┴─────────┐
                                              │   Mega 2560       │ ← GND 가 여기서 만난다
                                              │   + LED 스트립 GND │
                                              └─────────┬─────────┘
                              ┌ 신호선 ─── + 신호GND ───┘
                         ┌────┴─────┐
   배터리B (−) ━━━━━━┳━━━┥ 우 ESC ×2 ┝━━━ 우 스러스터 2개
                     ┃   └──────────┘
   배터리B (+) ━━━━━━┛

   ━━━  굵은 전원선 : 좌우 **분리 유지**   ✅ 문서대로
   ───  가는 신호선 : GND **공통**         🚨 반드시
```

**ESC 3핀 커넥터(신호/＋/GND) 중 GND 를 Mega GND 에 연결**하면 됩니다.
전류가 흐르는 굵은 선이 아니라 **가는 신호선 한 가닥**입니다.

### 🚨 LED 스트립도 같습니다

LED 전원을 `AA×3(4.5V)` 로 분리한 건 좋은 판단인데, **데이터선의 기준점은 여전히 공통**이어야 합니다.

```
AA×3 (+4.5V) ──→ 스트립 +
AA×3 (−)     ──┬─→ 스트립 GND
               └─→ **Mega GND**      🚨 이 연결이 빠지면 색이 틀어지거나 안 켜진다
Mega 핀 40   ──→ 스트립 Din
```

### 문서 수정 요청

§13-⑤ 문구를 **"굵은 전원선에 한정"** 으로 고쳐 주십시오.
지금 문장 그대로면 조립하는 사람이 신호 GND 도 안 잇습니다. 그러면
**ESC 가 안 돌고, 원인 찾기도 어렵습니다.**

## 2. 🚨 무선 비상정지 — 규정 항목

블록도에는 `전원 차단 회로` 하나만 있어 **버튼식인지 무선식인지 구분이 안 됩니다.**
손그림의 `원격` 이라 적힌 모듈이 그것인가요?

룰북 §8 은 **버튼식 + 무선식 둘 다 의무**입니다. 성능이 아니라 **출전 자격** 문제입니다.

```
FS-i6 여유 채널 → RC 스위치 모듈 → 고전류 릴레이 → 추진 전원 차단
```

🚨 **Mega 를 거치지 않아야 합니다.** 제어기가 죽어도 작동해야 하기 때문입니다.
Mega 는 **릴레이 상태를 감지만** 합니다(핀 38).

부품: `docs/전달용/부품_추천목록.md` §3

---

## 3. 🚨 비상정지가 **양쪽을 동시에** 끊어야 합니다

배터리 2개 = 차단 회로도 2개입니다.

**한쪽만 끊기면 살아있는 쪽 추력만 남아 배가 제자리에서 돕니다.**
비상정지가 오히려 위험을 만듭니다.

→ 버튼 1개(그리고 무선 1채널)가 **좌·우 차단 회로를 함께** 열도록 배선해야 합니다.

---

## 4. ⚠️ 블록도가 배터리를 1개로 그렸습니다

```
글 문서 : 배터리 2개, 좌우 독립 (배터리A→좌, 배터리B→우)   ← 이게 맞음(팀 확인)
블록도  : 4s Lipo 배터리 1개, 전원 차단 회로 1개
```

블록도를 **2계통으로** 고쳐 주십시오. 위 §3(동시 차단)이 그림에 드러나야 합니다.

## 5. ⚠️ `Arduino Due` → **Mega 2560**

블록도에 `Arduino Due` 로 적혀 있는데, **2026-07-28 에 Mega 2560 R3 으로 확정**됐고
지금 실물도 Mega 입니다. 그림만 낡았습니다.

(Due 는 3.3V 보드라 RC 신호에 레벨시프트가 필요했는데, Mega 는 5V 라 **직결 가능**합니다.
 이 차이 때문에 회로 부품이 달라지므로 표기를 맞춰야 합니다)

## 6. ⚠️ LED 4.5V 가 빠듯합니다

WS2812 스트립 8픽셀 기준:

| | |
|---|---|
| 풀백색 소비 | 8 × 60mA = **480 mA** |
| AA 알칼라인 3개 | 4.8V(새것) → **3.6V(소진)** |

**전압이 떨어지면 색이 틀어지거나 아예 안 켜집니다.** 480mA면 AA 가 빨리 닳습니다.
**경기 중 규정 표시등이 꺼지면 문제**가 됩니다.

→ **4s Lipo 에서 5V UBEC** 로 따는 편이 안정적입니다.
  (라우터 전원용 UBEC 를 검토 중이니 함께 보시면 좋겠습니다)

|---|---|---|
| 1 | **신호 GND 공통 배선을 넣을 수 있나** (ESC·LED 둘 다) | 안 되면 **ESC 제어 자체가 불가** |

## 8. 펌웨어 쪽 현재 상태 (참고 — 회로팀 조치 불필요)

실물 Mega 로 확인한 배선입니다.

| Mega 핀 | 기판 실제 | 비고 |
|---|---|---|
| 2, 3 | RC 수신기 | ✅ 사용 중 (스로틀 / 모드) |
| 4, 5 | RC 수신기 | 🚨 **읽을 수 없는 핀** — 아래 참고 |
| 10 | ESC 우(R) | |
| 13 | ESC 좌(L) | |
| 18 | M (컨버터 제어) | MD-30A 가 빠졌으므로 **용도 소멸 예정** |

🚨 **Mega 에서 RC 펄스 폭을 잴 수 있는 핀은 `2, 3, 18, 19, 20, 21` 뿐입니다.**
   나머지 핀은 코드가 읽을 방법이 없습니다(인터럽트 미지원).
   → RC 3채널이 저 6개 안에 있어야 합니다. **RC 선 한 가닥을 옮겨야 합니다.**

⚠️ **M 커넥터(핀 18)** — MD-30A 가 추진 경로에서 빠졌으니 이 신호는 더 이상 필요 없습니다.
   비워두면 **RC 조향을 핀 18 로** 받을 수 있어 배선 이동이 한 가닥으로 끝납니다.
   M 을 계속 쓸 계획이 있으면 알려 주십시오.

ESC 출력 핀은 **아무 핀이나 되므로** 펌웨어를 기판(10·13)에 맞추겠습니다.
핀표 확정은 위 §7 답과 M 커넥터 처리가 정해진 뒤 한 번에 하겠습니다.
