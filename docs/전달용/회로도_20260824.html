4. 작업 순서

배터리 두 개를 모두 분리한 뒤 시작합니다.

  1. 코일 회로 직렬화 — A2 → 릴레이 COM, 릴레이 NC → 비상정지, 비상정지 → 컨버터 OUT ⊖ (08-20 완료)
  2. 6번의 배터리 A ⊖ 선을 떼어 ESC(A) ⊖ 로 직결
  3. 5번의 ESC ⊖ 선을 떼어 6번으로 옮기고, 그 반대쪽 끝을 ESC(A) ⊕ 로
  4. 배터리 A ⊕ 선을 5번에 연결
  5. 컨버터·릴레이 IN ⊕ 를 5번보다 배터리 쪽 지점에 납땜
  6. ⊖ 로 쓰는 선을 검정으로 바꾸거나 표시
  7. 접촉기 21/22(b접점) → 아두이노 핀 38 / GND (09-09 완료 — 비상정지 빨간등)
5번을 빼먹으면 접촉기가 영원히 안 붙습니다. 2~4번을 하면 ⊕ 줄이 이제 끊기는 줄이 됩니다. 컨버터가 접촉기 뒤에서 전기를 받으면 — 접촉기가 닫혀야 컨버터가 켜지고, 컨버터가 켜져야 접촉기가 닫히는 순환에 빠집니다.

6. 금지 사항

하면 안 되는 것이유
배터리 A ⊕ 와 배터리 B ⊕ 를 잇는 것전압 차(16.7 / 14.7V)만큼 전류가 쏟아진다. 배터리가 부풀거나 탄다
접촉기로 ⊖ 를 끊는 것아두이노 신호 GND 로 우회로가 남아 완전히 안 끊긴다
전류 방향을 거꾸로 (6→5, 1→2)직류 아크를 소호실 반대쪽으로 밀어낸다. 접점이 탄다
한 단자에 2가닥 물리기접점을 우회한다. 눌러도 안 끊긴다
초록 버튼을 반쯤 누르기접촉저항이 올라가 그 지점이 탄다. 누르려면 끝까지
스러스터가 도는 상태에서 접촉기 여닫기큰 전류를 끊어 아크가 크다. 자율 모드(중립)에서 할 것

8. 아직 안 정해진 것

  • 컨버터 입력 양단 전압 — 교체 여부가 여기서 갈립니다
  • 릴레이 모듈 모드 점퍼 (1-2=M / 2-3=T / OPEN=1) — 자기유지여야 리모컨을 계속 누르지 않아도 됩니다
  • 무선 릴레이가 COM+NC 라, 수신기가 죽으면 접점이 닫힌 채 남아 무선 정지가 조용히 실패합니다. 버튼식이 직렬로 함께 있어 당장 위험하지는 않으나 대회는 2종을 요구합니다
  • FS-i6 페일세이프 — 조종기를 꺼도 수신기가 옛 값을 계속 내보냅니다
  • 비상정지 접점 블록의 세 번째 선 용도
