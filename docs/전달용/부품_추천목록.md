# 부품 추천 목록 — 회로팀 참고용

> 성격: **추천이지 지시가 아님.** 회로팀이 더 나은 선택지를 알면 그쪽으로 가되,
> 각 항목의 "선정 기준"만 만족하면 펌웨어는 무관하게 동작한다.
> 팀 재고 파악 시 이 기준표와 대조하면 "있는 것으로 되는지" 판단 가능.
> ⚠️ 모델명은 대표 예시 — 구매 전 재고/가격/사양 확인 필요.

## 1. ESC (T200용, 4개) — 미확정. 최우선 결정 항목

**선정 기준 (이것만 만족하면 어느 제품이든 OK):**
- **양방향(bidirectional)**: 1500µs=정지, 1100/1900µs=역/정방향 — 우리 펌웨어·노트북 코드 전체가 이 규약 전제
- 4S(14.8V) 지원, 연속 30A 이상
- 브러시리스(BLDC)용 — T200은 브러시리스 모터

| 추천 | 장점 | 유의점 |
|---|---|---|
| **1순위: BlueRobotics Basic ESC** | T200 제조사 순정 조합 — 궁합 검증 끝. 양방향 1100~1900µs 기본, 설정 작업 0. 우리 설계가 이 제품 기준 | 해외 직구라 배송 기간. 국내 재고 확인 |
| 2순위: 수중 스러스터용 범용 양방향 ESC (APISQUEEN 등 30~40A급) | 국내/알리 조달 쉬움, 저렴. 양방향 기본 | 품질 편차 — 4개+예비 동일 로트 권장. 벤치에서 중립점 실측 필수 |
| 3순위: 드론용 BLHeli_32 ESC를 양방향(3D) 모드 설정 | 구하기 제일 쉬움, 고성능 | **설정 도구로 3D 모드 전환 필요** — 작업 실수 여지. 팀에 경험자 있을 때만 |

**공통 유의:** 어떤 ESC든 벤치에서 ① arm 절차(부팅 후 몇 초·비프음) ② 실제 중립점 ③ 데드밴드 폭을 실측해서 알려줄 것 — 펌웨어 노브(arm_hold_ms 등)에 반영함.

## 2. Due 전원 (5V BEC, 1개)

**기준**: 입력 2~4S 지원, 출력 5V 3A 이상, 스위칭 방식

| 추천 | 장점 |
|---|---|
| **Hobbywing UBEC 5V/6V 3A** (또는 동급 시판 UBEC) | RC계 표준품, 노이즈 필터 내장, 저렴, 5V/6V 점퍼 선택 |
| 대안: Matek/Pololu 계열 스텝다운 모듈 | 소형, 기판 직장착 가능 |

⚠️ 리니어 레귤레이터(7805 등)는 비추 — 14.8V→5V 강하 시 발열 큼.

## 3. 비상정지 — 무선측 (RC 스위치 + 릴레이)

**기준**: 수신기 PWM 채널로 개폐 가능, 접점 정격 DC 60A 이상 (T200 4개 순간전류 감당)

| 추천 | 장점 |
|---|---|
| **RC 릴레이 스위치 모듈** (Turnigy/범용 "RC switch relay" 류) + **자동차용 고전류 릴레이(80~100A)** 조합 | 부품 흔함, 원리 단순(수신기 신호→소형모듈→대형릴레이), 고장 시 원인 추적 쉬움 |
| 대안: 로봇용 무선 킬스위치 완제품 | 배선 최소 | 가격↑, 대회장 주파수 혼선 이력 확인 필요 |

⚠️ DC는 AC보다 아크(불꽃)로 접점 손상 잘 됨 — 릴레이 정격이 "DC" 기준인지 확인.

## 4. 비상정지 — 버튼측

**기준**: DC 100A급 통전, 갑판에서 즉시 조작

| 추천 | 장점 |
|---|---|
| **XT90-S 루프키** (안티스파크 XT90 플러그를 "뽑는 열쇠"로) | 로봇 대회 표준 수법. 저렴·확실·스파크 방지 내장. "뽑으면 무조건 끊김" — 오동작 원리상 불가 |
| 대안: 선박/캠핑용 배터리 차단 스위치 (100A+) | 회전식이라 조작 명확, 방수형 존재 | 부피·가격↑ |

## 5. 표시등 (룰: 초록/노랑/빨강 + 점검 1 + 선택 방향지시 2)

**기준**: 주광(한낮 야외)에서 육안 식별, 색이 규정과 일치

| 추천 | 장점 |
|---|---|
| **1~3W급 고휘도 LED 모듈** (12V용) + **로직레벨 MOSFET**(IRLZ44N 등)로 구동 | 한낮 시인성 확보. MOSFET 구동이라 Due 핀 부담 0. 12V용 모듈이면 14.8V에서 저항 하나로 감당 |
| 대안: 항해등/경광등 스타일 LED 램프 | 시인성 최고, 방수 기본 | 소비전류·가격 확인 |
| 점검 LED: 일반 5mm LED + 330Ω | 저전류라 Due 직결 가능. 컨트롤 박스 투명창 안쪽이면 충분 |

## 6. 소품 (인터페이스 보드용)

| 품목 | 기준/추천 |
|---|---|
| 레벨시프트 저항 | 1/4W 일반 저항. 채널당 10kΩ+20kΩ (5V→3.33V) ×3채널 |
| 배 ID 스위치 | 2P 이상 DIP 스위치 아무거나. 슬라이드식보다 DIP(실수로 안 건드림) |
| 만능기판 | Due 실드형이면 최고, 없으면 일반 만능기판+듀폰 하우징 |
| MOSFET | 로직레벨 필수 (게이트 3.3V에서 완전 도통 — IRLZ44N, AO3400 등). 일반 IRF540은 3.3V로 안 켜짐 ⚠️ |

## 7. 배선 굵기 (참고 기준)

| 구간 | 권장 |
|---|---|
| 배터리 → 비상스위치 → 릴레이 → ESC 분기점 | **8~10AWG 실리콘선** (순간 100A 감당) |
| 분기점 → 각 ESC | 12~14AWG |
| 신호선 (PWM/LED/ID) | 22~26AWG. 신호선은 굵기보다 **고정(스트레인 릴리프)** 이 중요 |

## 8. 방수 컨트롤 박스 — 배선/커넥터 의견 (회로팀 반영용)

계획이 있다니 관점만 남김. 결정은 회로팀 몫:

1. **관통부가 방수의 전부다.** 박스 자체보다 선이 뚫고 들어가는 구멍이 뚫리는 지점. **케이블 글랜드(PG7/PG9)** 로 선 다발마다 조이는 방식 추천 — 저렴하고 확실. 구멍 수를 줄이려면 여러 신호를 한 다발로 묶어 글랜드 하나로
2. **자주 분리하는 선만 커넥터, 나머지는 직결.** 커넥터는 전부 잠재적 침수·접촉불량 지점. 분리가 필요한 것 = 모터선(ESC↔T200, 배 정비 시)과 배터리뿐. 방수 커넥터 쓸 거면 SP13/SP16 계열(IP68 항공잭식) 추천
3. **ESC 발열 주의.** 밀폐 박스 안 ESC 4개 = 오븐. 대책 중 택1: ESC를 박스 밖(물 튀김만 막는 위치)에 + 히트싱크 / 박스 안이면 알루미늄 판에 밀착 고정해 박스 벽으로 방열
4. **박스 안 배선 원칙**: 납땜+수축튜브 > 커넥터 (진동 대비). 선은 다발로 묶고 고정점 만들기 — "덜렁거리는 선"이 몇 주 뒤 단선의 원인
5. **XT90 루프키는 박스 밖** — 비상시 박스 열 시간 없음
6. 보너스: 실리카겔 몇 봉 + 뚜껑 개스킷 상태 확인을 출항 전 체크리스트에

## 9-2. LTE 라우터 (2026-08-10 추가 — 무선 링크용, 현황판 안건 ⑦)

**후보 확정 (구매 조사 완료 + 08-10 0트랙 추가):**

| 트랙 | 기종 | 전원 | 안테나 | 용도 |
|---|---|---|---|---|
| **0 (즉시 검증 — 채택)** | **폰을 배에 탑재** (공기계+데이터쉐어링 SIM 권장) | 자체 배터리 | 내장 | **비용 0으로 개념 검증**: 셀 커버리지·NTRIP·Tailscale SSH·수조까지. "핫스팟 안 됨" 결론은 폰이 물가에 있다는 전제였음 — 배에 실으면 폰=LTE 라우터 |
| A (보류) | Netgear Nighthawk M1 | USB-C 5V (배터리 제거 상시전원 — ⚠️벤치 검증 필수) | TS-9 ×2 (SMA 젠더 필요) | 0트랙에서 열/안정성 문제 관찰 시 |
| B (본격) | Teltonika RUTX11 | DC 9~50V → **4S 직결** | SMA 기본 | 0/A 검증 통과 후 판단 |

**0트랙 필수 검증**: ① 폭염 밀폐 박스 1시간+ 연속 핫스팟 (열 셧다운·배터리 안전 — 충전+핫스팟 동시 금지) ② 핫스팟 자동꺼짐/시간제한 설정 무력화 ③ 5GHz 핫스팟 지원 확인 (RC 2.4GHz 보호) ④ RC 수신기와 이격 배치는 동일 적용

**급전 원칙:**
- 🚨 **라우터 전원은 Mega용 BEC와 분리** (전용 UBEC 5V 3A) — LTE 송신 전류 스파이크가 제어기 전원을 흔들면 안 됨
- 🚨 **분기 위치 = 비상정지 릴레이 앞단** (퓨즈 경유) — 비상정지는 추진만 차단, 통신은 생존해야 회수·진단 가능
- 부하 분산: Mega BEC=배터리 B / 라우터=배터리 A 권장

**안테나 배치:**
- RC 수신기 안테나와 **최소 50cm~1m 이격** (선수/선미 반대편 배치)
- 본체 박스 안 + SMA 벌크헤드로 벽 관통 + 외부 안테나. 연장 케이블 RG316급 ≤1m (길수록 손실)
- 라우터 설정: **2.4GHz WiFi OFF, 5GHz만** (RC 대역 보호 — 출항 전 체크 항목)

**A트랙 추가 구매 목록:** UBEC 5V 3A ×1 / 인라인 퓨즈 3A ×1 / USB-A 암 어댑터 ×1 / A-to-C 케이블 ×1 / TS-9→SMA 젠더 ×2 / SMA 벌크헤드 연장(RG316 ≤1m) ×2 / (보류) LTE 외장 안테나 ×2

**발열:** ESC와 다른 구획 필수. M1=직사광 차단+측면 장착, RUTX11=알루미늄 판 밀착→박스 외벽 전도.

## 9. 회로팀 재고 대조 방법

기존 보유 부품이 파악되면: 위 각 항목의 **"선정 기준"과 대조** → 만족하면 그대로 사용 (추천 모델일 필요 없음) → 불만족/애매하면 모델명을 소프트팀에 전달 (사양 확인해줌).
