## 8. 방수 컨트롤 박스 — 배선/커넥터 의견 (회로팀 반영용)

계획이 있다니 관점만 남김. 결정은 회로팀 몫:

1. **관통부가 방수의 전부다.** 박스 자체보다 선이 뚫고 들어가는 구멍이 뚫리는 지점. **케이블 글랜드(PG7/PG9)** 로 선 다발마다 조이는 방식 추천 — 저렴하고 확실. 구멍 수를 줄이려면 여러 신호를 한 다발로 묶어 글랜드 하나로
2. **자주 분리하는 선만 커넥터, 나머지는 직결.** 커넥터는 전부 잠재적 침수·접촉불량 지점. 분리가 필요한 것 = 모터선(ESC↔T200, 배 정비 시)과 배터리뿐.
   🚨 **정정(2026-09-17): 종전의 "SP13/SP16 추천" 은 정격을 우리 부하와 대조하지 않은 것이다.**
   **SP13 은 3~13A**(핀 수 많을수록 낮아짐), SP17 은 5~10A 인데 **T200 은 개당 약 21A** 다. 쓰면 접점이 탄다.
   20A 를 넘기려면 **SP21(15~30A)** 이라야 하고 그것도 빠듯하다. 배터리(계통당 42A)는 SP 시리즈로 감당 안 되니 **EC5** 를 쓴다.
   → 현재 결론: **모터선은 납땜+수축튜브 직결 유지**(이미 그렇게 돌고 있다). 정비 편의가 필요해지면 그때 SP21 국내 재고를 찾는다.
3. **ESC 발열 주의.** 밀폐 박스 안 ESC 4개 = 오븐. 대책 중 택1: ESC를 박스 밖(물 튀김만 막는 위치)에 + 히트싱크 / 박스 안이면 알루미늄 판에 밀착 고정해 박스 벽으로 방열
4. **박스 안 배선 원칙**: 납땜+수축튜브 > 커넥터 (진동 대비). 선은 다발로 묶고 고정점 만들기 — "덜렁거리는 선"이 몇 주 뒤 단선의 원인
5. **XT90 루프키는 박스 밖** — 비상시 박스 열 시간 없음
6. 보너스: 실리카겔 몇 봉 + 뚜껑 개스킷 상태 확인을 출항 전 체크리스트에

**급전 원칙:**
- 🚨 **라우터 전원은 Mega용 BEC와 분리** (전용 UBEC 5V 3A) — LTE 송신 전류 스파이크가 제어기 전원을 흔들면 안 됨
- 🚨 **분기 위치 = 비상정지 릴레이 앞단** (퓨즈 경유) — 비상정지는 추진만 차단, 통신은 생존해야 회수·진단 가능

- RC 수신기 안테나와 **최소 50cm~1m 이격** (선수/선미 반대편 배치)

- 라우터 설정: **2.4GHz WiFi OFF, 5GHz만** (RC 대역 보호 — 출항 전 체크 항목)

**A트랙 추가 구매 목록:** UBEC 5V 3A ×1 / 인라인 퓨즈 3A ×1 / USB-A 암 어댑터 ×1 / A-to-C 케이블 ×1 / TS-9→SMA 젠더 ×2 / SMA 벌크헤드 연장(RG316 ≤1m) ×2 / (보류) LTE 외장 안테나 ×2

**발열:** ESC와 다른 구획 필수. M1=직사광 차단+측면 장착, RUTX11=알루미늄 판 밀착→박스 외벽 전도.

    Luxonis 공식 PoE 배포 가이드가 같은 브랜드(Revotech) PoE 익스텐더로 OAK 검증. 판매상태 "판매중", 우체국택배 국내배송, 리뷰 0(신규 리스팅).
    ⚠️ 미확인: 딘레일 클립 동봉 여부(사진은 벽면 플랜지) → 없으면 플랜지 나사 고정. DC 입력은 5.5×2.1 배럴 + 동봉 적/흑 리드선(사진).
  · [11번가 오션글로벌4 "12V DC~48V/50V 802.3af/at PoE 변환기 1000mbps 30W" — 옵션 **GAT-50V30W 57,730₩**](https://www.11st.co.kr/products/9621443724) — 같은 페이지 **GPOE-48V10W(38,130₩) 는 사지 말 것**(아래 10W 이유)
  🚨 **구매 전 리스팅 상세에 "IEEE 802.3af/at" 또는 "Active PoE" 문구 확인 필수** — "passive" / "24V passive" 면 X.
  🚨 **출력 10W 짜리 저가형(예: 11번가 진화상사B "10-30V DC 입력 10W" 38,220₩) 은 제외** — OAK 는 **Class 3 PD**(PSE 예산 15.4W 요구). 10W PSE 는 Class 3 를 거부하거나 부하에서 꺼질 수 있다. **≥15.4W(권장 30W)** 만.
  (알리 동일품 [Gigabit Industrial 30W PoE+ 12-48V](https://www.aliexpress.us/item/3256808364614676.html) 도 있으나 해외배송이라 제외)
  ⚠️ A/S·문서는 하이링크가 낫다. 가격차 ≈11~12만원. 신뢰성·재고 확실 우선이면 1순위(TRXmall 자사 재고), 비용 우선이면 2순위(active 확인 후)
- 해외 대안(참고): Tycon TP-DCDC-1248GD-M(9~36V in, 802.3af, 17W) — 국내 배송 불가면 X
- 대체 기준: 입력 **≥12~24V**(4S 커버) · 출력 **802.3af/at active** · **기가비트** · ≥15.4W
- 전력: 카메라 **최대 7.5W**(전형 4~5W) + 변환손실 → 4S 기준 **≈0.6A 피크**. 인젝터 입력에 **2A 퓨즈**

**케이블·어댑터**
- 카메라↔인젝터: **동봉 2m Cat5e(RJ45↔RJ45)** 로 충분 (데이터시트: 카메라쪽 표준 RJ45)
- 인젝터↔노트북: **USB-C 기가비트 이더넷 어댑터**(노트북에 이더넷 없음). 1000Mbps 표기 확인 — 100M 이면 프레임 끊김.
  노트북 USB-C(TB4) 포트 비어 있어 바로 사용 가능. **칩셋 ASIX AX88179(A) 권장 — Ubuntu 커널 기본 드라이버**(드라이버 설치 0).
  후보: TP-Link UE330C(허브+기가랜) 또는 다나와 "AX88179" 검색. 퓨즈: 다나와 "휴즈홀더" 인라인 블레이드 2A

**연결 사슬 (배)**
```
4S 14.8V(+) ─ 2A 퓨즈 ─▶ 인젝터 DC IN(+)     4S(−) ─▶ 인젝터 DC IN(−)
인젝터 PoE OUT(Data+Power) ─ 동봉 2m Cat5e(RJ45) ─▶ OAK-1 PoE
인젝터 LAN/Data IN ─ Cat5e/6 ─▶ 노트북 이더넷 (없으면 USB-C **기가비트** 어댑터)
```
**벤치(실내)도 같은 DC 인젝터**로 — 벤치 파워서플라이(12~24V) 또는 배터리에 물리면 됨. AC 인젝터 따로 살 이유 없음.

## 9-4. USB 허브 + 카메라 케이블 (2026-09-14 추가 — 노트북 포트 부족·2단 허브 제거)

**왜:** 배 노트북(IdeaPad Slim 3 15IAH8)은 **외부 USB 포트 2개**(09-17 확인), 이더넷 없음. 실기(08-06)에서
허브 2단 겹침 + 직결 포트 부족이 확인됐다(`소프트_작업체크리스트.md`). 노트북은 **자체 배터리로 운용**(충전 미연결)하므로
주변기기 전력을 노트북에서 뽑지 않도록 **유전원 허브**가 필요하다.
⚠️ 실기 기록상 "전원 부족" 은 증명되지 않았다 — 허브는 끊김 치료제가 아니라 **포트 정리**용이다.

**선정 기준:** USB 3.0(5Gbps) · 외부 전원 입력 · 데이터 포트 5개 이상 · 배 배터리에서 급전 가능

| 순위 | 기종 | 가격(다나와 최저, 09-14) | 비고 |
|---|---|---|---|
| **채택** | **ipTIME UH308** (데이터 7 + 충전전용 1, USB 3.0) | 27,900원 | 어댑터 5V(5.5×2.1mm 잭) 동봉 — **배에선 안 씀** |
| 대안 | ipTIME UH305 (데이터 4 + 충전 1) | 22,900원 | 예비 포트 0 → 비추천 |
| 상위 | StarTech ST7300USBME (산업용 7포트, DC 7~48V 단자대, ESD ±15kV) | 약 20만원 | 예산 있으면. 4S 직결 가능 |

**같이 살 것:** DC-DC 강압 5V **5A급**(XL4015 등, 3~5천원 — LM2596 3A 는 부족) / DC 플러그 5.5×2.1mm 케이블 /
인라인 퓨즈 3A(모듈 **입력**측) / **D455용 USB 3.0 C↔A 케이블 1m 이하**(실기 0fps 원인이 2.0 케이블이었음 — 허브보다 먼저)

**포트 배치:**
🚨 **정정(2026-09-17): 노트북 외부 포트는 2개뿐이다.** 종전 표는 USB-C 를 3번째 포트로 썼는데
실측(Bus3 Port1 / Port9)과 팀 확인 결과 **2개**다. 어댑터를 꽂을 자리가 없어 배정을 다시 짰다.

```
포트 1 ─ Arduino Mega 직결            ← 제어 경로. 허브 뒤에 두지 않는다
포트 2 ─ UH308 유전원 허브 ─┬─ AX88179 이더넷 어댑터 ─ PoE 인젝터 ─ OAK-1 PoE
                            ├─ D455
                            ├─ LiDAR A3 (전원 포함)
                            ├─ IMU
                            ├─ GPS
                            └─ (예비 3)
```

**왜 이렇게 되나** — 꽂을 것이 셋(아두이노·허브·어댑터)인데 포트가 둘이다. 어댑터를 허브에 올린다.
- **대역폭 여유 있다.** D455 컬러 720p30 = 442Mbps, OAK 를 기가비트 상한 1000Mbps 로 최악 가정해도
  합계 1455Mbps = USB 3.0 허브 5Gbps 의 **29%**. 실제 OAK 스트림은 더 낮다.
- **전원 문제 없다.** UH308 이 유전원이라 어댑터 전력을 배터리에서 뽑는다.
- **아두이노만은 직결 유지.** 유전원 허브면 수신기 4.09V 문제는 사라지지만(§전기계통 제약 §1),
  **수동 조종 경로**라 부품을 하나라도 덜 끼운다. 카메라가 죽으면 점수를 잃고 **조종이 죽으면 배를 잃는다.**

⚠️ **확인 시험**: 어댑터까지 허브에 올린 상태로 **카메라 + LiDAR 동시 3분 구동**(과제 목록 C4 계열).
D455 fps 와 OAK 프레임이 동시에 안 떨어지면 확정. 떨어지면 허브에 아두이노를 올리고 어댑터를 포트 2 로 옮긴다.

**주의사항 (회로팀):**
1. 극성 — 플러그 **중심 +, 바깥 −**. 꽂기 전 멀티미터로 확인. 반대면 허브 사망
2. 강압 모듈 출력을 **먼저 5.0~5.1V 로 맞춘 뒤** 허브에 연결 (가변 모듈 출고값 제각각)
3. 퓨즈는 모듈 **입력(배터리)** 측. 출력측이면 5A 부하에 끊김
4. 허브 전원은 항상 ON. 개별 포트 스위치 4개 ON 확인 → 출항 체크리스트
5. 충전 전용 포트에 장치 금지(데이터 안 감) — 테이프로 막을 것
6. 허브 아래 허브 금지(한 단만). Mega 는 직결
7. DC 잭·USB 커넥터 진동 대비 글루건/케이블타이. 플라스틱이라 방수 박스 안, 벨크로+타이 고정
8. ESD 보호 없음 → 모터 배선·ESC 와 이격이 유일한 방어
9. 노트북 배터리와 배 배터리는 **섞지 않는다**. 배 배터리→노트북 충전(PD 승압) 안 함 — 독립 원칙

**소프트 확인 (허브 도착 후):** udev(`/dev/ttyLiDAR`,`/dev/IMU`) 시리얼번호 기반인지 · `boat_boot.sh --check` 를
**어댑터 뽑은 상태에서** 돌려 거버너 performance 유지 확인(안 되면 `powerprofilesctl set performance` 추가) ·
카메라+LiDAR 동시 3분 구동 재시험 · 통신 거리 시험 때 노트북 배터리 % 기록(소모율 실측, 47Wh 급 → 2~3h 추정)

**OAK 연결은 §9-3** (OAK-1 PoE 확정, 802.3af active DC 인젝터 PSE5502G, 2A 퓨즈). 카메라 2대 동시 장착(OAK=비전, D455=조종 화면)은 `수동조종_카메라영상_설계.md` §2 — §0 구매표에 반영됨.
