### 🚨 32번 컨버터 사양 — 이게 없으면 대회 당일 아침이 위험하다

접촉기 코일이 **DC 24V**(08-18 라벨)인데 배터리는 14.8V다. **강압이 아니라 승압**이다.

| 항목 | 요구 | 근거 |
|---|---|---|
| 방향 | **승압 (boost)** 14.8V → 24V | 코일 24V, 배터리 4S |
| 입력 범위 | **16.8V 를 덮을 것** (예: 9~20V) | 4S 만충이 16.8V. **현 컨버터 11~16V 는 범위 밖** |
| 출력 전압 | **DC 24V** | MD-30a 코일 정격 (A1·A2 인쇄) |
| 출력 전류 | **2A 이상** | 코일 실측 48Ω → 정상 0.50A·12W. 접촉기 흡인은 정상의 3~10배라 순간 1.5~5A |
| 방수 | IP 등급 있으면 좋음 (필수 아님) | 박스 안이라 |

🚨 **도착하면 상세페이지가 아니라 실물 라벨에서 입력 전압을 재확인할 것.** 페이지와 실물이 다른 경우가 있다.

⚠️ **재구매 완료 전까지 지켜야 하는 것 (기한 없음 — 종전 "도착 전까지" 가 아니다):**
**배터리를 16V 넘게 충전하지 말 것.** 현 컨버터 상한이 16V라 만충 16.8V 를 꽂으면
과전압 보호로 출력이 죽고 **접촉기가 안 붙는다.** 한 달을 헤맨 그 증상이 그대로 재발한다.
충전은 셀당 4.0V(스토리지) 근처에서 멈춘다. 교체 절차와 교체 후 시험은 작업기록 §16.

✅ **루프키 — 대회 요구용으로는 불필요해졌다 (2026-09-17 확인).**
비상정지 2종이 **접촉기 코일 차단**으로 이미 동작 확인됐다(무선·유선 각각 단독, 08-25). 검사 9·10번 충족.
코일 하나가 두 극을 동시에 여니 "버튼 하나로 양쪽 동시 차단" 요구도 만족한다 — 열쇠 두 개를 따로 뽑는 문제가 애초에 없다.
위 3번 XT90-S 항목은 `회로재설계_부품점검표.md` 의 **뒤집힌 판정**(MD-30a 부족)에서 나온 것이다.

⚠️ **다만 배터리 분리 수단으로서의 가치는 남는다.** 접촉기는 전자석이라 코일에 전기가 돌아오면 다시 붙는다.
비상정지 후 사람이 배에 접근할 때 **물리적으로 끊어두는 물건**이 있으면 안전하다. 그 용도로 살지는 팀 판단.
