# 마스트 요구사항 — 확정 하드웨어 기준 (2026-09-15)

> ⚠️ 마스트 도면·사진을 아직 못 받았다. 이 문서는 **우리가 확정한 센서·부품이 마스트에 요구하는 조건**이다.
> 도면이 오면 이 표에 대조해서 피드백한다. 추측으로 치수 안 채웠다.

## 0. 마스트에 올라가는 것 / 올라가면 안 되는 것

| 부품 | 마스트 | 이유 |
|---|---|---|
| RPLIDAR A3 | ✅ **최상단 또는 360° 시야 확보되는 단** | 회전 스캐너. 마스트 기둥·GPS 안테나·카메라가 같은 높이에 있으면 그 방위가 **영구 사각**이 된다 |

## 1. 하중·진동
- 마스트 탑재 총 질량(대략): A3 ≈190g + OAK-1 PoE(IP67 알루미늄 81.9×81.9×31) + 안테나류 + 케이블. **1kg 이내로 잡아야** 1.6m 선체 롤 안정성·복원성에 영향 적음. 실측해서 여기에 적을 것: ______ g
- 스러스터 4×T200 진동이 마스트 끝에서 증폭된다 → **LiDAR 데이터 rate tick·IMU 노이즈** 실측 항목(수조 테스트 계획). 마스트 재질은 **알루미늄 프로파일(20×20 / 30×30) 또는 카본 파이프** 권장, PVC 는 휨.
- 마스트 하단은 **3점 이상 고정 + 스테이(지지 와이어) 1~2개**. 한 점 볼트는 진동에 풀린다.

## 2. 높이
- 정답 없음. 기준 2개:
  - **낮게**: 롤 안정, 케이블 짧음, 운반 쉬움
  - **높게**: LiDAR 가 파도·선체 자체(선수 튀는 물)를 안 찍음, 카메라가 부이를 위에서 봐서 수면 반사 줄어듦
- 실무 권장: **LiDAR 스캔면이 선체 최고점보다 10cm+ 위**, 카메라 렌즈는 수면에서 40~60cm. 도면에 이 두 치수를 적어 달라.
- OAK 최소 초점거리 50cm → 카메라 바로 앞 선체 구조물은 어차피 흐림. 무관.

## 3. 카메라 마운트 (OAK-1 PoE)
- 장착: 바닥 **¼-20 삼각대 나사** 또는 뒷면 **M4×4**(가로 4.5cm / 세로 2×3.75cm). 마스트엔 **뒷면 M4×4 가 낫다** — 삼각대 나사 1점은 진동에 돈다(각도가 돌면 `/red_angle` 부호·오프셋 전부 무효).
- 피치 각도 **조절 가능 + 고정 후 마킹**. 런북 §5 화각 실측은 각도 고정 뒤에 한다. 바뀌면 재실측.
- 동작 온도 **0~50°C**. 검정/알루미늄 통이 직사광 아래 여름 수면 위 → 50°C 넘을 수 있음. **그늘판(차양) 또는 흰색 마감** 고려. 온도는 depthai 가 준다 → 블랙박스에 기록.
- 케이블: 카메라 RJ45 → 동봉 2m Cat5e. 마스트 따라 내려와 방수박스 그랜드로 들어감. **커넥터에 하중 걸리지 않게 스트레인 릴리프** (케이블 타이 2곳). RJ45 는 방수 아님 — 카메라쪽 커넥터부 자체는 IP67 이지만 **케이블 중간 연장 커넥터 만들지 말 것**.

## 4. LiDAR (A3)
- 360° 중 **후방 일부 사각은 허용** (우린 전방 ±80° 위주). 단 사각이 생기는 방위를 **도면에 적어서** `ship_direction` 필터 범위와 맞춘다.
- 마스트 기둥이 LiDAR 뒤에 있으면 그 방위 고정 근접점 → 회피 알고리즘이 "뒤에 벽" 으로 오해할 수 있음. **기둥은 LiDAR 스캔면보다 아래**에서 끝나게.
- 수평 유지. 기울면 한쪽은 수면 찍고(가짜 장애물) 반대쪽은 하늘.

## 5. GPS 안테나
- **그라운드플레인(금속판 ≥10cm)** 위, 최상단. RTK 는 멀티패스에 민감 — 카메라·LiDAR 금속 몸체가 안테나와 같은 높이·바로 옆이면 FIXED 가 FLOAT 로 떨어진다.
- 안테나 위치 = 배의 "위치". 마스트가 CG 에서 떨어져 있으면 **LOS 유도 오프셋**이 생긴다 → 안테나-CG 거리 실측해서 기록: 전후 ____ cm / 좌우 ____ cm. (1.6m 배에서 20cm 안팎이면 무시 가능, 그 이상이면 파라미터 보정 검토)

## 6. 배선 (마스트 → 방수박스)
| 선 | 수량 | 비고 |
|---|---|---|
| Cat5e (OAK) | 1 | 인젝터는 박스 안 |
| LiDAR USB + 전원 | 1~2 | A3 는 USB(5V) — 길이 ≤2m |
| GPS 안테나 동축 | 1 | SMA/TNC, 최단 |
| LTE 안테나 동축 | 2 | RG316 ≤1m |
| 표시등 신호+GND | 3~4 | 22~26AWG |
- **전부 하나의 그랜드(또는 2개)로 박스 관통**. 마스트 뿌리에서 케이블을 한 번 묶고, 박스 입구에서 한 번 더.
- 동축 케이블은 **급격히 꺾지 말 것**(RG316 최소 굽힘반경 ≈ 10mm).

## 7. 도면 받으면 확인할 것 (체크리스트)
- [ ] 각 부품 높이(수면 기준) 치수
- [ ] LiDAR 스캔면 위에 아무것도 없나 (안테나·카메라·기둥)
- [ ] GPS 안테나 그라운드플레인 / 옆에 금속 몸체 없나
- [ ] 카메라 M4×4 브라켓 + 피치 조절
- [ ] 마스트 고정 3점+ / 스테이
- [ ] 총 질량 / CG 이동량
- [ ] 안테나-CG 오프셋
- [ ] 케이블 경로 · 스트레인 릴리프 · 그랜드 수
- [ ] RC 수신기 안테나가 LTE 와 반대편인가
- [ ] IMU 가 마스트에 **없는가**
- [ ] 탈부착(운반) 방식 — 대회장 이동 시 마스트 접히거나 분리되나. 분리식이면 **재조립 후 카메라 각도 재현성**(핀·마킹)
