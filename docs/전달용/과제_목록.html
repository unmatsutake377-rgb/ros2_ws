저장소의 미결 항목을 파트 상관없이 한 표로 모은 것. 각 파트 문서가 계속 주인이고, 여기는 “무엇이 남았고 무엇이 무엇을 막는가”만 본다.

09-15 통합 · 09-22 갱신 대회 10월 ⚡ = 09-15 이후 바뀐 것 🚨 = 뒤를 막는 것

09-15 판은 전기·펌웨어 쪽이 낡아 있었다. 이미 끝난 7항목이 미착수로 남아 있었고, 해야 할 5항목이 아예 빠져 있었다.

그대로 뒀으면 끝난 일을 다시 계획하고, 빠진 일은 아무도 안 했다. 이 판에서 정정했다 — ⚡ 표시.
