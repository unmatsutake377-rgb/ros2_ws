2. 주 전력

왜 (+) 만 끊는가
배터리를 격리하는 데는 두 가닥 중 한 가닥만 끊으면 됩니다. (+) 가 끊기면 전류가 흐를 길이 없습니다. 그래서 2극이면 배터리 2개에 딱 맞습니다 — 접촉기를 하나 더 살 필요가 없습니다.

3. 차단(비상정지) 회로

버튼이 100A 를 직접 안 끊습니다.
한영넉스 접점 블록은 제어회로용이라 큰 전류를 못 끊지만, 원래 이 자리에 쓰는 물건입니다. 전자석(코일)에 가는 가는 선만 끊으면 큰 접점이 알아서 떨어집니다.
🚨 아두이노는 차단 회로에 넣지 않습니다. 룰북 §8: 제어기가 죽어도 비상정지는 작동해야 합니다. 아두이노는 상태를 읽기만 합니다.

4. 신호 · 표시등 · 공통 GND

🚨 신호 GND 를 안 이으면 ESC 가 안 돕니다.
BESC30-R3 의 신호 커넥터는 GND · 빈칸 · 신호 3핀이고 가운데가 비어 있습니다. ESC 는 5V 를 주지도 받지도 않으므로, 신호 GND 를 Mega GND 에 잇는 것이 필수입니다. PWM 은 "어떤 기준점 대비 몇 V" 인데, 기준점이 다르면 ESC 가 읽은 값에 의미가 없습니다.
LED 를 AA 에서 Mega 5V 로 옮깁니다 — 새 부품 없이 문제가 풀립니다.

지금은 스트립 전원이 AA 3개(4.5V→3.6V)인데 Mega 가 Din 을 5V 로 때립니다. WS2812 계열은 Din 이 전원전압보다 높으면 안 됩니다(최대 VDD+0.5V) — 규격 위반이고 소자가 상합니다.

Mega 5V 에서 먹이면 Din 5V, VDD 5V 로 맞아떨어집니다. Mega 는 노트북 USB 전원이라 비상정지 중에도 살아 있어 빨간 표시등이 켜집니다(규정 4.2).

⚠️ 대신 밝기를 제한해야 합니다. USB 는 총 500mA 라 Mega 자신이 쓰는 몫을 빼면 여유가 크지 않습니다. 풀백색 대신 한 색을 중간 밝기로 쓰면 충분합니다.

5. 결선표 — 이것이 본체입니다

단자 하나하나를 적습니다. 이번 사고는 이 표가 없어서 생겼습니다. 각 선이 "그럴듯한 자리" 에 꽂혀 있어서 눈으로는 안 잡혔습니다. 작업할 때 이 표를 그대로 따라가고, 끝나면 한 줄씩 체크하십시오.

9. 작업 · 검증 순서

  1. 🚨 배터리 전부 분리 — 현재 배선은 접촉기가 닫히면 배터리 B 를 단락시킵니다
  2. MD-30a 의 1·2·5·6 배선 전부 제거
  3. 결선표 #1~7 (주 전력)
  4. 결선표 #8~12 (코일 회로) — 코일 전압·컨버터 출력 확인 후에
  5. 결선표 #13~14 (보조접점), #15~25 (신호·표시등), #26~30 (공통 GND)
  6. 무전원 도통 시험 — 배터리 연결 전에, 각 배터리의 (+) 와 (−) 가 어디서도 이어지지 않는지 확인. 삐 울리면 어딘가 잘못된 것입니다
  7. 배터리 하나만 연결 → 접촉기가 닫히는지 확인 → 버튼을 눌러 열리는지 확인
  8. 스러스터 연결 전에 비상정지 실물 시험 완료
  9. ESC arm 확인 — 켠 뒤 1500µs 몇 초 → 삐 두 번 (펌웨어 ARM_HOLD_MS = 2000)
  10. 스러스터 연결 → 저출력부터 좌/우 회전 방향 확인
🚨 7~8번을 건너뛰지 마십시오.
작년 구성이 동일했는데 배터리 B 가 타지 않았다는 것은, 비상정지가 한 번도 실제로 작동한 적이 없을 가능성을 뜻합니다. "달려 있으니 된다" 로 넘어가면 대회 당일에 처음 눌러보게 됩니다.
