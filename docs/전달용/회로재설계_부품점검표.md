## 0. 왜 다시 짜는가 — 확인된 사실

2026-08-17 실물 배선 조사에서 나온 것이다. 추측이 아니라 단자 단위로 확인했다.

| # | 확인된 것 | 근거 |
|---|---|---|
| **1** | 🚨 **배터리 B 가 접촉기 접점 양끝(`1번`·`2번`)에 물려 있다** | 배선표. 접점이 닫히면 배터리 직접 단락 |
| **2** | 🚨 **ESC 전원이 어디에도 연결돼 있지 않다** | 배선표. 추진 경로가 통째로 없다 |
| **3** | **MD-30a 는 30A · 2극** | 제품 라벨 사진 (LS Metasol, `⎓DC`, 단자 `1·2·5·6`) |
| **4** | 배터리 2개인데 접촉기는 1개 | 극이 2개뿐이라 **끊을 수 있는 선이 2가닥** — 2계통은 4가닥 |
| **5** | 무선 비상정지 부품이 확인되지 않음 | 룰북 §8 은 버튼식 + 무선식 **둘 다 의무** |

**🚨 미해결 — 작년과의 모순.** 작년도 같은 구성(접촉기 1개·배터리 2개·스러스터 동일)인데
배터리 B 가 타지 않았다. 접촉기가 평소 닫혀 있어야 추진 전원이 통하므로, 같은 배선이었다면
매 주행마다 단락됐어야 한다. 가능한 설명:

- ① 작년 배선이 실제로는 한 가닥 다르다
- ② 접촉기가 한 번도 닫힌 적이 없다
- ③ **추진 전원이 애초에 접촉기를 지나가지 않았다** ← 30A 로 버틴 것·단락이 안 난 것이 동시에 설명됨

③ 이면 **작년 배에는 실질적으로 비상정지가 없었다**는 뜻이다.
→ 가르는 질문: **ESC 굵은 전원선의 반대쪽 끝이 배터리 커넥터인가, 접촉기 단자인가.**

## 1. 바뀌지 않는 제약 — 설계는 이걸 만족해야 한다

### 1-1. 규정

| | 요구 | 출처 |
|---|---|---|
| 표시등 | 원격조종 **초록** / 자율운항 **노랑** / 비상정지 **빨강** | 규정 4.2 — 없으면 **보트 검사 탈락** |
| 비상정지 | **버튼식 + 무선식 둘 다** | 룰북 §8 — 성능이 아니라 **출전 자격** |

🚨 **무선 비상정지는 아두이노를 거치면 안 된다.** 제어기가 죽어도 들어야 한다.
아두이노는 `PIN_ESTOP_SENSE(38)` 로 **상태를 읽기만** 한다.
→ MD-30a 의 **보조접점(`13·14` = NO, `21·22` = NC)** 이 이 용도에 그대로 맞는다.

### 1-2. 전기

```
T200 1개 순간      약 25A  (16V 기준 제조사 스펙)
스러스터 4개       약 100A
계통당 (2개)       약 50A
배터리             4S 14.8V × 2
```

🚨 **14.8V 를 넘기면 안 된다.** T200 최대는 20V다.
배터리 2개를 **직렬로 이으면 29.6V** — 스러스터와 ESC가 탄다.
(지금 `배터리A(−)`와 `배터리B(+)`가 접촉기 두 극에 각각 들어가 있어 직렬의 모양을 하고 있다)

### 1-3. 신호 GND

굵은 전원선은 좌우 분리해도 되지만, **신호 GND 는 반드시 공통**이어야 한다.
PWM 은 "어떤 기준점 대비 몇 V" 이고 그 기준점이 GND다. 안 이으면 ESC 가 신호를 못 읽는다.
ESC 3핀 커넥터의 GND 를 Mega GND 에 연결하면 된다 — 가는 신호선 한 가닥이다.

## 2. 부품 점검표

### A. 추진 계통

| 부품 | 필요 정격 | 보유 (모델) | 실측/라벨 | 판정 |
|---|---|---|---|---|
| 배터리 | 4S 14.8V, **100A 방전 가능** (C레이팅 확인) | | 용량 ___mAh / ___C | |
| ESC ×4 | **양방향** 1100–1500–1900µs, 4S, 연속 30A+ | 배 안 (검은 테이프) | | 🚨 모델 미확인 |
| 스러스터 ×4 | T200 | T200 | — | ✅ |
| 배선 (배터리→분기) | 8~10AWG | | | |
| 배선 (분기→ESC) | 12~14AWG | | | |

🚨 **ESC 가 양방향이 아니면 후진이 안 되고 제어 체계 전체가 무너진다.**
펌웨어·노트북 코드가 전부 `1500=중립` 전제다. 테이프를 벗겨 모델명을 확인해야 한다.

🚨 **배터리 C레이팅.** 100A 를 낼 수 없는 배터리면 전압이 주저앉아 ESC 가 리셋된다.
`5000mAh × 30C = 150A` 식으로 계산한다. 라벨의 `mAh` 와 `C` 를 적을 것.

### B. 차단 계통 (비상정지)

| 부품 | 필요 정격 | 보유 | 판정 |
|---|---|---|---|
| 주 차단 (버튼식) | DC **100A 이상** 통전·차단 | MD-30a (30A · 2극 · 1개) | 🚨 **부족** |
| 무선 차단 | 수신기 채널로 개폐, 아두이노 무관 | 확인 안 됨 | 🚨 **없으면 출전 불가** |
| 보조접점 (상태 감지) | 아두이노가 읽을 접점 | MD-30a `13·14` / `21·22` | ✅ 있음 |

**부족 판정 근거 2가지:**
- **전류** — 30A 로 100A 를 끊으면 접점이 아크로 녹아 붙는다(융착). 그러면 **눌러도 안 떨어진다**
- **극 수** — 2극은 2가닥만 끊는다. 배터리 2계통은 4가닥 → **접촉기가 하나 더** 필요하고,
  **두 개가 같은 버튼에 동시에** 물려야 한다. 한쪽만 끊기면 살아있는 쪽 추력만 남아 배가 제자리에서 돈다

> 대안: `XT90-S 루프키`(뽑으면 무조건 끊김, 안티스파크 내장) 는 로봇 대회 표준 수법이고
> 100A 급이 흔하다. 접촉기를 키우는 것보다 싸고 확실할 수 있다. 무선측은 별도.

### C. 제어 전원

| 부품 | 필요 정격 | 보유 | 판정 |
|---|---|---|---|
| DC-DC 컨버터 | 입력 4S, 출력 5V 3A+ (아두이노·수신기) | 방열판 달린 검은 박스 | 입출력 전압 확인 필요 |
| 접촉기 코일 전원 | MD-30a 코일 정격 (`DC 12V`/`24V` 등) | | 🚨 **코일 전압 미확인** |
| 릴레이 모듈 | 코일 회로 개폐 | 초록 기판 + 파란 릴레이 | 용도 확인 필요 |
| 아두이노 전원 | USB 또는 5V | 현재 **노트북 USB** | 배 위에서도 노트북이 타므로 가능 |

### D. 표시등

| 부품 | 필요 | 보유 | 판정 |
|---|---|---|---|
| 룰 표시등 초록·노랑·빨강 | 주광에서 식별 | LED 스트립 (WS2812?) | 종류 확인 필요 |
| LED 전원 | 추진과 분리 | AA×3 (4.5V) | ⚠️ 480mA 면 빨리 닳음 |
| 점검 LED | 소형 | | |

⚠️ **AA 3개는 빠듯하다.** 8픽셀 풀백색이면 480mA, 알칼라인은 소진되며 4.8V→3.6V 로 떨어져
색이 틀어지거나 안 켜진다. **경기 중 규정 표시등이 꺼지면 검사 문제**가 된다.
→ 4S 에서 5V UBEC 로 따는 편이 안정적이다.

## 4. 구성도를 그릴 때의 골격 (참고 — 부품 확정 후 확정)

지금까지 나온 제약을 만족하는 구조는 대략 이렇다. **부품 정격이 확정되면 이 위에 숫자를 채운다.**

```
배터리A (4S) ──[차단 A]──┬── ESC 좌 ×2 ── 스러스터 좌 ×2
                          │
배터리B (4S) ──[차단 B]──┴── ESC 우 ×2 ── 스러스터 우 ×2
                  ↑
          버튼 1개 + 무선 1채널이 A·B 를 **동시에** 연다
                  │
                  └─ 보조접점 ──→ Mega 핀 38 (상태 읽기만)

배터리A ──→ DC-DC 5V ──→ Mega · 수신기        (차단기 **앞**에서 딴다 —
                                                 비상정지 후에도 제어기는 살아
                                                 "정지됨"을 표시해야 한다)

Mega GND ──┬── ESC 좌 신호GND
           ├── ESC 우 신호GND      🚨 굵은 전원선은 분리, 신호 GND 는 공통
           └── LED GND
```

🚨 **직렬 금지.** 배터리 A 와 B 는 **어디서도 서로 이어지지 않는다**(신호 GND 제외).
한쪽 `(−)`와 다른 쪽 `(+)`가 만나는 순간 29.6V 가 된다.
