보고서에서 뺀 Ⅵ 결론 초안(PPT 마지막 장 재료):
- 선형: 1번배 쌍동선 → 단동선(LOA 1.66 m), T200 2기 / 2번배 단동선(LOA 1.77 m), T200 4기(선수 측 안쪽·선미 측 바깥).
- 소프트웨어: 선내 노트북 1대 ROS2. OAK-1 PoE = 방위각, LiDAR = 거리, D455 = 수동 조종 화면.
- 안전: 2극 접촉기(버튼·무선), 센서 불신 시 발행 중단, 명령 0.5 s 끊기면 중립.
- 확인한 것: 1번배 부상 시험(흘수 45·95·105 mm)·수조 수밀·비상정지 단독 차단 / 2번배 수조 수밀 / 공통 OAK 화각·방위각, 시뮬 2,400 런.
- 대회 전 물 위 확인: 조향 부호·추력 PWM, IMU 오프셋·자기편각, LTE 핫스팟 켠 상태 RTK FIXED, 도크 접안 거리(2번배: 흘수선 표시·무선 비상정지 도달 거리).
