🔌 회로팀용 — 아두이노 Mega 업로드 안내

2026-08-11 · 펌웨어 파일은 소프트팀 제공, 업로드·배선은 회로팀 · 파일: arduino/ssf_boat/ssf_boat.ino

0. 🚨 먼저 — 무엇을 아두이노에 넣는가

파일언어어디서 도나아두이노에 넣나
ssf_boat.inoC++아두이노 Mega✅ 이것만
브릿지 (src/ssf_bridge/)파이썬배 노트북 (Ubuntu, ROS2)❌ 넣을 수 없음

브릿지는 파이썬이라 아두이노 IDE에서 컴파일 자체가 불가능하다. 라이브러리를 빼고 넣어도 안 되는 이유가 이것이다. 둘은 짝이지 대체재가 아니다:

노트북: ROS2 토픽 ──브릿지(파이썬)──▶ USB로 "L1500,R1500" 전송 아두이노: 그 글자를 받아 ──ssf_boat.ino──▶ ESC 4개 구동

브릿지 쪽은 회로팀이 손댈 게 없다. 2026-08-10 에 소프트팀이 패키지로 만들어 메인 launch 에 연결해 뒀다 (ros2 launch ssf_bridge ssf_bridge.launch.py, 포트는 udev 로 /dev/ttyMEGA 고정). 회로팀이 할 일은 .ino 업로드와 배선뿐이다.

참고: Mega 2560 에는 micro-ROS 를 올릴 수 없다. 8비트 AVR이라 RAM이 8KB뿐인데 micro-ROS는 수십 KB가 필요하다. 그래서 시리얼 텍스트 방식으로 설계했다.

1. 준비 (한 번만)

1
Arduino IDE 설치
2
툴 → 보드 → Arduino AVR Boards → "Arduino Mega or Mega 2560" 선택
프로세서: "ATmega2560 (Mega 2560)"
3
라이브러리 — 둘 중 하나
· (권장) 라이브러리 매니저에서 "Adafruit NeoPixel" 설치 → WS2812 표시등 사용
· (스트립 아직 없으면) ssf_boat.ino 상단의 #define LED_USE_WS2812 1 을 0 으로 바꾸면 외부 라이브러리 없이 컴파일된다 (표시등만 단색 LED 방식으로 전환, 나머지 동작 동일)

2. 업로드

파일 → 열기 → arduino/ssf_boat/ssf_boat.ino ✓ 버튼(검증)으로 컴파일 확인 → → 버튼(업로드)

정상이면 "프로그램 저장 공간 7420바이트(2%) 사용" 비슷한 메시지가 나온다.

에러가 나면 에러 메시지 전문을 소프트팀에 전달할 것 (추측하지 말고 원문 그대로).

3. 출력 확인 (시리얼 모니터)

툴 → 시리얼 모니터, 속도 115200 선택.

부팅 시:

Boat ID: FAULT ← 배 ID 스위치를 아직 안 달았으면 정상 (달면 A 또는 B) ESC armed. Setup done. Control loop start.

이후 0.1초마다 상태 줄이 계속 나온다:

S,0,0,2,0,1500,1500,1500,1500 │ │ │ │ └─────────────┴── 모터 4개 출력 µs (선수L,선수R,선미L,선미R) │ │ │ └─ 비상정지 감지 (0/1) │ │ └─── 배 ID (0=A, 1=B, 2=고장/미배선) │ └───── 통신 워치독 발동 (0/1) └─────── 모드 (0=대기, 1=수동RC, 2=자율)

이 줄이 계속 나오면 펌웨어는 정상 동작 중이다.

4. ⚠️ 벤치에서 모터가 안 도는 게 정상인 경우

부팅 직후 모드는 0(대기) 이고, 이때는 안전을 위해 모든 모터가 중립(1500) 고정이다. 모터를 움직이려면 아래 중 하나가 필요하다:

하려는 것필요한 것
수동 조종 시험RC 수신기 연결 + 조종기 켜기 — 모드 스위치가 잡혀야 모드 1(수동)로 들어간다
자율 명령 시험모드 스위치를 자율 쪽(펄스 < 1500µs)에 두고, 노트북 브릿지 또는 시리얼 모니터로 명령 전송

시리얼 모니터로 직접 명령을 흉내낼 수도 있다 — 입력창에 L1400,R1600 입력 후 전송. (단 모드가 2(자율)일 때만 반영되고, 0.5초 안에 다음 명령이 안 오면 워치독이 중립으로 되돌린다)

"모터가 안 돈다 = 고장" 이 아니다. 상태 줄의 첫 숫자(모드)를 먼저 확인할 것.
