# 회로 신규 설계 (2026-08-17)

> 기존 배선을 고치는 게 아니라 **요구사항에서 다시 그린 것**이다.
> 역추적으로는 세 번 틀렸다 — 부품과 정격에서 출발한다.
>
> 앞선 문서 `회로팀_최종본_회신.md` 는 **전제가 틀렸다. 보내지 말 것.**

## 0. 🚨 먼저 — 제 이전 지적 하나를 정정한다

제가 **"2극으로는 배터리 2계통을 못 끊는다"** 고 했다. **틀렸다.**

배터리를 격리하는 데는 **두 가닥 중 한 가닥만 끊으면 된다.** 관례상 `(+)` 를 끊는다.
`(−)` 가 이어져 있어도 `(+)` 가 끊기면 전류가 흐를 길이 없다.

→ **2극 = 배터리 2개.** MD-30a 의 극 구성은 **우리 구성에 정확히 맞는다.**
   접촉기를 하나 더 사야 한다는 제 말은 취소한다. **남은 문제는 전류 정격 하나뿐이다.**

## 1. 부품 확정

| 부품 | 모델 | 핵심 사양 | 판정 |
|---|---|---|---|
| 배터리 ×2 | LI-POLY 7200mAh **100C** | 순간 방전 여력 매우 큼 (7.2Ah × 100C) | ✅ 충분 |
| ESC ×4 | **BlueRobotics BESC30-R3** | 30A, **양방향 1100–1500–1900µs 공장 설정**, BEC 없음 | ✅ **최적** |
| 스러스터 ×4 | T200 | 14.8V 에서 개당 약 21A | ✅ |
| 차단기 | LS Metasol **MD-30a** | DC 전용, 2극, 보조접점 `2NO+2NC` (`13·14`/`21·22`) | ⚠️ `Ith` 확인 필요 |
| 비상정지 버튼 | 한영넉스 접점 블록 | 제어회로용 (수 A) | ✅ **코일 회로에 쓰면 정확히 맞음** |
| 컨버터 | GTWave XW-12-24-240W | 입출력 확인 필요 | ⚠️ 확인 |
| 릴레이 모듈 | 12V DC RELAY MODULE | 입력이 로직인지 RC 펄스인지 확인 필요 | ⚠️ 확인 |
| LED | 스트립 (`+5V`·`Din`·`GND`) | WS2812 계열로 보임 | ⚠️ 전원 부적합 |
| LED 전원 | AA ×3 (4.5V) | | 🚨 **교체 필요** |

### ✅ ESC 가 아주 좋은 선택이다

`BESC30-R3` 은 T200 제조사 순정 조합이고 **양방향이 공장 설정**이다.
`1500µs = 중립` 이 우리 펌웨어·노트북 코드 전체의 전제인데 **설정 작업 없이 그대로 맞는다.**
(드론용 ESC 였다면 3D 모드 전환 작업이 필요했다)

🚨 **BEC 가 없다** = ESC 가 5V 를 만들어주지 않는다. 아두이노·수신기 전원은 따로 만들어야 한다.
🚨 **신호선은 신호 + GND 2가닥**이다. 이 GND 를 Mega GND 에 반드시 이어야 한다 (§5).

### ⚠️ 차단기 정격 — 🚨 **내 첫 판단을 정정한다**

처음에 **"30A 라 부족하다"** 고 했다. 그건 **모델명의 `30` 만 보고 한 말**이었다. 실제 사양은 다르다.

| | |
|---|---|
| 제품 성격 | `DC-1/2/5`, **최대 1000V** 급 직류 접촉기 (산업용 고전압 DC 회로용) |
| 표기된 정격 | `125V DC 에서 40A` |
| 구성 | 주접점 2극 NO + 보조 `2NO+2NC` |
| 우리 조건 | 계통당 **순간 42A**, 순항은 훨씬 낮음 |

그리고 물리가 우리 편이다 — **직류 아크는 전압이 낮으면 유지되지 않는다.**
이 제품은 1000V 를 끊도록 만들어졌는데 우리는 **14.8V** 다. **끊기는 훨씬 쉽다.**

→ 남는 건 접점의 **열 용량(연속 통전 전류 `Ith`)** 하나다. 데이터시트를 봐야 확정된다.
   **교체 권고는 보류한다.** 아슬아슬하지만 "못 쓴다" 고 단정할 근거가 없다.
   (넘는 것으로 확인되면 EV·윈치용 100~200A 급 DC 컨택터로 교체. **DC 정격**인지만 확인할 것)

## 2. 주 전력 계통

```
배터리B (+) ──→ [접촉기 2번] ─접점─ [1번] ──→ ESC 좌 ×2 ──→ 스러스터 좌 ×2
배터리A (+) ──→ [접촉기 5번] ─접점─ [6번] ──→ ESC 우 ×2 ──→ 스러스터 우 ×2

배터리B (−) ─────────────────────────────────→ ESC 좌 ×2      (접촉기를 거치지 않는다)
배터리A (−) ─────────────────────────────────→ ESC 우 ×2
```

**단자 배정은 제품의 극성 마크대로다.** `2`·`5` 가 `⊕`, `1`·`6` 이 `⊖` 로 인쇄돼 있고,
직류 접촉기는 전류가 `⊕ → ⊖` 방향으로 흘러야 아크 소호 자석이 작동한다.
→ **배터리 `(+)` 를 `2`·`5` 에, ESC 로 나가는 선을 `1`·`6` 에.**

🚨 **배터리 A 와 B 의 `(+)` 는 어디서도 만나지 않는다.**
🚨 **한쪽 `(−)` 와 다른 쪽 `(+)` 는 절대 잇지 않는다** — 잇는 순간 29.6V 이고 T200(최대 20V)이 탄다.
   지금 배선이 정확히 그 모양(`배터리B(−)`→`6번`, `배터리A(+)`→`2번`)이므로 **전부 풀고 다시 한다.**

### 배선 굵기

| 구간 | 권장 |
|---|---|
| 배터리 → 접촉기 → ESC | **8~10 AWG** (계통당 42A, 순간 60A) |

⚠️ **퓨즈는 넣지 않았다.** 보유 부품에 없다 — 없어서 생기는 일은 §6 에 적었다.

## 3. 차단(비상정지) 계통

**핵심: 버튼도 무선도 굵은 전류를 직접 안 끊는다. 둘 다 코일 회로만 끊는다.**
코일이 꺼지면 접촉기가 **두 극을 동시에** 연다 → 양 계통이 같이 죽는다.

```
배터리B (+)          ← 접촉기 **앞**에서 딴다 (차단돼도 이 전원은 살아 있어야 한다)
   │
   ▼
[DC-DC 컨버터]  →  코일 정격 전압으로
   │
   ▼
[비상정지 버튼 NC]  ──직렬──  [무선 스위치 NC]  ──→  [접촉기 코일 A1 · A2]
                                  ↑ **아직 없음** (§6) — 확보되면 이 자리에 넣는다
   │
   └── 어느 하나라도 열리면 코일 무전원 → 접촉기 열림 → 양 계통 동시 차단
```

🚨 **아두이노는 이 회로에 없다.** 제어기가 죽어도 비상정지는 들어야 한다 (룰북 §8).
아두이노는 **상태를 읽기만** 한다.

### 상태 감지 — 펌웨어 수정 불필요

```
Mega 핀 38 ── 접촉기 보조접점 [21]
Mega GND   ── 접촉기 보조접점 [22]
```

`21-22` 는 **NC(b접점)** 이라 접촉기가 **꺼졌을 때 닫힌다.**
펌웨어는 `pinMode(38, INPUT_PULLUP)` 에 `LOW = 차단됨` 이므로:

| 상태 | 접점 | 핀 38 | 펌웨어 판정 |
|---|---|---|---|
| 비상정지 눌림 (접촉기 열림) | 닫힘 | LOW | **차단됨** ✅ |
| 정상 (접촉기 닫힘) | 열림 | 풀업 HIGH | 정상 ✅ |

**코드를 한 줄도 안 고쳐도 맞는다.**

### 🚨 무선 비상정지 — 확인 필요

`조종기에서 가능` 이라고 하셨는데, **조종기 채널만으로는 안 된다.**
수신기의 PWM 펄스를 **접점으로 바꾸는 장치**가 하나 필요하다.

- 보유하신 `12V DC RELAY MODULE` 이 **로직 입력(HIGH/LOW)** 이면 → 수신기에 직접 못 문다
- **RC 펄스 입력**을 받는 모듈이면 → 그대로 쓸 수 있다

→ 모듈의 입력 방식 확인이 필요하다. 로직 입력이면 **RC 스위치 모듈**을 사야 한다.

🚨 **수신기 페일세이프를 반드시 설정할 것.** 조종기 신호가 끊겼을 때 그 채널이
**차단 쪽**으로 가야 한다. 안 그러면 통신이 끊긴 배가 계속 달린다.

## 4. 제어 전원

```
노트북 USB ──→ [Mega 5V] ──┬──→ LED 스트립 +5V   (핀 40 → Din)
                            └──→ 수신기 +5V
```

**새 부품 없이 푼다.** Mega 는 노트북 USB 전원이라 **비상정지 중에도 살아 있다**
→ 빨간 표시등이 켜진다(규정 4.2). 차단기 뒤에서 땄으면 정지하는 순간 등도 같이 죽었을 것이다.

⚠️ 대신 **밝기가 USB 전류(총 500mA)에 묶인다.** 풀백색 말고 한 색을 중간 밝기로 쓴다.
   한낮에 심사위원이 못 볼 정도면 그때 별도 5V 전원이 필요해진다.

### 🚨 LED 전원을 AA 에서 바꿔야 한다 — 이유가 두 개다

**① 전압이 모자란다.** 스트립은 `+5V` 용인데 AA 3개는 새것 4.8V, 소진되면 3.6V 까지 떨어진다.
색이 틀어지거나 아예 안 켜진다. 8픽셀 풀백색이면 480mA 라 **금방 닳는다.**

**② 🚨 더 위험한 것 — 데이터핀 과전압.**
WS2812 계열은 `Din` 이 전원전압보다 높으면 안 된다(최대 `VDD + 0.5V`).
지금은 **Mega 가 5V 로 `Din` 을 때리는데 스트립 전원은 4.5V 이하**다. **규격 위반이고 소자가 상한다.**

→ **스트립을 Mega 5V 로 옮기면 두 문제가 같이 없어진다.** `Din` 5V, `VDD` 5V 로 맞는다. 살 것도 없다.

## 5. 신호 GND — 이거 빠지면 ESC 가 안 돈다

**굵은 전원선은 좌우 분리해도 되지만, 가는 신호 GND 는 반드시 한 점에서 만난다.**

```
Mega GND ──┬── ESC 좌 ×2 신호 GND
           ├── ESC 우 ×2 신호 GND
           ├── LED 스트립 GND
           ├── 수신기 GND
           ├── 배터리B (−)
           └── 배터리A (−)
```

PWM 은 "어떤 기준점 대비 몇 V" 다. 기준점이 다르면 ESC 가 읽은 값에 의미가 없다.
전압계 탐침 한쪽을 아무 데도 안 대고 재는 것과 같다.

⚠️ `(−)` 를 공통으로 묶어도 **`(+)` 가 분리돼 있으면 두 배터리 사이에 전류가 돌지 않는다.**
   직렬이 되는 건 **한쪽 `(−)` 와 다른 쪽 `(+)`** 가 만날 때다. 그것만 피하면 된다.

## 8. 작업 순서

1. 🚨 **배터리 전부 분리** — 지금 배선은 접촉기가 닫히면 배터리 A 를 단락시킨다
2. MD-30a 의 `1·2·5·6` 배선 **전부 제거**
3. `MD-30a` **코일 전압**과 `GTWave` **출력 전압** 확인 — 코일 회로가 여기 달려 있다
4. §2 대로 주 전력 배선
5. §3 대로 코일 회로 — 버튼·무선을 **직렬**로
6. §4 LED 전원을 AA 에서 **Mega 5V** 로 이설
7. §5 신호 GND 공통 결선
8. **무전원 도통 시험** — 배터리 연결 전에 `(+)`↔`(−)` 가 어디서도 안 만나는지 확인
9. 배터리 하나만 연결 → 접촉기 동작 확인 → 버튼을 눌러 차단 확인 (무선은 확보 후)
10. 스러스터 연결 전에 **비상정지 실제 시험** — 작년에 한 번도 안 했을 가능성이 있다

## 10. 2026-08-18 실측 — 값이 채워지고 원인이 하나 밝혀졌다

### 채워진 값

| 항목 | 값 | 근거 |
|---|---|---|
| **MD-30a 코일 전압** | **DC 24V** | 접촉기 `A1`·`A2` 옆 인쇄 |
| **GTWave 컨버터** | **4S 입력** | 라벨. 14.8V 와 맞는다 (12V 기기가 아니었다) |
| EC5 반대쪽 | **ESC** | 확인 |
| LED 5V | 배터리에서 | 확인 |

컨버터가 **14.8V → 24V 승압**이고 코일이 24V 다. **정격이 맞아떨어진다.**

### 🎯 접촉기가 스스로 안 붙는 원인 — 컨버터가 「뒤」에 있다

```
접촉기가 붙어야 → 컨버터에 전기 → 코일이 돌아 → 접촉기가 붙는다
                                                  ↑ 처음으로 돌아감
```

**시동 경로가 없다.** 손으로 초록 버튼(수동 조작)을 눌러야만 붙고, 놓으면 떨어진다.
실측: 코일 양단 0V / 비상정지 버튼 양단 0V / 주 단자에는 14V.
회로 어디에도 24V 가 없다 = 컨버터가 켜진 적이 없다는 뜻이다.

→ **컨버터 입력을 배터리 EC5 에서 직접 따야 한다**(접촉기 「앞」).
   §4 결선표가 이미 그렇게 돼 있다. 지금 배선이 그것과 다른 것이다.

⚠️ 안전상으로도 「앞」이 맞다. 비상정지가 걸려도 컨버터·표시등·아두이노는 살아 있어야
   "정지됨" 을 표시할 수 있다.

### 배터리 B 가 `(−)` 를 끊고 있다

```
배터리A (+) → 2번(⊕) ─접점─ 1번(⊖) → ESC     ✅ 정상
배터리B (−) → 6번(⊖) ─접점─ 5번(⊕) → ESC     🚨 (−)를 끊는다
```

`(−)` 는 여러 장치가 공유하는 선이라, **신호 GND 를 묶는 순간 우회로가 생겨 차단이 무력화된다.**
우리 설계는 ESC 신호 때문에 GND 공통이 필수이므로 어차피 묶어야 한다.

→ 배터리 B 를 **`(+)` 가 5번(⊕)으로 들어가고 6번(⊖)에서 나가도록** 바꾼다.
   단자도 같이 옮겨야 극성 마크(전류 ⊕→⊖)가 계속 맞는다.

### 🚨 작년에도 비상정지가 실질적으로 없었을 가능성

"작년에 이 배선 그대로였다" 는데 컨버터가 「뒤」에 있으면 **작년에도 접촉기가 안 붙었다.**
그런데 배는 달렸으므로 **추진 전원이 접촉기를 우회했다**는 뜻이 된다.

이 프로젝트 초기 분석의 `LEVEL 0 — 출전 불가` 목록과 일치한다:

> **3. 비상스위치 2종 없음 (검사 9·10번)** — 버튼식 + 무선식 둘 다 필수. 추진 전원을 차단해야 함.

작년 아두이노 코드에도 `estop` 관련 코드가 한 줄도 없다. 상태 보고 형식
(`S,모드,워치독,배ID,비상정지,...`)은 2025 회로AI 회신에서 **올해 새로 정한 규약**이다.

**"작년에 됐으니 괜찮다" 가 아니라, 작년에 없던 것을 올해 만들어야 한다.**
