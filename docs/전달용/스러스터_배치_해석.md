# T200 스러스터 배치 해석 — 1번배 2기 / 2번배 4기 (2026-09-17)

> 확정: **1번배 T200 ×2, 2번배 T200 ×4** (2026-09-17 사용자). 종전 "2 vs 4 미합의"(`회로팀_전원문서_검토.md` #1) 해소.
> 재현: `python3 tools/thruster_layout.py` → `docs/전달용/배치도/thruster_layout.png`
> **CFD 아님.** 강체 조종모델 + 횡류항력(cross-flow drag) 요댐핑 + 작동원판 제트확산 + 정수압 트림.
> 선체 메시도 검증 실측도 없어서 CFD 를 돌리면 그럴듯한 허구가 된다. 이 단계엔 이 모델이 맞다.

## 0. 결론 먼저

| 배 | 위치 | 근거 |
|---|---|---|
| **1번배 (2기)** | 선미, **y = ±220mm**, 프로펠러 축을 **선저 아래 ≥50mm** | 폭 580 한계치. 얕은 흘수 탓에 선저 직부착은 환기 |
| **2번배 (4기)** | 선미 y = ±145 (조향 전담), 선수 **x=450, y = ±85** | 폭 430 이 한계. 후류 회피 + 조향은 뒤 |

## 1. 지배 원리 — 요 모멘트는 y 에만 비례

추력이 선체 길이방향이면 요 모멘트는 `N = y × T`. **x 는 요권한에 무관하다.**
앞뒤 위치는 환기·트림·후류로만 정하고, **좌우 간격이 조향 성능 전부를 결정한다.**

## 2. 1번배 — 환기가 진짜 문제

흘수 73mm(질량 35kg 가정), 프로펠러 Ø76. 축 잠김 h, `h/D < 1.0` 이면 환기로 추력을 잃는다.

| 장착 | 축 잠김 | h/D | 판정 |
|---|---|---|---|
| 선저에 직부착 | 73mm | **0.96** | **환기 확실, 추력 상실** |
| 선저 아래 50mm | 123mm | 1.61 | 안전 |
| 선저 아래 100mm | 173mm | 2.27 | 안전 |

**이번 해석에서 제일 실행에 직결되는 결과다.** 그냥 붙이면 프로펠러가 수면 바로 아래에서 공기를 빤다.

요 권한 (차동, 전진+후진 동시):

| y (mm) | 요모멘트 (Nm) | 정상 요레이트 (°/s) |
|---|---|---|
| 120 | 9.8 | 41 |
| 180 | 14.8 | 51 |
| **220** | **18.0** | **56** |

y 한계 220 = 반폭 290 − 본체 반경 50 − 여유 20.

## 3. 2번배 — 폭 430 이 발목

흘수 96mm, **건현 89mm (낮다)**. y 한계 145, 좌우 본체 안 닿는 최소 55.
선수 제트가 선미를 때리지 않으려면 횡오프셋 ≥ 제트반경(거리에 따라 58~90mm).

| 안 | 선미 | 선수 | 요레이트 | 후류 | 판정 |
|---|---|---|---|---|---|
| (가) 둘 다 최대폭 | ±145 | x750 ±145 | 53°/s | 필요 90 / 실제 0 | **간섭** |
| **(나) 추천** | **±145** | **x450 ±85** | **47°/s** | 필요 58 / 실제 60 | 회피 |
| (다) 선수 바깥 | ±75 | x550 ±145 | 46°/s | 필요 69 / 실제 70 | 회피하나 **침로 불안정** |

**세 안이 전부 46~53°/s 다.** 요레이트는 모멘트의 제곱근에 비례해서, 모멘트를 26% 키워도 회전은 13% 빨라질 뿐이다.
→ **조향 성능으로는 배치를 못 고른다.** 침로 안정성으로 고른다. 넓은 쌍이 앞에 있으면 뒷바퀴 조향 차처럼 직진이 불안하다. 그래서 (나).

⚠️ **한계**: 후류를 피하려면 선수 쌍이 선미에서 300mm 앞이어야 한다. 1.7m 배에서 그건 선수가 아니라 중앙이다.
**폭 430 에 4기는 기하학적으로 빡빡하다.** 더 앞으로 빼면 제트가 퍼져 필요 오프셋이 커지고, 선체 폭이 그걸 못 준다.

## 4. 부수 확인 2건

- **트림 걱정은 근거 없다.** `회로팀_최종본_회신.md` 가 "선수 추력이 뱃머리를 박는다"고 했으나, 계산하면 전출력 **0.19°(뱃머리 3mm)**, 70% 게인에서 0.14°. 무시 가능.
  선수 70% 게인은 **트림이 아니라 후류·전류부하로 정당화**해야 맞다.
- **최고속은 못 낸다.** 마찰저항만 넣은 모델이라 균형점이 Fn 1.47 에서 나오는데 배수량형 가정 밖이다.
  조파저항·활주 미포함 → **속도를 말하면 거짓말**. 실측 항목.

## 5. 가정 (바뀌면 결론도 바뀜)

| 항목 | 값 | 민감도 |
|---|---|---|
| 질량 (장비 포함) | 35 kg 추정 | **흘수 통해 환기·요댐핑 동시 지배 — 제일 민감** |
| 방형계수 Cb | 0.50 | 흘수 |
| 횡류 항력계수 | 1.1 | 요레이트 |
| T200 추력 @14.8V | 전진 46N / 후진 36N | 제조사 12V·16V 공개표 보간. **데이터시트로 확인 필요** |
| 제트 확산 반각 | 6° | 2번배 선수 y |

진수해서 건현을 재면 **1번배 "선저 아래 50mm"** 숫자가 제일 먼저 바뀐다.

## 6. 배치와 별개 — 펌웨어에 생긴 새 위험

두 배의 **스러스터 개수가 달라졌다**(2 vs 4). 종전엔 "크기가 달라 PWM 범위가 다르다"였는데, 이제 **구동할 ESC 개수 자체**가 다르다.
그런데 기록된 버그가 있다 (`docs/문제와작업/문제별_설명과_대응방법.md`):

```cpp
#define It_is_Aship 0   // 주석: A배=0, B배=2
if (It_is_Aship == 1) {   // 코드는 1을 검사 → B배 분기가 절대 안 걸림
```

개수까지 달라진 지금은 튜닝 문제가 아니라 **없는 스러스터에 신호를 보내거나 있는 걸 안 돌리는 문제**가 된다. 우선순위 상향 필요.

## 7. 실측 대기

- 건현(진수 후) → 흘수 → 환기 판정·장착 깊이 재계산
- T200 14.8V 실제 추력 (데이터시트 또는 벤치)
- 2번배 선체 바닥 형상 — 선수기를 x450 에 실제로 달 수 있는 평면이 있는지
- 4기 장착 후 2번배 건현 재확인 (89mm 에서 더 줄어듦)
