## 0. 🚨 먼저 정해야 하는 것 — 부표 높이

`CLAUDE.md` §8 과 보고서 5곳에 같은 문장이 있다: **"LiDAR 장착 높이 = 부표 높이. 안 맞으면 부표를 못 본다."**
그런데 **부표 지름·높이는 규정에 없다**(소프트 체크리스트 미해결 항목). → 운영측 문의 또는 작년 사진에서 추정.

이 값이 아래 배치의 LiDAR 높이(§3)와 그에 얹힌 OAK 높이·마스트 상한(§4)을 **동시에** 좌우한다.
**부표 높이가 나오기 전까지 LiDAR·마스트 높이는 잠정값이다.**

 [LTE 라우터] (반대 현)                 GPS 안테나(갑판, 해치 아닌 고정부)

|---|---|---|
| **마스트** | 중심선, **선수가 좁아지기 직전** — 1번 배 선미에서 ≈1230mm, 2번 배 ≈1130mm. 해치와 ≥30mm 이격 | 뱃머리가 화면에 들어오고, LiDAR 와 박스 사이. 무게(≈0.5kg)는 트림에 무의미 — 위치는 시야로 정한다 |

### 2-1. GPS 안테나 설치 — u-blox 문서 기준 (2026-09-16)
출처: ZED-F9P Integration Manual(UBX-18010802 §4.4 안테나), C94-M8P User Guide(UBX-15031066 §3.3.1), ANN-MB 데이터시트.
- **접지판 필수**: 패치 안테나는 **Ø100~150mm 금속판**(F9P 매뉴얼 "minimum 100–150 mm diameter"; C94 키트 동봉 판 최소 10cm; ANN-MB 권장 15cm). 수면 반사(멀티패스)가 아래에서 오므로 갑판 높이 안테나엔 접지판이 곧 FIXED 유지 조건. **Ø150 알루미늄 or 아연도금 강판** 쓴다.
- **자석 베이스는 알루미늄에 안 붙는다.** ANN-MB 는 자석 베이스 + 나사 구멍 2×Ø4.5 — **강판**을 쓰거나 알루미늄이면 **나사 2개로 고정**. 자석만 믿고 물 위 나가면 떨어진다.
- **위치**: 중심선, **해치 바로 뒤 고정 갑판, 선미에서 ≈535mm**(09-16: 안테나 케이블이 짧아 해치에 붙임. 접지판 Ø120 앞끝 595 ↔ 해치 600). 이유 — 해치 앞은 마스트(220mm)가 40cm 안에 있어 그 방위 고도각 ~29° 아래 위성을 가림, 해치 뒤면 마스트가 70cm 밖(~17°). CG(≈배 길이 40~45% ≈ 700mm)와 15~25cm 차 → LOS 오프셋 무시 가능. 해치 위 ✗(열 때마다 이동).
- **두 배 공통 x≈535(접지판이 해치에 닿기 직전), 중심선.** 대안 검토: 해치 앞~마스트 사이(마스트 7cm → 72° 가림) ✗, 해치 옆 갑판(1번 배 옆폭 10cm < 안테나 60×82, 2번 배 불가) ✗, 선미 끝(RC/LTE 자리·CG 50cm 오프셋) ✗.
- **해치 경첩은 뒤쪽 ✗** — 열리며 안테나를 덮는다. 경첩 앞(마스트 쪽) 또는 옆. 접지판 Ø120 중심 535 → 앞끝 595, 해치 뒤끝 600.
- LTE: 0트랙(폰 박스 안)이면 외부 안테나 없음. A트랙이면 LTE 안테나는 **선미 모서리 x≈50 한쪽 현** → GPS 와 ≥50cm.
- **하늘 가림 0**: 안테나 위·옆 30cm 안에 카메라·LiDAR·표시등·사람 손 닿는 물건 없음. 마스트가 유일한 높은 물체.
- **RF 이격**: F9P 매뉴얼 "cellular/Wi-Fi 송신 안테나 근처 주의" → **LTE 라우터·안테나와 ≥50cm**(선미 반대현). RC 수신기(2.4GHz)도 반대현. 이미 배치 §2 와 일치.
- **케이블**: ANN-MB 5m SMA 동봉 — **자르지 말고** 여분은 박스 안에 지름 ≥10cm 로 느슨히 감는다(RG174 급, 급격히 꺾지 말 것). 갑판 관통은 안테나 바로 옆 그로밋 1개, 박스 안 수신기 SMA 로 최단.
- **A배(C94-M8P)**: 키트 동봉 L1 패치 안테나 + 접지판(≥10cm). **UHF 무선 안테나는 안 쓴다**(보정은 NTRIP) — 달지 말 것. 설치 원칙은 B배와 동일.
- **B배(ZED-F9P)**: `dynamic_model: sea` 이미 설정(zed_f9p_rover.yaml). RTK FIXED 조건 "C/N0 40 이상" — 접지판·하늘 가림이 이걸 좌우한다.
- 실측 대기: 실제 안테나 모델(ANN-MB / ANN-MS / 기타), 케이블 길이, 접지판 보유 여부 → `하드웨어_위치_회신_프롬프트.md` GPS 절.

## 4. 마스트 — `tools/cad/mast.py` (파라메트릭, STEP+STL)

- **v2 (09-16):** 40mm 각관(벽 5mm) 마디 1개 + **베이스(IMU 포켓·칼라, 두께 20 이상 — IMU 높이에 맞춰 자동)** + **D455 선반(마디 앞면, 아래)** + **캡 = OAK 판(위)** + IMU 뚜껑(나일론 M3×4). 부품 4개. 갑판→OAK 상단 **218mm ≤ 220**. 두 배 공용 1세트.
- OAK RJ45 그랜드는 **아래**로(위로 두면 220 초과) — 그랜드 끝 ≈갑판+97, D455 는 선반 앞쪽(관 면에서 40mm 물림)이라 안 겹침. 조립 STEP 에서 간섭 0 확인(스크립트 자동 검사).
- **고정: 갑판(FRP) 관통 M5 ×4** — 나사못 ✗. 뒷면 와셔 ≥Ø20 또는 백플레이트(갑판 <3mm 일 때). 구멍에 실란트, 가장자리 모따기, 과체결 ✗. 곡면이면 고무판/실란트로 밀착. 글루건·양면테이프 ✗(벗김 하중·PP 비접착·열).
- 케이블: 베이스 중앙 Ø22 → 갑판 그로밋(베이스 옆 30mm 안) → 박스 그랜드. 갑판 노출 구간 스파이럴 튜브.
- 각도: **OAK 아래 11°, D455 아래 15°**, 둘 다 **롤 0**(픽셀→방위 변환이 수평 전제). 물 위 첫 시험에서 확정 후 마운트에 표시선.
- 파라미터 바꿀 것: `IMU_L/W/H`(iAHRS 케이스 실측 — 지금은 ⚠️ 가정 50×50×20), `BASE_HOLE_PITCH`(갑판 구멍 130×가로대 간격), `D455_TILT`/`OAK_TILT`, `MAST_H`(None = 자동). 볼트 M5 길이 = 갑판 두께 + 베이스 두께(로그 출력) + 10. `OAK_*` 치수는 OAK-1 PoE 데이터시트 기준 — 도착 시 실측. RJ45 그랜드 돌출(≈35mm) 은 **위쪽**으로(아래로 두면 거싯과 간섭).

## 5. 카메라 장착 시 소프트 쪽 조건 (기존 문서에서 모음)

- OAK: `hfov_deg` 재측정(카탈로그 HFOV 69°/DFOV 81°, 카탈로그값 그대로 쓰지 말 것 — 런북 §3), 표식 중앙 0°·좌측 끝 ≈hfov/2·부호 검증(런북 §7). **장착 후 위치를 바꾸면 전부 다시.**
- OAK 화면 아래에 뱃머리·LiDAR 몸체가 들어오면 HSV 검출 ROI 아래 몇 줄 제외.
- D455: `v4l2` 모드 스트림 전용 — `realsense2_camera` 노드 띄우지 않음(장치 점유). `CAM_DEV` 로 장치 고정.
- IMU: 정북 정렬 → `/imu/yaw`=0 까지 `mount_offset_deg`, 시계방향 90° 회전 시 값 증가 확인(`CLAUDE.md` §5 체크). 장착 위치가 바뀌면 `cm` 자기보정 다시.
- 부표 지름이 나오면 `소프트_작업체크리스트` 의 최소 면적 임계값도 재검토(20cm 부표 = 8m 에서 70px²).
