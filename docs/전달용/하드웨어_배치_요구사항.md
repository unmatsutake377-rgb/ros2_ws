## 0. 🚨 먼저 정해야 하는 것 — 부표 높이

`CLAUDE.md` §8 과 보고서 5곳에 같은 문장이 있다: **"LiDAR 장착 높이 = 부표 높이. 안 맞으면 부표를 못 본다."**
그런데 **부표 지름·높이는 규정에 없다**(소프트 체크리스트 미해결 항목). → 운영측 문의 또는 작년 사진에서 추정.

이 값이 아래 배치의 LiDAR 높이(§3)와 그에 얹힌 OAK 높이·마스트 상한(§4)을 **동시에** 좌우한다.
**부표 높이가 나오기 전까지 LiDAR·마스트 높이는 잠정값이다.**

## 0-2. ⚠️ `마스트_요구사항.md`(09-15) 와 이 문서의 충돌 — 팀 결정 필요

같은 날 올라온 `docs/전달용/마스트_요구사항.md` 는 **다른 마스트 개념**을 전제한다. 어느 쪽이든 되지만 **하나로 정해야** CAD·구매·높이표가 맞는다.

| 항목 | 이 문서 (배치 요구사항) | 마스트_요구사항.md | 왜 다른가 |
|---|---|---|---|
| LiDAR | **갑판 직치**(회전면 +3cm), 마스트에 안 올림 | 마스트 **최상단** (스캔면이 선체 최고점 +10cm) | 22cm 상한 안에서 OAK 아래끝(+6cm) 과 회전면을 분리하려고 갑판에 내렸다. LiDAR 를 마스트 위로 올리면 OAK 위로 올라가야 하고 22cm 를 넘긴다 |
| GPS 안테나 | 갑판 고정부(레버암 오차) | 마스트 최상단 근처 + 접지판 | 높이 h 에서 롤 θ 만큼 h·sinθ 수평 오차. h=20cm·10° = 3.5cm 로 낮은 마스트면 감내 가능, 60cm 면 10cm |
| LTE 안테나 | 선미 반대현(라우터 옆) | 마스트 상단 | 0트랙(폰) 이면 안테나가 없다. A트랙 라우터일 때만 해당 |
| 재질·고정 | PLA/PETG 프린트, FRP 관통 M5×4, 스테이 없음 (높이 22cm 라 모멘트 작음) | 알루미늄 프로파일/카본, 3점+ 스테이 | 높이가 다르면 답이 다르다 — 22cm 짜리에 스테이는 과잉, 60cm 짜리에 PLA 는 부족 |
| 탑재 질량 | 카메라 2대 ≈0.5kg | ≤1kg (LiDAR·안테나 포함) | — |

**결정 항목 (하나 고르면 나머지 문서·CAD 를 맞춘다):** ① 마스트에 LiDAR 를 올리나 (→ 22cm 상한 재검토) ② GPS 를 올리나 ③ 프린트인가 알루미늄인가.
공통으로 맞는 것은 이미 반영돼 있다: OAK 는 뒷면 M4×4 + 피치 조절·마킹, IMU·인젝터는 마스트 금지, 케이블은 그랜드 1~2개로 관통, 스트레인 릴리프.
⚠️ 두 문서 공통의 진짜 선행 항목은 **§0 부표 높이** — 이게 나와야 LiDAR 높이가 정해지고, 그래야 ①이 정해진다.

## 2. 배치 (평면) — 두 배 공통 원칙

```
선미 ─────────────────────────────────────────── 선수
 [RC 수신기] (한쪽 현)          [방수박스: 노트북·배터리·허브·IMU]  [마스트: D455 위 / OAK 아래]  [LiDAR]
 [LTE 라우터] (반대 현)                 GPS 안테나(갑판, 해치 아닌 고정부)
```

| 장비 | 위치 | 왜 |
|---|---|---|
| **마스트** | 중심선, **선수가 좁아지기 직전** — 1번 배 선미에서 ≈1230mm, 2번 배 ≈1130mm. 해치와 ≥30mm 이격 | 뱃머리가 화면에 들어오고, LiDAR 와 박스 사이. 무게(≈0.5kg)는 트림에 무의미 — 위치는 시야로 정한다 |
| **LiDAR A3** | 선수 끝 중심선, **갑판에 직접**(기둥 없이) | 회전면 360° 확보. 같은 높이에 아무것도 두지 않는다. 마스트가 낮아져 OAK 아래끝(갑판+6cm)보다 회전면(갑판+3cm)을 낮게 |
| **GPS 안테나** | 갑판 중앙부, **해치가 아닌 고정 갑판**, 금속 접지판 위 | 마스트 꼭대기 ✗ — 롤 레버암 오차(높이 60cm × 10° 롤 = 10cm, RTK 1cm 를 날림). 해치 위 ✗ — 열 때마다 움직임 |
| **IMU (RB-SDA-v1)** | 박스 바닥, 무게중심 근처, 선체축 정렬, 단단히 고정 | 마스트 ✗(진동). **자기 헤딩** 사용 → 모터·ESC·배터리 굵은 배선에서 **≥30cm**. 실기 |m|≈80µT 이상치의 유력 원인 |
| **RC 수신기 / LTE 라우터** | 선미 양현에 **서로 반대쪽**, ≥50cm 이격, 안테나 높게, 수신기 안테나 2개 직각 | `부품_추천목록` §9-2, `boat_launch_checklist` 통신 항목 |
| **룰 표시등** | 외부에서 사방으로 보이는 곳 (마스트 뒤쪽 면 권장) | 규정 4.2, 검사 항목 |
| **비상 버튼** | 갑판 접근 가능 위치 | `회로_요구사항서` §4 |
| **모터** | 선수·선미 프로펠러를 물흐름 일직선에 두지 말 것 | `회로_요구사항서` §5 |

## 3. 높이 (측면) — ⚠️ 흘수 추정치 기준, §0 부표 높이에 종속

| 장비 | 갑판 기준 | 수면 기준 (2번 배, 건현 14cm 가정) | 수면 기준 (1번 배, 24cm) |
|---|---|---|---|
| LiDAR 회전면 | +3 cm (갑판 직치) | ≈ 17 cm | ≈ 27 cm |
| OAK 중심 (아래끝) | +10 cm (+6) | ≈ 24 cm (20) | ≈ 34 cm |
| D455 렌즈 | +24 cm | ≈ 38 cm | ≈ 48 cm |
| 마스트 최고점 | **+22 cm** | — | — |

- 🚨 **LiDAR 17cm 가 부표에 걸리는지**가 §0. 안 걸리면 LiDAR 를 짧은 기둥으로 올리고 OAK 를 그 위로 → 마스트 22cm 상한과 충돌 → 팀 재결정.
- D455 가 낮아 먼 부표를 미리 보는 여유는 적다(낮은 마스트의 대가). 물 위 시험에서 답답하면 `tools/cad/mast.py` 의 `MAST_H` 만 올린다.

## 4. 마스트 — `tools/cad/mast.py` (파라메트릭, STEP+STL)

- 40mm 각관(벽 5mm) 150mm + 베이스 160×120×8 + D455 선반 캡. 갑판→선반 최고점 **219.6mm**. 두 배 공용 1세트, 마디 1개.
- **고정: 갑판(FRP) 관통 M5 ×4** — 나사못 ✗. 뒷면 와셔 ≥Ø20 또는 백플레이트(갑판 <3mm 일 때). 구멍에 실란트, 가장자리 모따기, 과체결 ✗. 곡면이면 고무판/실란트로 밀착. 글루건·양면테이프 ✗(벗김 하중·PP 비접착·열).
- 케이블: 베이스 중앙 Ø22 → 갑판 그로밋(베이스 옆 30mm 안) → 박스 그랜드. 갑판 노출 구간 스파이럴 튜브.
- 각도: D455 아래 15°(뱃머리가 화면 아래 끝에), OAK 아래 7°·**롤 0**(픽셀→방위 변환이 수평 전제). 물 위 첫 시험에서 확정 후 마운트에 표시선.
- 파라미터 바꿀 것: `MAST_H`(높이), `D455_TILT`/`OAK_TILT`, `BASE_HOLE_PITCH`(갑판 구멍 130×90). `OAK_*` 치수는 OAK-1 PoE 데이터시트 기준 — 도착 시 실측. RJ45 그랜드 돌출(≈35mm) 은 **위쪽**으로(아래로 두면 거싯과 간섭).

## 5. 카메라 장착 시 소프트 쪽 조건 (기존 문서에서 모음)

- OAK: `hfov_deg` 재측정(카탈로그 HFOV 69°/DFOV 81°, 카탈로그값 그대로 쓰지 말 것 — 런북 §3), 표식 중앙 0°·좌측 끝 ≈hfov/2·부호 검증(런북 §7). **장착 후 위치를 바꾸면 전부 다시.**
- OAK 화면 아래에 뱃머리·LiDAR 몸체가 들어오면 HSV 검출 ROI 아래 몇 줄 제외.
- D455: `v4l2` 모드 스트림 전용 — `realsense2_camera` 노드 띄우지 않음(장치 점유). `CAM_DEV` 로 장치 고정.
- IMU: 정북 정렬 → `/imu/yaw`=0 까지 `mount_offset_deg`, 시계방향 90° 회전 시 값 증가 확인(`CLAUDE.md` §5 체크). 장착 위치가 바뀌면 `cm` 자기보정 다시.
- 부표 지름이 나오면 `소프트_작업체크리스트` 의 최소 면적 임계값도 재검토(20cm 부표 = 8m 에서 70px²).
