## 2026-09-16 검토 반영 (v4.1)
1. **IMU 터널 개방** — `IMU_CABLE_SPACE` 14→24. 전엔 IMU 몸통(x 끝 10.5)이 터널 입구(x 6~14)를 56% 막았다. 포켓 50→60, 뚜껑 66→76. 베이스는 160×148×20 그대로.
2. **크레들 뒷판 접지** — 뒷판 밑을 바닥턱 밑면까지 내림. 전엔 D455 3.5 / OAK 3.95mm 떠서 서포트가 필요했다.
3. **이음 쿠폰에 칼라 추가** — 베이스↔마디는 플러그(안)+칼라(바깥) 이중 끼움인데 쿠폰이 안쪽만 시험했다. 프린트 오차가 겹치는 **칼라 쪽이 더 빡빡하다**.

남긴 것: 뚜껑 나사 보스 살두께 2.75mm. 나일론 M3 셀프탭에 갈라질 수 있으나 **이건 쿠폰이 답을 줄 항목**이라 그대로 뽑아본다. 갈라지면 `LID_MARGIN` 8→12.
