# 통합 시험 출력 세트 (2026-09-16)

생성: `MAST_TEST=1 python3 tools/cad/mast.py` → `tools/cad/out_test/`

**실물과 형상이 같다.** 다른 것은 **베이스 판 크기 하나뿐** — 160×148 → 113×128 로 줄이고 M5 볼트 구멍을 뺐다.
갑판이 아직 없어 볼트 구멍은 어차피 시험할 수 없다. 나머지(포켓·칼라·플러그·터널·크레들·틸트)는 실물 그대로다.
축소가 기능을 잘라먹지 않은 것은 광선 검사 8/8 항목으로 확인했다(포켓 공동·바닥·터널·중앙구멍·리베이트·판 가장자리·칼라 벽/보어).

## 왜 쿠폰 말고 이걸 뽑나

쿠폰은 끼움 치수만 본다. 아래 4개는 **조립된 실물에서만** 드러난다.

1. **적층 정렬** — 베이스 플러그 → 마디 소켓 → 마디 플러그 → 캡 소켓이 실제로 일직선으로 서는가
2. **케이블 실경로** — IMU 포켓 → 터널 → 중앙 Ø22 → 관 속 → 크레들 슬롯까지 선이 실제로 지나가는가
3. **카메라 간 20.1mm** — D455 상단과 OAK 그랜드 끝 사이 여유가 실물에서 유지되는가
4. 🚨 **서포트 자국** — 크레들 바닥면은 **카메라가 앉는 기준면**이다. 서포트를 떼어낸 뒤 그 면이 쓸 만한가.
   이건 계산으로 답이 안 나온다(프린터·재료·서포트 설정에 달림). 실물로만 알 수 있다.

## 통짜(권장) vs 분할 — 둘 다 만들어 뒀다

`MAST_FUSED=1` 을 주면 base+seg+cap 이 **하나로 붙은** `mast_fused.stl` 이 나온다. 이음(플러그·칼라·M4 볼트)이 사라진다.

| | 통짜 `mast_fused` | 분할 4부품 |
|---|---|---|
| 서포트 | **8204mm²** | 8577mm² |
| 재료 | **534㎤ ≈ 393g** | 545㎤ ≈ 401g |
| 바닥 접지 | 14037mm² | 14037mm² |
| 높이 | 216mm (세움 고정) | 최대 140mm |
| 서포트탑 최고 | **194mm** | 낮음 |
| 실패 시 손실 | **전부** | 1부품만 |
| 조립 | 없음 (뚜껑만) | M4 이음 볼트 |

통짜가 서포트도 재료도 **근소하게 적다** — 이음부 중복이 사라져서. 눕히는 방향은 전부 나쁘다(21900~28000mm²). **세움이 유일한 선택.**

**층 방향은 제약이 아니다.** 세워 뽑으면 층이 굽힘 하중과 수직이라 최악 방향이지만, 계산하면:

| 가속도 | 베이스 굽힘모멘트 | 최대 인장응력 |
|---|---|---|
| 1g | 561 N·mm | 0.08 MPa |
| 5g | 2805 N·mm | 0.38 MPa |
| 10g | 5611 N·mm | 0.77 MPa |

각관 40×40 벽5 의 단면계수 7292mm³, 탑재질량 Σm·h = 0.057 kg·m(D455 116g@62 + OAK 200g추정@175 + 구조 150g@100) 기준.
PETG 층간 인장강도 20~35MPa 대비 **30배 이상 여유**. ⚠️ OAK 질량은 추정 — 실물 오면 저울로 재서 다시 계산(선형이라 비례).

**남는 위험은 출력 실패 하나뿐**: 194mm 서포트탑과 전손. 프린터를 믿으면 통짜, 아니면 분할.

## 🚨 출력 방향

- `mast_base`, `mast_imu_lid` : **STL 방향 그대로**. 서포트 사실상 불필요.
- `mast_seg1` : STL 방향 그대로(관 세워서). D455 크레들 바닥턱에 서포트 필요.
- `mast_cap` (분할일 때만) : **반드시 Y축 270° 회전.** STL 방향 그대로는 **바닥 접지가 0** 이다 —
  OAK 크레들 바닥턱이 관보다 아래로 내려오고 11° 기울어 평평한 면이 없다. 기울어진 모서리로 서게 된다.
  Y270° 로 돌리면 접지 1308mm², 서포트 3851mm².

**서포트 설정**: 크레들 안쪽(카메라 안착면)에 닿는 서포트는 **인터페이스 간격을 넉넉히**(0.2~0.25mm) 준다.
떼어낸 뒤 그 면의 평면도를 자로 확인하고, 거칠면 사진과 함께 기록한다 — 그게 이 시험의 핵심 결과다.

## 확인 항목

- [ ] 4부품이 흔들림 없이 적층되고 M4 이음 볼트가 양쪽 구멍에 통과
- [ ] 케이블(4핀 + Cat5e + USB)이 포켓 → 터널 → 중앙 → 관 → 크레들까지 실제로 지나감
- [ ] D455 를 크레들에 끼우고 OAK 자리에 손을 넣어 20mm 여유가 실제로 있는가
- [ ] 크레들 바닥면 서포트 자국 — 카메라가 흔들리지 않고 평평히 앉는가
- [ ] 마스트가 자립하는가(베이스 판 축소 상태라 실물보다 불리 — 참고만)

측정·사진은 `docs/전달용/회신/통합시험_YYYYMMDD.md` 에 남긴다.

## 통짜로 뽑을 때

- 파일 `mast_fused.stl` + `mast_imu_lid.stl` (뚜껑은 어차피 별도)
- 방향 **세움(STL 그대로)**. 접지 14037mm², 서포트 8204mm².
- 메시 검사 통과: 비정상 모서리 0 / winding 오류 0 / 퇴화면 0 / 닫힌 solid.
- 🚨 서포트탑이 최고 194mm 까지 올라간다. 가늘고 긴 서포트가 주 실패 모드다.
  브림 넉넉히, 서포트 XY 간격 좁게, 가능하면 중간에 한 번 확인.
