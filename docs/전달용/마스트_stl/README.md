## v4 변경 (팀 피드백 2026-09-16)
- 카메라 2대 모두 **U자 크레들**(뒷판+바닥턱+좌우턱, 위 열림). 무게는 바닥턱이 받고 M4 나사는 잠금만.
- 바닥턱 커넥터 노치: D455 USB-C ±37 두 곳(부호 실측 전이라 양쪽), OAK 그랜드 중앙 35폭.
- IMU 포켓 = **중심선 선미쪽**, **접착식**(VHB+방진패드, 나사 없음). 뱃머리 화살표는 베이스 윗면 각인.
- D455 62 로 내림 + L자 USB-C 가정 → OAK 와 세로 여유 확보.
- 프린트는 **완성품 확정 후**(팀 결정) — 지금은 CAD/STEP 검토용.

## 검토했다가 기각한 것 — 크레들 분리형(v5), 2026-09-16

`seg1`·`cap` 의 서포트(4177 / 3851mm²)를 없애려고 **크레들을 관에서 떼어 볼트로 붙이는 모듈**로 바꿔봤다.
관은 세워서, 크레들은 등판을 바닥에 대고 각각 평평하게 뽑는다는 구상. `tools/cad/mast_v5_probe.py` 로 시제를 만들어 측정했다.

**기각.** 의도한 방향에서 오히려 나빴다.

| | v4 (현행) | v5 (분리형, 등판 바닥) |
|---|---|---|
| D455 쪽 서포트 | 4177mm² | **4455mm²** |
| OAK 쪽 서포트 | 3851mm² | **7831mm²** |
| 상부 질량(갑판 +134 이상) | 97g | **166g** (+69g) |
| 장착용 군살(등판+쐐기) | 없음 | 부피의 **58~67%** |

이유: 크레들을 떼어내도 **기울어진 카메라를 수직 장착면에 붙이려면 쐐기가 필요**하고, 그 쐐기가 오버행을 그대로 만든다.
구조를 바꿔서 풀 문제가 아니다. **서포트를 받아들이고, 서포트 자국이 카메라 안착면에 얼마나 남는지를 실물로 확인하는 쪽이 맞다.**
(계산으로 답이 안 나오는 항목 — 프린터·재료·서포트 설정에 달렸다.)
