카메라
- 모델: OAK-1 PoE, 구매처 리얼리스토어(국내 정식 대리점, A/S 가능) 661,000₩/대
- 주문 옵션 3개: FIXED-FOCUS 선택 / 32MP MAX 업그레이드 **선택 안 함** / 페이지의 "PoE Injector(US Cord) +42,000₩" **선택 안 함**
  (US Cord 는 AC 미국플러그라 배에서 못 쓴다. 벤치도 아래 DC 인젝터로 갈음한다)
- 스펙: IMX378 · HFOV 69°/DFOV 81° · IP67 · 커넥터 표준 RJ45 · 802.3af Class 3 · 전형 4~5W, 최대 7.5W
  · 81.9×81.9×31mm · ¼-20 + 뒷면 M4×4 · 동작 0~50°C
- **2m Cat5e 동봉** → 카메라↔인젝터 케이블은 따로 살 필요 없다

인젝터 (필수 — 4S 배터리 14.8V 에서 카메라에 48V PoE 를 먹인다)
- **802.3af/at active 여야 한다.** OAK 는 협상형 PD 라 passive 48V 인젝터는 쓰면 안 된다.
- 출력 **10W 짜리 금지** — Class 3 는 PSE 예산 15.4W 를 요구한다. ≥15.4W, 권장 30W.
- 후보 2개 (둘 다 조건 충족, 남은 건 선택):
  · A안 하이링크 DIVA-IPoEI — 12~48V DC in, 802.3af/at, 기가비트, −40~80°C, 딘레일.
    제조사가 차량·선박 용도 명시. TRXmall 자사 재고 **180,000₩**. A/S·문서 확실.
  · B안 REVOTECH PSE5502G — 11번가 **72,620₩**, 스펙 동급(12~48V in, 802.3af/at, 30W, 기가비트, −40~75°C).
    2026-09-15 상품 이미지로 모델 확인 완료. 단 **도착 예정 2주**, 리뷰 0(신규 리스팅),
    이전 동급 리스팅이 판매중지된 이력이 있어 재고가 불안하다.
- 인젝터는 **비방수(제어판넬용)** → 방수 컨트롤 박스(실측 400×300×200) **안**에 넣고 이더넷·DC선만 밖으로 뺀다.
- 소비전력 계산: 카메라 최대 7.5W + 변환손실 → 4S 기준 ≈0.6A 피크 → 인젝터 DC 입력에 **2A 인라인 퓨즈**.

연결 사슬
  4S(+) ─ 2A 퓨즈 ─▶ 인젝터 DC IN(+)   /   4S(−) ─▶ 인젝터 DC IN(−)
  인젝터 PoE OUT ─ 동봉 2m Cat5e ─▶ OAK-1 PoE
  인젝터 LAN IN ─ Cat5e ─▶ 노트북 (노트북에 이더넷 포트가 없어 USB-C 기가비트 어댑터 필요)
- 어댑터는 **AX88179 칩셋**(우분투 커널 기본 드라이버, 설치 0). 1000Mbps 표기 확인 — 100M 이면 프레임이 끊긴다.

[물어볼 것]

1) 수량 — 여기가 제일 큰 금액이다.
   - 저장소 §0 주문표는 OAK **2대**(배 A/B 각 1대), 인젝터 **2개**, 그런데 USB 어댑터는 **1개**로 적혀 있다. 앞뒤가 안 맞는다.
   - 배 노트북은 저장소에 **IdeaPad Slim 3 15IAH8 한 대**만 나온다. 노트북이 한 대면 A/B 를 동시에 못 돌리니
     OAK 2대가 정말 필요한지, 아니면 1대를 옮겨 다는지 결정해야 한다(661,000₩ 차이).
   - 물어라: 노트북 몇 대인가 / A·B 동시 운용 계획인가 / OAK 최종 수량 / 그에 맞춘 인젝터·어댑터 수량.

2) 인젝터 기종 — A안(하이링크 18만) vs B안(REVOTECH 7.3만). 2대 기준 가격차 약 21만원.
   - 물어라: 비용 우선인가 납기·재고 확실 우선인가 / **언제까지 손에 있어야 하나**(대회 10월에서 역산,
     수조 시험·통신 거리 시험 일정) / B안이 또 판매중지되면 A안으로 바로 갈 여유가 있나.
   - 절충안도 제시해라: 한 개는 A안, 한 개는 B안(예비 겸 비교)도 가능하다.

3) 예산·발주 경로
   - 물어라: 총액 승인이 났나 / 누가 발주하나(개인 카드·학교 구매·지도교수) / 세금계산서·현금영수증 필요한가
     / 2차 계획서 집행 시점이 발주를 막고 있나(막고 있다면 언제 풀리나).

4) 리드타임
   - 물어라: 리얼리스토어에 재고·발송일을 문의했나(안 했으면 이게 먼저다) / 배송지는 어디인가.

5) 인젝터 실물 미확인 2건 — 도착하면 바로 확인할 것이라 미리 적어둔다.
   - 딘레일 클립이 동봉되나(사진은 벽면 플랜지) → 없으면 박스 안에 플랜지 나사로 고정.
   - DC 입력이 5.5×2.1 배럴잭인지 적/흑 리드선인지 → 배선 방법이 달라진다.
   - 물어라: 박스(400×300×200) 안에 인젝터 자리를 잡아둘 사람이 누구인가(회로팀 협의됐나).

6) 전원 분기점 — 회로팀 결정 사항이라 발주서에 메모만 남긴다.
   - 인젝터 DC 입력을 배터리 **어느 지점**에서 따나. 권장은 **비상정지 차단 앞단**이다 —
     비상정지는 추진만 끊고 카메라·통신은 살아 있어야 회수·진단이 된다.
   - 물어라: 이 방침에 회로팀이 동의했나 / 2A 퓨즈는 재고가 있나 새로 사나.

7) 예비
   - 물어라: 인젝터 예비 1개를 살 건가(배 2척 + 벤치를 동시에 쓰면 모자란다) / 카메라 예비는 가격상 없다고 보면 되나.
