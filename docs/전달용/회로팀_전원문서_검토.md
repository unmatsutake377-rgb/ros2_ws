# 회로팀 전원 문서 검토 — 요약과 충돌 사항

> 회로팀이 작성한 "회로 최종 정리"(전원 시스템 설명서)를 소프트팀 관점에서 검토한 것.
> 원본은 회로팀 보유. 작성 시점상 회로팀이 소프트팀 요구사항서를 보기 전에 만든 것으로 추정.

## 1. 회로팀 설계 요약

- 배터리 4S 14.8V **2개** — 병렬 아님. 배터리A→좌측 계통, 배터리B→우측 계통 **완전 독립** (전기적 미연결 명시)
- 계통당 전원 사슬: `배터리 → EC5 커넥터 → 릴레이(E-Stop) → MD-30A DC-DC 컨버터 → LED/장치 → 스러스터`
- 릴레이 = 전원 ON/OFF + 비상정지(버튼). LED = 전원 공급 표시등
- 조립 순서·점검 체크리스트·자주 하는 실수까지 문서 품질 좋음

**타당한 부분**: 독립 이중화 발상, 릴레이 E-Stop, EC5 고전류 커넥터, LED 상태 확인, 시험운전 절차 — 방향성 건전.

## 2. 🚨 소프트/시스템 설계와의 충돌 (해소 필요)

| # | 충돌 | 내용 | 심각도 |
|---|---|---|---|
| 1 | **스러스터 2개 vs 4개** | 회로 문서는 좌/우 2개 전제. 시스템 설계는 T200 ×4 (선수2+선미2) | 🚨 전원 용량·배선 전체에 영향. 최우선 합의 |
| 2 | **ESC가 문서에 없음** | 전원이 "컨버터→스러스터" 직결로 그려짐. T200은 브러시리스 — **ESC 없이는 아예 안 돎.** 전원 사슬에 ESC 위치 필요 | 🚨 |
| 3 | **MD-30A 컨버터의 위치 의문** | 추진 경로에 DC-DC 컨버터가 들어가 있음. T200+ESC는 **14.8V 직결이 정상** — 중간 컨버터는 불필요하고, 30A 제한이 스러스터 전류(개당 순간 ~25A)를 못 받쳐 병목/차단 위험. 컨버터가 필요한 곳은 **Arduino Due 5V 공급**(저전류) 쪽 | 🚨 |
| 4 | **제어계가 문서에 전무** | Arduino Due, RC 수신기, 레벨시프트, ESC 신호선, 룰 표시등(초록/노랑/빨강) 미등장. 전원만 다룬 문서로 보임 — 의도면 OK, 다만 통합 시점 필요 | ⚠️ |
| 5 | **무선 비상정지 없음** | 버튼식만 있음. **대회 규정은 버튼식+무선식 둘 다 의무** (룰북 §8) | 🚨 규정 미충족 |
| 6 | **"좌우 전기적 완전 분리"와 신호 GND 충돌** | Due 하나가 좌우 ESC 모두에 PWM 신호를 보냄. PWM은 GND 기준 → **최소한 신호 GND는 좌·우·Due가 공통**이어야 함. 완전 분리 원칙과 조정 필요 (전원부 분리 유지 + 신호 GND만 공통이 일반 해법) | 🚨 오동작 직결 |
| 7 | **Due 전원 출처 미정** | 배터리 2개 체제에서 Due·수신기의 5V는 어느 배터리에서? (한쪽 지정 또는 별도 소형 배터리) | ⚠️ |
| 8 | **E-Stop 버튼 1개 → 릴레이 2개** | 좌우 계통에 릴레이가 하나씩. 비상 시 **버튼 하나로 양쪽이 동시에** 끊겨야 함 (한쪽만 끊기면 배가 제자리 회전하며 폭주) | 🚨 |
| 9 | LED 의미 겹침 | 회로 문서 LED = 전원표시. 규정 표시등(초록/노랑/빨강)은 별도로 필요 — 혼동 방지 위해 이름 구분 필요 | ⚠️ |

## 3. 회로팀 회의 안건 (충돌 해소 순서)

1. **스러스터 개수 확정** (2 vs 4) — 이게 정해져야 나머지 계산 가능
2. ESC 도입 + 전원 사슬 수정안 합의: `배터리 → EC5 → E-Stop(버튼+무선 직렬) → ESC → T200`, 컨버터는 Due 5V 전용으로 이동
3. 무선 E-Stop 추가 (규정) — RC 스위치 모듈+릴레이, 소프트팀 부품_추천목록 §3 참고
4. E-Stop 1버튼-양계통 동시 차단 배선
5. 신호 GND 공통화 방침
6. Due/수신기 전원 출처
7. 이후: 소프트팀 회로_요구사항서 §7 핀표 회신

## 4. 배터리 2개 독립 구조에 대한 소프트팀 의견

구조 자체는 **찬성** (부하 분산·이중화 이점 실재). 단 펌웨어 관점 유의점:
- 한쪽 배터리만 방전/차단되면 배가 **한쪽 추력만으로 원을 그림** — 자율운항 중이면 위험. 잔량 불균형 관리(출항 전 동시 만충)를 운용 체크리스트에 넣을 것
- 좌우 전압이 다르면 같은 PWM에도 추력이 달라 직진이 휨 — 노트북측 조향이 보정하긴 하나, 배터리 페어링(같은 로트·같은 사이클) 권장
