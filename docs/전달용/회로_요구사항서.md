# 회로 요구사항서 — Arduino Due 펌웨어 ↔ 회로 연결 사양

> 회로판 담당자용. 펌웨어(arduino/ssf_boat)가 전제하는 물리 연결을 정리한 것.
> 펌웨어 상태: 컴파일 검증 통과 (2026-07-22). 핀 배정 회신 오면 즉시 반영 가능.
> 설계 배경 전체는 `docs/펌웨어_설계문서.md` 참고 (안 읽어도 이 문서만으로 작업 가능).
> **핀 번호는 비워둠 — 배치는 회로 담당이 정하고, 결과를 맨 아래 표에 채워서 돌려주면 펌웨어에 반영함.**

---

## 1. 전체 연결 블록도

```
4S LiPo 14.8V ─┬─ [버튼식 비상차단 스위치] ─ [무선 비상정지 릴레이] ─┬─ ESC ×4 ─ T200 ×4
               │                                                    │
               └─ 5V BEC ─ Arduino Due 전원 (노트북 USB 전원에 의존 금지)
                                │
RC 수신기(FS-iA6/iA6B) ─ 채널 3개 ─ [5V→3.3V 레벨시프트] ─ Due 입력
노트북 ─ USB ─ Due Programming 포트 (micro-ROS 통신. 수동경기 땐 탈거)
(Due Native USB 포트 = 디버그 전용 — 평시 미배선, 점검 때만 사용)
```

## 3. 전원 계통 요구

- **Due 전원 = 5V BEC로 배터리에서 독립 공급.** 이유: 수동 경기 때 노트북을 배에서 내리는 운용(경량화) — 노트북 USB 전원에 의존하면 Due가 같이 죽음
- ESC 4개 전원: 4S 직결. **T200 4개 풀스로틀 순간 수십 A** — 배선 굵기/커넥터 정격 확인
- 전 계통 GND 공통 (수신기–Due–ESC 신호가 GND 기준이므로)

## 4. 비상정지 (대회 규정 — 필수)

규정: "추진시스템 **전원을 차단**시키는 버튼식 + 무선식 비상스위치 필수"

- **버튼식**: 배터리→ESC 라인의 고전류 물리 차단 스위치 (갑판 접근 가능 위치)
- **무선식**: 수신기 여유 채널 → **RC 스위치 모듈 → 고전류 릴레이**로 같은 라인 차단
  - 🚨 **Due를 거치지 않는 독립 회로여야 함** — 제어기가 죽어도 비상정지는 작동해야 한다는 취지. 펌웨어의 정지 로직은 별개 보조 장치일 뿐, 규정 충족은 이 회로가 함
- Due는 릴레이 상태를 감지선(#16)으로 읽기만 함

## 5. 장착 관련 요청 (선체 담당과 공유)

- **선수 모터와 선미 모터를 물흐름 일직선상에 두지 말 것** — 선미 프로펠러가 선수 후류를 먹으면 효율 하락. 좌우 또는 깊이로 어긋나게
- 룰 표시등: 초록(수동)/노랑(자율)/빨강(비상정지) — 심사위원이 보는 것이므로 외부에서 잘 보이는 위치

## 6. 회로 담당에게 확인 요청

1. 수신기 모델: **FS-iA6인가 iA6B인가** (겉면 표기)
2. 방향지시등(#12~13) 채택 여부
3. 완성된 핀 배정표 (아래 양식)
