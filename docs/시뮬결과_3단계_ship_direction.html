🚨 ZeroDivisionError — angle_increment == 0

LiDAR가 이상한 스캔을 보내면 int((0 - angle_min) / angle_increment_deg)에서 노드가 죽었습니다 (411회 예외).

이건 작년 코드에도 있던 버그입니다. 방어 코드가 0건이었습니다. 재작성본에만 가드가 있었고, 점진적 이관 경로에는 들어간 적이 없었습니다.
수정 후: 크래시 0회, 정지 페일세이프 160회 발동 → 안전하게 멈춥니다.
