# 1번배(A배) 구성 — 실물 기준 확정표 (2026-10-29, 1번배 담당 Ubuntu 세션)

> 1번배 노트북(Lenovo IdeaPad Slim 3, 이 저장소의 Ubuntu 세션)은 **1번배 전용**이다.
> 공용 코드의 기본값은 바꾸지 않는다(`boat` 필수화는 Davidson 결정, 2번배 노트북도 같은 코드를 쓴다).
> 1번배에 무엇이 실려 있고 launch 에 무엇을 주는지는 **이 표가 기준**이다. 실물을 바꾸면 이 표부터 고친다.

## 1번배 대회 launch

```bash
sudo ~/ros2_ws/tools/boat_boot.sh
ros2 launch launch_files launch_files.launch.py boat:=A course:=main      # 종합임무
# 토너먼트: ... boat:=A course:=tournament waypoints_file:=<레인별 녹화본.yaml>
```

`course` 는 필수다(11-09, 계약서_토너먼트분리_20261109) — 빠지면 launch 가 거부한다.

`gps_config` 는 주지 않는다 — 기본값 `zed_f9p_rover.yaml` 이 지금 1번배 실물(F9P)과 맞다(아래 GPS 행).
두 배 모두 F9P 다(11-01 팀장 확인). `c94_m8p_rover.yaml` 은 쓰지 않는다.
