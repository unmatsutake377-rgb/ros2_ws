## 코드 확인 사실
1. 시제품 훅은 (C) 세 갈래(갭 선택·비킴·후진 상태기계)가 끝난 뒤 `final_angle` 을 덮어씀. DWA 가 고르면 후진 상태기계 리셋. `_side_prev` 는 갭 기준.
2. 상태 추정 `observe(final_angle)` 은 리미터 전 값. 리미터는 control_cb 에서. 굴림은 명령이 바로 바뀐다고 가정.
3. 굴림마다 추력 상태 T=0 에서 시작, u·v·r 만 이어받음. DWA 모드 밖 틱엔 추정 멈춤. 초기 (0.9, 0, 0).
4. 빈 리스트 기본값 금지(`test_launch_params.py:307-309` T4, rclpy Humble 원소 타입 미정, north 선례).
5. 센티널 `[-1]` 은 부팅 wp_mode −1 과 겹침 → 허용 목록 필터 필수.
6. 시제품 배율(감쇠 ÷a, 질량·관성 ÷a)은 식으로 '추력×a·감쇠 그대로' 와 같음 — 발견 11 표의 감쇠·추력 개별 변경과 다름.
7. full_course_sim 은 코드 기본값으로 돌림 → 기본 끔이면 기존 시뮬 불변. 발견 11 DWA 측정은 전부 비킴 끔 상태.

## 옮길 사양 (시제품과 동일)
- 조건: (C)(20000) 이고 `_side_wp_mode ∈ dwa_modes ∩ {5, 8}`. 다른 경로 비트 동일.
- 후보 `arange(0, 160+1e-6, 5)` 33개, 동률이면 작은 각(우현) 우선.
- 굴림 2.5 s / 0.1 s = 25 스텝, substeps 2, 시작 (0,0,ψ0) + 추정 (u,v,r), T=0.
- 점: 병합 뒤 distance_array, 0.05 < r ≤ 5.0, LiDAR 각 a → (r cos(a−80), r sin(a−80))(x 앞, y 왼쪽), `dwa_lidar_x_m` 을 x 에 더함.
- 여유: 직사각형 L×B 와 점 최소 거리, 스텝마다(t=0 제외), < d_hard 0.25 면 후보 버림·굴림 중단.
- 비용: |wrap(goal−head)|/180 + 0.8·max(0, 0.8−여유)/0.8 + 0.1·|a−last|/160, goal = yaw_mapped−80, head = −wrap(ψ).
- 모두 불가 → None → 기존 결과. 고르면 후진 상태기계 리셋.
- 명령→PWM: −1~161 → off=a−80, d=int(|off|/81·100), pr=1360−s, pl=1360+s; 161<a<5000 → 1590/1590; 그 밖 1500. steer_invert 미반영(물리 기준).
