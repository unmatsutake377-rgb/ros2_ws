# 변경 계약서: ship_dock 전방 거리(front_min_dist)를 공간 median 최소로 — 물보라 한 점의 거짓 CONTACT 막기 (2026-11-09)

ssf-contract 작성(읽기 전용 역할이라 메인 세션이 저장). 상태: **11-09 승인 — 결정 1~7 모두 권고안대로.**

## 문제와 근거 (합성 시뮬, 실측 아님)
`ship_dock.front_min_dist()` 가 정면 ±15° 섹터의 **raw 최솟값**을 쓴다. 물보라 반사 한 점이 1.0 m 아래로 튀면 `approach_decision` 이 즉시 CONTACT → BACKOFF → DONE.
- LiDAR 잡음(σ 3 cm + 결측 5 % + 정면 ±30° 광선 1 % 에 0.3~1.5 m 물보라)에서 APPROACH→CONTACT 0 초가 197/200 판(기준 중앙 4 초). 도킹 칸 안 A 89.6 %→34 %, B 95.6 %→36.5 %.
- 시뮬 몽키패치로 `ship_direction/failsafe.py` `median_min(kernel 5, min_valid 3)` 를 끼우면 물보라 판 A 87.5 %·B 99 %. 물보라 없는 같은 시드 200 판 A 179→173(잃음 10/얻음 4, 유의하지 않음)·B 192→197.

## 변경 단위
`ship_dock` 노드 하나, 커밋 하나(원자 묶음 아님 — 토픽·`active_wp_mode`·`/candidate_angle` 규약 불변).

2. `src/ship_dock/ship_dock/ship_dock.py` — `front_median_kernel` 선언·검증(157-158 근처), `front_min_dist` 의 raw 루프(373-378)만 `median_min(scan.ranges, lo, hi, kernel)` 로(lo/hi·stale·inc 가드 그대로), 부팅 로그(251-258)에 kernel 표시, 모듈 docstring [10], BACKOFF None 경고 문구(549-553).

4. `src/ship_dock/test/` — 테스트 추가.

손대지 않는 것: `ship_direction/failsafe.py`(원본, 읽기만), `package.xml`·`setup.py`, `tools/sim/ssf_sim.py`(무관). `full_course_sim`·`dock_sim` 은 실제 `ship_dock.py` 를 로드 → 사본 동기화 없음.

## 파라미터
| 이름 | 기본값 | yaml | launch | 비고 |
|---|---|---|---|---|
| `front_median_kernel` (신규, int) | 5 | `ship_dock.yaml` `/ship_dock` | 대회 launch 가 이 yaml 을 넘김 → yaml 값이 대회값 | 0·1 = raw(옛 동작, 롤백) |

이상값(결정 3): 0·1 raw / 2~9 median(짝수 k 는 창 k+1 — 부팅 로그에 실효 창) / 음수·9 초과 → 부팅 ERROR + 대체. `5.0` 처럼 소수점이면 rclpy 타입 불일치로 노드가 안 뜸 → 현장 조정표에 "정수로".

## 동작 변화
- median 값 ≥ 섹터 raw 최소 — **섹터 끝 k//2 점 제외**(창이 섹터 밖 ±k//2 점까지 본다. 끝 안쪽 3점 중 2점 이상 무효 + 바로 밖 2점이 가까울 때만 깨짐, 리뷰 권고 1 — 원본 의미 유지, `test_sector_edge_window_reaches_outside`). → CONTACT·standoff·realign_min 판정은 같거나 늦어지고, BACKOFF 이탈(`dist ≥ 2.5`)은 같거나 빨라진다.
- raw 에선 숫자였던 고립 점이 median 에선 None: APPROACH = SEARCH 대신 STOP_BLIND(정지, 타임아웃은 흐름). 표식이 보이는 정상 접근 중 섹터 전체가 듬성한 반사뿐이어도 STEER → STOP_BLIND(틱마다 판정, 정지·전진이 번갈아 나오다 30 s 접근 타임아웃 → BACKOFF 가능). WARN 에 버린 점 수를 넣어 LiDAR 고장(0)·고립 반사(>0)를 가른다(리뷰 권고 2) / CONTACT = 시간 전이라 무영향 / BACKOFF = 스캔 신선이면 REVERSE 유지(raw 가 2.5 m 이상 고립 반사였다면 DONE_BACKOFF 대신 8 s 뒤 DONE_TIMEOUT). 전부 inf·stale 은 옛 동작과 같음.
- BACKOFF None 의미에 "유효점은 있으나 모두 고립" 이 섞임 — 행동(후진) 같고 로그 문구만.
- 섹터 점 수: 실제 라이다 ±15° 약 120~134 점(0.223~0.25°). k=5 면 3 점 미만 폭 물체(1 m 에서 약 1.3 cm, 3 m 에서 약 4 cm)가 지워짐 — 도크 면 무관.

## 위험
1. 물보라가 3 점 이상 덩어리면 못 거름(섹터 끝 k//2 점을 빼면 raw 보다 나빠지지는 않음). 2 점 물보라 + 양옆 결측(창 `[5, inf, 0.5, 0.5, inf]`)도 통과한다. 합성 시험은 1 % 고립 광선뿐 — 실해역 ⚠️.
2. BACKOFF 이탈 확인이 빨라질 수 있음. 도크 뒷벽이 듬성하게 반사되거나 2 점 이하 얇은 기둥이 최근접이면 도크 앞에서 DONE_BACKOFF(20000)(`dock_fsm_logic.py:144-145`).
3. 사본 어긋남 — `failsafe.py` 를 나중에 고치면 사본은 안 따라감 → 동일성 테스트 필수.
4. 벤치: `tank_test_plan.html:185` "가짜 /scan 전방 0.8 m" 를 한두 광선으로 주면 지워져 CONTACT 안 남 → 섹터 전체 또는 연속 3 점 이상.
5. ~~근거 하네스가 저장소에 없음~~ → 결정 5 반영됨(`bee0aa9`, `--lidar-noise`).
