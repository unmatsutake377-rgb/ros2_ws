## 2. 배별 IMU 설정 — `boat:=A|B` 필수

🚨 이 커밋부터 **`ros2 launch launch_files launch_files.launch.py` 는 `boat:=A` 또는 `boat:=B` 없이는 거부된다.** pull 뒤 반드시 재빌드(새 yaml 두 개가 install 에 들어가야 함).

```bash
cd ~/ros2_ws && git pull && source /opt/ros/humble/setup.bash
colcon build --symlink-install --packages-select ssf_heading launch_files && source install/setup.bash
colcon test --packages-select ssf_heading launch_files; colcon test-result --verbose --test-result-base build/launch_files
```

| 볼 것 | 기대 | 결과 |
|---|---|---|
| colcon test (launch_files lint 포함, ssf_heading 새 test_boat_config 15개) | 실패 0 | ____ |
| `ros2 launch launch_files launch_files.launch.py` (boat 없음) / `boat:=C` / `boat:=a` | 셋 다 **노드 하나도 안 뜨고** 거부(Required argument / not valid) | ____ |
| `boat:=A` / `boat:=B` | LogInfo `boat=A, 파일=… → …`, `ros2 param get /yaw_mux mount_offset_deg` = 0.0, `invert_yaw` = False | ____ |
| install 의 `ssf_heading_A.yaml` 을 잠시 이름 바꾸고 `boat:=A` | 종료 코드 ≠ 0, `ros2 node list` 비어 있음, 남은 프로세스 0 (검사가 맨 앞이라 어떤 Node 도 안 뜸) | ____ |
| `ros2 launch ssf_heading ssf_heading.launch.py boat:=A` (벤치) | 같은 LogInfo, 같은 값 | ____ |
| 전체 launch 중 `python3 tools/check_params.py --boat A --gps-config <launch 에 준 값>` | 불일치 0 | ____ |

CLAUDE.md 정정 제안(Ubuntu 원본): §1-4 "배별 분리 파일은 아직 없다 — 배별 분기는 GPS `gps_config` 인자뿐" → "배별 분기 = `gps_config` + **`boat:=A|B`(필수, 대문자)** — 현재 IMU 두 값만(`ssf_heading_A/B.yaml`). 다른 배별 값(half_width·PWM)은 그 노드들에 yaml 이 안 실려 별도 계약". §8 IMU 장착 오프셋 항목에 "값은 배별 파일, 반드시 소수점" 추가. `launch_files.launch.py` GPS 주석 "B배: 인자 없이" 는 GPS C2 커밋 때 정정.
