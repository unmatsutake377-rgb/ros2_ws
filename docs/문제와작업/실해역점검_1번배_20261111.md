## 3. 라이다 (RPLIDAR A3 80BF) — 부표·막대 검출

측정법: 라이다 + OAK 를 같은 순간(±0.06 s)으로 2 초마다 저장, 카메라 화면 위에 라이다 방위를 겹침. 정면 = LiDAR 원 각도 80°(`LIDAR_FORWARD_DEG`).

| 단계 | 라이다 상태 | 물 위 결과 |
|---|---|---|
| ① 설치 그대로 | 물 위에서 앞으로 숙임 | 정면 ±40° **전부 반사 없음**(401칸). 흰 부표는 3.8~5.5 m 에서만 가끔, **막대 1~3 m: 1/176 스캔** |
| ② 높이 올림 | 숙임 그대로 | 육상: 사람 정상 검출. 물 위: 흰 부표 39 %, 막대 거의 0 |
| ③ 육상에서 수평계 0° | 물에 뜨니 **−2°**(앞 숙임) | 흰 부표 3.3 m 검출, 막대 여전히 못 봄 |
| ④ 높이 더 올림(−2° 그대로) | | **막대 4~6 m: 73~85 % 스캔**(각도 덮임 36~48 %) |
| ⑤ 1~3 m 왕복 ×2 | | 1차: 막대가 가까이 보인 29장 중 **50 % 이상 덮임 10장, 20 % 미만 15장**(평균 35 %). 2차: 3~5 m 약 65 %, 가장 가까운 1~1.5 m 부분은 놓침 |

해석:
- 레이저가 **막대 꼭대기 높이 근처**를 지나가고, 앞으로 약간 숙여 있어 "어느 거리대에서만" 걸린다. 배가 가감속하며 1~2° 들리고 숙이면 3 m 앞에서 5~10 cm 출렁여 잡혔다 놓쳤다 한다.
- 막대는 양 끝이 흰 부표에 걸려 들리고 **가운데가 처져 더 낮다** → 부표 쪽 끝만 잡히는 장면이 많다.
- 카메라는 모든 장면에서 막대를 선명하게 봤다(빨강 뚜렷).
- 대회 전 권고: 물 위에서 0°, 레이저 창 중심을 막대(가운데) 꼭대기보다 확실히 아래로. 왕복 시험에서 1~3 m 70 % 이상을 기준으로.
  단 수면에 너무 가까우면 물보라·물결 거짓 장애물이 늘어난다 — 높이·각도 최종값(수면 기준 cm, 수평계 °)을 이 문서에 적을 것: ⬜ 미기록.
- 이 실측은 **11-11 시뮬(`feat/vision-obstacle` 브랜치, 계약서_카메라장애물_20261111)의 가정 "라이다는 흰 부표는 늘 본다"가 틀렸다**는 근거다 — 카메라 퓨전 재평가는 이 영상으로.

라이다·카메라 방향(육상, 사람 실측 방위 대조): 실제 −5° → 라이다 −5.0° / 실제 −3° → 라이다 −2~−12°(중심 −6.9°, 폭 = 사람 몸). 라이다 정면 가정은 맞다.
카메라는 같은 사람을 약 −1°·+2° 에 보여 **약 4° 오른쪽 틀어짐**(눈대중 방위라 대략).
OAK 개체가 11-10 과 다르다: 11-11 MXID `1944301091BAFD2E00`(11-10 `19443010E167FD2E00`) — 화각 실측 때 어느 개체 값인지 구분할 것.
OAK 노출은 켠 뒤 약 3 초에 안정, 수신 약 20 fps.
