## 2. 질문 3개 답

**Q1. 뎁스 영상을 쓸 계획이 있는가** → **소프트 쪽엔 없다.** 구독자 0개이고, 거리는 LiDAR `/scan` 에서 얻는다(CLAUDE.md §3-3).
비전 3종의 depth 의존은 V1(07-23)에서 이미 제거됐다. **끈 채로 두는 것을 권한다.**
되살릴 계획이 생기면 USB 케이블 교체 후 재측정이 선행돼야 한다. ⚠️ 최종 판단은 팀 몫.

**Q2. 전원 공급형 허브를 살 수 있는가** → **이미 구매 목록에 있다. 사는 것이 아니라 발주하면 된다.**
`부품_추천목록.md` §0 8번 = **ipTIME UH308 유전원 허브 + DC-DC 5V 5A(XL4015) + 퓨즈 3A**, 27,900원 + 5천, **미발주**.
실측에서 4.09V 를 만든 것은 *버스전원* 허브다. UH308 은 유전원이라 이 제약을 푼다. 구매 목록 #31 로 발주 항목을 세웠다.

**Q3. 마스트·박스 설계에서 아두이노 USB 케이블 경로가 확보되는가** → **확보된다. 갑판 관통이 없다.**
노트북과 아두이노가 **둘 다 방수박스 안**이라 박스 내부 배선이다. 갑판 관통부는 A(마스트 Ø25)·B(LiDAR Ø10)·C(GPS Ø8) 셋뿐이고
USB 는 거기 없다(`하드웨어_배치_요구사항.md` §2-2). **경로 길이는 박스 내부 치수로 결정되는데 박스 내부 배치가 아직 미정이라
정확한 길이를 못 준다.** 짧고 굵은 케이블을 쓰고, 노트북 본체 포트에 직결한다는 것만 §2-3 에 고정했다.

**#4 보충**: 1번배가 2기라도 신규설계의 계통 구조(배터리 2개, 계통당 ESC 2개)는 그대로 쓸 수 있다.
1번배는 계통당 **ESC 1개·스러스터 1개**가 되어 계통당 전류가 42A 에서 **21A 로 절반**이 된다. 배선 굵기는 여유가 생긴다.
다만 **1번배는 좌우 1기씩이라 선수·선미 구분이 없다** — `펌웨어_설계문서.md` 의 "선수 좌/우 + 선미 좌/우" 4채널 전제와
`회로_요구사항서.md` §7 핀표의 ESC 4행이 1번배에는 맞지 않는다. 배별 채널 수 분기가 필요하다.
🚨 관련 기록된 버그: `문제별_설명과_대응방법.md` 의 `It_is_Aship` 주석/코드 불일치(주석 B=2, 코드 `==1` 검사)로
**B배 분기가 절대 안 걸린다.** 개수까지 달라진 지금은 튜닝 문제가 아니라 **채널 수가 틀리는 문제**가 된다.
