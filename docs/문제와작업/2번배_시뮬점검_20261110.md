## 2. 접촉 — 판(런)당

접촉 = 닿는 순간 1회(떨어졌다 다시 닿으면 +1). 충돌 물리 없음.

| 대상 | 잡음 없음 합 (판당, 범위) | 잡음 합 (판당) |
|---|---|---|
| 게이트 부표 | 0 | 0 |
| 위치유지 부표 | 20 (1.0, 1–1) | 20 (1.0) |
| 탐색 부표 | 21 (1.05, 1–2) | 9 (0.45) |
| 회피 mode 5 | 20 (1.0, 0–3) | 21 (1.05) |
| 회피 mode 8 | 30 (1.5, 0–6) | 22 (1.1) |
| 도크 | 68 (3.4, 2–7) | 58 (2.9) |
| 합 | 159 (≈8) | 130 (≈6.5) |

- 위치유지 판당 1회 = 알려진 출발 시 스침(`계약서_위치유지출발후진_20261109.md`). 위치유지 20·탐색 21 은 그 문서의 B 기준값과 같다.
- 도크에는 의도한 정면 접안 1회가 포함된다.
- 11-06 B fossen(`시뮬3자유도_발견_20261106.md`: 155 = 회피 70/위치유지 20/탐색 20/도크 45) 대비 회피 70 → 50, 도크 45 → 68. 그 사이 도킹 물보라 필터(51c2a00) 등 변경.
- 운동 계수·장애물 배치는 가정 → 절대 횟수보다 전후 비교용.
