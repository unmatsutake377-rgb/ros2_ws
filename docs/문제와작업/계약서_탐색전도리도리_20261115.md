## 3. 새 FSM

```
INIT(20000, hold_sec) → SCAN → SEARCH → APPROACH → ORBIT → DONE
SCAN 순서 (상대각 좌 양수, psi0 = SCAN 진입 yaw):
  STOP 50000 (scan_stop_sec, 관성 정지)
  → 오른쪽 −scan_angle 까지 SPIN_RIGHT 5000 → HOLD 50000 (scan_hold_sec, 정지 촬영)
  → 0 까지 SPIN_LEFT 6000 → 왼쪽 +scan_angle 까지 SPIN_LEFT 6000 → HOLD 50000
  → 0 까지 SPIN_RIGHT 5000 → SEARCH
어느 틱에서든 공지 색 + 신선한 방위(rel, col 둘 다) → 즉시 APPROACH (지금 SEARCH→APPROACH 와 같은 조건)
scan_timeout_sec 초과 / yaw 없음·stale / scan_enabled=false → SCAN 건너뛰고 SEARCH (막히지 않음)
```
회전 목표 판정 = ship_avoid `_dori_step` 과 같은 식(`target = psi0 − rel`, `err = wrap180(target − yaw)`, err>0 → 5000).

1. 도킹 이탈 WP 가 도크 구조물 가까움 → 제자리 회전 원(반길이 ≈0.83 m) 접촉. ship_direction SPIN 통과 경로엔 장애물 검사 없음(`ship_direction.py:1041`) — **SCAN 진입 전 LiDAR 회전 원 검사 추가 필요**(ship_avoid `spin_clear` 방식, 안 되면 SCAN 건너뜀).

**결론**
- 도리도리는 **부표가 카메라 거리 안인데 정면 시야 밖일 때만** 이득. 탐색 진입 WP 가 부표에서 멀면(>12 m) 시간만 약 13 s 손해.
- ±60° 는 배 뒤쪽 부표를 못 본다 → **±90° 가 우세**(발견 20/20, 최대 약 −33 s). §10-1 권장을 ±90° 로 바꾼다.
- 따라서 이 기능은 **탐색 진입 WP(턴 직전 WP)를 부표 무리 가까이(세 부표 모두 약 10 m 안) 두는 것**과 한 묶음이다. 현장 WP 배치 절차에 적어야 함.
- ⚠️ 시뮬 한계: 회전 원 장애물 검사는 단순(전 방위 1.0 m), 카메라 가림·햇빛 없음, 실제 선회율·오버슈트 미실측.
