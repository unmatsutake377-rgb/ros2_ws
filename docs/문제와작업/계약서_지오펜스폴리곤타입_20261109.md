## 문제
`src/north_goal_angle/north_goal_angle/north_goal_angle.py:168-169` `self.declare_parameter('geofence_polygon', []).value or []`.
rclpy(Humble) 는 기본값 `[]` 의 타입을 BYTE_ARRAY 로 정할 것으로 보인다(빈 리스트에서 all(isinstance(v, bytes)) 가 참). yaml `[]` 은 'not set' 이라 지금은 뜨지만(`tools/check_params.py:219-222` 실측), 실제 좌표(DOUBLE_ARRAY)를 넣으면 `InvalidParameterTypeException` 으로 부팅 때 죽을 가능성이 높다. 폴리곤을 넣고 rclpy 로 부팅한 기록 없음. 저장소에서 `[]` 기본값 선언은 이 한 곳.

## 0. 확인된 것 / 미확인
- 지금 상태(정적 타입 + yaml `[]` → not set)로 뜨는 것은 실측됨.
- 정수가 섞인 목록은 노드가 안 뜬다(`wp_timeout_sec`, 10-29 실측). 정수·소수 혼합은 rcl yaml 파서 단계에서 거부될 가능성 높음 ⚠️ `-p` 경로 미확인.
- ⚠️ 미확인: Humble 에서 `Parameter.Type.from_value([])` = BYTE_ARRAY 여부, DOUBLE_ARRAY 값에서 예외 여부 → S0. 미리 볼 명령: `python3 -c "from rclpy.parameter import Parameter as P; print(P.Type.from_value([]))"`.
- ⚠️ 미확인: 들어오는 값 자료형(list vs `array.array('d')`) → 검증 함수가 list·tuple·array 모두 받음.

### 선언 방식 (결정 1)
- **A. `ParameterDescriptor(dynamic_typing=True)` (권고)**: 값 없음 → `[]`, yaml `[]`(NOT_SET) → None → 빈 목록, DOUBLE/INTEGER/STRING 배열·숫자 하나 → 노드 검증이 판정(ERROR + 꺼짐, 노드는 계속). 함정: `rcl_interfaces` import → C0 필요.
- B. `Parameter.Type.DOUBLE_ARRAY` 선언(비권고): yaml 없으면 초기화 안 된 파라미터 → `ParameterUninitializedException` ⚠️, 정수만이면 부팅 사망, 스텁 추가 필요.
- D. 기본값 `[0.0]`(대안): import 없음, C0 불필요. 단 정수만이면 부팅 사망(웨이포인트 FSM 까지 멈춤), `[0.0]` 을 '미설정'으로 따로 처리.

- None·길이 0 → `([], True)` 꺼짐, ERROR 없음(지금과 같음).
