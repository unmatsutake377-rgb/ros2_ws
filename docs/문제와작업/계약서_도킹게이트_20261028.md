- **토픽 계약**

  - 10000 처리: `ship_turn`(:138-139)·`ship_back`(:125-126)은 10000 을 받으면 즉시 `buoy_rel = None`. **지금 버그에서는 모드 2·3 동안 dock 의 10000 이 turn 의 유효 방위를 매 프레임 지운다 — 실제 피해 지점.** `ship_dock`(:146-149, :166-172 `marker_ok`)은 10000 과 묵은 값을 똑같이 False 로 본다. `blackbox` 는 그대로 기록.
  - 확인법(Ubuntu): dock 을 `target_shape:=Squre` 로 띄우고 `ros2 topic pub /wp_mode std_msgs/Int32 "{data: 3}" -r 2` → `ros2 topic echo /image_angle` 에 turn 값만, 10000 없음. `data: 7` 이면 10000 만(선택지 A). `/wp_mode` 를 끊으면 dock 침묵 + 5 s 마다 WARN.
