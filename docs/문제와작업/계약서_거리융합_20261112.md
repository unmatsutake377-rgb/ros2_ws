## 0. 결론
1. **대회(11-13) 전에는 src 를 고치지 않는다.** 물 위 D455 뎁스 시험 0회라 켤 수 없고(대회 이득 0), D455 하드웨어 결정이 엇갈림
   (실해역점검_1번배_20261111.md:16,77 "D455 빼기" ↔ 실해역_시험_정리_20261109.md §9-0c "유지, 직결 포트"), 대회 launch 노드 6개를 건드리게 된다.
2. 제안 구조(`/scan_fused` 를 모든 미션 노드가 구독)는 **좁혀서**: 1단계는 `ship_direction` 하나만 구독 전환, 섞는 건 회피 모드 [5, 8] 에서만
   (그 밖 모드는 `/scan` 을 필드 하나 안 바꾸고 그대로 통과). 미션 노드 4종(gate·turn·back·dock)은 `/scan` 유지(§1).
3. **항상 가중평균은 쓰지 않는다** — 두 값이 일치할 때만 가중평균, 어긋나면 `min`(§5).
4. **LiDAR 고장 시 카메라만 쓰기(camera_only)는 기본 꺼짐** — 꺼져 있으면 지금처럼 L1/L2 정지. 켜는 건 별도 계약(§2).

## 2. 페일세이프와 camera_only
- 지금: `/scan` 0.7 s 넘게 3회 연속 → L1(감속 0.7), 3.0 s → L2 STOP_HOLD(`:784-792`). healthcheck WAIT(한 번도 못 받음)는 실패 아님(`healthcheck.py:301,312`). rplidar respawn 없음.
- 충돌: (a) camera_only 로 계속 내면 SensorWatch 가 안 늙어 **L1/L2 가 사라짐** (b) 부팅부터 LiDAR 없이 카메라로 ARMED → `/health_ok=true` 출발(침묵 사망)
  (c) inf/nan = 빈 공간 → 카메라 시야 밖(OAK ±32°, D455 ±43.5° ⚠️)을 inf 로 두면 "옆이 비었다", 막힘으로 칠하면 후보 0 → 후진/STOP(거짓 정지)·미션 노드엔 유령 물체
  (d) 감속을 걸 권한은 ship_direction `/failsafe_level` 하나뿐 (e) 11-11 LiDAR 끊김 3회는 전부 허브째(IMU·GPS·D455 같이) — camera_only 가 쓸모 있는 건 **LiDAR 단독 고장**뿐.
- 규칙 K(기본): `camera_only_enabled: false`. LiDAR 가 `lidar_stale_sec`(0.5) 넘으면 `/scan_fused` 발행 중단 → 지금과 같은 L1/L2. `/range_source` 는 `lidar_lost` 계속.
- 규칙 C(켤 때, 별도 계약 — 단위 8): LiDAR 를 한 번 받은 뒤 끊긴 경우만 / 마지막 LiDAR 격자 사용 / 시야 밖은 ship_direction 에만 막힘 / ship_direction 이 `/range_source` 보고 레벨 ≥1(감속) / `camera_only_max_sec`(⚠️ 10 s) 지나면 중단 → L2 / 확인된 카메라 셀만 / §7-2 안전 스위치 표 + healthcheck 경고.
- 더 큰 이득: **LiDAR 가 살아 있는데 앞을 못 보는 고장** — 11-11 ① 숙인 자세에서 정면 ±40° 401칸 전부 무반사(실해역점검 §3), `/scan` 은 계속 와서 페일세이프가 모름.
  range_fusion 이 "앞 섹터 유효 반환 ≈ 0 인데 카메라는 물체를 봄"을 `lidar_blind` 로 알리는 것.

## 5. 융합 (셀 단위, 신뢰도는 ~5° 섹터 단위)
| 경우 | 출력 |
|---|---|
| fusion 꺼짐·모드 밖·`/wp_mode` stale·카메라 stale | LiDAR 메시지 그대로 |
| LiDAR 만 | dL |
| 카메라만(LiDAR 가 못 보는 낮은 물체) | dC — conf_C ≥ `cam_only_cell_min_conf`, `min_sector_deg` 로 넓힘(smooth_spikes 1% 셀 제거 대응) |
| 둘 다, 일치(\|dL−dC\| ≤ max(0.3 m, 0.1·min)) | w_L·dL + w_C·dC, w = 정규화 conf 를 [0.3, 0.7] 로 자름 |
| 둘 다, 어긋남 | **min(dL, dC)**, 어긋남 횟수로 양쪽 신뢰도 감점 |
- 평균이 위험한 예: LiDAR 1.5 m, 카메라 4 m(뒤 물체·반사), w 0.5 → 2.75 m = 물체 없는 거리, 3.0 m 감지 경계 넘으면 마스크에서 사라짐.
- 신뢰도(소스·섹터별, 최근 N 프레임): 유효 반환 비율, 시간 잡음(MAD), 예측 대비 점프(≥0.5 m, WLS 예측 — 도리도리 계약서 §3-1), 연속 오검출 × 0.05 감점(하한 0.3). `/range_source` 로 냄.
- 거짓 장애물: min·카메라 단독 셀은 거짓 정지·후진을 늘린다 → 시뮬 오탐 스트레스가 합격 조건.
