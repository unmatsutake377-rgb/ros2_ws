내일 회로팀에게 물어볼 것 (이 목록 그대로 들고 가면 됨)

  • ① Mega 스케치 — 상황 대부분 종료됨 (참고 확인만) — 브릿지가 작년(2025) 자료 발굴 코드로 판명(노트북 세션 검증). 받는 쪽은 우리 완성본이 그대로 담당. 회로팀엔 가볍게만: "혹시 작년 자료에 L,R 받는 아두이노 코드도 있었나요? 있으면 참고로 보고 싶어요" (없어도 무방)
  • ② ESC 모델명 — T200에 물릴 ESC. 기준: 양방향(1500 중립)·4S 지원·30A↑. 모델명만 받아오면 arm 절차/중립점 벤치 항목을 Claude가 정리
  • ③ ~~수신기 상자 모델~~ 해결됨 — FS-iA6 확정 (08-07). PWM 전용, 텔레메트리 없음 → 통신거리 실측 항목이 소프트팀 체크리스트에 등재됨
  • ④ 핀 배정표 — 요구사항서 §7 빈 표 채워달라기. 🚨 RC 3채널은 핀 2,3,18,19,20,21 중에서만 (Mega 인터럽트 제약) · 0,1번 핀 금지(USB 겹침)
  • ⑤ 전원 설계 회의 (전원문서_검토.md §3 지참): ESC가 전원 사슬 어디 들어가는지 / MD-30A 컨버터는 추진경로에서 빼고 Mega 5V 공급용으로 / 무선 비상정지 추가(규정 의무) + 버튼·무선 모두 좌우 동시 차단 / 신호 GND 한 가닥 공통 / Mega·수신기 전원 출처
  • ⑥ 브릿지 실행법 전달 — Ubuntu에선 python3 브릿지.py --port /dev/ttyACM0 (코드 수정 아님, 실행 인자)
