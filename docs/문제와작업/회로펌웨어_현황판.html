지금 살아 있는 일 (우선순위)

  • ① 회로팀 답변 5건 — Q1 MD-30A 위치(이거 하나로 핀표·M커넥터가 정리됨) / Q2 신호 GND 공통 / Q3 무선 비상정지 부품(규정) / Q4 버튼 하나로 좌우 동시 차단 / Q5 ESC 신호선 4가닥 독립(아니면 선수 게인 튜닝 영구 불가) 회로팀
  • ② RC 선 한 가닥 이설 — 읽을 수 없는 핀(4·5)에 물린 RC 채널을 인터럽트 핀(19/20/21 또는 18)으로. 목적지는 Q1 답에 따라 결정 회로팀
  • ③ 핀표 확정 → 펌웨어 반영 → 재업로드 (Q1·Q2 답 이후 한 번에) Claude
  • ④ 벤치 검증 — docs/절차/펌웨어_벤치검증_절차서.md 순서대로. 🚨 최우선은 §2-3 수신기 failsafe 판정(조종기 끄기) 나
  • ⑤ 라우터 0트랙 검증 — 폰 온보드로 답사 때 셀 커버리지 + 폭염 박스 열 셧다운 확인 나
  • ⑥ WS2812 스트립 실물 — 픽셀 수·전원(AA 3개는 부족 → UBEC 권장) 회로팀

답 오면 이어지는 작업 (Claude 담당)

  • Q1 답 → M 커넥터(핀 18) 처리 결정: 컨버터가 빠지면 핀 18 을 RC 로, 남으면 M 제어 기능 신규 구현
  • Q5 답 → (가)면 선수 게인 유지 / (나)면 gain_num 전부 10 으로 맞추고 "선수 게인 튜닝 불가" 못박기
  • 핀표 확정 시 코드 §1 반영 + 재컴파일·재업로드
  • 벤치 결과 → 노브 확정 (arm 시간·데드밴드·조향 부호·모터 invert)
  • 이후: 수조 → 물 위 튜닝(선수 게인·전압 강하 관찰)

🚧 양보 불가 4건 (회의 때 물러서면 안 되는 것 — 물리/규정)

  • 1. ESC 존재 ✅ Basic ESC 확정 — 남은 건 전원 사슬 내 위치가 회로도에 반영되는 것
  • 2. 신호 GND 공통 ⏳ — 좌우 전원 분리는 유지하되 GND 한 가닥은 연결 (안 하면 신호 오동작)
  • 3. 무선 비상정지 ⏳ — 룰북 의무. 버튼식만으론 규정 미달. + 라우터 전원은 그 앞단 분기
  • 4. 스러스터 4개 ✅ 확정 — 전원 설계 반영 확인만 남음
