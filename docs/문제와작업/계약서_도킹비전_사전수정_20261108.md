## 항목 A — `circle_circularity_min` 0.82 → 0.87 (dock 만)

- 파일: `dock_logic.py:44` `classify_shape` 기본 인자, `basic_image_subscriberdock.py:144-145` declare 기본값, `vision.yaml` `image_subscriber_dock` 절. 같은 커밋 문서: `dock_logic.py` docstring, `docs/전달용/소프트웨어_동작설명서_20261105.md:243`·`.html:291` "0.82 이상이면 원".
- 파라미터: 범위 (0.785, 1.0), 반드시 소수. gate·turn 은 선언 안 함(`shape_vertices_*` 로 따로 판정).
- 위험:
  1. 반대 방향 오인 — `4<=v<=6`·원형도 0.82~0.87 컨투어가 CIRCLE→SQUARE. 목표가 red Square 일 때 작게 보이는 빨간 원(다른 칸 원 표식·빨간 부표)이 사각으로 잡힐 수 있음. 실물 부표로는 미확인.
  2. 삼각 분기 공유(`dock_logic.py:71-73`): v==3·원형도 0.82~0.87 이 None→TRIANGLE.
  3. 여유가 블러 가정에 달림: 모서리를 변의 r 만큼 깎은 정사각 원형도 = 4π(1−2r²)/(4−2.343r)² (r=0.083→0.856, 0.10→0.868, 0.125→0.886). OAK ISP 샤프닝·모션 블러에서의 둥글림은 미확인.
  4. §3 "임계는 혼동행렬 수치로" — 근거가 합성 기하뿐(결정 1).
  5. `dock_sun_stress.py:12` 0.82 하드코딩(결정 2).
- 검증: 기존 테스트 깨짐 없음(확인). 새 테스트 `test_dock_logic.py`: (a) 특징값 표(§0) — 기본 인자로 SQUARE/CIRCLE, `circle_circularity_min=0.82` 면 작은 사각이 CIRCLE 인 것도 단언, 출처 스크립트·cv2 버전 주석 (b) 해석적 모서리 깎인 사각 r∈{0.05,0.08} → SQUARE (c) v=3·원형도 0.85 → 0.87 에서 TRIANGLE (d) 정적: dock declare 기본값(AST) = vision.yaml dock 절 = `classify_shape` 기본 인자.
- 실기: `ros2 param get /image_subscriber_dock circle_circularity_min` = 0.87.
- 되돌리기: `git revert`. 현장: vision.yaml dock 절 `circle_circularity_min: 0.82` + launch 재시작.
- docs: 동작설명서 md·html, 현장 조정표 행(기본 0.87, 되돌리기 0.82, "실영상에서 사각이 원으로 가면 올리고 원이 사각으로 가면 내림").
