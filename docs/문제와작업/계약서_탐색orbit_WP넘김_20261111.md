## 6. 위험

1. **공지 색 부표를 SEARCH 동안 못 보면 선회 0회로 지나간다**(A). 지금(SPIN)은 시간 초과까지 그 자리에서 찾는다. 카메라 시야 ±32°·`y_zone`·`require_shape` 때문에 GPS 경로에서 부표가 옆으로 지나가면 놓칠 수 있다 — WP 녹화 위치를 부표 정면 접근이 되게 잡는 것이 중요(웨이포인트_녹화절차).
2. **한 모드 3 구간에 한 바퀴만**(B). 규정이 탐색 부표 여러 개를 돌게 하면 틀린다 — ⚠️ 규정 PDF 확인(앞 계약서 §8-6).
3. **C 의 LiDAR 우선**: ORBIT 중 ±25°·5 m 안의 다른 반사(게이트·회피 부표, 도크, 다른 배)를 따라갈 수 있다. 지금은 카메라가 색으로 다시 잡아 주던 것이 LiDAR 가 이기면 안 된다. 완화 — 연속 매칭(직전 LiDAR 방위가 다음 기대값)은 이미 있음. 실해역 부표 간격이 5 m 안이면 ⚠️.
4. LiDAR 높이 = 부표 높이 ⚠️ 미확인(CLAUDE.md §8). LiDAR 가 부표를 못 보면 C 는 카메라로 떨어져 ③ 그대로 → 60–70° 에서 이탈. 1번배 11-11 실해역 점검(라이다 막대 미검출·각도 조정) 결과와 같이 봐야 한다.
5. DONE 래치 뒤 20000 이면 GPS 가 WP 좌표(=부표 위치로 녹화된 경우)로 향한다 — hold 의 DONE 과 같은 동작이고 도착 반경 3.5 m 에서 넘어간다. 탐색 부표 접촉은 프로토 10 런 0.
6. `north_goal_angle` WP 시간 초과(mode 3 90 s/WP)가 orbit 도중에 오면 WP 만 바뀌고 모드는 3 그대로 → ship_turn 은 영향 없음. 마지막 mode 3 WP 가 시간 초과면 orbit 이 잘린다.
7. 반경 ≈ 4 m(목표 3) 는 그대로 — 규정 반경 제한이 있으면 별도.
