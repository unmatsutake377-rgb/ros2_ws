# 변경 계약서: ship_dock APPROACH 와 ship_back HOLD forward 의 /candidate_angle 조향을 ±80° 로 클램프 — 정확히 180.0(후진 신호)이 우연히 나오지 않게

작성: ssf-contract (2026-11-04). 배경: 계약서_후진통과_20261104 §3 표, §6 위험 3, §10 결정 6. 상태: **승인됨** (§10). 줄 번호는 9c7d0a4 기준(착수 때 재확인).

## 0. 결함과 현재 도달 가능성
- 후진통과(7ae1383) 뒤 `/candidate_angle` 180.0 은 "신선하면 260 후진". 무클램프 경로 둘:
  - **ship_dock** APPROACH `self.publish(angle)`(`:317`), angle = image_angle 그대로(`:251`). |angle| > 25 발행은 contact 1.0 < dist < realign_min 1.5 m 구간뿐(`dock_fsm_logic.py:49-50`) → 180 이 나온다면 도크 바로 앞.
  - **ship_back** HOLD forward `publish(rel_to_raw(rel))`(`:250`), rel = clamp_pm180(image_angle)(`:133`). 입력이 180 홀수배면 정확히 180.0. 단 선미 방향(LiDAR −100°)에 2.9 m 넘는 물체가 있어야 forward.
- **지금 화각에서 동작 변화 없음**: 검출기 각 = −atan((vX−cx)/fx)(`vision_geom.py:88-90`) → |각| ≤ hfov/2 = 31.95°, atan 이라 hfov 무관 늘 < 90°. 10000·NaN 은 먼저 걸러짐(`ship_dock.py:196`, `ship_back.py:130`). ship_back LiDAR 대체 ±30°. 시뮬 카메라도 ≤ HFOV/2.
- (B) 경계: +80 → 160, −80 → 280 → 0 (양끝 포함) → ±80 은 정상 조향 범위의 정확한 끝.

## 1. 변경 단위 (노드별 두 커밋, B1 → B2)
1. **B1 ship_dock**: 모듈 상수 `STEER_LIMIT_DEG = 80.0`(ship_turn.py:65-68 과 같은 이름·주석). `publish_steer(rel)` = `publish(clamp(rel, −L, L))`, 부호 있는 값 그대로(rel_to_raw 안 끼움 — blackbox 값 표기 유지). `:317` 만 교체. BACKOFF `:335`(180)·SPIN·STOP 그대로. approach_decision(`:306-309`)·ALIGN(`:284`)·spin_toward(`:291`)에는 클램프 전 값. docstring [7] 한 줄.
2. **B2 ship_back**: 같은 상수. `:250` → `publish(rel_to_raw(clamp(rel, −L, L)))`(ship_turn.py:269 와 같은 순서). `:133` clamp_pm180·buoy_rel 은 그대로(LiDAR 매칭 방위 유지). `:252` 180 그대로.
- 둘은 독립, 어느 쪽만 들어가도 안전. ship_turn·dock_sim·ship_direction·test_candidate_reverse 는 안 건드림.

## 2. 토픽
`/candidate_angle`(발행, 조향값 범위만 |rel| ≤ 80), `/image_angle`·`/scan`·`/wp_mode`(구독, 불변). 새 토픽 없음. 모드별 발행자 수 불변.

## 3. 특수 상수·규약
- 80 은 튜닝값 아닌 하류 프로토콜 상수((B) 0~160, LIDAR_FORWARD_DEG 80).
- 5000/6000/20000/50000·180(후진) 발행값 그대로, 클램프는 조향 경로만.
- 부호 그대로. 180 입력 → ship_dock +80(좌), ship_back −80(우).
- NaN: `max(−80, min(80, nan))` = +80 → 상류 NaN 가드 유지 필수.
- 범위 밖 입력: 지금 80 < |rel| < 180 → STOP_HOLD+warn, 정확히 180 → 후진. 바뀐 뒤 둘 다 ±80 최대 조향 전진. 현재 검출기로는 둘 다 도달 불가.

## 4. 파라미터
권고: **모듈 상수**(파라미터 아님). (a) ship_turn 이 같은 값을 상수로 둠(`ship_turn.py:67`) (b) §1-4 대상(배별 실측값) 아님 (c) 파라미터면 180 이상 설정으로 사고 재현 가능, ship_dock 은 yaml 이 대회에 안 실림 (d) §1-8 공유 모듈 금지 → 노드마다 정의, reviewer 6번 점검 대상.

## 5. 위험
1. 클램프를 판단 앞에 넣으면 재정렬 판단·LiDAR 매칭 방위가 바뀜 → 발행 직전에만.
2. NaN → +80 (상류 가드 의존).
3. ship_direction "candidate 매핑 범위 초과" warn 이 사라지고 조용히 최대 조향(§1-6).
