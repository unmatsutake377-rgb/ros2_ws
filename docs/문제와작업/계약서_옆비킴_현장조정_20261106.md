## 핵심 요약 (코드 확인 사실)
1. 비킴 각(20/140)은 0~160 일반 조향값이라 레이트 리미터를 거친다(`ship_direction.py:544-572`). 단 직전 출력이
   260·50000 이면 리미터 상태가 None 이라 바로 건너뜀(`:559-561`) — B 상황(후진·쿨다운 뒤)은 첫 틱부터 60° 꺾음.
2. `away_deg > 80` 위험: 목표각이 0~160 밖이면 motor_control 에서 −10 은 분기(6) 직진, 170 은 분기(5) 후진
   (`motor_control.py:293-314`). 가드 `0 < away_deg ≤ 80`.
3. 시제품은 비킴 틱에 `_side_prev` 를 남기지 않고(`:868-869`), `_reset_reverse_sequence()` 로 후진 0.5 s 도중에도 끊는다.
4. 시뮬 접촉 모델은 선체 중심 원(반경 0.29, `full_course_sim.py:648-649`) → 1.66~1.77 m 선체의 **선미 휘두름 접촉은
   시뮬로 못 봄**. 지오펜스도 시뮬에서 꺼짐(`:76`).
5. hold_dist_m 은 yaml 만 바꿔도 반영: launch 가 `parameters=[_pkg_yaml('ship_back'), params['ship_back']]`
   (`launch_files.launch.py:92-93`), 노드는 시작 때 한 번만 읽고 파라미터 콜백 없음(`ship_back.py:102`, src grep 0건)
   → `ros2 param set` 은 소리 없이 효과 없음.
6. hold_dist_m 은 다른 노드 값과 묶임: north `arrive_radius_hold_modes_m: 3.5` 주석 "> hold 2.5 + tol 0.4 = 2.9"
   (`north_goal_angle.yaml:42`), `los_logic.py:124` `SHIP_BACK_HOLD_OUTER_M = 2.9` 하드코딩, `test_los_logic.py:256-264` 가
   ship_back.yaml hold+tol 과 같은지 검사. 3.5 로 올리면 유지 띠 바깥 3.9 > north 반경 3.5 인데 WARN 안 남(상수 2.9 를 봄).
   저장소 yaml 을 바꾸면 그 테스트가 깨짐. 발견 2 의 3.5 시뮬은 north 반경 3.5 그대로.

## 위험
1. 목표 사이 호 미검사: 정면 ±10°·tgt ±15° 만 봄 → tgt 20 이면 35~70°(리미터가 쓸고 지나가는 곳)에 0.5 m 장애물이 있어도 비킴.
2. 선미 휘두름: 우회전 시 선미가 좌현(장애물 쪽)으로 돎. `|center−80|` 상한이 없어 정횡(150~160) 0.3 m 에서도 발동.
   시뮬 원형 선체라 측정 불가. LiDAR 의 선체 길이 방향 위치 미확인. 실배 확인 필요.
3. 후진 도중 끊김·진동: 정면 최솟값이 0.8 근처에서 흔들리면 260↔20 이 0.1 s 단위로 바뀔 수 있음(리미터가 못 막음).
4. hold_dist 3.5: north 반경 3.5 < 유지 띠 3.9, WARN 없음(`los_logic.py:124`). hold+tol ≥ 5.0 이면 HoldTimer 리셋
   (`hold_logic.py:179`) → 60 s 뒤 포기. yaml 에 정수(`3`)면 ship_back 부팅 실패, mode 2·3 침묵(`launch_files.launch.py:50`).
5. 지오펜스: tgt 창 검사는 병합 뒤 distance_array 라 신선한 경계 포함. stale 이면 못 봄(기존 (C) 도 같음). 시뮬 미검증.
