## 당일 순서 (09-23 작성, 수조 5×5m)

브릿지 재시작 = 아두이노 리셋 = ESC 재시동 20초. 아래 순서는 재시작을 **3회**로 묶은 것이다.

**0. 전날**: `git pull && colcon build --symlink-install && tools/run_tests.sh` 310 passed. 부표 2개(30~40cm, 절반 잠기게), 줄자, 폰 나침반.

**1. 벤치(물 밖)**: 배터리 1·2 → 5·6. 조종기 SWA~D 위·스로틀 아래로 켬. 아두이노 USB 직결. `sudo tools/boat_boot.sh` → 메인 launch → 터미널 2 `ros2 launch ssf_tools ssf_tools.launch.py` → 터미널 3 `mission_monitor`.
`/scan` hz, `/imu/yaw`, `/boat_mode` 가 RC 따라 1↔2. **IMU 재부팅 재현**(정북 `/imu/yaw_raw` → 전원 분리 → 재측정. 같으면 mount_offset 확정, 다르면 보고하고 IMU 는 건너뜀). 부표 3m 앞 바닥에 놓고 `obstacle_min_dist` 확인. **프로펠러 뺀 채** AUTO 로 `/desired_angle 80.0` 양쪽 도는지.

**2. 조향 부호**: 메인 launch 내림(라이다 Ctrl+C). `ros2 launch ssf_bridge ssf_bridge.launch.py` + `ros2 run motor_control motor_control --ros-args --params-file …/motor_control.yaml`. 중앙에서 `5000.0` → 오른쪽 돌면 정상, 왼쪽이면 `steer_invert: true`.

**3. max_diff**: 5000/6000 각 6초 2~3회, 블랙박스 `gyro_z`.

**4. reverse_pwm 방향**: `260.0` → 뒤로 가야. 앞으로 가면 즉시 정지·보고. `/motor_reverse` True 확인.

**5. base_pwm**: 코너에서 대각선 직진 `80.0`, 반대 코너 1m 전 `50000.0`. `-p base_pwm:=1400 / 1360 / 1300` 으로 motor_control 만 재시작(param set 은 런타임 반영 안 됨). `gps_vel` 또는 줄자 3m + 폰 영상. 1.2m/s 값 채택.

**6. 게이트 2m (핵심)**: 부표 2개 정중앙 2.0m 간격. 배 코너, 진입 3.5m. motor_control 내리고 메인 launch 복귀(ESC 20초 — 마지막 재시작). `ros2 topic pub -1 /wp_mode std_msgs/msg/Int32 "{data: 1}"` → AUTO. 3회.
통과 → 0.29/0.25 확정. 후진 반복 → clearance 0.20. 스침 → 0.30. 코너에서 벽 회피하려 들면 첫 1m 수동으로 밀고 AUTO.

**7. hold_dist_m**: 부표 하나 중앙, `/wp_mode` 2. 정지 거리만.

**8. 정리**: 라이다 Ctrl+C. `~/ssf_logs/blackbox_*.csv` 보관·채팅에 업로드.

## 반영 규칙

- 값 하나 바꿀 때 **세 곳**을 같이: yaml · 노드 `declare_parameter` 기본값 · 해당 테스트의 fake 값. (half_width 가 세 곳에 따로 있어서 09-23 에 걸렸다.)
- 바꾼 줄의 `⚠️ 실측 필요` 주석을 지우고 `실측 09-XX: 조건(PWM/속도/FIXED 여부)` 로 바꾼다. 근거 없는 숫자로 되돌아가지 않게.
- 커밋은 값마다 따로. 메시지에 **측정 조건과 원시 수치**(예: `1360 → 1330, gps_vel 1.18m/s, FIXED`).
- 블랙박스 CSV(`~/ssf_logs/blackbox_날짜.csv`) 는 지우지 말고 커밋 메시지에 파일명.
