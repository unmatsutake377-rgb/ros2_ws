# 변경 계약서: 대회·벤치 launch 에 `boat` 인자를 두고, `yaw_mux` 의 배별 IMU 값(`mount_offset_deg`·`invert_yaw`)을 배별 파일에서 읽게 한다

> ssf-contract 작성 2026-10-29. 상태: **Davidson 승인 대기** (방향 동의, "문제 실재 확인 후 진행")

## 0. 문제 실재 확인 (코드 근거)

**구조적 문제는 실제로 있다. 아직 터지지 않았을 뿐.**
- 두 launch 모두 파일 하나 고정: `launch_files.launch.py:77-79`, `ssf_heading.launch.py:19-20` → `ssf_heading.yaml`. 두 값은 `ssf_heading.yaml:30-31` `yaw_mux:` 에 한 벌. 배 분기 경로는 `gps_config`(`launch_files.launch.py:35-37`) 하나뿐.
- 아직 안 터진 이유: 두 값이 0.0/false(미측정). 이 줄을 바꾼 커밋은 `ace1e33` 하나뿐. C5(`과제_목록_전체.md:58`)가 "조립 완료 후"로 막혀 있음 → **두 번째 배를 C5 로 잴 때 처음 충돌**. 이 변경은 C5 보다 먼저 들어가야 의미가 있다.
- `/boat_id` 재사용 불가: 펌웨어 "ID 스위치 불가(팀 결정)", 미배선이면 `DEFAULT_BOAT_ID BOAT_A`(`ssf_boat.ino:505-511`) → 두 배 모두 0. 런타임 토픽인데 `yaw_mux` 는 생성자에서 한 번 읽음(`yaw_mux.py:56-57`). 브릿지는 포트 없으면 안 뜸(`ssf_bridge.launch.py:26-29`).
- `gps_config` 가 같은 실패를 이미 겪는 중: 기본값 F9P(B)(`launch_files.launch.py:36`), 운용 문서 launch 명령엔 인자 없음(`ros2_운용법.md:152`, `ubuntu_setup.md:301`, `boat_launch_checklist.md:68`), 인자를 적은 곳은 `tank_test_plan.html` 뿐 → "기본값 + 사람이 기억" 방식은 이미 실패 중.
- 전제: C5 ① 에서 재부팅마다 `/imu/yaw_raw` 정북값이 달라지면 `mount_offset_deg` 자체가 무의미(→ `cog_offset`). `invert_yaw` 는 기본 소스 `imu_relative` 인 한 배마다 필요.

**제안의 부작용**
1. 인자를 필수로 하면 문서의 launch 명령이 전부 거부됨 — 고칠 곳: 위 문서 3곳, `.claude/agents/ssf-verifier.md:20`, `문제별_설명과_대응방법.md:352`(소문자 `boat:=a`, 없는 인자).
2. 벤치 launch(`ssf_heading.launch.py`)에도 같은 인자 필요 — 없으면 C5 보정 중 다른 배 파일을 고칠 수 있음.
3. 새 yaml 은 `setup.py:16` glob 이 빌드 때 잡음 → pull 후 재빌드 필요.
4. `check_params.py` 는 파일별 대조 → 두 배 파일을 다 넣으면 실측 뒤 안 실린 배 파일이 매번 거짓 '불일치'.
5. "나중에 같은 인자로 half_width·base_pwm·steer_invert" 는 공짜가 아님 — `ship_direction`·`motor_control` 은 `parameters=` 없이 뜸(`launch_files.launch.py:240-255`, §1-4). 배별 파일을 붙이면 처음으로 yaml 이 코드 기본값을 덮음 → 별도 계약, §6 시뮬 파라미터에 닿을 수 있음.

## 계약

- **변경 단위**: `yaw_mux` 설정 경로(노드 코드 불변). 한 커밋: `ssf_heading.yaml`(두 키 제거 + 주석), 신규 `ssf_heading_A.yaml`·`ssf_heading_B.yaml`(`yaw_mux:` 절에 두 키만, `0.0`/`false` + `# ⚠️ 실측 필요`), `ssf_heading.launch.py`·`launch_files.launch.py`(`boat` 인자, 공통 → 배별 순서), `tools/check_params.py`(배 인식). 문서(CLAUDE.md §1-4, 상세 §1-4·§3-5, 운용 문서 3곳, tank_test_plan, verifier 정의)는 다음 커밋 가능. 두 단계면: ① 배별 파일 + launch 전달(공통 키 유지, 값 같아 결과 동일) ② 공통 키 제거.
- **토픽 계약**: 변경 없음. `/imu/yaw_raw`(구독, iahrs_driver), `/ublox_gps_node/fix_velocity`(구독), `/motor_reverse`(구독, motor_control.py:82), `/imu/yaw`(유일 발행 → ship_goal_angle·north_goal_angle·ship_turn·healthcheck·blackbox), `/heading_status`(발행 → healthcheck).
- **특수 상수**: 닿지 않음. `/boat_id` enum(0=A, 1=B)과 인자 대소문자 맞출 것 — 기존 문서끼리 이미 어긋남(`ssf_tools.launch.py:5` `boat:=b`, 문서 `boat:=a`).
