# 변경 계약서: ship_dock — LiDAR 거리 None 가드를 APPROACH 에만, CONTACT/BACKOFF 는 거리와 무관하게 진행 (11-06)

상태: **승인 (11-06 팀장)** — ① APPROACH None: 정지 유지하되 30 s 타임아웃은 진행(→BACKOFF), 표식 유실→SEARCH 는 현행(차단) ② BACKOFF None: 스캔이 신선한데 전방 반환 없음(②)이면 후진, /scan stale(①)이면 STOP + ERROR ③ 8 s 타임아웃 None → 현행 backoff_timeout(STOP 유지) ④ 로그 심각도 제안대로 ⑤ 시뮬 최소 측정거리 모사는 별도 ⑥ 보고서 표 = Ⅲ-11 (근거 docs/문제와작업/시뮬3자유도_발견_20261106.md 발견 1)

## 핵심 요약
- 결함: `ship_dock.py:402-406` 의 `dist is None and state in (APPROACH, CONTACT, BACKOFF) → STOP_HOLD; return` 이
  CONTACT 3 s(494-498)·BACKOFF 8 s/거리 판정(501-517)·APPROACH 표식 유실→SEARCH(469-471)·30 s→BACKOFF(472-475) 보다 앞 →
  None 동안 상태 전이 평가가 통째로 차단. (`state_t` 시계는 흐르므로 거리가 돌아오면 그 틱에 즉시 전이.)
- None 원인 둘, 코드는 구별 안 함(`front_min_dist` 333-364): ① /scan 없음·stale(>1.0 s) ② 스캔은 신선한데 전방 ±15° 에 유한·양수 반환 없음
  (최소 측정거리 미만 / 25 m 안에 아무것도 없음). 실물 벽 밀착은 ②. 드라이버 range_min=0.15(`rplidar_node.cpp:257`), 실제 하한 미확인.
- 변경 단위 = ship_dock 하나. 토픽·QoS·특수 상수·파라미터 변경 없음. 순수 판정은 dock_fsm_logic.py 로.
- 시뮬(full_course_sim·dock_sim)은 실제 ship_dock.py 를 import → 자동 반영. ssf_sim 은 무관.

## 위험
1. BACKOFF 를 None 에도 후진시키면 LiDAR 사망(①)에도 뒤 못 보고 8 s 후진 → 결정 2.
2. 거리 복귀 틱에 즉시 전이(`elapsed` 가 state_t 기준). 수정 후 CONTACT·BACKOFF 는 해소, APPROACH 는 결정 1.
3. BACKOFF 중 선수가 돌아 전방에 도크가 안 잡히면 dist ≥ 2.5 를 못 보고 8 s 뒤 backoff_timeout → 남은 WP 동안 STOP(기존과 같음). 결정 3.
4. 테스트 스텁 `LaserScan=object` — None 은 `fresh_sensors(dist=inf)` 또는 `last_scan_t=None/stale` 로. 기존 테스트는 None 경로를 안 밟아 안 깨짐.
5. `full_course_sim._backoff_by_dist`(846-853)는 BACKOFF→DONE 간격 < 8 s 로 거리 도달 추정 → 전후 비교 때 done_reason 로그로 교차 확인.
6. 문서 `소프트웨어_동작설명서:294` "거리를 모르면(APPROACH·CONTACT·BACKOFF) 멈춘다", `dock_fsm_logic.py:6`·`test_dock_fsm_logic.py` 헤더가 거짓이 됨 → 같은 커밋에서 갱신.

## 사람이 정할 것
1. APPROACH None 동안: (a) 30 s 타임아웃만 진행(STOP 유지하다 BACKOFF) (b) 타임아웃+표식 유실 둘 다 진행 (c) 현행 차단 유지 — 검사관 권고 (a)
