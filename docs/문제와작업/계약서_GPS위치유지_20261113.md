1. **기본 `hold_source: gps`**(코드 기본값 == yaml == gps). 부표 비전 경로는 `hold_source: vision` 옵션으로 그대로 남김.

2. **위치유지 WP = 부표 옆 대기점**(부표에서 2~3 m 떨어진 물 위 점을 녹화). 부표 좌표에 찍지 않음(GPS 필터 지연 ~1 m + 관성 → 접촉 위험).
   → 11-13 검증 시뮬(합성, 92 조건 × 40) 뒤 **약 1.5 m(허용 1.0~2.0)** 로 좁힘: 2.5 m 는 조류가 부표 반대쪽으로 밀 때 부표 5 m 밖인데 성공으로 셈. 조류 있으면 부표가 위쪽·대기점이 아래쪽. 정지는 WP 앞 ≈1.5 m(GPS 지연 ≈1.0 + 관성 ≈1.1).
3. **5 초 판정 = 반경 4.5 m 안 연속 6 s**, 벗어나면 0 부터 다시(`gps_keep_radius_m 4.5`, `gps_hold_time_sec 6.0`).
4. 조류 대응 = 정지 + 반경 넘으면 재접근(후진 안 씀). 범위 mode 2 만(search_behavior:=hold 의 mode 3 는 vision 경로 그대로).

## 2. (나) 동작 정의 (구현)
상태 이름은 그대로(INIT/SEARCH/HOLD/DONE — 시뮬 분류가 "HOLD" 문자열 사용, full_course_sim.py:1001).
1. INIT: 20000 1 s.
2. SEARCH: 20000(north 가 WP 로 데려감). **쓸 수 있는 거리** < `gps_enter_m` 이면 HOLD.
3. 쓸 수 있는 거리 = 유한 ≥ 0, 수신 후 `goal_dist_stale_sec` 안, **모드 진입 1.0 s 뒤에 받은 값**(진입 가드 — 직전 WP1 의 ≈0 m 오판 방지, ship_dock.py:90-95 와 같은 장치).
4. HOLD(GPS): 거리 > `gps_resume_m` 이 될 때까지 50000 → 넘으면 < `gps_enter_m` 이 될 때까지 20000(재접근은 north/ship_direction) — 직전 출력 기억 히스테리시스.
5. 판정: `HoldTimer(gps_keep_radius_m, gps_hold_time_sec)` 를 GPS 거리로 — 반경 안 연속, 이탈 시 재시작 → 만족하면 DONE(20000) → north 가 반경 안 dwell 0.5 s 채우고 다음 WP.
6. 거리 없음(stale·미수신): 50000, `unknown_giveup_sec`(10) 뒤 DONE. `hold_max_sec`(60) 그대로.
7. GPS 모드는 180(후진)·조향각을 **내지 않는다**(GPS 1 Hz·필터 지연 — 후진 방향 모름, 후진 추력 미실측).
8. `/goal_distance` 구독은 `hold_source == gps` 일 때만 생성(vision 이면 DDS 그래프 지금 그대로).
9. 🚨 제약: `gps_enter_m ≥ north arrive_radius_hold_modes_m(3.5)`, `gps_resume_m ≥ gps_enter_m`, `gps_keep_radius_m > gps_resume_m` — 위반 시 시작 가드 ERROR + 기본값(check_hold_params 패턴, hold_logic.py:22-64) + 교차 패키지 테스트(test_los_logic.py:256 방식).
   (20000 동안 배가 3.5 m 안이면 north 가 dwell 0.5 s 로 WP 를 넘겨 정지 전에 끝나 버린다 — wp_advance.py:68-83.)

## 6. 조류·GPS 영향
- 작년 문제(ship_back.py:4-5): 정지만 하면 0.5 m/s 조류에 5 s 2.5 m 밀림 → resume 히스테리시스로 재접근.
- GPS 필터 지연(gps_filter.py:60-72, α 0.15/0.30, 1 Hz): 지연 ≈ v(1−α)/α — 접근 0.6 m/s ≈1.4 m, 표류 0.5 m/s ≈1.2 m(계산, ⚠️ 미실측) → 실제로 ~1 m 늦게 섬(대기점 WP 로 대응), 표류 때 거리값이 안쪽으로 나와 거짓 성공 가능(keep 4.5 로 여유).
- RTK FIXED ±1.5 cm 무시 가능. FLOAT 품질은 `/goal_distance` 에 안 실림(⚠️).
