## 1. 🚨 아두이노는 노트북 USB 에 **직결**이어야 한다 (배치에 직접 영향)

**RC 수신기(FS-iA6B)는 자체 배터리가 없다. 아두이노 5V 로 돌아간다.**
그 5V 는 노트북 USB 에서 온다. 즉 **USB 경로가 곧 조종 계통의 전원 경로**다.

실측 (조종기 텔레메트리 `IntU1` = 수신기가 실제로 받는 전압):

```
버스전원 허브 경유  :  4.09V   ← FS-iA6B 최소 동작 4.0V. 여유 0.09V
노트북 직결        :  4.70V   ← 정상
```

🚨 **4.09V 에서도 RC 는 동작하고 있었다.** 경보만 떴다 — 그래서 놓치기 쉽다.
조금만 더 처지면 수신기가 꺼지고 **수동 조종을 통째로 잃는다.**

**고정할 배치:**

| 장비 | 자리 | 이유 |
|---|---|---|
| **아두이노 Mega** | **노트북 직결 (필수)** | 수신기 전원이 여기 달렸다 |
| 카메라 D455 | 허브 가능 | 뎁스를 끈 뒤 30.0fps·오류0 확인 (§2) |
| LiDAR · IMU · GPS | 허브 | 전부 12Mbps 시리얼 |

**할 일:** 배선·배치·운용 문서에서 USB 포트 배정을 다루는 곳을 찾아 이 표로 맞춰라.
노트북 외부 USB 포트가 **2개뿐**이라는 것도 명시해라(실측: Bus3 Port1 / Port9).

⚠️ **전원 공급형(powered) 허브를 쓰면 이 제약이 사라진다.** 구매 목록에 없으면 추가를 제안해라.

## 2. 카메라 뎁스 스트림을 껐다 — 켜면 D455 가 USB 에서 떨어진다

실측:

```
컬러+뎁스 : 컬러 10.8fps · 뎁스 0.6fps · 최대공백 1.75s
            2분간 USB 끊김 13회 · 드라이버 오류 583,090 줄
            (xioctl(VIDIOC_QBUF) failed ... No such device 무한 재시도)
컬러 전용 : 30.0fps · 최대공백 0.03s · 오류 0 줄
```

**배제한 원인** — 같은 길을 다시 파지 마라:

```
허브 경유        → 노트북 직결로 바꿔도 그대로 10fps
USB 2.0 로 붙음  → SuperSpeed(5000M) 확인했는데도 그대로
USB autosuspend  → boat_boot.sh 적용(autosuspend=-1) 후에도 그대로
측정 코드 병목   → camera_info(작은 메시지)로 재측정해도 같은 수치
```

`enable_depth: False` 로 `launch_files.launch.py` · `camera.launch.py` 둘 다 반영했다.
**안전한 근거: 뎁스를 구독하는 코드가 하나도 없다.** V1(07-23)에서 비전 3종의 depth 의존을
제거했고 거리는 LiDAR `/scan` 에서 얻는다(CLAUDE.md §3-3). 전수 검색으로 재확인했다.

**할 일:** `cam_stream_*` 계열과 `수동조종_카메라영상_설계.md` 가 컬러 토픽만 쓰는지 재확인하고,
문서에 "뎁스는 꺼져 있다" 를 명시해라. ⚠️ 뎁스를 되살릴 계획이 있으면 **USB 케이블부터 교체해서**
재측정할 것 — 마지막까지 남은 의심은 케이블 품질이다.

## 3. 브릿지가 시리얼 포트를 열면 아두이노가 리셋된다 (운용 제약)

`ssf_bridge` 가 `/dev/ttyMEGA` 를 여는 순간 DTR 이 걸려 보드가 리셋된다.

```
브릿지 재연결  →  아두이노 리셋  →  스러스터 중립
               →  ESC 재시동 대기 15~25초  →  그동안 배가 안 움직인다
```

**할 일:** 운용·체크리스트 문서에 넣어라.

```
· 경기 중 브릿지를 재시작하지 않는다 (20초 공백 = 그 판을 날린다)
· launch 순서상 브릿지는 한 번만 띄운다
· 출발 전 점검에서 ESC 시동을 확인한 뒤에는 브릿지를 건드리지 않는다
```

## 4. 같이 반영할 부수 항목 4개

**(a) LED 스트립 밝기 상한 40.** 스트립도 아두이노 5V 를 수신기와 공유한다.
자율 모드의 노랑이 전류가 제일 크다(채널 2개 점등). 40 에서 합계 0.33A,
USB 폴리퓨즈 0.5A 안에 들어온다. **더 올리려면 전원을 먼저 분리할 것.**

**(b) 배터리 연결 순서: 1·2번 먼저 → 5·6번.** 네 ESC 가 동시에 전원을 받아야 한다.
순서가 바뀌면 일부만 시동이 걸린다.

**(c) 라이다는 Ctrl+C(SIGINT)로 끈다.** 강제 종료하면 정지 명령이 안 가 라이다가 스캔
상태로 남고 **다음 실행이 `SL_RESULT_OPERATION_TIMEOUT` 으로 실패한다.** 복구는 USB 재삽입.

**(d) 🚨 라이다 개체마다 각분해능이 다르다 — A배/B배 배정에 영향.**

| 개체 | 시리얼 | 상태 | 한 바퀴 점 / 분해능 |
|---|---|---|---|
| 1번째 | (무응답) | 🚨 **케이블 단선** (빨강 VCC·노랑 TX·초록 RX) | — |
| 2번째 | `D5F1ED93…` | ✅ | 1248점 / 0.275° |
| 3번째 | `80BFED95…` | ✅ | 1439점 / 0.250° |

회전수는 파라미터로 못 맞춘다(드라이버가 `setMotorSpeed` 에 값을 안 넘긴다).
즉 **두 배의 각분해능이 서로 다른 채로 나간다.** `min_obstacle_cells` 처럼 점 개수에
의존하는 튜닝값은 개체마다 다르게 동작한다.

**할 일:** 배별 설정 문서에 **어느 배에 어느 시리얼을 실었는지 적는 칸**을 만들어라.
그리고 고장품 본체에 물리적 표시가 필요하다는 것을 구매·점검 목록에 넣어라 —
라벨이 지워져 겉으로 구분이 안 되고, **이미 두 번 같은 진단을 반복했다.**

## 5. 답이 필요한 질문 3개

1. **뎁스 영상을 쓸 계획이 있는가?** 지금은 구독자 0개라 껐다. 쓸 계획이면 알려달라
   (USB 케이블 교체부터 다시 검증해야 한다).
2. **전원 공급형 허브를 살 수 있는가?** 있으면 USB 포트 배정 제약이 통째로 사라진다.
3. **마스트·박스 설계에서 아두이노 USB 케이블 경로가 확보되는가?** 노트북 본체 포트까지
   직결이어야 하고, 케이블이 길거나 얇으면 5V 가 처진다. 경로 길이를 알려달라.
