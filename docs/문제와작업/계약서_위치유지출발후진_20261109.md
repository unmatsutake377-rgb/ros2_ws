## 6. 위험
1. **해제 뒤 되돌아감 — 시제품에서 확인됨(부록 A).** 180 받는 동안 north 는 dwell 을 안 셈. 해제 거리(4.5) > 도착 반경 3.5 이면 해제 뒤 north 가 다시 WP(=부표 좌표) 쪽으로 몰아 **부표 1.36 m 까지 재접근**한 뒤 출발. 시간 +23~37 s 의 주원인. 실제 대회 WP 를 부표 위에 찍는지 ⚠️ 미확인.
2. **후진 중 뒤를 아무도 안 봄.** ship_direction (B) 는 180 을 그대로 260(:1001-1006), 경계 가드 구조상 후진 미적용(:176-178), 후방 섹터 읽는 노드 0(grep). 최대 8 s, 실배 1590 후진 속도 §8 미실측.
3. `_front_nearest` 는 색 구분·median 없는 원시 최근접(:252-268) — 물보라·다른 부표에 걸림. 180↔20000 매 틱 전환 시 ESC 전·후진 급전환(즉시 전환 가능 여부 미확인, 계약서_목표근접감속 위험 6). 래치/히스테리시스 결정.
4. `front_sector_half_deg` 재사용 시 HOLD LiDAR 보조(:146, :285)와 묶임.
5. 조류가 계속 미는 경우 max_sec 끝에 거리 < dist 인 채 20000 → 지금과 같은 접촉, 8 s 늦게. WP 시간 초과(mode 2 120 s, 3 90 s)는 그대로.

안전 요약: 상한 max_sec, stale 이면 후진 안 함, 포기 DONE(hold_max·unknown_giveup·search_timeout) 미적용(시제품, 결정 4). 5·7·8 모드는 timer_cb 즉시 return(:307) 침묵. L2·STOP_HOLD 가 (0) 단계 우선, L1 상한 후진에도. 워치독 충돌 없음. /motor_reverse→yaw_mux 는 cog_offset(사용 금지)에서만 의미.
규정: HoldTimer 성공(5 m·5 s) 뒤 시작 → 위치유지 점수 무관. 종합임무 시간 점수 반영 방식 ⚠️ 미확인.

### 시제품 코드 (스크래치 `proto_depart.py`, full_course_sim 의 ShipBack 클래스 몽키패치 — src 미변경)
```python
def patch(F, depart_dist, depart_max):
    C = F.SB.ShipBack
    orig_set, orig_timer = C.set_state, C.timer_cb
    def set_state(self, s):
        if getattr(self, "state", None) == "HOLD" and s == "DONE":
            self._dep_t = F.SB.time.monotonic()
        orig_set(self, s)
    def timer_cb(self):
        if self.wp_mode in self.active_wp_modes and getattr(self, "_dep_t", None) is not None:
            now = F.SB.time.monotonic()
            if now - self._dep_t <= depart_max and self.state in ("DONE", "INIT", "SEARCH") and \
               (self.state != "SEARCH" or self.last_seen_t is None or self.last_seen_t <= self._dep_t):
                d, _ = self._front_nearest(now)
                if d is not None and d < depart_dist:
                    self.publish(F.SB.REVERSE_REL); return
                self._dep_t = None
            elif now - self._dep_t > depart_max:
                self._dep_t = None
        orig_timer(self)
    C.set_state, C.timer_cb = set_state, timer_cb
```
