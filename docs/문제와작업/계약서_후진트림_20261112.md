## 2. 부호 규약
- `apply_steer(+s)` = (pwm_r = c−s, pwm_l = c+s) 는 전진·후진 모두 좌선회(CCW). 후진(c=1590)에선 좌측이 더 후진 → 좌현이 뒤로 끌림 → 좌선회.
  검산: full_course_sim.py:753-754 `w = K_W·(TL−TR)`, boat3dof.py:11·58 `N = Σ −y·T`.
- **후진 좌선회 보정 = 우측을 더 후진**: t > 0 → pwm_r = 1590+t, pwm_l = 1590−t (= apply_steer(−t, center=reverse_pwm)).
  t > 0 = 후진 중 물리적 시계 방향 보정. steer_invert 는 apply_steer 를 거치므로 같이 뒤집힌다.
- PWM: ROS >1500 = 후진, 1590 = 중립 +90 µs(브리지 3000−pwm → 시리얼 1410, bridge.py:177). ESC 데드밴드 ±25(실효 65 µs).
- L1(0.7): 좌우 각각 apply_slow → 트림도 0.7배(t=10 → 1570/1556). /motor_reverse: 좌우 평균 1590 유지 → 판정 불변(:241).

## 6. 실측 절차 (11-13 아침, 코드 없이 가능 — 값은 이걸로만 정한다)
1. 대회 launch(ssf_bridge) 끄고 `python3 tools/hold.py <L> <R> 3` (시리얼 원값, AUTO, 시동 대기 15 s). ROS 1590/1590 = 시리얼 L1410 R1410.
   트림 t = L 1410+t, R 1410−t (ROS pwm_r = 1590+t 와 같음).
2. 헤딩 = /imu/yaw_raw 전후(1번배 시계 증가 확인됨) + 영상·육지 표적.
3. t=0 2~3회 → 평균 Δψ0(좌선회면 음수). **|Δψ0| < 5° / 3 s 면 여기서 끝(트림 0).** 아니면 t=+15 2회 → k = (Δψ15−Δψ0)/15,
   t* = round(−Δψ0/k), t* 로 1~2회 확인. L1 수준(L1462 R1462)도 1회.
4. t* 를 1번배 노트북 motor_control.yaml `reverse_trim_us` 에 정수로(커밋 안 함) → launch 재시작 → 시작 로그 확인.
   🚨 hold.py 의 t 는 시리얼 채널 기준이다. 코드의 t 는 apply_steer 를 거쳐 steer_invert 와 같이 뒤집히므로,
   1번배 yaml `steer_invert: true` 면 t* 의 **부호를 뒤집어** 넣는다(측정 전 steer_invert 값부터 확인 — 리뷰 권고 1).
   `reverse_pwm − |t| ≥ 1540` 유지(L1 0.7 에서 t 53~64 면 약한 쪽이 데드밴드 ±25 안 — 리뷰 권고 2, 가드 개선은 대회 뒤).
