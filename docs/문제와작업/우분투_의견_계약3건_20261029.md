## 0. 순서

**① WP 타임아웃 → ② GPS C1(신선도) → ③ GPS 실물 시험(인계 §2 ①②④) → ④ GPS C2(ublox 직접 선언 + respawn) → ⑤ 배별 IMU (C5 정북 보정 전)**

- 타임아웃을 먼저: 노드 하나짜리 작은 변경, GPS 상태와 무관하게 **지금 실제로 배를 가두는 문제**(WP7 무제한, 도킹 실패 시 영구 정지), 그리고 GPS 신선도 계약이 "stale 이어도 시간 초과 진행은 유지"를 전제로 깐다 — 그 진행이 WP7 이후엔 지금 없다.
- C2 는 반드시 C1 과 실물 시험 뒤(계약서 §1 과 같은 이유: C2 만 먼저면 얼어붙은 위치로 조향).
- GPS C2 와 배별 IMU 는 둘 다 `launch_files.launch.py` 를 고친다 → **동시 구현 금지**, 앞 커밋 뒤 줄 번호 재확인.
