## 3. `tools/cad/mast.py` 실측 반영
파일 상단 파라미터만 고친다(로직 손대지 마라):
- `IMU_L, IMU_W, IMU_H = <입력값>` — 케이스 포함 실측. 케이블이 나오는 면이 포켓의 **중앙 구멍 쪽(−X−Y 대각)** 을 보게 놓을 수 있는지 확인. 안 되면 `IMU_POCKET_C` 를 바꾸지 말고 케이블 홈(`IMU_CH_D` 원통, 코드의 `ch_plane`) 방향만 그 면으로 돌려라 — 방법 모르면 멈추고 보고.
- IMU 보드 "앞" 이 케이스의 어느 면인지에 따라 포켓 바닥 화살표(`arrow` polyline, +Y 가 뱃머리)가 맞는지 확인. 보드 앞 = 뱃머리 방향이 되도록 IMU 를 넣었을 때 케이블 면이 어디 오는지 한 줄로 기록.
- `BASE_HOLE_PITCH = (130.0, <가로대 간격>)` — 입력 있으면.
- 갑판 두께 입력 있으면 파일 docstring "실측 후 고칠 파라미터" 에 `볼트 M5 길이 = 갑판 두께 + BASE_T(20) + 와셔·너트 ≈ 10 → ____ mm` 로 계산해 적어라.

재생성·검증:
```bash
python3 tools/cad/mast.py
```
- 출력 마지막 줄들에서 **`한계 220 → OK`** 확인. `초과!` 면 `MAST_H` 를 줄여 다시(캡 상단 = 20+4+MAST_H+4+36).
- `IMU 포켓 …` 줄의 포켓 치수가 입력 +1mm 인지 확인.
- 결과 복사:
```bash
cp tools/cad/out/mast_{base,seg1,cap,imu_lid}.stl docs/전달용/마스트_stl/
cp tools/cad/out/mast_assembly.step docs/전달용/마스트_stl/mast_assembly_v2.step
git add tools/cad/mast.py docs/전달용/마스트_stl && git commit -m "cad(mast): IMU 실측 <L×W×H> 반영, 가로대 <간격>, STL/STEP 재생성" && git push
```
