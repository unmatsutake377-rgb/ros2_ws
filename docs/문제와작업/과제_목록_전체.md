## 의존 관계 요약 (막힌 사슬)

```
A1 부표 높이 ──▶ B6 마스트 장착 높이 ──▶ D4 LiDAR 부표 확인
A2 MD-30A ────▶ B3 인터페이스 보드 ──▶ (C1 ✅ 이미 통과)
C1 ✅ ─────────▶ C5 IMU 캘리브 ──▶ D2 자율 조향부호 ──▶ D3 PWM 실측 ──▶ D8
A6 OAK 모델 ✅ ▶ B9 발주 ──────────────▶ C6 런북 ──▶ D5
A8 갑판 ──────▶ B5 ──▶ B6 ──▶ D1
A10 ✅ ────────▶ B10 IMU 실측 ──▶ B6 프린트
F1 GPS 측위 ──▶ D7 웨이포인트 녹화
```

**⚡ 사슬이 하나 짧아졌다.** C1(펌웨어 벤치)이 09-01~09-03 에 통과해서, D2 는 더 이상 A2→B3 를
기다리지 않는다. **지금 D2 를 막는 것은 C5(IMU 캘리브레이션) 하나뿐**이고, 그건 나침반만 있으면 된다.

A3·A6·A10 은 풀렸다. 남은 결정은 **A1/A11(부표·파고 문의)·A2(MD-30A)·A8(갑판)** — 전부 돈이 안 든다.
발주는 B9 부터(OAK 배송·인젝터 2주), 프린트는 B10(IMU 치수) 뒤.

🚨 **규정 검사(E)는 5개 중 2개가 끝났다.** 남은 셋 중 **E3 흘수선 표시**만 물건이 필요하고,
E4·E5 는 확인이다. 대신 **F2(한낮 LED 시인성)가 새로 E1 뒤에 붙었다** — 표시등이 켜지는 것과
심사위원이 볼 수 있는 것은 다르다.
