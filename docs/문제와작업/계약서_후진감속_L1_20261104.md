# 변경 계약서: motor_control — failsafe L1 중 후진(분기 5)에도 L1 속도 상한(1500 기준 편차 × failsafe_l1_speed)

작성: ssf-contract (2026-11-04). 배경: 계약서_후진통과_20261104 §6 위험 2, §10 결정 5. 상태: **승인됨** (§10). 줄 번호는 9c7d0a4 기준(작업 착수 때 재확인).

## 0. 지금 후진에 L1 이 안 걸리는 이유
- `slow_ok = False` 시작(`motor_control.py:184`), True 는 분기 (2)·(4)·(6)뿐(`:195, :212, :223`). 분기 (5) `161 < a < 5000`(`:215-217`)는 reverse_pwm 1590 그대로.
- L1 상한은 근접 감속과 같은 게이트: `ratio = min(speed_ratio(), failsafe_speed_cap())` 뒤 `if slow_ok and ratio < 1.0`(`:230-233`).
- 이력: slow_ok 게이트는 3552bf4(근접 감속용), L1 상한은 02bfc39 가 그 위에 얹음. 후진 제외 근거는 "다가가지 않으니 감속 대상 아님"(근접 감속 논리)뿐 — L1 에서 후진을 뺀 근거는 없음 → 게이트 공유의 부수효과로 봄(⚠️ 측정 기록 없음).
- 현재 L1 출력: 전진 1360 → 1402, 후진 1590 그대로, SPIN 1600/1400 그대로.

## 1. 변경 (권고 식)
- 분기 (5) 안에서만 `cap = failsafe_speed_cap()`(L1 이면 failsafe_l1_speed 0.7, 아니면 1.0, `:138-143`).
- `cap < 1.0` 이면 `pwm_r = pwm_l = apply_slow(reverse_pwm, cap)` = `round(1500 + (reverse_pwm−1500)×cap)` (기존 L1 전진과 같은 식, `:150`).
- 결과: 1590 → **1563**(ROS) → ssf_bridge 3000−1563 = 1437(시리얼). Motor_run 15631563.
- **근접 감속 speed_ratio() 는 후진에 넣지 않는다** (L0 BACKOFF·위치유지 후진이 깎임, CLAUDE.md §6 "min_speed_ratio 전진만" 위반). 분기 (5) 에 `slow_ok = True` 넣는 단순 구현 **금지**.
- 주석 정정: `:22-25, :48-51, :147-149, :184, :225-229`, `motor_control.yaml:18-22` → "L1 상한 = 전진·후진 공통, 근접 감속 = 전진만".

## 2. 변경 단위
- 노드 하나 = motor_control. 한 커밋: motor_control.py + 새 테스트 + yaml 주석. 원자 묶음 아님.
- 후진통과(7ae1383) 커밋 뒤 착수. 각 상태 단독 안전.

## 3. 토픽 (전부 불변)
`/desired_angle`(구독), `/failsafe_level`(구독, 해석 범위만 후진까지), `/obstacle_distance_array`(후진엔 계속 안 씀), `Motor_run`(값만: L1 후진 15631563), `/motor_reverse`(True 유지). 새 토픽 없음.

## 4. 특수 상수·규약
- 분기 경계 불변. ROS >1500 = 후진 유지, 반전은 ssf_bridge 한 곳.
- `/motor_reverse`(평균 > 1500): 1563 → True.
- ship_direction 자체 후진 [L](260, 0.5 s)도 같은 분기 → **같이 70%**. 출처 구분 불가(새 신호값·토픽 필요 → §1-3·§1-8 로 제안 안 함).
- 워치독(`:171-181`)이 먼저 return → 중립 그대로. SPIN 불변. L2 는 ship_direction STOP_HOLD 로 처리.
- L1 지속: /scan 또는 /yaw_error 0.7~3.0 s 묵음, 최대 약 2.3 s.
- §1-8 "측정 완료된 motor_control 체인 뜯지 말 것": 인터페이스·부호·reverse_pwm·분기 경계는 불변 → 문언상 뜯기 아님. 그러나 동작 변경이고 상세 §3-2:181-182 "(후진은 안 건드림)", 상세 §6:884 "failsafe_l1_speed 0.7 → 50판 접촉 24→14"(후진 제외 상태 측정, 재현 스크립트 없음 ⚠️)와 어긋남.

## 6. 위험
1. `slow_ok = True` 식 구현 시 근접 감속까지 후진에 걸림.
2. failsafe_l1_speed 범위 검증 없음(음수면 후진이 전진으로) → 후진 쪽에도 `cap < 1.0` 게이트 동일하게.
3. [L] 후진 0.5 s 이동거리 L1 중 70% — 시뮬 근거 없음.
4. 모든 시뮬이 L1 을 안 밟음(avoid_sim fs_max 전부 0) → 시뮬 통과는 근거 아님.
5. 문서 불일치(motor_control.py 주석, 상세 §3-2).
