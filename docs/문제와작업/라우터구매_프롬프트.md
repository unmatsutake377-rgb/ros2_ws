자율운항선박 대회(KABOAT)용으로 배에 실을 LTE 라우터를 사려고 해.
한국에서 지금 실제로 구매 가능한 제품을 웹에서 조사해서 추천해줘.

## 왜 필요한가
- 배에 실린 Ubuntu 노트북이 경기 내내 인터넷이 필요함 (RTK GPS 보정데이터 NTRIP 수신 + 물가에서 SSH 원격 접속)
- 대회 코스가 최대 116m라 휴대폰 핫스팟(실외 실효 20~30m)으로는 안 됨
- 외부에서 배로 들어오는 접속은 Tailscale VPN으로 해결 예정이라 통신사 CGNAT(사설 IP)는 문제 안 됨

## 필수 조건 (하나라도 어기면 탈락)
1. 한국 통신사 LTE 밴드 호환 (해외직구 기종이면 국내 밴드 지원 반드시 확인)
2. WiFi AP 기능 내장 — USB 동글 형태는 탈락 (노트북 USB 포트가 부족함)
3. 5GHz WiFi 지원 — 배에 2.4GHz RC 조종기가 있어서 대역 간섭을 피해야 함
4. 배에서 전원 공급 가능: USB 5V 충전(배터리 내장형) 또는 DC 입력 9~30V (배터리가 4S 리튬 14.8V)

## 우대 조건 (있으면 가점)
- 외장 안테나(SMA 커넥터) — RC 수신기와 안테나를 물리적으로 떨어뜨려 장착해야 해서
- 진동·야외 환경 내구성
- 배터리 내장 (배 전원과 독립되면 회로 작업이 줄어듦)

## 조사해줄 것 — 두 가지 예산 트랙으로
A. 저예산 검증용 (수만 원대): 중고 포켓와이파이/에그류 포함.
   "일단 대회장에서 LTE가 되는지" 개념 검증용. 중고 시세와 구매처(중고나라/당근 등 시세 수준)도.
B. 본격 장비 (수십만 원대): 산업용 LTE 라우터 (예: Teltonika RUTX11 같은 부류).
   국내 정식 구매처와 가격, 4S 배터리(14.8V) 직결 가능한 DC 입력 범위인지.

각 트랙에서 2~3개 기종을 골라 아래 표로 정리해줘:
| 기종 | 가격(신품/중고) | LTE 밴드 국내호환 | 5GHz | 전원 방식 | 외장안테나 | 구매처 링크 | 비고 |

## 같이 조사해줄 것
- 라우터/에그용 SIM 데이터 요금제 옵션 (데이터쉐어링, 에그 전용 요금제 등) — 월 비용 수준
- 각 기종의 실사용 후기에서 야외/이동 환경 안정성 언급

## 주의
- 스펙은 제조사 공식 페이지나 신뢰할 수 있는 판매처 기준으로 확인 (블로그 소문 금지)
- 단종 여부 확인 — 실제로 지금 살 수 있는 것만
- 최종 추천은 "A트랙 1개 + B트랙 1개"로 좁혀서, 왜 그건지 이유와 함께

## 결과 받은 뒤 할 일

1. 후보 기종 스펙을 회로/펌웨어 담당 AI(이 저장소 세션)에 전달 → 전원·안테나 요구사항 대조
2. 회로팀과 협의: 급전 방식(BEC 추가 vs 직결 vs 자체 배터리) · 방수 박스 배치 · **RC 수신기와 안테나 이격**
3. 구매는 A트랙(저예산 검증)부터 — 대회장 답사 때 셀 커버리지 확인과 함께 개념 검증 후 B트랙 판단
4. 확정되면 `docs/전달용/부품_추천목록.md`와 회로 대장에 반영
