버그 1. 배 ID 고장 시 표시등이 죽는다

증상 — 배 ID 판정이 FAULT(두 핀 모두 GND = 배선 실수)가 되면 모터는 중립으로 잘 잠기지만, 룰 표시등(WS2812)이 영영 꺼진 채가 되고 점검 LED 경보 점멸도 안 된다.

왜 위험한가 — ① 대회 규정은 "비상정지 시 빨강"을 요구하는데 이 상태에선 비상정지를 눌러도 빨간등이 안 켜진다(규정 위반). ② 물 위에서 아무 표시 없이 조용히 멈춰 있는 배가 된다 — 이 프로젝트가 가장 경계하는 "조용한 고장" 유형. 부팅 때 8회 빠른 점멸은 나오지만 지나가는 신호라 놓치기 쉽다.

// 수정 전 — updateLeds 가 else 안에만 있었다
if (boatId == BOAT_FAULT) {
  driveNeutral();                // ← 여기서 끝. 표시등 갱신 없음
} else {
  ...
  driveMotors(cmdL, cmdR);
  updateLeds(...);               // ← 정상일 때만 갱신
}

// 수정 후 — 분기 밖에서 항상 갱신
bool estopActive = (digitalRead(PIN_ESTOP_SENSE) == LOW);
if (boatId == BOAT_FAULT) { driveNeutral(); rcLostAlert = false; }
else                      { ... driveMotors(cmdL, cmdR); }
updateLeds(estopActive);         // ← 고장이어도 룰 표시등·경보가 산다

개선 2. 수동 모드 RC 소실 경보 추가

이전 — 점검 LED 경보는 자율 워치독과 배 ID 고장에만 반응했다. 수동 조종 중 조종기가 꺼지거나 전파가 끊기면 안전하게 중립으로 가지만 아무 표시가 없다. 물가에서는 "왜 안 움직이지?"의 원인이 안 보인다 (배터리? 펌웨어? 전파?).

수정 — 수동 모드인데 RC 가 신선하지 않으면 rcLostAlert 를 세워 점검 LED 를 점멸시킨다. 대기 모드(아직 RC 신호를 한 번도 못 받음)에서는 점멸하지 않는다 — 그건 고장이 아니라 정상 초기 상태다.

if (mode == MODE_MANUAL) {
  if (rcFresh(0) && rcFresh(1)) mixManual(cmdL, cmdR);
  else                          rcLostAlert = true;   // 점검 LED 로 알린다
}
...
bool alert = watchdogActive || rcLostAlert || (boatId == BOAT_FAULT);

경보 3종 정리: ① 자율 워치독(노트북·브릿지 침묵) ② 수동 RC 소실 ③ 배 ID 고장

개선 3. "기본값 A" 와 "핀 확정 A" 를 눈으로 구분

배경 — 08-12 변경으로 ID 핀 미배선 시 기본값 A 로 돈다. 그런데 부팅 LED 는 두 경우 모두 "짧게 1회"라 구분이 안 됐다. 시리얼 로그에는 구분되어 찍히지만 물 위에선 시리얼을 못 본다. 두 척을 동시에 돌릴 때 "왜 둘 다 A 로 도는가"를 현장에서 잡을 수단이 필요하다.

점검 LED 신호뜻
짧게 1회A배 — ID 핀으로 확정
짧게 2회B배 — ID 핀으로 확정
긴 점등 1초 → 짧게 N회기본값으로 정해짐 (ID 핀 미배선)
빠른 8회 점멸고장 — 두 핀 모두 GND = 배선 실수

확인 4. 문제없음으로 확인한 것들

  • 정수 오버플로 없음 — 편차 최대 ±600, 게인 곱해도 ±6000 이라 int 범위 안전
  • millis() 롤오버 안전 — 시간 비교가 전부 뺄셈 방식이라 49일 롤오버에도 정상
  • 모터 매핑 일치 — 명령 배열 {L,R,L,R} ↔ 설정표 [FL,FR,RL,RR]
  • 시리얼 파서 견고 — 형식 불일치·범위 초과·음수 전부 폐기, 깨진 명령이 워치독을 먹이지 못함
  • ISR 공유변수 보호 — 8비트 보드의 비원자 읽기를 snapPulse/snapStamp 로 차단

🔵 알아두되 조치 불필요: WS2812 전송(show()) 중에는 인터럽트가 잠깐 꺼져 이론상 ESC 펄스 하나가 흔들리거나 RC 엣지 하나를 놓칠 수 있다. 색이 바뀔 때만 전송하는 설계로 이미 완화돼 있고(상태 색은 드물게 바뀜), ESC 는 펄스 하나 튀는 것을 걸러낸다. 벤치 절차서 §6 에 확인 항목으로 넣어 뒀다.
