## 핵심 요약
- **문제(코드 확인):** `ship_direction.py:329` `yaw_error = 0.0` 으로 시작하고, `failsafe.py:92,117-118` 은 첫 메시지를 받은 센서만 감시(ARMED)한다. 부팅부터 `/yaw_error` 가 없으면 레벨 0 그대로이고, (C) 경로(`ship_direction.py:906-907`)는 0 을 "목표가 정면"으로 읽어 뱃머리 방향으로 갭을 고른다.
  - `/yaw_error` 가 안 오는 경우: ① north 는 `gps_ok` 일 때만 `/north_goal_angle_tp` 발행(`north_goal_angle.py:575-593`) ② `ship_goal_angle` 은 IMU·목표 방위 둘 다 오기 전엔 미발행(`ship_goal_angle.py:83-85`). `/wp_mode`·WP 시간 초과는 GPS 없이도 진행(`:595`, `:605-646`).
- **추천 안 A(좁게):** "실효 후보각 == 20000 이고 yaw_error 를 아직 한 번도 못 받음 → STOP_HOLD". 새 파라미터·새 토픽·`/failsafe_level` 변경·SensorWatch 변경 없음.
  - 임무 노드가 주는 각도·5000·180 경로(`_compute` (A)(B), `:801-835`)는 yaw_error 를 읽지 않음 → 막지 않음, 거짓 정지 없음.
  - 후보각 1.0 s 무수신 → 20000 대체, wp_mode 변경 → 20000 초기화도 같은 (C) 입구라 함께 잡힘.
- **안 B(SensorWatch 유예) 비추천:** ARMED 제거는 "경기 시작하자마자 안 움직임" 기록(`docs/문제와작업/3차보고_WT901C_오탐지정지_도크분리.md:102`), 모든 모드 정지(비전 임무까지), 유예 시간 근거 미실측, /scan 미수신은 이미 안전(발행 없음 → motor_control 중립).
- **MANUAL 중 STOP_HOLD 는 안전:** 펌웨어가 MANUAL 에서 노트북 명령 무시(`ssf_boat.ino:809-812`). AUTO 전환 순간부터 1500 이 나간다(지금은 전진).
- **보이는 변화:** GPS fix 없는 실내 수조·벤치에서 20000 으로 전진하던 동작이 정지로 바뀜(`tank_test_plan.html:348` 게이트 수조 시험).

## 특수 상수
- 20000: "미션 없음 → 갭 선택"이 "yaw_error 받은 적 있을 때만, 아니면 50000"으로 좁아짐. motor_control 불변.
- 50000: (0) 과 같은 경로 → reverse 상태기계·레이트 리미터 리셋.
- 5000/6000, 180→260, 일반 각도, geofence 하드 가드: 불변. (C) 의 경로 없음 260 루틴은 미수신 중 시작 안 됨.

## 파라미터
새 파라미터 없음. 끄는 스위치도 만들지 않음(끄기 쉬운 안전 스위치 증가 방지). failsafe_warn/stop/confirm, candidate_stale, reverse_duration/cooldown 불변. 대회 launch 는 ship_direction 에 yaml 을 안 넘김(코드 기본값 = 운용값).

## 위험
1. 판정은 반드시 `is None`. `not yaw_error` 면 0.0(정확히 정렬)에서 영구 정지.
2. None 이 `yaw_error % 360.0`(`:906`)에 닿으면 TypeError → 노드 사망 → 영구 중립. control_cb 판정 + `_compute` 가드 둘 다 필요.
3. 기존 fake self 에 새 속성 없으면 기존 테스트 대량 실패 → 같은 단위에서 수정.
4. 로그 폭주: 게이트에서 후보각이 20000↔각도로 깜빡일 때(`ship_gate.py:234`) 진입 ERROR 반복 방지 — 진입·반복은 막힌 틱에서, 복구(INFO)는 yaw_error 첫 수신에서만.
5. RTK 미수렴(cov > 2.0)으로 tp 미발행이면 20000 구간 내내 정지. `/failsafe_level` 0 이라 mission_monitor 는 정상으로 보이고 ERROR 로그만 원인을 알림.
