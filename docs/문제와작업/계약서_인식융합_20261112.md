## 3. LiDAR 끊김 때 실제 동작
t=0 LiDAR 정지 → ~0.5 s 융합 노드 depth/row 로 계속 → 1.0 s 미션 노드 lidar 모드면 거리 None → 0.7~1 s L1 → **3.0 s L2 가 모든 모드를 STOP_HOLD(`ship_direction.py:786`)**.
→ 이득 창 ~2 s. 11-11 끊김 3회는 허브째(D455 도 같이) → 1단계 OAK 입력은 방위 토픽뿐이라 거리 없음 → **이득 0**.
새 동작: L2 정지 중 ship_back 이 카메라 거리로 HoldTimer 를 채워 '성공 DONE' 가능(지금은 10 s 포기) — 안전 차이 없으나 성공 근거가 카메라(위험 2).

## 5. 융합·인식 (물체 단위)
- LiDAR: 브랜치 `obstacle_fusion_logic.lidar_clusters`(gap 2°/0.3 m, 최소 2점) 재사용 — 세 번째 군집기 금지.
- D455: 열마다 유효 픽셀 하한 + median, 0 = 모름, 수면 띠 제거(높이·피치 ⚠️), 0.5~6 m ⚠️, 열 거리 점프로 덩어리, z→r = z/cos(방위) → LiDAR 원점.
- OAK: 1단계 = 검출기 토픽(확인-N 은 검출기에 있음). v3 색 다수결(LowMap, GPS 세계좌표)은 ship_avoid 에 남김. bbox 필요한 row·lidar_behind 는 다중 물체 검출 노드 뒤(Q7).
- 연관: OAK 방위 구간 ± `fusion_margin_deg`(3°) 겹침 ↔ 군집·덩어리, 군집 ↔ D455 덩어리 방위 겹침.
- 거리: L·D 일치(≤ max(0.3 m, 0.1·min)) → 가중평균(w = 정규화 conf, [0.3, 0.7]) / 어긋남 → **min**, 감점, flags bit0 / L 만 → dL / D 만 → dD / row 만 → dR(conf 상한, 평균에 안 넣음).
- 신뢰도(소스·~5° 섹터): 유효 반환 비율, MAD, 예측 대비 점프 ≥0.5 m, 연속 오검출 −0.05(하한 0.3).
- 시야: LiDAR 360°, OAK 63.9°, D455 87° ⚠️. 외부 보정·카메라 높이 전부 ⚠️ 실측.
