# 1번배(2기) ESC↔T200 3상 배선 — ✅ 최종 (2026-10-26 저녁, 팀장 확정)

| 자리 | Mega 핀 | 접촉기 단자 (전원) | ESC↔스러스터 3상 색 | 확인 |
|---|---|---|---|---|
| **좌** | 12 | **1번** (배터리 B, 2→1 극) | **교차** — 초↔파 (흰 그대로), 10-26 교체 | `hold.py 1600 1600` 뒤로 바람 ✅ |
| **우** | 11 | **6번** (배터리 A, 5→6 극) | **교차** — 초↔파 (흰 그대로), 10-26 교체 | 팀장 육안 확인 ✅ (교체 전 `hold.py 1600` 에서 앞으로 = 역방향이었다) |

- 둘 다 교차다. "왜 둘이 같지" 하고 한쪽을 되돌리지 말 것 — 되돌리면 그쪽이 역방향이 된다.
- 교체 자리에 테이프·유성펜 표시.
- 실물 규약 >1500 = 전진(뒤로 바람). ROS 는 <1500 = 전진 → `ssf_bridge` `invert_thrust_direction` true 그대로.
- ⬜ 남은 확인: `hold.py 1750 1250 10` → 좌 전진·우 후진(제자리 우선회) 이면 `steer_invert` false 유지. 다음 벤치 때.
- 스러스터·ESC·프로펠러 중 하나라도 바꿔 달면 이 표는 무효 — `hold.py 1600 1600` 으로 재판정.

## 10-26 에 겪은 함정 — 수동 모드 육안 판정 금지

조향 트림이 +60µs 남짓 밀린 상태에서 수동으로 보면 펌웨어가 **좌 전진 / 우 후진**을 내보낸다.
그러면 역방향 배선인 쪽이 "정상" 으로, 정상 배선인 쪽이 "역방향" 으로 보인다.
실제로 "왼쪽을 고쳤더니 오른쪽이 갑자기 뒤집혔다" 로 보였다 — 둘 다 처음부터 역방향이었고 명령이 비대칭이었을 뿐이다.
→ 판정은 **대칭 명령 `hold.py 1600 1600`** 으로만. 조종기 Sticks Cal 을 다시 했으면 중앙값도 재측정(펌웨어 1502/1424, 10-26).

## (10-26 오후 원표 — 확인된 적 없음, 기록용)

| 자리 | ESC ↔ 스러스터 | 메모 |
|---|---|---|
| **좌** (ESC 좌, Mega 핀 12) | **색 동일** 흰-초-파 | 변경 없음 |
| **우** (ESC 우, Mega 핀 11) | **교차** — ESC 초 ↔ 스러스터 파, ESC 파 ↔ 스러스터 초 (흰 그대로) | 교차한 자리에 테이프·유성펜 표시 |

- 이유: T200 프로펠러 CW/CCW 2종(반작용 상쇄). 같은 명령에 둘 다 물을 **뒤로** 밀어야 한다. 4기 배(2025)에서 좌앞·우뒤를 교차한 것과 같은 원리(`좌측스러스터_접촉기_20260819.md` §10·11).
- 🚨 "왜 우측만 색이 다르지" 하고 되돌리지 말 것. 되돌리면 좌우가 서로 상쇄해 배가 안 나간다.
- 확인: `python3 tools/hold.py 1600 1600 12` → 둘 다 뒤로 바람(전진). `hold.py 1750 1250 15` → 좌 전진·우 후진(제자리 우선회) 이면 `steer_invert` false 유지.
- 실물 규약 >1500 = 전진. ROS 는 <1500 = 전진 → `ssf_bridge` `invert_thrust_direction` true 그대로.
- 스러스터·ESC·프로펠러 중 하나라도 바꿔 달면 이 표는 무효 — `hold.py 1600` 으로 다시 판정.
