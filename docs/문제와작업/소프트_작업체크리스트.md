## ⚠️ 관리 주의

- **NTRIP 계정 50일 미접속 삭제** — 주기적 접속 필요
- **IMU 시리얼 `0001`** 고유성 없음 — udev product 문자열 의존
- **카메라 D455 USB3 케이블** 필요 (현 2.1 링크). 노트북 **USB-C 포트(TB4, 20Gbps)가 비어 있어**
  허브 교체 불필요 — **C-to-C** 케이블이면 된다(⚠️ 충전전용 다수, `5Gbps` 표기 확인)
- **NTRIP 마운트포인트는 '측정 장소' 기준** — 현재 `SEJN`(세종). 대회장 확정 시 재계산
- **`waypoints.yaml` 좌표(마산)가 실제 대회장인지 미확인** — 시험장소와 197km 차이
- 🚨 **배의 무선 링크가 미정** — SSH 뿐 아니라 **NTRIP(RTK)도 같은 링크를 쓴다.**
  · 코스 최대 **116m** 인데 휴대폰 핫스팟 실효는 **20~30m** → **핫스팟으로는 코스를 못 덮는다**
  · 끊기면 SSH 는 "못 봄" 이지만 **NTRIP 은 FIXED(±1.5cm)→단독(±3~5m) 로 정밀도 붕괴**
  · **LTE 라우터** 가 유력(거리 무관·NTRIP 해결). 단 CGNAT 라 외부→배 SSH 는 메시 VPN 한 겹 필요
  · 안전은 SSH 에 안 걸려 있다 — 비상 제어는 **RC 조종기(별도 무선)**, 기록은 blackbox 로컬 저장
  ⏸ 접속 기기·라우터 확보 후 착수. 분석·지시문: `docs/문제와작업/SSH환경구축_프롬프트.md`
- 🚨 **통신 거리 실측 필요** — 조종기 **FS-i6 / 수신기 FS-iA6**(확정).
  **iA6 는 텔레메트리가 없어 RSSI 를 못 본다** → 끊기고 나서야 안다. 실측이 유일한 근거.
  웨이포인트 녹화는 **조종기와 SSH 가 동시에** 116m 를 덮어야 한다(하나만 되면 못 찍는다).
  절차: `docs/절차/boat_launch_checklist.md` §"통신 거리 시험" — **System-ID 보다 먼저**
- **`hfov_deg` 7.62° 불일치** — camera_info 실측 79.12° vs 설정 71.5°. 케이블 오면 재확인
