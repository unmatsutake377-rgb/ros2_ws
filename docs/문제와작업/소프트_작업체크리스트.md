## 1. GPS / north_goal_angle — LOS·부가기능 이식 (팀원 작업)

- [ ] base = **저장소 최신 `north_goal_angle.py`** 에서 시작 (제출본 아님)
- [ ] **이식**: LOS 유도 · 동적 lookahead · GPS 공분산/점프 필터 · 위치 스무딩 · 도착반경/통과선 판정
- [ ] 순수로직 모듈(`los_logic`/`gps_filter`) + 단위테스트 (우리 방식)
- [ ] **활용 가능성 판단** → LOS·부가기능이 실제로 도움 되면 수정 반영, 아니면 보류
- [ ] **제외 확인**: DR·쿼터니언·ZUPT·속도융합·navpvt오프셋·조향클램프
- [ ] **보존 확인**: waypoints.yaml+검증 · geofence · `/candidate_angle` 발행자 1개
- 근거 문서: `docs/전달용/회신_GPS코드_기능추출_수정제안.md`

## 2. IMU — 내일 처리
