## 6. 위험
1. **묵은 candidate 로 인한 무한 후진.** ship_direction 은 candidate 수신 시각을 저장하지 않음(`:287, 375-381`). ship_dock·ship_back 이 후진 도중 죽으면 마지막 180 을 붙들어 모드가 바뀔 때까지 후진. 지금은 같은 상황이 정지 → **수정 전보다 나빠지는 유일한 경로.**
2. 뒤쪽 감지 없음. [I] 는 180 을 못 막고 후진은 L1 감속에서도 빠짐.
3. 미래의 우연한 180.0: ship_dock APPROACH 무클램프, ship_back ±180 접힘. 광각·규약 변경 시 전진이 후진. 현재 hfov/2 < 32° 라 안전.
4. `dock_sim.py` 사본을 같이 안 고치면 시뮬이 계속 "후진 0/500".
5. 문서 역전: `9c7d0a4` 가 보고서·dock_sim 에 "BACKOFF 후진 미동작"으로 적음 → 수정 뒤 그대로면 문서가 실제와 반대.

## 9. 사람이 정할 것
1. 일치 방식: 정확 일치(권고) / ±ε / 전용 특수값.
2. 고칠 위치: ship_direction (B)(권고). 발행 노드 단독은 불가.
3. CLAUDE.md §3 특수 신호 표에 "`/candidate_angle` 180.0 = 후진 요청 → `/desired_angle` 260" 추가 — CLAUDE.md 는 이번 수정 대상 아님, Davidson 직접.
4. 위험 1(묵은 candidate 무한 후진)을 이번에 막을까: (a) 180 이 X 초 넘게 갱신 안 되면 STOP (b) 연속 후진 시간 상한. 둘 다 새 파라미터(코드 기본값 + yaml). 아니면 미션 노드 상한만 믿음.
