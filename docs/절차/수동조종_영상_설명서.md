# 수동 조종 화면 — D455 실시간 영상 설명서 (2026-10-29 확정)

> 배의 D455 영상을 물가 MacBook 에서 실시간으로 본다. ROS 와 무관한 UDP/RTP(H.264) 단방향 — 이 화면이 죽어도 RC 수동 조종은 영향 없다.
> 확정 설정: **424x240 · 30 fps · 1000 kbps · 수신 버퍼 80 ms** (10-29 1번배 실측, 기록 `docs/결과분석/영상지연_실측_20261029.md`). 스크립트 기본값이 이 값이라 **옵션 없이 치면 된다.**
> 설계 근거: `docs/문제와작업/수동조종_카메라영상_설계.md` · 벤치·문제 해결 표: `docs/절차/카메라영상_설치와_벤치.md`

## 매번 하는 것 (3단계)

### 1. MacBook — 수신 창 먼저
```bash
cd ~/ros2_ws && git pull && ./tools/cam_view.sh
```
- `=== 카메라 수신 === UDP 5600 대기 (지터버퍼 80ms)` 가 나오면 대기 중. 창은 영상이 오면 뜬다.
- 터미널 앞에 `(base)` 가 붙어 있으면 먼저 `conda deactivate` (아래 §설치-MacBook).
- MacBook IP 확인: `ipconfig getifaddr en0` (같은 공유기) / `tailscale ip -4` (Tailscale).

### 2. 배 노트북(Ubuntu) — 송신
```bash
cd ~/ros2_ws && git pull && ./tools/cam_stream.sh <MacBook IP>
```
- 로그에서 확인:
  - `모드 : v4l2  424x240@30  1000kbps`
  - `장치 : /dev/videoN (Intel(R) RealSense(TM) ...)` ← **RealSense** 여야 한다. `Integrated Camera` 면 노트북 내장 웹캠을 잡은 것.
- 자율 스택(launch·`camera.launch.py`)이 떠서 D455 를 쥐고 있으면 `Device busy` → 끝에 `ros` 를 붙인다: `./tools/cam_stream.sh <IP> ros`

### 3. 화면 확인
- **좌상단 시계 = 배 시각, 우하단 시계 = MacBook 시각.** 둘 다 흐르면 정상.
- **좌상단 시계가 멈추면 영상이 멈춘 것** — 그 화면을 믿지 말 것.
- 두 시계 차이 ≈ 전송 지연(양쪽 시계가 맞을 때).

### 끝내기
- **각 터미널에서 Ctrl-C 한 번.** `■ 중지 (Ctrl-C)` 가 나오면 완전히 꺼진 것.
- 영상 **창의 X 로 닫기만 하면 3초 뒤 다시 뜬다**(끊김 자동 복구용). 끄려면 Ctrl-C.

| 규칙 | 왜 (10-29 실제로 겪음) |
|---|---|
| 송신 1개 · 수신 1개만 | 같은 포트로 두 영상이 들어오면 섞여서 계속 깨진다. 이제 두 번째 실행은 `❌ 이미 돌고 있는 …` 으로 막힌다 — 안내된 `kill …` 로 옛 것을 끄고 다시 |

| 상태 확인 명령 | Mac `pgrep -fl "videotestsrc\|cam_view\|udpsrc"` · Ubuntu `pgrep -af "videotestsrc\|cam_stream\|v4l2src"` |

## 설정 바꾸기 (필요할 때만)

| 상황 | 명령 |
|---|---|
| 더 선명하게(망이 좋을 때) | `./tools/cam_stream.sh <IP> v4l2 640 480 30 1500` — 10-29 실내 공유기에선 흔들 때 깨졌다 |
| 더 깨지면(망이 나쁠 때) | 송신 `... v4l2 424 240 30 600` / 수신 `CAM_JITTER_MS=120 ./tools/cam_view.sh` |
| 지연을 더 줄이고 싶을 때 | 수신 `CAM_JITTER_MS=40 ./tools/cam_view.sh` — 대신 깨짐이 는다 |
| 장치를 직접 지정 | `CAM_DEV=/dev/video6 ./tools/cam_stream.sh <IP>` (1번배 노트북: D455 컬러 = video6) |

인자 순서: `cam_stream.sh <IP> [v4l2|ros|oak] [폭] [높이] [fps] [kbps]`. D455 컬러가 지원하는 크기: 424x240 · 480x270 · 640x360 · 640x480 · 848x480 · 1280x720.

## 처음 한 번 — 설치

### 설치-MacBook (물가)
1. Homebrew — `brew.sh` 의 설치 명령(비밀번호 필요). Apple 칩이면 끝에 안내되는 `eval "$(/opt/homebrew/bin/brew shellenv)"` 두 줄까지.
2. `brew install gstreamer` (`pygobject3` 는 바코드 지연 벤치를 할 때만)
3. 🚨 **Anaconda 가 깔린 Mac**: conda 의 옛 gstreamer 가 먼저 잡혀 `avdec_h264`·`clockoverlay` 가 "No such element" 가 된다.
   `which gst-inspect-1.0` → `/opt/homebrew/bin/...` 여야 한다. 아니면 `conda deactivate`, 상시로 `conda config --set auto_activate_base false`.
4. 확인: `gst-inspect-1.0 avdec_h264 | head -3` 등 3개(`avdec_h264`·`clockoverlay`·`rtph264depay`)에 `Factory Details:`.
   첫 실행의 `GLib-GIRepository-WARNING …`, `objc … implemented in both libgtk-3 … libgtk-4` 경고는 무해(플러그인 첫 스캔).
5. 저장소: `git clone https://github.com/unmatsutake377-rgb/ros2_ws.git ~/ros2_ws` (공개 저장소 — 토큰 불필요)
6. 방화벽: 꺼져 있으면 그대로(`socketfilterfw --getglobalstate`). 켜져 있으면 첫 수신 때 "허용".

### 설치-배 노트북 (Ubuntu 22.04)
```bash
sudo apt install -y gstreamer1.0-tools gstreamer1.0-plugins-base gstreamer1.0-plugins-good \
  gstreamer1.0-plugins-bad gstreamer1.0-plugins-ugly gstreamer1.0-libav gstreamer1.0-x \
  v4l-utils python3-gi gir1.2-gstreamer-1.0 gir1.2-gst-plugins-base-1.0 chrony
```
- `v4l-utils`(=`v4l2-ctl`) 가 없으면 장치를 못 찾아 `YUYV 를 내는 /dev/video 노드가 없다` 만 반복한다.
- D455 는 USB 3 포트(허브면 그 포트 전원 버튼 켜기). `lsusb` 에 `8086:0b5c ... RealSense ... 455`.
- 장치 목록 보기: `for d in /dev/video*; do echo "== $d $(cat /sys/class/video4linux/$(basename $d)/name)"; v4l2-ctl -d $d --list-formats 2>/dev/null | grep -E "\[[0-9]+\]"; done`

## 안 될 때

| 증상 | 원인 → 조치 |
|---|---|
| 수신 창이 안 뜸 | 송신이 안 옴: IP 틀림(MacBook IP 가 바뀌었나) · 두 기기가 다른 망 · 공유기 AP 격리. Mac 에서 `sudo tcpdump -i en0 -c 5 udp port 5600` 로 패킷 도착 확인 |
| 창은 뜨는데 검다, 시계 둘은 흐름 | 내장 웹캠을 잡음 → 로그 `장치 :` 이름 확인, `CAM_DEV=/dev/videoN` |
| 창은 뜨는데 회색, 우하단 시계만 흐름 | 키프레임을 못 받음(테스트 명령에 `key-int-max`·`config-interval` 없음). `cam_stream.sh` 로 보내면 안 생김 |
| 계속 깨진다 | ① 송신이 두 개(`pgrep` 확인) ② 패킷 손실 → kbps 낮추기 · `CAM_JITTER_MS` 올리기 · 5 GHz · 공유기 가까이 |
| 흔들 때만 잠깐 뭉개짐 | 정상 범위(압축 + 실내 노출). 0.5 초 안에 돌아오면 OK |
| `Device or resource busy` | 카메라 노드가 D455 를 쥠 → `ros` 모드 |
| Ctrl-C 했는데 다시 켜짐 | 옛 스크립트. `git pull` (10-29 이후 Ctrl-C 한 번에 끝남) |
