## 0. 🚨 안전 수칙 (어기면 다침 / 장비 죽음)

1. **프로펠러를 전부 뗀 상태로 시작한다.** T200은 물 밖에서 프로펠러가 돌면 위험하고, 물체가 빨려든다.
2. **T200은 물 밖 장시간 구동 금지** — 수냉 구조라 공랭이 안 된다. 물 밖 시험은 **짧게, 저출력으로**.
3. **전원 순서**: 배터리 연결 **전에** 모든 배선 확인 → 배터리 연결 → 마지막에 시험.
   끝낼 때는 역순 (배터리 먼저 분리).
4. **업로드할 때는 ESC 전원을 뗀다** — 부팅 시 `ESC armed.` 로 중립 펄스가 나간다.
5. 4S(14.8V)는 단락 시 수십 A가 흐른다. 벗겨진 선·악어클립 접촉 주의.
6. 사람 두 명 권장 — 한 명은 조작, 한 명은 **배터리 분리 대기**.

## 0-1. 준비물

- Mega + 인터페이스 배선 / ESC 4개 + T200 4개 (프로펠러 제거) / 4S 배터리
- FS-i6 조종기 + FS-iA6 수신기
- 노트북 (시리얼 모니터 또는 `arduino-cli monitor -p /dev/ttyMEGA -c baudrate=115200`)
- 유성 매직·테이프 (모터에 FL/FR/RL/RR 표시)

## 1. 시리얼 생존 확인 (모터 전원 없이)

**하는 법**: Mega만 USB로 노트북에 연결 → 시리얼 모니터 115200.

| 확인 | 기대값 | 결과 |
|---|---|---|
| 부팅 로그 | `Boat ID: A  (ID pins open -> default)` → `ESC armed.` → `Setup done.` | |
| 상태 줄 | `S,0,0,0,0,1500,1500,1500,1500` 이 **0.1초마다** | |
| 모드 필드(첫 값) | RC 없으면 **0(대기)** | |

⚠️ 아무것도 안 나오면: 보드레이트 확인 → 포트 확인 → 그래도 없으면 재업로드.

## 2. RC 입력 실측 → 노브 확정

**하는 법**: 수신기 연결(스로틀→핀2, 조향→핀3, 모드→핀18, 5V·GND 공통) → 조종기 켜기.
아직 ESC 전원은 넣지 않는다. 상태 줄의 **모드 필드**로 판단한다.

### 2-1. 모드 스위치

| 스위치 위치 | 기대 모드 필드 | 결과 |
|---|---|---|
| 한쪽 | 1 (수동) 또는 2 (자율) | |
| 반대쪽 | 반대값 | |

- 모드가 **0에서 안 변하면**: 그 채널이 핀18에 안 들어왔거나, 조종기에서 스위치가 그 채널에 배정 안 됨
- **어느 쪽이 자율(2)인지 반드시 기록** — 펌웨어는 `펄스 < 1500µs = 자율`. 반대로 나오면 조종기에서 채널 반전

### 2-2. 스로틀·조향 실측값

시리얼로는 RC 원신호가 안 보이므로, **모드를 수동(1)** 으로 두고 상태 줄의 **출력 필드(5~8번)** 로 역산한다.

| 스틱 상태 | 기대 출력 | 실측 (FL,FR,RL,RR) |
|---|---|---|
| 스로틀 중립, 조향 중립 | 1500 근처 4개 (데드밴드 안이면 정확히 1500) | |
| 스로틀 최대 전진 | 4개 모두 1500보다 **작아짐** (선수는 덜 움직임 — 게인 0.7) | |
| 스로틀 최대 후진 | 4개 모두 1500보다 **커짐** | |
| 조향 최대 좌 | 좌(FL,RL) vs 우(FR,RR) 가 **반대 방향**으로 갈림 | |
| 조향 최대 우 | 위와 반대 | |

**확정할 노브**
- 중립에서 1500이 아니면 → 조종기 트림 조정 (또는 `RC_DEADBAND_US` 상향)
- 최대에서 1100/1900에 **도달 못 하면** → 조종기 엔드포인트 확대 또는 `STEER_SCALE_N` 조정
- 조향 방향이 반대면 → `STEER_INVERT_RC = true` (⚠️ **여기서 고친다.** 모터 배선 반전과 혼동 금지)

### 2-3. 🚨 RC failsafe 동작 (제일 중요)

**하는 법**: 수동 모드에서 스로틀을 조금 밀어둔 상태로 **조종기 전원을 끈다.**

| 관측 | 의미 | 대응 |
|---|---|---|
| 0.5초 내 출력이 1500으로 복귀 | 수신기가 펄스를 끊음 (정상 경로) | 조치 불필요 |
| **출력이 계속 유지됨** | 수신기가 **마지막 값을 계속 내보냄** | 🚨 조종기 메뉴 → RX Setup → Failsafe → 스로틀·조향을 **중립(0%)** 으로 설정 후 재시험 |

## 3. ESC arm 확인 → `ARM_HOLD_MS` 확정

**하는 법**: **프로펠러 제거 확인** → ESC 4개 신호선 연결(5/6/7/8) → 배터리 연결 → Mega 재부팅.

| 확인 | 기대 | 결과 |
|---|---|---|
| arm 비프음 | 부팅 후 몇 초 내 4개 ESC 모두 "삐-" | |
| 비프까지 걸린 시간 | 2초(`ARM_HOLD_MS`) 안에 끝나는가 | |
| 부팅 중 모터 움찔 | **없어야 정상** | |

- 일부 ESC만 arm → 그 채널 배선/전원 확인
- 2초로 부족하면 `ARM_HOLD_MS` 상향 (예: 3000)

## 4. 모터 4개 방향 → `invert` 확정 (프로펠러 없이)

**하는 법**: 수동 모드에서 스로틀을 **살짝만** 전진 → 각 모터 축의 회전 방향을 눈으로 확인.
(축에 테이프를 붙이면 보기 쉽다)

| 모터 | 위치 | 전진 시 도는 방향 | 프로펠러 달았을 때 추력 방향 | invert 필요? |
|---|---|---|---|---|
| FL | 선수 좌 | | | |
| FR | 선수 우 | | | |
| RL | 선미 좌 | | | |
| RR | 선미 우 | | | |

- 프로펠러를 잠깐 달아 **손을 대지 말고** 바람 방향으로 확인해도 된다 (짧게)
- 반대인 모터는 `motors[]` 표의 `invert` 를 `true` 로
- 🚨 **좌우가 통째로 반대**면 그건 invert가 아니라 **조향 부호 문제** (§2-2의 `STEER_INVERT_RC`)

## 5. 자율 경로 + 워치독

**하는 법**: 모드 스위치를 **자율(2)** 로 → 시리얼 모니터 입력창에 명령을 직접 친다.

| 보낼 것 | 기대 출력 | 결과 |
|---|---|---|
| `L1400,R1400` | 4개 모두 1500 미만 (전진 방향) | |
| `L1400,R1600` | 좌우가 반대 방향 | |
| **아무것도 안 보내고 0.5초 대기** | 4개 모두 **1500 복귀** + 워치독 필드 **1** | |
| 다시 `L1450,R1450` | 즉시 반영 + 워치독 필드 **0** | |
| `L9999,R9999` (범위 밖) | **무시됨** — 출력 불변, 워치독도 안 먹임 | |

여기까지 통과하면 **명령 사슬 + 안전장치가 전부 검증된 것.**

| 확인 | 기대 | 결과 |
|---|---|---|
| `ros2 topic echo /boat_mode` | 모드 값이 실시간으로 나옴 | |
| 모드 스위치 조작 | 토픽 값이 따라 바뀜 | |
| `Motor_run` 발행 → 출력 | 상태 줄 출력 필드가 그 값으로 | |
| **USB를 뽑았다 꽂기** | 브릿지가 자동 재연결, 토픽 재개 | |

## 9. 벤치에서 확정 **못 하는** 것 (물 위로 넘김)

- 선수 게인 (`gain_num`) — 추력 균형은 물에서만 측정 가능
- 자율 조향 부호 (노트북 `steer_invert`) — GPS·IMU가 붙어야 판단 가능
- 전압 강하로 인한 리셋 여부 — 4모터 실부하가 필요
- WS2812 주광 시인성 — 야외에서
