> Mac 에는 한컴오피스·LibreOffice 가 없어 여기서는 hwp 를 만들 수 없다. 변환은 **Windows 한글 2020 이상**에서 한다.
> 원본: `docs/전달용/보고서_분담/KABOAT2026_설계보고서_SSF_A_10차수정본.docx` / `_B_10차수정본.docx`

## 1. 한글에서 여는 순서
1. 한글 실행 → 파일 → 불러오기 → 파일 형식 "MS Word 문서(*.docx)" → 10차수정본 선택.
2. 열린 직후 **파일 → 다른 이름으로 저장 → 한글 문서(*.hwp)** 로 먼저 저장 (`KABOAT2026_설계보고서_SSF_A_10차.hwp`). 이후 편집은 hwp 에서.
3. 보기 → 개요 보기(또는 [찾아가기]) 에서 Ⅰ~Ⅴ, 1)~7), 1.1)~ 수준이 1·2·3 으로 들어왔는지 확인. 안 들어왔으면 서식 → 개요 → 문단에 개요 수준 지정(제목 글꼴 크기 16/13/11 pt 가 1/2/3 수준).

| 글머리 기호 "•" | A 는 Word 목록(numbering) → 한글 문단 번호로, B 는 문자 "•" | 둘 다 그대로 보이면 됨. 들여쓰기만 맞춤 |
| 기호 ⊕ ⊖ ≈ − × ∇ ° µ | 글꼴 대체로 □ 로 보임 | 해당 글자만 "맑은 고딕"으로 |
| 캡션 "그림 Ⅲ-n / 표 Ⅲ-n" | 로마숫자 Ⅲ 가 □ | 글꼴 "맑은 고딕" 확인 (Ⅲ 는 U+2162, 맑은 고딕에 있음) |
| 머리글/쪽번호 | docx 에 없음 | 필요하면 한글에서 추가 |

## 3. 표지·목차
- 표지 학과명 "조선해양모빌리티공학과", 팀명 "TEAM _ S.S.F A (1번배)" 확인.
- 목차는 docx 에 **텍스트로 적힌 것**(자동 목차 아님). 한글에서 자동 목차로 바꾸려면 개요 수준이 들어간 뒤 도구 → 차례/색인 → 차례 만들기.

## 4. 제출 전 최종
- hwp 저장 뒤 PDF 로 한 번 더 내보내 쪽수·그림 잘림 확인 (A 와 B 각각).
- 파일명: `KABOAT2026_설계보고서_SSF_A.hwp` / `_B.hwp` (차수 표기는 제출본에서 뺀다).
