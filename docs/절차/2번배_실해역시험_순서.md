## 1. 물가에서 (진수 전)

1. 세우는 법 3가지 확인: 조종기 SwD 위(수동) · 노트북 `Ctrl+C` · 배 위 버튼. 무선이 고쳐졌으면 4번째로 리모컨.
2. 조종기 건전지 새것.
3. 노트북: `sudo tools/boat_boot.sh` → `ros2 launch launch_files launch_files.launch.py boat:=B`
4. 조종기 ON(스위치 전부 위, 스로틀 맨 아래) → 손 뗌.
5. 배터리 1·2 → 5·6, ESC 삑 → 15~25 s. 이때 돌면 배터리 빼고 0-6 다시.
6. `ros2 run ssf_tools mission_monitor` 띄워 두기. 블랙박스 CSV 쌓이는지(`~/ssf_logs/`), System-ID 날은 `rate_hz` 20~50.
