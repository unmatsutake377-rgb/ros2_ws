# 퓨즈홀더 · XL4015 전압 조정 — 세팅 절차 (2026-09-23)

> 대상: 구매목록 #9 (XL4015 + DC 플러그) · #10 (BF303 홀더 + 5x20 퓨즈).
> 준비물: 멀티미터, 드라이버(+·−), 인두 또는 압착기, 수축튜브, 절연테이프.
> 🚨 **배터리 분리한 채 시작한다.** 연결 순서는 작업기록 §13 — 1·2번 쪽 먼저.

---

## 0. 어디에 뭐가 들어가나

```
배터리A ⊕ (접촉기 5번보다 배터리 쪽)
   ├─[BF303 + 2A]─▶ PoE 인젝터 DC IN ⊕
   └─[BF303 + 3A]─▶ XL4015 IN+  ──▶ XL4015 OUT+ ─(DC플러그 가운데)─▶ UH308
배터리A ⊖ ─────────▶ 인젝터 DC IN ⊖ · XL4015 IN−  ──▶ XL4015 OUT− ─(DC플러그 바깥)─▶ UH308
```

- **퓨즈는 ⊕ 선에만.** ⊖ 에는 안 넣는다.
- **퓨즈는 XL4015 「앞」(입력측).** 출력측에 넣으면 5A 부하에 끊긴다.
- 분기점은 **접촉기 앞** — 비상정지가 걸려도 카메라·센서는 살아 있어야 한다.

---

## 1. 퓨즈홀더 만들기 (BF303 ×4 — 2A ×2, 3A ×2)

BF303 은 통 양쪽에 **전선 리드가 달린 인라인 홀더**다. 통을 돌려 열면 5x20 퓨즈가 들어간다.

1. 통을 열고 **퓨즈를 끼운다.** 인젝터용 2개엔 **2A**, XL4015 용 2개엔 **3A**. 
   → 끼우자마자 통에 **유성펜으로 "2A" / "3A"** 적는다. 겉이 똑같아서 나중에 못 가린다.
2. 리드 한쪽을 **배터리A ⊕ 분기선**에, 다른 쪽을 **부하(인젝터 또는 XL4015 IN+)** 에 잇는다.
   방향은 없다 — 퓨즈는 극성이 없다.
3. 잇는 방법 둘 중 하나:
   - **납땜**: 피복 8mm 벗기고 꼬아서 납땜 → 수축튜브. 
   - **압착**: 리드 끝에 페룰·링단자 압착 → 단자대에 조임. 인두 없이 된다.
4. 🚨 **도착 시 확인**: BF303 페이지에 카트리지 치수가 없었다. 5x20 퓨즈가 **딸깍 들어가는지** 먼저 본다.
   안 들어가면 F-520 클립(110원) 2개를 리드에 납땜하는 대안.

## 2. XL4015 전압 조정 — 🚨 허브 연결하기 「전」에

**출고 상태 트리머가 12V 넘게 맞춰져 있을 수 있다. 그 상태로 허브를 꽂으면 허브가 죽는다.**
그래서 **허브를 안 꽂은 채로** 전압을 먼저 맞춘다.

1. **배터리 분리 상태**에서 배선한다:
   `배터리A ⊕ → [BF303+3A] → XL4015 IN+` · `배터리A ⊖ → XL4015 IN−`
   출력 단자(OUT+ / OUT−)에는 **아무것도 물리지 않는다.**
2. 단자 네 개 극성을 **눈으로 두 번** 본다. IN+/IN− 는 기판에 인쇄돼 있다. 반대로 물리면 모듈이 탄다.
3. 배터리 연결 (1·2번 먼저).
4. 멀티미터 DC V 모드, **빨강 → OUT+, 검정 → OUT−**. 지금 값을 읽는다. 5V 가 아닐 것이다.
5. **트리머**를 돌린다. XL4015 에는 트리머가 **둘** 있다 — CV(전압)·CC(전류).
   - 하나를 몇 바퀴 돌려 본다. **전압이 움직이면 그게 CV.** 안 움직이면 CC 다.
   - 멀티턴 트리머라 **10~20바퀴**는 돌아야 크게 바뀐다. 천천히.
   - **CC 는 시계방향 끝까지**(최대) 두면 된다. 전류 제한은 퓨즈가 하니 여기서 안 건다.
6. **5.0~5.1V** 에 맞춘다. 5.2 넘기지 말 것.
7. **배터리 분리.** 값이 유지되는지 재연결해서 한 번 더 읽는다 (트리머가 밀리지 않았는지).
8. 트리머에 **네일 락(매니큐어)이나 글루 한 방울** — 진동으로 돌아가는 걸 막는다.

## 3. DC 플러그 극성 확인 → 허브 연결

1. XL4015 OUT+ → DC 플러그 케이블 **빨강**, OUT− → **검정**. 단자대에 조인다.
2. 배터리 연결 → 멀티미터 빨강 탐침을 **플러그 안쪽 핀**에, 검정을 **바깥 통**에.
   **+5.0V 근처가 읽혀야 맞다.** 음수(−5V)가 나오면 빨강·검정이 바뀐 것 — 배터리 빼고 바꿔 조인다.
3. 확인됐으면 배터리 분리 → 플러그를 허브에 꽂는다 → 배터리 연결.
4. 허브 전원 LED 켜짐 확인. 포트 스위치 4개 ON.

---

## 4. 인젝터 분기 (같은 방식, 2A)

1. `배터리A ⊕ → [BF303+2A] → 인젝터 DC IN ⊕` · `배터리A ⊖ → 인젝터 DC IN ⊖`.
2. 인젝터 DC 입력이 **배럴잭이면** 5.5×2.1 케이블 하나 더(허브와 같은 것). **리드선이면** 직결.
3. 인젝터는 입력 범위가 12~48V 라 **조정할 게 없다.** 꽂으면 끝.
