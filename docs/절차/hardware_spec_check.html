5. 데이터 수집 전 "이것만은" 체크리스트

데이터를 모아도 못 쓰는 사고를 막으려면, 수집 전에 이 4개를 확인하세요:
☐ 블랙박스가 실제로 CSV를 쓰는가~/ssf_logs/에 파일이 쌓이나
☐ gyro_z·gps_vel 컬럼이 채워지나빈칸이면 /imu/data·/fix_velocity 발행 확인
☐ 로깅 주파수 20~50Hzsystem-ID는 촘촘해야 함
☐ 포트 이름이 맞나udev 없으면 /dev/ttyUSB0 등으로 바뀜 → 노드가 센서 못 찾음
내가 지금 다 알고 있는 것: 센서 모델 5종, 연결 방식(포트·baud·프로토콜), PWM 규약, 필요한 파라미터 목록과 얻는 방법.
내가 아직 모르는 것(측정해야 함): 새 배의 실제 물리값(폭·추력·관성), IMU 방향 부호, 대회장 좌표·자기편각, 카메라 실측 스펙(초점거리·왜곡).
→ 이건 "모르는 게 정상"입니다. 배와 대회장이 있어야 나오니까요.
