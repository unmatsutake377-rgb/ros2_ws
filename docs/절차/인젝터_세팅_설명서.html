PoE 인젝터 세팅 — PSE5502G

배터리 4S → 인젝터 → 이더넷 한 가닥 → OAK-1 PoE. 노트북 쪽(IP·드라이버·토픽)은 10-31 벤치에서 끝났으므로 여기선 전원 계통과 점화 확인만 다룬다. 1번배 기준, 2번배도 같다.

한 줄 요약. EC5 암 피그테일(접촉기 앞) → 2 A 퓨즈 → 인젝터 DC IN(배럴, 중심 +). 인젝터 POE OUT → 동봉 Cat5e → OAK. 인젝터 Ethernet IN → NM-UCL02 → 노트북 USB-C. 켜고 ping 169.254.1.222 되면 끝.

2퓨즈홀더5분

  1. BF303 통을 돌려 열고 5×20 유리관 2 A 를 끼운다. 딸깍 들어가는지 확인.
  2. 통에 유성펜으로 "2A 인젝터". 허브용 3 A 통과 겉이 똑같다.
  3. 퓨즈는 극성 없음. ⊕ 선에만 들어간다. ⊖ 엔 퓨즈 없음.

3분기 피그테일15분 · 배터리 분리 상태

배터리 A (4S) ── EC5 ── EC5 암 피그테일 ← 접촉기 5번보다 배터리 쪽. 비상정지가 걸려도 살아 있다 │ ├─ ⊕(빨강) ── BF303 2A ── 수 플러그 중심 핀 ─┐ │ ├─▶ 인젝터 DC IN └─ ⊖(검정) ─────────────── 수 플러그 바깥 ──┘ (허브 5 V 모듈 갈래도 같은 피그테일에서 딴다. 그쪽은 3 A)
  1. 피그테일 ⊕ 에서 BF303(2A) 을 거쳐 수 플러그 중심 핀으로. ⊖ 는 플러그 바깥으로.
  2. 갈래 합류는 납땜 + 수축튜브 또는 압착 분기단자. 트위스트에 테이프는 금지(진동에 풀린다).
  3. 잇고 나서 플러그 끝을 멀티미터로: 중심 +, 바깥 −. 인젝터 라벨 극성과 같은지 한 번 더.
접촉기 뒤에서 따지 않는다. 비상정지는 추진만 끊어야 한다. 뒤에서 따면 비상정지와 함께 영상이 끊겨 회수·진단이 안 된다. 승압 컨버터(접촉기 코일)·LTE 라우터와 같은 원칙.

4벤치 점화10분 · 배에 싣기 전

  1. 인젝터에 DC IN 만 연결. 벤치 파워 12~14 V, 전류제한 1 A(또는 배터리). DC RUN 켜짐. 안 켜지면 → §7.
  2. 전원 끄고 POE OUT ─ 동봉 Cat5e 2 m ─ OAK. Ethernet IN ─ Cat5e ─ NM-UCL02 ─ 노트북 USB-C. 두 포트 바꿔 꽂으면 안 켜진다.
  3. 전원 켬. 10~20 s 안에 POE RUN + OAK 뒷면 LED. OAK 부팅은 느리다.
  4. 노트북(10-31 에 만든 연결 그대로): 
    ip link | grep enx                       # 어댑터 UP 인가
nmcli con up oak-poe                     # 169.254.1.10/16
ping -c 3 169.254.1.222                  # 카메라 폴백 IP
sudo ethtool <enx…> | grep -E "Speed|Duplex"   # 기가비트 인젝터 확인 (10-31 은 100 Mb 반이중이었다)
    ping 0 % 손실이면 물리 계통 끝.
  5. 입력 전류 메모(벤치 파워 표시). 기대 0.4~0.6 A. 1 A 제한에 걸리면 어딘가 단락.
드라이버는 ping 뒤에. 드라이버를 끄면 카메라가 재부팅한다(2 s 뒤 끊김, 14 s 뒤 복귀). 다시 띄울 땐 20 s 기다린다. 토픽 확인은 ros2 topic hz /oak/rgb/image_raw, 640×360 MJPEG 에서 26 fps 가 10-31 기준값. 나머지(hfov 실측·HSV·vision.yaml 토픽 전환)는 oak_arrival_runbook.md §4~7.

5배에 싣기

부품자리이유
인젝터 (81×77×26)박스 안 벽면, 플랜지 나사 2개. 접촉기·ESC·굵은 배선과 떨어진 쪽비방수. 스위칭 노이즈원이라 IMU 선에서도 멀리
퓨즈홀더박스 안 배터리 쪽, 손 닿는 자리, 라벨 위로물 위에서 갈아 끼운다
Cat5e → OAK갑판 관통 1가닥, 실란트 + 드립 루프, 마스트 따라 꼭대기배 밖으로 나가는 유일한 선
Cat5e → 노트북박스 안에서 NM-UCL02 → 노트북 USB-CUSB-A 허브에 꽂지 않는다

케이블은 전부 타이로. 플러그 쪽은 커넥터에 하중 안 가게 5 cm 앞에서 한 번 묶는다. RJ45 는 양 끝 딸깍 소리.

6배 위에서 켜는 순서

  1. 배터리 EC5 연결. 인젝터 DC RUN 바로 켜짐(접촉기 상태와 무관해야 정상).
  2. 10~20 s 뒤 POE RUN. 노트북 ping 169.254.1.222.
  3. 비상정지 버튼을 눌러 본다. 추진은 죽고 DC RUN·POE RUN·ping 은 살아 있어야 분기점이 맞는 것.
  4. 대회 launch 올리고 ros2 topic hz /oak/rgb/image_raw.

8끝났다는 기준

  • 뒷면 라벨에 802.3af/at · DC 12~48 V 확인, 사진 보관
  • 퓨즈홀더 "2A 인젝터" 라벨, 손 닿는 자리
  • 플러그 끝 멀티미터 중심 + / 인젝터 라벨과 일치
  • 벤치: DC RUN → POE RUN → ping 0 % · 입력 전류 메모
  • 배: 비상정지 눌러도 DC RUN·POE RUN·ping 유지
  • ros2 topic hz /oak/rgb/image_raw 20 fps 이상
같이 온 승압 컨버터(24 V 3 A)는 이 문서 범위 밖. 접촉기 코일용이다. 결선은 회로_신규설계.md §3 — 입력도 접촉기 앞 EC5, 출력 24 V 먼저 재고 코일 A1·A2.
