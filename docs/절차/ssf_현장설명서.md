# ssf 현장 설명서 — 물가 MacBook 에서 값·웨이포인트·영상 다루기 (2026-11-10)

> 이것 하나로 현장에서 쓸 수 있게 만든 판. 파라미터 앱의 처음 설치·보안 설명은 `맥북_원격조작_설명서.md` §4-2A,
> 값별 권장 범위·결정은 `현장_조정표_20261106.md`, 웨이포인트 규칙 상세는 `웨이포인트_녹화절차.md`,
> 영상 문제 해결은 `실시간영상_빠른설명서.md`.
> 도구: `tools/ssf`(MacBook 명령) · `tools/ssf_param_app.*`(화면) · `tools/ssf_waypoints.py`·`ssf_wp_record.sh`(웨이포인트)
> · `tools/ssf_cam.py`·`ssf_cam_send.sh`(영상) · `tools/ssf_ros_net.sh`(ROS 격리).

## 0. 먼저 알아 둘 것

- 코드는 **배 노트북**에서 돈다. MacBook 은 SSH(Tailscale)로 붙어 화면·키보드 노릇만 한다.
- 🚨 **값은 판과 판 사이에만** 바꾼다. 바꾼 값은 yaml 에만 들어가고 **launch 재시작 뒤** 반영된다(`ros2 param set` 은 효과 없음).
- 🚨 **모드 전환은 조종기로만.** ssf·앱에는 그 기능이 없다.
- 🚨 영상은 조종과 **완전히 따로**다. 영상이 꺼지거나 죽어도 RC 조종은 그대로 된다.
- 녹화·영상은 배 노트북 **tmux** 안에서 돈다 → SSH 가 끊기거나 브라우저를 닫아도 계속된다. 같은 명령(또는 앱)으로 다시 붙는다.

| 배 | SSH 별명 | 앱 주소 | 영상 포트 | 녹화 세션 | 영상 세션 |
|---|---|---|---|---|---|
| 1번배 | `boat-a` | http://localhost:8765 (파란 띠) | 5600 | `ssf_wp_A` | `ssf_cam_A` |
| 2번배 | `boat-b` (계정 `ssfb`) | http://localhost:8766 (주황 띠) | 5601 | `ssf_wp_B` | `ssf_cam_B` |

## 1. 처음 한 번 (MacBook)

1. SSH 키 접속: `~/.ssh/config` 에 `boat-a`·`boat-b`, `ssh-copy-id boat-b`(비밀번호는 본인이 입력). 확인:
   ```bash
   ssh -o BatchMode=yes boat-b hostname
   ```
2. ssf 받기 — 저장소가 없는 MacBook:
   ```bash
   scp boat-b:ros2_ws/tools/ssf ~/ssf && chmod +x ~/ssf
   ```
   `~/.zshrc` 에 `alias ssf=~/ssf`. 🚨 배 노트북을 `git pull` 한 뒤에는 **이 scp 를 다시** 해야 새 명령이 생긴다.
3. 배 등록(각 배 한 번) — 출력의 hostname 이 그 배 노트북이 맞는지 본다:
   ```bash
   ssf b init
   ```
4. 영상 수신용 gstreamer(없으면): `brew install gstreamer`. 처음 수신 때 macOS 가 연결 허용을 물으면 **허용**.

## 2. 매번 — 앱 켜기

```bash
ssf app b
```
`ssf app both` 면 두 배 다. 끄기 = 그 터미널에서 **Ctrl+C**. 탭: 현장 조정 · 전체 파라미터 · 저장소와 다른 값 · **웨이포인트** · **영상** · 바꾼 기록.
위 오른쪽 **launch 실행 중 / 꺼짐** 표시를 보고, 실행 중이면 값 적용·녹화는 판과 판 사이에.

**위쪽 RTK 불**(모든 탭, 2 초마다 — 배 GPS `/ublox_gps_node/navpvt` 의 carrSoln):

| 불 | 뜻 · 할 것 |
|---|---|
| 🟢 RTK FIXED ±1.5cm | 보정 정상 — 웨이포인트 찍어도 됨 |
| 🟡 RTK FLOAT | 보정은 들어옴 — FIXED 될 때까지 기다림 |
| 🟠 GPS 단독 | 보정 없음(±수 m) — NTRIP·인터넷(핫스팟) 확인 |
| 🔴 위치 없음 | 하늘·안테나 확인 |
| ⚫ GPS 없음 | GPS 드라이버(launch)가 안 돎·3 s 넘게 끊김 |

불은 배 노트북의 작은 감시 노드(`tools/ssf_gps_watch.py`, **구독만**, tmux `ssf_gps_<배>`)가 켠다 — 앱이 띄우고, 앱을 2 분 안 보면 스스로 끝난다.
ROS 격리(`ROS_LOCALHOST_ONLY`)를 그대로 써서 다른 배 GPS 는 보지 않는다. 터미널로는 `ssf b gps` (FIXED 면 종료 코드 0).

## 3. 값 바꾸기 (현장 조정 탭)

항목마다 아래 안내가 늘 보인다(내용은 현장_조정표에 있는 것만).

| 배지 | 뜻 | 예 |
|---|---|---|
| 🔴 매 경기 교체 | 당일 공지·경기장마다 바꾼다 | 도킹 표식 색·모양, 부표 색, `hsv.<공지 색>`, `geofence_polygon` |
| 📏 실측해서 넣기 | 재서 넣는다(지어내지 않는다) | `mount_offset_deg`, `invert_yaw`, `dwa_lidar_x_m`, `dwa_model_agility` |
| 🌊 물 위 확인 후 조정 | 실배를 보고 고른다 | `hold_dist_m`, `side_escape_deg`, `front_median_kernel` … |
| ⚪ 보통 그대로 | 문제 있을 때만 | `dist_tol_m`, 후진 시간 … |
| 🔒 바꾸지 않음 | 결정된 값 | `side_lock_enabled`(대회 false) |

- 배지를 누르면 그 종류만 보인다. 각 줄: **무엇 · 권장 · 확인(실배에서 볼 것) · 되돌리기**.
- 값을 바꾸고 아래 **확인하고 적용** → 전 → 후, 파일, 영향 코스(⚠️ 공통 파일이면 종합임무·토너먼트 둘 다) 확인 → **N번배에 적용**.
- 거부되면 이유가 그대로 뜬다(범위 밖, 정수 자리에 소수, 폴리곤 위경도 뒤바뀜 등). 우회하지 말고 값을 고친다.
- 적용 뒤: launch 재시작 → 시작 로그·`ros2 param get` 으로 확인 → **현장_조정표 §4 기록란**에 적는다.

터미널로 하려면(먼저 `--dry-run`):
```bash
ssf b set hold_dist_m 3.0 --dry-run
```
`get` · `set … --course tournament` · `undo` · `diff` · `log` — `ssf` 만 치면 사용법.

## 4. 웨이포인트 찍기

### 4-1. 앱에서 (웨이포인트 탭, 추천)

1. 배를 띄우고 위쪽 불이 **🟢 RTK FIXED** 인지 본다(또는 `ssf b gps`).
2. **녹화 시작**: 코스(토너먼트 / 종합임무), 토너먼트면 레인 이름(영문·숫자, 예 `1`).
   - 화면에 `ROS 격리: ROS_LOCALHOST_ONLY=1` 이 보여야 한다(다른 배 GPS 가 섞이지 않게).
   - 같은 파일이 이미 있으면 `~/ssf_logs/waypoint_backup/` 에 먼저 복사된다.
3. 노란 줄 **"지금: …"** 이 무엇을 묻는지 보고 그 버튼만 쓴다.

| 지금 | 할 것 |
|---|---|
| 명령을 기다리는 중 | 조종기로 지점에 대고 몇 초 머문 뒤 **📍 지금 위치 찍기**. 목록 · 번호 삭제 · 번호 다시 찍기 · **💾 저장·종료** |
| mode / dwell / 이름을 묻는 중 | 답 칸에 입력(Enter) 또는 **⏎ 기본값 그대로**(템플릿 값) |
| 끝 | 검사 결과를 보고 **창 닫기** |

4. 찍기 성공 = 화면에 `표본 N개 평균 → lat …, lon … (최대 공분산 …)`. `⚠️ 최근 GPS fix 없음` 이면 GPS·RTK 부터. 공분산 경고면 다시 찍는다.
   - 녹화 패널 맨 위에 RTK 상태가 크게 보인다. **FIXED 가 아닐 때 📍 찍기를 누르면 확인 창**("RTK FIXED 가 아니다 — 그래도 찍을까요?")이 뜬다.
   - 녹화 시작 화면 ①에도 그 순간의 GPS 상태가 한 줄 찍힌다.
5. 저장 뒤 **"✅ 이번 녹화를 저장했다"** 를 확인. `⚠️ 이번에 저장된 것이 없다` 면 그 파일은 이전 것 — 쓰지 않는다.
6. 아래 파일 목록에서 ✅/⚠️/❌ 와 mode 순서를 보고, 화면의 `waypoints_file:=…` 를 launch 인자로 쓴다. 어느 파일을 썼는지 현장_조정표 §4 에.

규칙(상세 `웨이포인트_녹화절차.md`):
- mode 는 0·1·2·3·5·7·8 만. mode 2·3 은 부표 좌표에서.
- **종합임무**: WP7 다음 점은 엔터 금지 — mode 8 · dwell 3 · 이름 `WP10 토너먼트 회피` 직접 입력. 도킹 네 줄은 `tools/dock_wp.py` 출력을 끼운다.
- **토너먼트**: 레인마다 다른 파일, 전부 mode 8, 마지막 점 = 결승선 너머 약 3 m · dwell 0.5 · 경기장 경계 안
  (`geofence_polygon` 을 넣었으면 목록이 경계 밖 점을 ⚠️ 로 잡는다).
- 녹화본은 저장소 파일에 복사하지 않는다(`~/ssf_logs/` 에만).

강제 종료(저장 안 함)는 확인 창을 거친다 — 저장(q) 안 한 점은 버려진다.

🚨 **녹화는 한 사람이 한 곳에서.** 앱·`ssf` 버튼끼리는 배 노트북이 하나씩 처리하지만(동시에 눌러도 두 번째는 거부), 누군가 터미널에서 녹화 창(tmux)에 직접 붙어 키를 치면 그 키는 막을 수 없다.

### 4-2. 터미널로

```bash
ssf b wp tournament 1
```
- `ssf b wp main`(종합임무), `ssf b wp`(목록·검사만), 끝에 `--dry-run` 이면 실행할 명령만 보여 준다.
- 앱과 **같은 tmux 세션**이라 터미널에서 시작해 앱에서 이어도 된다.
- 다른 코스·레인 녹화가 열려 있으면 `❌ 다른 녹화가 열려 있다(…)` 로 거부 → 그 녹화를 저장·종료하거나 앱에서 강제 종료.
- 위를 보고 싶으면 트랙패드 스크롤(마우스 모드) — 빠져나오기 `q`. 앱 버튼은 이 상태에서도 알아서 빠져나온 뒤 보낸다.

## 5. D455 실시간 영상

### 5-1. 켜기

1. D455 를 노트북 **USB 3(파란) 포트**에 꽂고 5 초. 앱 **영상** 탭의 `D455 USB` 가 ✅ 여야 한다.
2. **흔들기 시험**(출항 전): 배 노트북에서 `dmesg -w` 를 띄우고 카메라·케이블·커넥터를 흔든다 → `disconnect` 0.
   케이블 불량이면 허브째 끊겨 **IMU(헤딩)까지** 끊긴다(`실시간영상_빠른설명서.md` §3-1).
3. MacBook:
   ```bash
   ssf b cam
   ```
   배 송신(tmux) + 이 Mac 수신 창. Mac 주소(Tailscale)는 자동, 포트는 1번배 5600 · 2번배 5601.
4. 창의 **좌상단 시계 = 배 시각**. 멈추면 영상이 멈춘 것 — 화면을 믿지 않는다.

### 5-2. 끄기·다른 방법

- **Ctrl+C 한 번** = 수신 창 + 배 송신 둘 다 끔. 터미널 창을 그냥 닫아도 송신은 꺼진다.
- 앱 영상 탭: **▶ 송신 켜기 / ■ 송신 끄기**, 송신 로그 끝. 그때 수신 창만: `ssf b cam view`.
- `ssf b cam status` = D455 USB · 모드 · 로그, `ssf b cam stop` = 송신만 끔.
- 자율 launch 가 D455 를 쥐고 있으면(카메라 노드) 자동으로 `ros` 모드(640x480), 아니면 `v4l2`(424x240).

## 6. 안 될 때

| 보이는 것 | 원인 · 할 것 |
|---|---|
| `command not found: ssf` | §1-2 |
| `Permission denied (publickey,password)` | 키 미등록 또는 계정 이름 틀림(2번배 `ssfb`). `ssh-copy-id boat-b` |
| `Connection refused` (port 22) | 그 노트북에 SSH 서버 꺼짐 — 노트북에서 `sudo apt install -y openssh-server` → `sudo systemctl enable --now ssh` |
| `🚨 배가 다르다` | 별명과 등록이 어긋남 — 어느 노트북이 몇 번 배인지 확인 후 `ssf b init` |
| 앱이 15 초 안에 안 뜸 | 배 노트북 `git pull` 됐는지, `python3 -c "import yaml"` |
| 포트 8765/8766 사용 중 | 이 Mac 에 남은 터널: `lsof -i :8766`. 🚨 연습 모드(`ssf_practice`)를 진짜 앱과 같은 포트로 띄우면 진짜 앱이 꺼진다 |
| 웨이포인트 `❌ 이미 녹화 중` / `다른 녹화가 열려 있다` | 열린 녹화를 이어서 하거나 저장·종료 / 앱에서 강제 종료 |
| 웨이포인트 버튼이 `다른 걸 묻고 있다` 로 거부 | 노란 "지금:" 줄의 질문에 먼저 답한다 |
| `⚠️ 최근 GPS fix 없음` | GPS·RTK 상태. 화면에 `ROS 격리` 줄이 있는지 |
| RTK 불 ⚫ `GPS 감시 실패: …` | 문구 그대로 — ROS 환경·`ublox_msgs` 빌드 확인 |
| RTK 불이 계속 🟠 단독 | NTRIP 접속(인터넷·핫스팟). 마운트포인트는 측정 장소 30 km 이내(`웨이포인트_녹화절차.md` §1) |
| 녹화 화면 `❌ 중간에 끝났다(코드 N)` | 그 위 문구가 원인. 창은 엔터(앱: 창 닫기)로 닫는다 |
| 영상 `D455 USB ❌` / 로그 `RealSense 컬러 장치가 없다` | 꽂고 5 초, 파란 포트, 허브 전원, 케이블 — `실시간영상_빠른설명서.md` §3 |
| `❌ 이미 송신 중` | 보기만: `ssf b cam view` · 끄기: `ssf b cam stop` |
| 영상 창이 안 뜸 | 송신 로그의 `대상 : 100.x.x.x:포트` 가 이 Mac 주소인지 · macOS 연결 허용 · `tailscale status` |
| 연결 끊김 | `tailscale status` 로 배 노트북이 보이는지 |
