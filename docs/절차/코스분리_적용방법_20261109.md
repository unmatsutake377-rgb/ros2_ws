## 0. 받기 전에 — 예전 파라미터 저장 (② 비교용)

받기 전 코드로 한 번 띄워서 파라미터를 저장해 둔다. 이미 pull 했다면 이 단계는 건너뛰고 ②는 "dwa_hull 값만 확인"으로 대신한다.

```bash
cd ~/ros2_ws && ros2 launch launch_files launch_files.launch.py boat:=A
```

다른 터미널에서 (2번배는 파일 이름의 A 를 B 로):

```bash
mkdir -p ~/ssf_logs/param_dump && ros2 param dump /ship_direction > ~/ssf_logs/param_dump/before_ship_direction_A.yaml && ros2 param dump /motor_control > ~/ssf_logs/param_dump/before_motor_control_A.yaml && ros2 param dump /north_goal_angle > ~/ssf_logs/param_dump/before_north_goal_angle_A.yaml
```

launch 는 `Ctrl+C` 로 끈다.

## 1. 받기·빌드·테스트

```bash
cd ~/ros2_ws && git pull --no-rebase && colcon build --symlink-install && colcon test && colcon test-result --verbose | tail -20
```

`colcon test` 실패가 있으면 여기서 멈추고 결과를 보낸다(Mac 에는 ROS·flake8 이 없어 lint 는 여기서 처음 돈다).

## 2. 새 launch 명령

종합임무·수조·실해역 시험 (2번배는 `boat:=B`):

```bash
ros2 launch launch_files launch_files.launch.py boat:=A course:=main
```

토너먼트 (레인별 녹화본 경로 — `docs/절차/웨이포인트_녹화절차.md` §3a):

```bash
ros2 launch launch_files launch_files.launch.py boat:=A course:=tournament waypoints_file:=$HOME/ssf_logs/waypoints_tournament_A_1.yaml
```

- 🚨 `boat:=A` 만 주면 이제 **launch 가 거부**한다(`course` 필수).
- `waypoints_file` 을 비우면 `config/waypoints_tournament.yaml` 템플릿(자리표시 좌표)으로 뜬다 → 경기에서는 반드시 녹화본.
- 판(경기) 사이에는 launch 를 다시 띄운다(웨이포인트 순번이 되돌아가지 않는다).
- `dwa_hull` 은 launch 가 `boat` 로 자동으로 넣는다 → 2번배 yaml 손편집 하지 않는다.

## 3. 부팅 확인 6가지 (벤치, 프로펠러 물 밖·비상정지 눌러 ESC 무전원)

| # | 할 것 | 통과 기준 |
|---|---|---|
| ① | `ros2 launch launch_files launch_files.launch.py boat:=A` | launch 가 거부하고 노드가 하나도 안 뜬다 |
| ② | `course:=main` 으로 띄우고 0단계처럼 `ros2 param dump` → `after_*.yaml` 로 저장, `diff ~/ssf_logs/param_dump/before_ship_direction_A.yaml ~/ssf_logs/param_dump/after_ship_direction_A.yaml` (motor_control·north_goal_angle 도) | 1번배: 차이 0. 2번배: `/ship_direction` 의 `dwa_hull` 이 'B' 로 바뀐 것 하나만. north 에 `course: main`·`waypoints_file` 이 새로 보이는 것은 정상 |
| ③ | `course:=tournament` (waypoints_file 비움) | 시작 로그에 `course=tournament`·`waypoints_tournament.yaml`·`미션 순서(mode): [8, 8]`·`DWA 켬: 선체 A`(2번배 B)·경계선 WARN. `ros2 param get /ship_direction dwa_enabled` → true, `ros2 param get /motor_control goal_slow_min_ratio` → 1.0 |
| ④ | `course:=tournament waypoints_file:=$HOME/ros2_ws/src/north_goal_angle/config/waypoints.yaml` | north 가 ERROR(몇 번째 웨이포인트가 mode 몇인지) 내고 멈춘다 — 배가 출발하지 않는다 |
| ⑤ | 마지막 웨이포인트(mode 8)를 지나게 한 뒤 `ros2 topic hz /candidate_angle`, `ros2 topic echo /candidate_angle` | 약 2 Hz 로 값 50000, `🏁 코스 … 끝` INFO 1회, `Motor_run` 15001500. main·tournament 둘 다 |
| ⑥ | `ros2 launch north_goal_angle north_goal_angle_launch.py` (인자 없음) | 로그 `course=main`, 웨이포인트 `config/waypoints.yaml` |

⑤는 실제로 배를 움직이기 어려우면 웨이포인트 파일을 노트북 현재 위치 근처 2점짜리로 만들어 `waypoints_file:=` 로 준다(저장소 파일은 고치지 않는다).

**하나라도 실패하면** 코스 분리를 쓰지 않는다 → 결과를 보내고, 계약서 §9-9 대안(토너먼트 당일 waypoints.yaml 교체·복원)으로 간다.
