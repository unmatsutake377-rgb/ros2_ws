OAK 카메라 · USB 허브 세팅 설명서 (2026-10-26)

누가: 회로 담당 + 소프트 담당 한 명씩. 어디서: 벤치(물 밖). 얼마나: 처음은 반나절. 이 문서는 손으로 하는 순서다. 소프트웨어 세부(드라이버·IP·토픽·화각)는 oak_arrival_runbook.md §1~7 이 원본이고 여기선 그 순서만 부른다. 배터리 연결은 항상 1·2번 먼저 → 5·6번. 작업 중엔 배터리 분리가 기본.

준비물: 멀티미터, 압착기 또는 인두+수축튜브, 드라이버, 유성펜, 케이블타이, 벤치 파워서플라이(12~24V, 전류제한 1A — 배터리 대신 첫 시험용).

1. 퓨즈홀더 2개 만들기 (10분)

  1. BF303 통을 돌려 연다. 5×20 유리관 퓨즈가 딸깍 들어가는지 먼저 본다(페이지에 치수가 없었다). 안 들어가면 F-520 클립(110원)으로 대체.
  2. 하나엔 2A, 다른 하나엔 3A. 끼우자마자 통에 유성펜으로 "2A 인젝터" / "3A 허브". 겉이 똑같다.
  3. 퓨즈는 극성 없다. 어느 쪽 리드가 배터리 쪽이든 상관없다.

2. 분기 피그테일 만들기 (15분)

EC5 암 피그테일 한 가닥의 ⊕(빨강) 에서 두 갈래를 딴다. ⊖(검정)도 두 갈래.

피그테일 ⊕ ──┬── BF303(2A) ── (수 플러그 ⊕) → 인젝터
            └── BF303(3A) ── SZWENGAO IN+ (빨강)
피그테일 ⊖ ──┬── (수 플러그 ⊖) → 인젝터
            └── SZWENGAO IN− (검정)
  • 갈래 합류는 납땜 + 수축튜브 또는 압착 분기단자. 트위스트만 하고 테이프 감는 건 금지 — 배 진동에 풀린다.
  • ⊕ 선에만 퓨즈. ⊖ 엔 퓨즈 없음.
  • 5V 모듈 리드선 색: 빨강 IN+ · 검정 IN− · 노랑 OUT+ · 검정 OUT− 가 보통이지만 모듈 라벨로 확인(Input / Output 인쇄돼 있음). 반대로 물리면 모듈이 탄다.

3. 허브 계통 먼저 (20분) — 카메라보다 쉽고 인젝터 없이 된다

  1. 배터리 분리 상태. 피그테일 ⊖ → SZWENGAO IN−, ⊕ → BF303(3A) → SZWENGAO IN+.
  2. 출력엔 아직 아무것도 안 꽂는다.
  3. 벤치 파워 12~14V 를 피그테일 EC5 에(또는 배터리 연결). 멀티미터 DC V: 빨강 → OUT+, 검정 → OUT−. 4.9~5.1V 면 정상. 아니면 모듈 불량 — 2개 있으니 교체.
  4. 전원 끄고 DC 5.5×2.1 수 플러그 케이블을 OUT 에 잇는다: 중심 핀 = ⊕(OUT+), 바깥 = ⊖. 잇고 나서 플러그 끝을 멀티미터로 한 번 더(중심 +).
  5. UH308 DC IN 에 플러그. UH308 USB 업스트림 → 노트북 USB-A②. 전원 켜고 허브 LED.
  6. 라이다·IMU·GPS·D455 를 허브에. 노트북에서: bash lsusb ls /dev/ttyLiDAR /dev/IMU /dev/ttyGPS 2>/dev/null 넷 다 보이면 끝. D455 는 /dev/video* 로.
  7. 🚨 아두이노는 허브에 꽂지 않는다. 노트북 USB-A① 직결. 수신기 전압이 여기 달렸다(허브 경유 4.09V, 최소 4.0).

4. 카메라 계통 (인젝터 도착 후, 30분)

  1. 배터리 분리. 피그테일 ⊖ → 수 플러그 ⊖, ⊕ → BF303(2A) → 수 플러그 ⊕. 플러그 끝 극성 확인(중심 +).
  2. 인젝터 라벨에서 DC IN 극성 확인(보통 중심 +). 맞으면 꽂는다. ⚠️ 역극성 보호 없는 제품이다 — 과전압 보호와 다르다.
  3. 인젝터 PoE OUT(또는 "PoE/Data") 포트 → OAK 동봉 Cat5e 2m → OAK. 인젝터 LAN(또는 "Data In") 포트 → NM-UCL02 → 노트북 USB-C. ⚠️ 두 RJ45 포트를 바꿔 꽂으면 안 켜진다. 인젝터 몸체에 PoE/LAN 인쇄 확인.
  4. 벤치 파워 12~14V(또는 배터리) 연결. 인젝터 LED, 10~20초 뒤 OAK 뒷면 LED. OAK 는 부팅에 시간이 걸린다.
  5. 노트북 쪽은 런북 §3 그대로: bash ip link # enx… 가 UP 인가 nmcli con add type ethernet ifname <enx…> con-name oak-poe ipv4.method manual ipv4.addresses 169.254.1.10/16 nmcli con up oak-poe ping -c 3 169.254.1.222 # 카메라 공장 기본 IP ping 되면 물리 계통 끝. 안 되면 §6.
  6. 이후(드라이버 → 토픽 이름 → vision.yaml → hfov_deg 실측 → HSV)는 oak_arrival_runbook.md §1·§4~7. 소프트 담당.

5. 박스 안에 넣기

부품 자리 이유
인젝터 PSE5502G (81×77×26) 박스 안, 접촉기와 떨어진 벽면. DIN 레일 or 플랜지 나사 비방수
SZWENGAO 5V (64×57×22) 박스 안 아무 데나. IP68 이지만 방열 위해 밀착 금지 발열 25W급
UH308 박스 안, 노트북 옆. 케이블 7개가 나온다
퓨즈홀더 2개 박스 안 배터리 쪽, 손 닿는 자리. 라벨 위로 물 위에서 갈아 끼울 수 있게
관통 Cat5e 1가닥(OAK)만 갑판 관통 → 마스트. 실란트 + 드립 루프 배치 요구사항 §2-2

케이블은 전부 타이로 고정. 플러그 쪽은 커넥터에 하중 안 가게 5cm 앞에서 한 번 묶는다.
