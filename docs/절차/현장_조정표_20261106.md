# 현장 조정표 (실해역·대회장) — 2026-11-06

실제 배로 확인한 뒤 **yaml 값만** 바꿔 적용하는 항목. 코드는 현장에서 고치지 않는다.
근거: `docs/문제와작업/계약서_옆비킴_현장조정_20261106.md`, `docs/문제와작업/시뮬3자유도_발견_20261106.md`.

## 1. 바꾸는 법

1. 판과 판 사이에만 바꾼다. 경기 중에는 손대지 않는다.
2. 배 노트북에서 해당 yaml 을 연다: `~/ros2_ws/src/<패키지>/config/<파일>.yaml`
3. 값은 **소수점으로** 쓴다(`3.5`, `60.0`). 정수(`3`)로 쓰면 노드가 부팅 때 죽고 그 임무가 침묵한다.
4. launch 를 다시 띄운다. 노드는 시작 때 한 번만 읽는다 — `ros2 param set` 은 **효과가 없다**(오류도 안 남).
5. 반영 확인: `ros2 param get /<노드> <이름>` 과 노드 시작 로그.
6. 반영이 안 되면(설치 폴더가 symlink 가 아닐 때) 그 패키지만 빌드:

```bash
cd ~/ros2_ws && colcon build --symlink-install --packages-select ship_direction
```

⚠️ launch 재시작 = 브릿지 재연결. udev 규칙(`tools/udev/98-ssf-serial-safety.rules`)이 없으면 아두이노가 리셋돼 ESC 시동까지 **15~25 s 공백**. 다시 띄운 뒤 ESC 시동음·`/boat_*` 확인하고 출발.
⚠️ 설치 폴더 symlink 여부는 Ubuntu 에서 아직 확인 안 함: `ls -l ~/ros2_ws/install/ship_direction/share/ship_direction/config/`

현장에서 바꾼 값은 돌아와서 저장소 yaml 에 반영할지 정한다(두 배가 다르면 저장소에는 공통값, 배별 값은 이 표에).
노트북에서 `git diff src/*/config/` 로 바꾼 곳 확인.

🚨 **두 배 공용 파일 규칙 (2026-11-09)** — 배별 파일은 `ssf_heading_A/B.yaml` 뿐이고, 나머지(`motor_control.yaml`·`ship_direction.yaml`·`waypoints.yaml` 등)는 두 배가 같은 파일을 쓴다.
- **배 노트북에서 `src/*/config` 를 커밋·push 하지 않는다.** 한 배 값이 저장소에 올라가면 다른 배가 `git pull` 로 그 값을 받는다. 공통값 반영은 메인 컴퓨터에서 이 표를 보고 한다.
- 노트북에 손편집이 남은 채 `git pull --no-rebase` 가 "would be overwritten" 으로 막히면: `git stash && git pull --no-rebase && git stash pop` → 충돌 나면 손편집 값을 이 표에서 다시 넣는다.
- 2번배 고정 손편집: DWA 켤 때 `dwa_hull: 'B'`. 두 배 코스가 다르면 `waypoints.yaml` 도 배별 손편집(녹화본 `~/ssf_logs/waypoints_recorded.yaml`) — 이 표에 기록.
