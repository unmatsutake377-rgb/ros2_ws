## 1. 안전을 위한 주의사항 (반드시 먼저 읽으십시오)

1. 🚨 **모드 전환(수동 ↔ 자율)은 조종기(RC)로만 합니다.** 노트북에서 `/boat_mode` 를 바꾸지 마십시오.
2. 🚨 **프로펠러가 물 밖일 때만 벤치 시험을 합니다.** 비상정지를 눌러 ESC 전원을 끈 상태가 기본입니다.
3. 🚨 **조향 부호(`steer_invert`)와 IMU 방향(`invert_yaw`)을 확인하기 전에는 자율로 출발하지 마십시오.** 가장 흔한 사고입니다(배가 정반대로 감).
4. 🚨 **설정 파일을 고친 뒤에는 launch 를 다시 시작합니다.** `ros2 param set` 은 효과가 없습니다(노드가 시작할 때 한 번만 읽습니다).
5. 🚨 **배 노트북에서 고친 값은 git 에 커밋하지 않습니다.** 현장 기록은 `docs/절차/현장_조정표_20261106.md` §4 기록표에 적습니다.
6. 🚨 **NTRIP(GPS 보정) 접속 정보는 `~/.ssf/` 에만 둡니다.** 저장소·채팅에 올리지 마십시오.

## 2. 구성 — 무엇이 무엇을 하나

```
 센서                         판단                                   구동
 ─────                        ─────                                  ─────
 GPS(ZED-F9P) ──▶ north_goal_angle ── 목표 방위 ──▶ ship_goal_angle ── /yaw_error ──┐
 IMU(iAHRS) ──▶ yaw_mux ── /imu/yaw ──┘     │ /wp_mode, /candidate_angle            │
                                          │ /geofence_state(경계)                 ▼
 카메라(OAK-1) ─▶ 검출기(gate·turn·dock) ─▶ 미션 노드(ship_gate·ship_back·ship_dock)
                                                        │ /candidate_angle      │
 LiDAR(RPLIDAR A3) ───────────────────────────────▶ ship_direction ── /desired_angle ──▶ motor_control ──▶ ssf_bridge ──▶ 아두이노 ──▶ 스러스터
```

| 노드 | 하는 일 | 설정 파일 |
|---|---|---|
| `yaw_mux` | IMU 원시 yaw 를 보정해 `/imu/yaw` 로 냅니다 (배마다 장착값이 다름) | `ssf_heading/config/ssf_heading.yaml` + `ssf_heading_A.yaml` / `_B.yaml` |
| `north_goal_angle` | 웨이포인트를 순서대로 따라가며 목표 방위·거리, 미션 번호(`/wp_mode`), 경계(지오펜스)를 냅니다 | `north_goal_angle/config/north_goal_angle.yaml` + 코스별 파일 + 웨이포인트 파일 |
| `ship_goal_angle` | 목표 방위와 현재 헤딩의 차이(`/yaw_error`)를 냅니다 | `ship_goal_angle/config/ship_goal_angle.yaml` |
| 검출기 3개 | 카메라에서 부표·표식 색과 모양을 찾아 각도를 냅니다 | `color_shape_detector/config/vision.yaml` |
| `ship_gate` | 게이트(mode 0·1): 빨강·초록 부표 사이로 들어갑니다 | `ship_gate/config/ship_gate.yaml` |
| `ship_back` | 위치유지(mode 2)·탐색(mode 3): 부표 앞 일정 거리에서 버팁니다 | `ship_back/config/ship_back.yaml` |
| `ship_dock` | 도킹(mode 7): 표식을 찾아 정렬·접안·이탈합니다 | `ship_dock/config/ship_dock.yaml` |
| `ship_direction` | LiDAR 로 장애물을 피하며 최종 조향각을 정합니다. 페일세이프(센서 끊김 시 감속·정지)도 여기 있습니다 | `ship_direction/config/ship_direction.yaml` + 토너먼트 파일 |
| `motor_control` | 조향각을 좌우 모터 PWM 으로 바꿉니다 | `motor_control/config/motor_control.yaml` + 토너먼트 파일 |
| `ssf_bridge` | PWM 을 아두이노로 보냅니다 (추력 방향 반전은 여기 한 곳) | 파라미터 기본값 사용 |

**미션 번호(`wp_mode`)와 담당**

| mode | 미션 | 담당 노드 |
|---|---|---|
| 0 · 1 | 게이트 시작 · 끝 | `ship_gate` |
| 2 | 위치유지 | `ship_back` |
| 3 | 탐색 부표(색 찾기) | `ship_back` (기본 `search_behavior:=hold`) |
| 5 | 장애물 회피 | 없음 = 정상 (`ship_direction` 단독) |
| 7 | 도킹 | `ship_dock` |
| 8 | 토너먼트 회피 | 없음 = 정상 (`ship_direction` 단독, 토너먼트에서는 DWA 켬) |

**특수 신호값** — `/candidate_angle`·`/desired_angle` 에 이 숫자가 오면 각도가 아니라 명령입니다.

| 값 | 뜻 |
|---|---|
| `5000` | 제자리 우선회 |
| `6000` | 제자리 좌선회 (예약, 지금 쓰는 노드 없음) |
| `20000` | 미션 없음 → GPS 방향으로 가며 LiDAR 회피 |
| `50000` | 정지 (STOP_HOLD) |
| `180` → `260` | 후진 (미션 노드가 180 을 내면 `ship_direction` 이 260 으로 바꿔 냄) |
| `10000` | (검출기) 표식 안 보임 |

## 3A. MacBook 에서 값 넣기 — SSH (현장 기본 방법)

배는 물 위에 있고 배 노트북 키보드에는 손이 안 닿습니다. **현장에서는 물가 MacBook Air 에서 SSH 로 배 노트북에 붙어 값을 넣습니다.**

- **코드는 배 노트북에서 돕니다. MacBook 은 키보드와 화면일 뿐입니다.** MacBook 에는 ROS 가 없습니다. 모든 `ros2` 명령은 SSH 창 안에서 칩니다.
- 연결 길: MacBook ─(Tailscale)─ 배 노트북 SSH. 처음 한 번 하는 설정(주소 별명 `boat-a`·`boat-b`, 키 등록)은 `docs/절차/맥북_원격조작_설명서.md` §1~§2.
- ⏳ MacBook → 배 SSH 는 아직 확인 기록이 없습니다. **대회 전에 `ssh boat-a`·`ssh boat-b` 를 한 번씩 해 보십시오.**

### 3A-1. 값 하나 바꾸기 — 매번 이 순서

| 순서 | 어디서 | 명령 | 하는 일 |
|---|---|---|---|
| ① | MacBook 터미널 | `ssh boat-a` (2번배 `ssh boat-b`) | 배 노트북에 접속 |
| ② | SSH 안 | `hostname` | 🚨 **어느 배인지 확인.** 1번배에 붙어 2번배 파일을 고치는 사고 방지 |
| ③ | SSH 안 | `tmux attach -t ssf` (없으면 `tmux new -s ssf`) | 🚨 SSH 가 끊겨도 launch 가 안 꺼지게 tmux 안에서 작업 |
| ④ | tmux 창 3 | `cd ~/ros2_ws && nano src/ship_direction/config/ship_direction_tournament.yaml` | 파일 열기 (경로는 아래 3A-2 표) |
| ⑤ | nano | `Ctrl+W` → 키 이름 입력 → Enter | 바꿀 줄 찾기. 값만 고치고 `#` 뒤 설명·들여쓰기는 그대로 |
| ⑥ | nano | `Ctrl+O` → Enter (저장), `Ctrl+X` (나가기) | 저장 |
| ⑦ | SSH 안 | `python3 tools/param_check.py src/ship_direction/config/ship_direction_tournament.yaml` | **검사.** 무엇을 바꿨는지 보여 주고, 소수점·정수·빈 리스트·오타 키를 잡습니다. ✅ 가 나와야 다음으로 |
| ⑧ | SSH 안 | (3장 ③ 에서 화살표가 없던 노트북만) `colcon build --symlink-install --packages-select ship_direction` | 설치 폴더에 반영 |
| ⑨ | tmux 창 0 | `Ctrl+C` → launch 명령 다시 (6장) | 🚨 **재시작해야 반영됩니다** |
| ⑩ | tmux 창 3 | `ros2 param get /ship_direction dwa_enabled` | 새 값이 들어갔는지 확인 |
| ⑪ | — | 현장 조정표 §4 기록표 | 바꾼 값·시각·이유 기록. 🚨 배 노트북에서 커밋하지 않음 |

**원래 값으로 되돌리기:** `git restore src/ship_direction/config/ship_direction_tournament.yaml` → launch 재시작. (그 파일에서 고친 것 전부가 저장소 값으로 돌아갑니다.)
**지금까지 고친 것 보기:** `git status --short src/` (어느 파일을 고쳤는지), `python3 tools/param_check.py <파일>` (무슨 값을 바꿨는지).

`param_check` 가 잡아 주는 실수 (실제 출력 예):

```
  ❌ yaw_mux.mount_offset_deg: 타입이 바뀜 소수 → 정수 (0.0 → 37) → 소수점을 붙이세요: 37.0
  ❌ /ship_direction.side_lock_confirm_frames: 타입이 바뀜 정수 → 소수 (3 → 3.0) → 정수로 적으세요: 3
  ❌ /ship_direction.dwa_modes: 빈 리스트 [] — 노드가 타입을 못 정한다. 끄려면 해당 enabled 를 false 로
  ⚠️ /ship_direction.dwa_enable: 기준에 없는 키 — 오타면 노드가 조용히 무시한다
```

### 3A-4. 편하게 — VS Code 로 고치기 (선택)

MacBook VS Code 의 **Remote - SSH** 로 `boat-a` 에 붙어 `~/ros2_ws` 폴더를 열면, 배 노트북 파일을 MacBook 화면에서 바로 고칠 수 있습니다(`맥북_원격조작_설명서.md` §1-5).
⚠️ 처음 붙을 때 배 노트북에 약 100 MB 를 내려받으므로 대회장 LTE 말고 미리 WiFi 에서 한 번 붙어 둡니다.
⚠️ 고치는 건 VS Code 로 해도, **검사(⑦)·launch·`ros2` 명령은 tmux 안에서** 합니다. VS Code 내장 터미널은 창을 닫으면 같이 꺼집니다.

### 3A-5. 비상 — SSH 가 있어도 세우는 순서는 그대로

## 4. 처음 한 번만 하는 설정 — 배마다 다른 실측값

이 장의 값은 **배마다 다르고, 한 번 재면 대회 내내 유지**합니다. 재는 순서대로 적었습니다.

### 4-1. 헤딩(IMU) — `ssf_heading_A.yaml` / `ssf_heading_B.yaml`

| 파라미터 | 지금 값 | 역할 | 넣을 값 | 재는 법 |
|---|---|---|---|---|
| `mount_offset_deg` | `0.0` ⚠️ | IMU 를 배에 단 방향 보정. `/imu/yaw` 가 진북 기준 뱃머리 방위가 되도록 더하는 각 | 실측값 (예 `37.0`) | 배를 나침반으로 정북에 맞춘 뒤 `ros2 topic echo /imu/yaw` 가 **약 352**(한국 편각 −8°, 자북→진북)가 되게 조정 |
| `invert_yaw` | `false` ⚠️ | IMU 회전 방향이 반대로 달렸을 때 뒤집기 | `true`/`false` | 뱃머리를 시계방향으로 90° 돌렸을 때 값이 **늘어나야** 정상. 줄면 `true` |

🚨 `mount_offset_deg` 는 **반드시 소수점**(`37.0`). `37` 로 적으면 `yaw_mux` 가 부팅 즉시 죽고 `/imu/yaw` 가 끊깁니다.
🚨 이 두 키는 배별 파일에만 둡니다. 공통 `ssf_heading.yaml` 에 적으면 배별 값에 덮여 반영되지 않습니다.
🚨 launch 첫 줄 `boat=…, 파일=…` 로 내 배 파일이 맞는지 확인하십시오.

## 5. 대회마다 하는 설정

### 5-1. 웨이포인트(GPS 좌표) — `north_goal_angle/config/waypoints.yaml` (종합임무)

형식: `- {구역: "설명", lat: 위도, lon: 경도, mode: 미션번호, dwell: 머무는초}`

| 바꾸는 것 | 바꾸지 않는 것 |
|---|---|
| 각 줄의 `lat`·`lon` (대회장 실측) | `mode`, `dwell`, 줄 순서 (이것이 미션 순서입니다) |

- **도킹 네 줄**(`도킹 접근 10m` ~ `WP9 도킹 이탈`, ⚠️ 현장 교체 표시)은 손으로 좌표만 고치지 않습니다. 목표 칸이 공지되면 `tools/dock_wp.py` 가 찍어 주는 네 줄로 통째로 바꿉니다(`docs/절차/도킹_칸별_웨이포인트.md`).
- 녹화 방법: `docs/절차/웨이포인트_녹화절차.md`.
- 위도·경도를 바꿔 넣거나 오타가 있으면 배가 출발하지 않고 "몇 번째 줄이 왜 틀렸는지" 로그를 냅니다. 정상입니다(틀린 좌표로 달리지 않도록).
- 로그의 WP 번호는 0부터 센 순번입니다. 도킹 접근 두 줄이 끼어 있어 `WP8 입구` = 10, `WP9 이탈` = 11, `WP10` = 12 로 찍힙니다.

### 5-2. 토너먼트 웨이포인트 — 노트북 녹화본

- 레인별로 녹화해 **노트북에만** 둡니다: `~/ssf_logs/waypoints_tournament_<배>_<레인>.yaml` (`웨이포인트_녹화절차.md` §3a).
- 🚨 **모든 줄이 `mode: 8`** 이어야 합니다. 다른 mode 가 섞이면 `north_goal_angle` 이 ERROR 를 내고 멈춥니다(배가 출발하지 않음).
- 마지막 줄 = 결승선 너머 약 3 m, `dwell: 0.5`. 마지막 WP 를 지나면 즉시 정지(50000)합니다.
- 저장소의 `config/waypoints_tournament.yaml` 은 자리표시 템플릿입니다. 녹화본을 거기에 복사하지 말고 launch 의 `waypoints_file:=` 로 넘깁니다.

### 5-3. 경기장 경계(지오펜스) — 코스별 north 파일

| 파일 | 파라미터 | 넣을 값 |
|---|---|---|
| `north_goal_angle_main.yaml` (종합임무) | `geofence_polygon` | `[lat1, lon1, lat2, lon2, …]` 평탄 배열, 최소 3점(숫자 6개) |
| `north_goal_angle_tournament.yaml` (토너먼트) | `geofence_polygon` | 같은 형식. **결승선 너머까지 포함** |

- 역할: 경계를 "가짜 LiDAR 벽"으로 만들어 회피가 경계를 장애물처럼 피하게 합니다. 경계 이탈은 실격입니다.
- 🚨 **실제 경계를 그대로 찍습니다. 안쪽으로 줄이지 마십시오.** 배가 줄인 선을 넘는 순간 경계 정보가 꺼져 오히려 더 나갈 수 있습니다(11-09 시뮬).
- 비어 있으면(`[]`) 경계 방어가 꺼집니다. 토너먼트에서는 시작 WARN 이 뜹니다. 시작 로그에 `geofence ON(n점)` 이 보여야 합니다.
- 🚨 **[위도, 경도, 위도, 경도, …] 순서, 원소마다 소수점**(예 `[35.1862375, 128.5655118, …]`). 정수·문자열·홀수 개·6개 미만·한국 범위 밖(위경도 뒤바뀜 포함)이면 ERROR 1회 + 경계 꺼짐(노드는 뜸) → 시작 로그 `geofence OFF(폴리곤 오류 — 위 ERROR)`. 정수와 소수를 섞으면 launch 자체가 안 뜹니다. 넣은 뒤 `python3 tools/param_check.py <파일>` 로 먼저 검사(소수·정수 섞임·빈 리스트만 잡음). 정수만·홀수 개·뒤바뀜은 **시작 로그의 ERROR 로만** 보이므로 `geofence ON(n점)` 확인이 최종 판정.
- ⚠️ 경계를 피하는 반응은 약 3 m 앞부터입니다. 경계 쪽으로 크게 꺾인 채 순항하면 다 못 돌 수 있습니다(시뮬 경기 중 이탈 약 1~2 %). 실해역 4-5c 에서 확인합니다.
- 결승선 뒤 이탈은 감점이 아닙니다(11-09 확인).

### 5-4. 미션 색·표식 — `vision.yaml`

| 절 | 파라미터 | 지금 값 | 역할 | 넣을 값 |
|---|---|---|---|---|
| `image_subscriber_turn` | `turn_color_mode2` | `"white"` | 위치유지 부표 색 | 공지 색 (`red`/`green`/`white`) |

## 6. 실행하기 — launch 명령

**종합임무 · 수조 · 실해역 시험**

```bash
ros2 launch launch_files launch_files.launch.py boat:=A course:=main
```

**토너먼트**

```bash
ros2 launch launch_files launch_files.launch.py boat:=A course:=tournament waypoints_file:=$HOME/ssf_logs/waypoints_tournament_A_1.yaml
```

(2번배는 `boat:=B`, 파일 이름의 `A` 도 `B` 로)

| 인자 | 필수 | 기본값 | 역할 |
|---|---|---|---|
| `boat` | 🚨 필수 | — | `A` 또는 `B`. 배별 IMU 값 파일과 DWA 선체를 고릅니다 |
| `course` | 🚨 필수 | — | `main`(종합임무) 또는 `tournament`. 코스별 덮어쓰기 파일을 고릅니다. 빠지거나 `Main` 처럼 틀리면 launch 가 거부합니다 |
| `waypoints_file` | — | (비움) | 웨이포인트 파일 경로. 비우면 코스 기본 파일(main=`waypoints.yaml`, tournament=템플릿) |
| `gps_config` | — | `zed_f9p_rover.yaml` | GPS 설정. 두 배 모두 ZED-F9P 라 그대로 |
| `search_behavior` | — | `hold` | 탐색(mode 3): `hold`=부표 앞 위치유지(2026 안내문). `orbit`=부표 돌기(옵션) |
| `record` | — | `true` | 블랙박스 CSV(`~/ssf_logs`) 기록 |

- 🚨 판(경기) 사이에는 launch 를 다시 띄웁니다. 웨이포인트 순번이 처음으로 되돌아가지 않습니다.
- 🚨 RC 가 AUTO(`/boat_mode` 2)여야 미션이 진행됩니다(`require_boat_mode_auto: true`). 벤치에서 아두이노가 없으면 `ros2 topic pub /boat_mode std_msgs/msg/Int32 "{data: 2}"`.

## 8. 파라미터 사전 — 노드별 전체 설명

"바꿔도 됨" 열: **현장** = 현장 조정 항목 / **실측** = 실측 뒤 한 번 / 🔒 = 바꾸지 마십시오 / — = 보통 그대로.

### 8-1. `motor_control` (모터 출력)

| 파라미터 | 기본값 | 역할 | 바꿔도 됨 |
|---|---|---|---|
| `base_pwm` · `max_diff` · `reverse_pwm` | 1360 · 100 · 1590 | 순항 전진 · 최대 조향 차 · 후진 PWM (4-2) | 실측 |
| `spin_forward_pwm` · `spin_diff` | 1500 · 100 | 제자리 선회 가운데 PWM · 세기 | — |
| `steer_invert` | false | 조향 좌우 뒤집기 (4-2) | 실측 |

| `min_speed_ratio` | 0.7 | 감속 때 최저 속도 비율 | 🔒 |
| `failsafe_l1_speed` | 0.7 | 센서 경고 단계(레벨1)에서 속도 상한 비율. 1.0 이면 끔 | — |
| `goal_slow_start_m` · `goal_slow_full_m` | 8.0 · 3.0 | WP 에 가까워지면 이 거리부터 감속, 이 거리 이하에서 최저 | 현장 |

| `cmd_timeout_sec` | 0.5 | 조향 명령이 이보다 끊기면 모터 중립(1500/1500) | 🔒 |

### 8-2. `ship_direction` (회피·최종 조향·페일세이프)

## 9. 값을 적을 때 지킬 형식

고친 뒤에는 `python3 tools/param_check.py <파일>` 로 아래 규칙을 자동 검사합니다(3A-1 ⑦).

| 규칙 | 틀린 예 | 맞는 예 | 틀리면 |
|---|---|---|---|
| 소수 파라미터는 소수점 | `mount_offset_deg: 37` | `37.0` | 노드가 부팅 때 죽음 |
| 리스트 원소도 전부 소수점 | `[120, 90]`, `[120.0, 90]` | `[120.0, 90.0]` | 노드 사망 / 파일 전체 못 읽음 |
| 정수 파라미터는 정수 | `side_lock_confirm_frames: 3.0` | `3` | ERROR + 기능 꺼짐 |
| 빈 리스트 금지 | `dwa_modes: []`, `dwell_wait_modes: []` | 끄려면 `enabled: false` | 타입을 못 정해 부팅 실패 |
| "없음"을 0 으로 쓰지 않기 | WP 제한시간 0 | 그 mode 를 표에서 뺌 | 틱마다 WP 를 건너뜀 |
| 문자열은 따옴표 | `turn_color_mode3: red` | `"red"` | — (YAML 은 받지만 습관으로) |
| 경계 폴리곤은 소수, [위도, 경도] 순서, 짝수 개 6개 이상 | `[35, 128, …]`, `[128.56, 35.18, …]` | `[35.1862, 128.5655, …]` | ERROR + 경계 꺼짐(섞이면 launch 실패) |

## 10. 문제 해결

| 증상 | 가능한 원인 | 조치 |
|---|---|---|
| launch 가 바로 거부됨 | `boat`·`course` 빠짐 또는 오타(`Main`) | `boat:=A course:=main` |
| 노드가 뜨자마자 죽음 (`InvalidParameterTypeException`) | 소수 자리에 정수 | 9장 형식대로 |
| 배가 출발하지 않음, north ERROR "웨이포인트 내용 오류" | 좌표 오타·위경도 뒤바뀜, 토너먼트에 mode 8 아닌 줄 | 로그가 알려 주는 줄 수정 |
| 배가 출발하지 않음, 로그 이상 없음 | RC 가 AUTO 아님(`/boat_mode` ≠ 2) | 조종기 AUTO |
| 출발했는데 계속 정지(50000) + 5 초마다 ERROR | `/yaw_error` 를 한 번도 못 받음 (GPS fix 없음 → 목표 방위 없음) | GPS fix·RTK 확인 |
| 목표와 반대쪽으로 감 | `invert_yaw` 또는 `mount_offset_deg` 틀림 | 4-1 다시 |
| 조향이 반대로 꺾임 / 5000 에 왼쪽으로 돎 | `steer_invert` | 4-2 |
| 시작 WARN "geofence_polygon 이 비었거나 오류로 거부됐다" | 토너먼트 경계 미입력 또는 형식 오류 | 5-3 (ERROR 가 같이 있으면 그 문구대로 고침) |
| 시작 WARN "웨이포인트 파일이 패키지 템플릿" | 토너먼트인데 `waypoints_file:=` 을 빠뜨림 | 6장 토너먼트 명령, 녹화본 경로 |
| 로그 "DWA 가능한 후보 없음"(폴백)이 잦음 | 물보라·가까운 장애물. DWA 가 기존 회피로 넘김 | 잦으면 `dwa_enabled: false` |
| 도킹 중 갑자기 정지 + '🚧🛑' | 경계 2 m 안 하드 정지(정상 동작) | 도크가 경계 가까우면 폴리곤 확인 |
| 탐색 부표를 못 찾음 | `turn_color_mode3` 가 공지 색과 다름, HSV 범위 | 5-4 |
| 두 배가 서로 토픽을 받음 | `ROS_LOCALHOST_ONLY` 없음 | 3장 ② |
| yaml 을 고쳤는데 그대로 | launch 재시작 안 함 / 설치 폴더가 symlink 아님 | 재시작, 3장 ③ |
| 고친 뒤 노드가 안 뜨거나 값이 안 바뀜 | 형식 실수·키 오타 | `python3 tools/param_check.py <파일>` (3A-1 ⑦) |
| MacBook 에서 `ros2 topic list` 가 빈 목록 | MacBook 에서 쳤음 (정상) | SSH 안에서 칩니다 |
| SSH 가 `timed out` | Tailscale·배 핫스팟 | `맥북_원격조작_설명서.md` §6 |
