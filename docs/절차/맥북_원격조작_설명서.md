# MacBook 원격 조작 설명서 — 물가 MacBook 에서 배 노트북에 손으로 입력하기 (2026-10-30)

> 왜: 웨이포인트 찍기·yaml 값 고치기·launch·모니터링은 사람이 직접 쳐야 한다. 배는 헤드리스라 물 위에선 배 노트북 키보드에 손이 안 닿는다.
> 관련: `Tailscale_세팅.md`(연결) · `웨이포인트_녹화절차.md`(WP 찍기 상세) · `boat_launch_checklist.md`(출발 순서) · `수동조종_영상_설명서.md`(영상)

## 0. 결론 먼저

- **코드는 배 노트북에서 돈다. MacBook 은 키보드·화면일 뿐이다.** MacBook 에는 ROS 가 없다.
- 길: MacBook ─(Tailscale)─ 배 노트북 **SSH**. 영상이 지나가는 그 망이다.
- 🚨 **ROS2 토픽은 Tailscale 을 못 건넌다**(DDS 멀티캐스트). MacBook 에서 `ros2 topic list` 는 빈 목록이 정상이다. 모든 ROS 명령은 **SSH 안에서** 친다.
- 🚨 **무엇이든 `tmux` 안에서 띄운다.** SSH 가 끊기면 그 창에서 돌던 노드도 같이 죽는다. tmux 안이면 배에서 계속 돈다.
- 모드 전환은 여전히 **조종기만**. 노트북에는 그 통로가 일부러 없다.
- ⏳ **아직 MacBook → 배 SSH 는 한 번도 확인 안 됐다**(10-30 기준. 확인된 건 영상뿐). §1 을 대회 전에 꼭 한 번 해 볼 것.

## 1. 처음 한 번 — MacBook

### 1-1. 주소 (`Tailscale_세팅.md` §3)

| 배 | Tailscale 이름 | 100.x IP |
|---|---|---|
| 1번배 | ssf-boat-a | 100.84.57.20 |
| 2번배 | 지금 `ssfb-ideapad-slim-3-15abr8` (→ `ssf-boat-b` 로 바꿀 예정) | 100.119.219.33 |

이름이 바뀌어도 되게 **IP 로 적는다**.

### 1-2. 별명 만들기 — 매번 IP 안 치게

MacBook 터미널:
```bash
nano ~/.ssh/config
```
아래를 붙여 넣는다. `<사용자>` 는 각 배 노트북 로그인 이름(Ubuntu 터미널에서 `whoami`).
```
Host boat-a
    HostName 100.84.57.20
    User <1번배 사용자>
    ServerAliveInterval 15
    ServerAliveCountMax 4

Host boat-b
    HostName 100.119.219.33
    User <2번배 사용자>
    ServerAliveInterval 15
    ServerAliveCountMax 4
```
`ServerAlive…` = 15 초마다 살아 있나 확인, 1 분 무응답이면 끊는다(LTE 가 잠깐 멈췄을 때 화면이 얼어붙은 채로 남지 않게).

### 1-3. 비밀번호 없이 붙게 — 키 등록 (한 번)

```bash
ssh-keygen -t ed25519          # 이미 ~/.ssh/id_ed25519 가 있으면 건너뛴다. 질문은 Enter
ssh-copy-id boat-a             # 배 노트북 비밀번호를 한 번 묻는다 — 본인이 입력
ssh-copy-id boat-b
```
비밀번호·키 내용은 저장소·채팅 어디에도 적지 않는다.

### 1-4. 접속 확인 (대회 전 필수)

```bash
ssh boat-a
```
배 노트북 프롬프트가 뜨면, 그 안에서:
```bash
hostname                       # 어느 배인지 — 엉뚱한 배 yaml 을 고치는 사고 방지
ros2 topic list | head         # launch 가 떠 있으면 토픽이 보여야 한다 (SSH 안이라 보임)
```
✅ 되면 `Tailscale_세팅.md` §4-3 옆에 "SSH 확인 <날짜>" 를 적는다.

### 1-5. (선택) VS Code 로 yaml 편하게 고치기

1. MacBook VS Code → 확장 **Remote - SSH** 설치.
2. `Cmd+Shift+P` → `Remote-SSH: Connect to Host` → `boat-a`.
3. **Open Folder** → `~/ros2_ws`. 이제 배 노트북 파일을 MacBook 화면에서 고친다.

⚠️ 처음 붙을 때 VS Code 가 배 노트북에 서버(약 100 MB)를 내려받는다. **대회장 LTE 말고 미리 WiFi 에서** 한 번 붙어 둘 것.
⚠️ 고치는 건 VS Code 로 해도, **ROS 명령은 tmux 안에서**(§3). VS Code 내장 터미널은 창을 닫으면 같이 죽는다.

## 2. 처음 한 번 — 배 노트북 (Ubuntu, 손이 닿을 때)

| 항목 | 명령 | 상태 |
|---|---|---|
| SSH 서버 | `sudo apt install -y openssh-server && sudo systemctl enable --now ssh` | 2번배: 세팅 문서 2-13. **1번배: 확인 필요** |
| 방화벽 | `sudo ufw allow in on tailscale0` (ufw 켜져 있을 때만) | 확인 필요 |
| tmux | `sudo apt install -y tmux` | 1번배 08-12 설치됨. 2번배: 세팅 문서 1부 |
| 키 만료 끄기 | login.tailscale.com/admin/machines → 두 배 **Disable key expiry** | ⏳ 남음 |

확인: `systemctl is-active ssh` → `active`.

## 3. 매번 — 붙고 tmux 열기

```bash
ssh boat-a
tmux new -s ssf               # 처음
tmux attach -t ssf            # 끊겼다가 다시 붙을 때 — 아까 화면 그대로
```

tmux 손에 익힐 키 (먼저 `Ctrl+b` 를 누르고 손 뗀 뒤 다음 키):

| 키 | 하는 일 |
|---|---|
| `Ctrl+b` → `c` | 새 창 |
| `Ctrl+b` → `n` / `p` | 다음 / 이전 창 |
| `Ctrl+b` → `0`~`9` | 그 번호 창으로 |
| `Ctrl+b` → `d` | tmux 에서 빠져나오기 (안의 노드는 계속 돈다) |
| `tmux ls` | 열려 있는 세션 목록 |

권장 창 배치:

| 창 | 내용 |
|---|---|
| 0 | launch (미션 전체) |
| 1 | `mission_monitor` |
| 2 | 영상 송출 `cam_stream.sh` |
| 3 | 그때그때 (yaml 편집, healthcheck, waypoint_recorder) |

## 4. 수동 입력 작업별

### 4-1. 웨이포인트 찍기

```bash
ros2 run north_goal_angle waypoint_recorder
#   배를 RC 로 지점에 대고 몇 초 정지 → Enter → mode → dwell → 이름
#   l 목록 · d N 삭제 · r N 재캡처 · q 저장
```
- 저장: `~/ssf_logs/waypoints_recorded.yaml` (끝날 때 절대경로가 크게 찍힌다).
- 먼저 RTK **FIXED** 확인, mode 는 `{0,1,2,3,5,7,8}` 만 — 상세 `웨이포인트_녹화절차.md` §1·§3.
- 🚨 **조종기와 SSH 가 동시에** 그 지점까지 닿아야 찍힌다.

태워 보기 → 확정 → 복사 순서는 `웨이포인트_녹화절차.md` §5 그대로.

### 4-2. yaml 값 고치기

| 무엇 | 파일 (배 노트북 `~/ros2_ws/` 아래) | 주의 |
|---|---|---|
| WP 좌표·dwell | `src/north_goal_angle/config/waypoints.yaml` | 녹화본을 복사해 쓰는 게 기본. 손으로 칠 땐 mode·순서 유지 |
| 헤딩 장착값 | `src/ssf_heading/config/ssf_heading_A.yaml` (2번배는 `_B`) | `mount_offset_deg` 는 **반드시 소수점**(37.0). 정수면 yaw_mux 즉사 |
| NTRIP 마운트포인트 | `~/.ssf/ntrip_credentials.yaml` 의 `mountpoint` | 🚨 저장소 밖 파일. 커밋·복사·화면 공유 금지 |

```bash
nano src/ssf_heading/config/ssf_heading_A.yaml      # 저장 Ctrl+O, Enter · 나가기 Ctrl+X
```
`src/…/config` 를 고쳤으면 그 패키지를 다시 빌드한다(안 하면 `install/` 의 옛 값을 읽는다):
```bash
cd ~/ros2_ws && colcon build --symlink-install --packages-select ssf_heading     # 또는 north_goal_angle
```
그다음 launch 를 다시 띄워야 반영된다. launch 첫 줄 `boat=…, 파일=…` 로 어느 배 파일을 읽었는지 확인.

🚨 고치기 전에 `hostname` — 1번배에 붙어서 `_B.yaml` 을 고치는 실수 방지.

### 4-3. launch (출발 전, 배가 물가에 있을 때)

창 0 에서 (`boat_launch_checklist.md` §3 ①):
```bash
sudo ~/ros2_ws/tools/boat_boot.sh                    # sudo 비밀번호는 본인이 입력
ros2 launch launch_files launch_files.launch.py boat:=A       # 2번배는 boat:=B
```
- 배터리·조종기 순서(③~⑥)는 체크리스트 그대로. **배터리는 launch 뒤, 조종기 수동 상태에서.**
- 멈출 때 `Ctrl+C` — 라이다가 정지 명령을 받는다(강제 종료 금지, 체크리스트 §4).

### 4-4. 모니터링

창 1:
```bash
ros2 run ssf_tools mission_monitor       # 🟢 수동 / 🟡 자율 / 🚨 브릿지 끊김
```
출발 전 점검:
```bash
ros2 run ssf_tools healthcheck
```

### 4-5. 영상 (수동 토너먼트)

창 2 에서 `cam_stream.sh <MacBook 100.x>`, MacBook 에서 `cam_view.sh` — `수동조종_영상_설명서.md`.
MacBook 주소는 `100.93.158.11`. 배 자기 주소를 넣으면 화면이 안 뜬다.

## 5. 배 세우는 법 — SSH 가 있어도 순서는 그대로

| 순서 | 방법 | SSH 와의 관계 |
|---|---|---|
| 1 | 조종기 모드 스위치 MANUAL + 스틱 중립 | 무관 — 제일 빠르다 |
| 2 | tmux 창 0 에서 `Ctrl+C` | SSH 가 살아 있어야 한다. 끊겼으면 재접속 → `tmux attach -t ssf` → 창 0 → `Ctrl+C` (수십 초) |
| 3 | 배의 비상정지 버튼 | 손이 닿아야 한다 |

⚠️ tmux 덕분에 **SSH 가 끊겨도 미션은 계속 돈다**. 그건 장점이지만, 끊긴 순간 2번 수단은 재접속할 때까지 없다는 뜻이다. 비상은 항상 **1번(조종기)**.

## 6. 안 될 때

| 증상 | 먼저 볼 것 |
|---|---|
| `ssh: connect … timed out` | 두 기기 `tailscale status` 에 서로 보이나. 배 폰 핫스팟 켜져 있나 |
| `Connection refused` | 배 노트북 `systemctl is-active ssh`. ufw `allow in on tailscale0` |
| `Permission denied (publickey…)` | §1-3 키 등록. `~/.ssh/config` 의 `User` 이름 |
| `Host key verification failed` | 배 노트북을 재설치했다면 `ssh-keygen -R 100.84.57.20` 후 재접속 |
| 화면이 멈춤 | LTE 순간 끊김. 1 분 뒤 자동 종료(§1-2) → 다시 `ssh` + `tmux attach -t ssf` |
| `ros2: command not found` | SSH 안에서 `source ~/ros2_ws/install/setup.bash` (.bashrc 에 없으면) |
| `ros2 topic list` 빈 목록 | MacBook 에서 쳤다 — 정상. SSH 안에서 칠 것 |
| `tmux attach` 가 `no sessions` | 배 노트북이 재부팅됐다. launch 부터 다시 |
| 키 만료로 Tailscale 끊김 | §2 Disable key expiry. 당장은 배 노트북에서 `sudo tailscale up` 재로그인 |
