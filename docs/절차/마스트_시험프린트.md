# 마스트 시험 프린트 — 맞춤 확인 쿠폰 절차 (2026-09-16)

> 통짜 마스트(4부품, 합계 수백 g)를 뽑기 전에 **맞는지 모르는 것만** 작게 뽑아 확인한다.
> 생성: `python3 tools/cad/mast.py` → `python3 tools/cad/fit_test.py` → `tools/cad/out_fit/fit_*.stl`
> 치수는 `out/placement.json` 을 거쳐 본체와 **같은 값**을 쓴다. 쿠폰만 고치는 일은 없다 — 항상 `mast.py` 파라미터를 고치고 다시 생성한다.

## 0. 왜 이것만 뽑나

| 확인 대상 | 실물 있나 | 쿠폰으로 되나 |
|---|---|---|
| D455 끼움·나사간격·USB 노치 | ✅ 있음(현역) | ✅ 바로 확인 |
| iAHRS 포켓·뚜껑·케이블 터널 | ✅ 있음 | ✅ 바로 확인 |
| 각관 이음(플러그 0.4 여유) | 부품 없음 | ✅ 쌍으로 확인 (프린터 편차가 제일 큰 항목) |
| OAK 크레들 | ❌ **미발주** | ⚠️ 목업 블록으로 간접 확인만. 실물 오면 재확인 |
| 갑판 볼트·가로대 | 갑판 미제작 | ❌ 갑판 두께·가로대 간격 실측 전엔 무의미 |

## 1. 뽑을 것 (우선순위)

| # | 파일 | 무엇을 보나 | 없으면 생기는 사고 |
|---|---|---|---|
| 1 | `fit_cradle_d455.stl` | 카메라가 위에서 들어가나, M4 2개가 맞나, USB 가 노치로 나오나 | 본체 다 뽑고 나서 카메라가 안 들어감 |
| 2 | `fit_pocket_imu.stl` + `fit_pocket_lid.stl` | IMU 가 포켓에 앉나, 뚜껑 M3 4개 맞나, 케이블이 터널로 나가나 | 베이스(제일 큰 부품)를 다시 뽑아야 함 |
| 3 | `fit_joint_plug.stl` + `fit_joint_socket.stl` | 0.4mm 여유가 이 프린터에서 맞나 | 마디가 안 끼거나 덜렁거림 |
| 4 | `fit_cradle_oak.stl` + `fit_oak_mockup.stl` | 크레들 형상·그랜드 노치 (목업 기준) | OAK 도착 후 재확인은 여전히 필요 |

1~3 만 먼저 뽑아도 된다. 4 는 시간 남을 때.

## 2. 프린트 설정

- 재질 **PETG 또는 ASA**(PLA ✗ — 여름 갑판 열로 각도가 처진다). 밝은 색.
- 레이어 0.2 / 벽 4 / 인필 40% / 서포트: 쿠폰 1·4 는 **불필요**(바닥턱이 바닥에 닿게 눕혀서), 쿠폰 2·3 은 불필요.
- 방향: 크레들은 **뒷판을 바닥에** 두고 눕힌다(좌우턱이 위로). 포켓 블록은 바닥면 그대로. 이음 쌍은 세워서.
- ⚠️ 쿠폰은 **본체와 같은 프린터·같은 노즐·같은 재질**로 뽑아야 의미가 있다. 다른 장비로 뽑으면 여유값 결론을 못 쓴다.

## 3. 확인표 — 불합격이면 고칠 파라미터

전부 `tools/cad/mast.py` 상단 파라미터다. 고친 뒤 `mast.py` → `fit_test.py` 순서로 다시 생성한다.

| 확인 | 합격 기준 | 불합격 → 고칠 것 |
|---|---|---|
| D455 가 좌우턱 사이로 들어감 | 손으로 밀어 들어가고 좌우 흔들림 ≤0.5mm | 안 들어가면 `CRADLE_CLEAR` 1.0 → 1.4 / 헐거우면 → 0.6 |
| D455 뒷면 M4 2개 정렬 | 나사 2개가 억지 없이 들어감 | 어긋나면 `D455_HOLE_PITCH`(도면 95) 재확인 |
| USB-C 가 바닥턱에 안 걸림 | 플러그가 노치로 자유롭게 아래로 | 반대쪽이면 `D455_USB_X` 부호 확정 → 노치 한쪽만 남김 |
| 좌우턱 높이 | 넣고 빼기 편하고 빠지지 않음 | `CRADLE_LIP_D455` (지금 12) |
| iAHRS 가 포켓에 앉음 | 바닥에 평평히 닿고 좌우 여유 ≤1mm | `IMU_CLEAR` (지금 1.0) |
| 케이블이 터널로 나감 | 4핀 하네스가 꺾임 없이 통과 | `IMU_CH_D` (지금 8) / 위치 `IMU_CH_X` |
| 뚜껑 M3 4개 | 나일론 M3 가 탭 없이 들어감(셀프탭) | `LID_SCREW_D` (지금 2.5) |
| 플러그↔소켓 | 손으로 끼워지고 좌우 유격 없음 | 빡빡 `PLUG_CLEAR` 0.4 → 0.5 / 헐렁 → 0.3 |
| M4 관통 볼트 | 이음 볼트가 양쪽 구멍에 통과 | `BOLT_D` (지금 4.4) |

## 4. 기록

측정값과 판정을 `docs/전달용/회신/시험프린트_YYYYMMDD.md` 에 남긴다(캘리퍼 값 그대로).
바꾼 파라미터는 커밋 메시지에 "쿠폰 결과 반영" 으로 적어 추적되게 한다.

## 5. 이 단계로 확정되지 않는 것

- 갑판 볼트 길이·가로대 간격 (갑판 두께 실측 필요)
- OAK 실물 끼움·그랜드 좌우 오프셋 (도착 후)
- 카메라 각도(틸트) — 물 위 첫 시험
- 마스트 전체 강성·진동 — 통짜 조립 후
