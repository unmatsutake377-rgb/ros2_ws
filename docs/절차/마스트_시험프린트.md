# 마스트 시험 프린트 — 맞춤 확인 쿠폰 절차 (2026-09-16)

> 통짜 마스트(4부품, 합계 수백 g)를 뽑기 전에 **맞는지 모르는 것만** 작게 뽑아 확인한다.
> 생성: `python3 tools/cad/mast.py` → `python3 tools/cad/fit_test.py` → `tools/cad/out_fit/fit_*.stl`
> 치수는 `out/placement.json` 을 거쳐 본체와 **같은 값**을 쓴다. 쿠폰만 고치는 일은 없다 — 항상 `mast.py` 파라미터를 고치고 다시 생성한다.

## 0. 왜 이것만 뽑나

| 확인 대상 | 실물 있나 | 쿠폰으로 되나 |
|---|---|---|
| D455 끼움·나사간격·USB 노치 | ✅ 있음(현역) | ✅ 바로 확인 |
| iAHRS 포켓·뚜껑·케이블 터널 | ✅ 있음 | ✅ 바로 확인 |
| 각관 이음(플러그 0.4 여유) | 부품 없음 | ✅ 쌍으로 확인 (프린터 편차가 제일 큰 항목) |
| OAK 크레들 | ❌ **미발주** | ⚠️ 목업 블록으로 간접 확인만. 실물 오면 재확인 |
| 갑판 볼트·가로대 | 갑판 미제작 | ❌ 갑판 두께·가로대 간격 실측 전엔 무의미 |

## 1. 뽑을 것 (우선순위)

| # | 파일 | 무엇을 보나 | 없으면 생기는 사고 |
|---|---|---|---|
| 1 | `fit_cradle_d455.stl` | 카메라가 위에서 들어가나, M4 2개가 맞나, USB 가 노치로 나오나 | 본체 다 뽑고 나서 카메라가 안 들어감 |
| 2 | `fit_pocket_imu.stl` + `fit_pocket_lid.stl` | IMU 가 포켓에 앉나, 뚜껑 M3 4개 맞나, 케이블이 터널로 나가나 | 베이스(제일 큰 부품)를 다시 뽑아야 함 |
| 3 | `fit_joint_plug.stl` + `fit_joint_socket.stl` | 0.4mm 여유가 이 프린터에서 맞나 | 마디가 안 끼거나 덜렁거림 |
| 4 | `fit_cradle_oak.stl` | 크레들 형상·그랜드 노치 | OAK 도착 후 재확인은 여전히 필요 |

🚨 **`fit_oak_mockup.stl` 은 뽑지 말 것.** ① 목업과 크레들을 같은 프린터로 뽑으면 치수 오차가 **서로 상쇄**되어
"목업이 들어갔다"가 "실물 OAK 가 들어간다"를 뜻하지 않는다. ② PETG 120g 대에 74mm 브리지가 걸린 폐쇄 공동이라 비싸다.
대신 **크레들만 뽑아 안쪽 폭을 캘리퍼로 재고 데이터시트 81.9 × 31 과 직접 비교**한다. 그게 정직한 시험이다.

**6개를 한 판에 같이 뽑는 것을 권한다.** 바닥 면적 합계 240cm² 로 220×220 베드의 **50%** 라 한 번에 올라가고,
예열·작업이 한 번으로 끝난다. OAK 크레들은 카메라가 없어도 **안쪽 폭을 캘리퍼로 재서 81.9 × 31 과 비교**하면
CAD 오류와 큰 부품(86mm)의 수축을 미리 잡는다 — 카메라 도착한 뒤에 알면 늦다.

## 2. 프린트 설정

- 재질 **PETG 또는 ASA**(PLA ✗ — 여름 갑판 열로 각도가 처진다). 밝은 색.
- 레이어 0.2 / 벽 4 / 인필 40%.
- **서포트: 6종 전부 불필요** (실측: 급경사 아래보기 면적 최대 99mm², 무시 가능).
  🚨 **실물 마스트 부품은 다르다** — `seg1` 4177mm², `cap` 4337mm² 라 서포트나 방향 재검토가 필요하다.
  쿠폰이 서포트 없이 나왔다는 결론을 실물에 그대로 옮기지 말 것 (`docs/전달용/마스트_stl/README.md` 참고).
- 방향: **STL 방향 그대로** 앉히면 된다. 크레들은 뒷판 밑면과 바닥턱 밑면이 같은 평면이라 서포트가 진짜로 필요 없다
  (2026-09-16 이전 버전은 뒷판이 3.5~4mm 떠 있어 어느 쪽으로 눕혀도 서포트가 필요했다 — 지금은 고쳐졌다).
  포켓 블록·이음 쌍도 그대로.
- ⚠️ 쿠폰은 **본체와 같은 프린터·같은 노즐·같은 재질**로 뽑아야 의미가 있다. 다른 장비로 뽑으면 여유값 결론을 못 쓴다.

## 2-1. 뽑기 전 5분 — 실물로 먼저 볼 것

D455 와 iAHRS 는 **실물이 손에 있다.** 캘리퍼로 아래 3개만 먼저 보면, 틀렸을 때 프린트 한 판을 통째로 아낀다.

| 확인 | 저장소 기준값 | 근거 | 다르면 |
|---|---|---|---|
| D455 나사 **면** | 로고 있는 **뒷면** | 도면 337029-017 Fig 10-11 (p150): "2X M4 MOUNTING POINTS MAX INSERTION DEPTH 4MM" 지시선이 로고 면 | 바닥면이면 **크레들 개념 자체 재검토** |
| D455 나사 **규격·간격** | **M4**, 95mm | 같은 도면의 95 치수 + 하단 주석 "Recommended torque for both M4 mounting points is 0.4 Nm" | `D455_HOLE_PITCH` / `D455_HOLE_D` |
| USB-C 좌우 | ¼-20 기준 **37mm**, 부호 미확정 | 같은 도면 바닥면 뷰의 (37.01) | 노치를 실제 쪽 하나만 남김 (`D455_USB_X` 부호) |

⚠️ 같은 도면 바닥면 뷰에 **¼-20(삽입 ≤9mm)** 과 **2×M2 USB 케이블 고정**이 함께 있다. 즉 바닥면에도 나사 자리가 있으니
"나사 구멍을 봤다"만으로 뒷면이라 단정하지 말 것 — **로고 면인지**를 봐야 한다.

## 3. 확인표 — 불합격이면 고칠 파라미터

전부 `tools/cad/mast.py` 상단 파라미터다. 고친 뒤 `mast.py` → `fit_test.py` 순서로 다시 생성한다.

| 확인 | 합격 기준 | 불합격 → 고칠 것 |
|---|---|---|
| D455 가 좌우턱 사이로 들어감 | 손으로 밀어 들어가고 좌우 흔들림 ≤0.5mm | 안 들어가면 `CRADLE_CLEAR` 1.0 → 1.4 / 헐거우면 → 0.6 |
| D455 뒷면 M4 2개 정렬 | 나사 2개가 억지 없이 들어감 | 어긋나면 `D455_HOLE_PITCH`(도면 95) 재확인 |
| USB-C 가 바닥턱에 안 걸림 | 플러그가 노치로 자유롭게 아래로 | 반대쪽이면 `D455_USB_X` 부호 확정 → 노치 한쪽만 남김 |
| 좌우턱 높이 | 넣고 빼기 편하고 빠지지 않음 | `CRADLE_LIP_D455` (지금 12) |
| iAHRS 가 포켓에 앉음 | 바닥에 평평히 닿고 좌우 여유 ≤1mm | `IMU_CLEAR` (지금 1.0) |
| 케이블이 터널로 나감 | 4핀 하네스가 꺾임 없이 통과 | `IMU_CH_D` (지금 8) / 위치 `IMU_CH_X` |
| 뚜껑 M3 4개 | 나일론 M3 가 탭 없이 들어감(셀프탭) | `LID_SCREW_D` (지금 2.5) |
| **뚜껑이 리베이트에 들어감** | 손으로 얹으면 앉고 네 구멍이 맞음 (편측 0.4) | `LID_FIT` (지금 0.8). 안 들어가면 1.2 / 덜렁거리면 0.6. **사포로 갈지 말 것** — 본체 뚜껑도 같은 값이라 갈아버리면 본체가 맞을지 알 수 없게 된다. 나사 4개가 위치를 잡으니 헐거운 쪽이 안전 |
| 뚜껑 나사 보스 | 조일 때 안 갈라짐 | 갈라지면 `LID_MARGIN` 8 → 12 (살두께 2.75 → 4.75) |
| 플러그↔소켓 | 손으로 끼워지고 좌우 유격 없음 | 빡빡 `PLUG_CLEAR` 0.4 → 0.5 / 헐렁 → 0.3 |
| M4 관통 볼트 | 이음 볼트가 양쪽 구멍에 통과 | `BOLT_D` (지금 4.4) |
