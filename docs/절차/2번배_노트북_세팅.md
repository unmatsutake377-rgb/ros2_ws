> 순서표다. **1부는 사람이 손으로**, 2부부터는 그 노트북의 Claude Code 세션에 이 파일을 넘겨 진행한다.
> 공통 상세는 `ubuntu_setup.md`(1번배 때 쓴 원본) — 여기는 **2번배에서 달라지는 것**과 그 뒤에 추가된 것(카메라 송신·SSH·Tailscale·OAK·아두이노 안전 규칙)을 한 줄로 엮는다.

## 1부 — 사람이 직접 (Claude 세션 없음)

### 1-0. 지우기 전에 (초기화 = 디스크 전체 삭제, 되돌릴 수 없음)
기존 내용이 있으면 USB·다른 PC 로 옮겨 둘 것:
- `~/.ssf/` (NTRIP 계정 등 — **GitHub 에 올리지 말 것**)
- `~/ros2_ws` 에서 커밋·push 안 한 변경 (`cd ~/ros2_ws && git status`) / rosbag·블랙박스 CSV
- `/etc/udev/rules.d/99-ssf.rules` (있으면 — 포트값 참고용)
- 기종·RAM 메모: `sudo dmidecode -s system-product-name`, `free -h` (8 GB 면 빌드 병렬 제한 필요)

### 1-1. Ubuntu 22.04 LTS 설치 (24.04 ❌ — ROS2 Humble 은 22.04 전용)
- BIOS(Lenovo 는 F2)에서 **Secure Boot 끄기**.
- USB 부팅 → "Erase disk and install" → **"Install third-party software" 체크**.
- 사용자·호스트명: 1번배와 헷갈리지 않게 **호스트명에 b/2 를 넣는다** (예: `ssf-boat-b`). Tailscale·SSH 에서 이 이름이 보인다.
- 설치 후 WiFi 연결.

### 1-2. 기본 도구 + Claude Code
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y git curl wget nano build-essential tmux
curl -fsSL https://claude.ai/install.sh | bash
```
- 끝나고 새 터미널에서 `claude` → 로그인.
- 🚨 `sudo` 는 비밀번호가 필요하다. 2부에서 Claude 가 `sudo` 명령을 내면 **사람이 그 터미널에서 직접** 친다(또는 GUI 인증창 `pkexec`).

### 1-3. 저장소 받기 (private — 토큰 필요, `git_사용법.md`)
```bash
cd ~ && git clone https://github.com/unmatsutake377-rgb/ros2_ws.git
git config --global credential.helper store
git config --global user.name "<이름>" && git config --global user.email "<깃허브 이메일>"
```
- Password 자리에 **Personal Access Token**(repo 권한).
- 그다음 `cd ~/ros2_ws && claude` 로 세션을 열고 **"docs/절차/2번배_노트북_세팅.md 2부부터 진행해"**.
