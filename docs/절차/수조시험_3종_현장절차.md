# 수조 시험 3종 — 현장 절차 (배 노트북용 요약)

전체 계획·근거는 `docs/절차/tank_test_plan.html`. 이 파일은 현장에서 보는 한 장짜리.
수조 6 × 6 m, 담수. 순서: **경사 → 롤 감쇠 → (조향 부호) → 직진 속도**. 배마다 한 세트, 파일명에 `1번배` / `2번배`.
배 무게 W: 2번배 25 kg(실측), 1번배 30 kg(추정 — 재면 그 값).

## 1. 경사 시험 → GM  (모터 불필요, 먼저)
준비: 무게 아는 추(2 kg 권장, 없으면 배터리 1개를 저울로), 줄자, 폰 수평계 앱을 갑판 중앙에 테이프 고정.
1. 장비 다 싣고 띄움. 손 떼고 30 s → θ₀ 기록.
2. 추를 중심선에 놓음 → θ₁ 기록(기준).
3. 추를 좌현 가장자리로. 중심선→추 중심 거리 d 줄자(≈0.20~0.25 m). 멈추면 θ_L.
4. 우현으로 같은 d → θ_R. 좌·우 각 2회.
5. (덤) 같은 추를 선수 끝/선미 끝에 놓고 선수·선미 흘수 변화 → 트림.

- 계산: `GM = w·d / (W·tan θ)`, θ = |θ_L−θ₁| 와 |θ_R−θ₁| 의 평균. 예: 2 kg·0.20 m·5°, W 25 → 0.18 m.
- θ 가 2° 아래면 묻힘 → d 늘리거나 추 무겁게.
- **사람이 배를 잡고 있으면 안 됨**(손이 복원력이 됨).
- 보낼 것: w, d, θ₁·θ_L·θ_R(각 2회), W, 기울어진 사진 1장.

## 2. 롤 감쇠 → 횡요 고유주기  (모터 불필요)
`/imu/data` 미발행 → 폰 **phyphox "Inclination"**. 폰을 갑판 중앙에 긴 쪽 선수 방향으로 단단히 고정.
1. 기록 시작, 10 s 가만히(기준).
2. 한쪽 뱃전을 손으로 **천천히 눌러** 10° 안팎. 밀치지 말고 누르기만.
3. 딱 놓고 멈출 때까지 손 안 댐(15~20 s).
4. 20 s 간격 3회 → CSV 내보내기(파일명에 배 이름). 백업: 선수 쪽에서 영상 1개(뒤에 수조 벽 수평선).

- 벽 반사파가 돌아오기 전 **첫 3~4주기만** 쓴다.
- 보낼 것: phyphox CSV, 놓은 시각 메모 3개, 영상.

## 3. 직진 속도  (모터)
먼저 조향 부호 5분: 메인 launch 내리고 bridge + motor_control 만.
```bash
ros2 launch ssf_bridge ssf_bridge.launch.py
```
```bash
ros2 run motor_control motor_control --ros-args --params-file ~/ros2_ws/src/motor_control/config/motor_control.yaml
```
ESC 시동 15~25 s 뒤
```bash
ros2 topic pub -r10 /desired_angle std_msgs/msg/Float32 "{data: 5000.0}"
```
오른쪽으로 돌면 정상, 왼쪽이면 `steer_invert: true`. 정지 `50000.0`, 후진 `260.0` 으로 뒤로 가는지 확인.

직진:
- 코스 **대각선 8.5 m**. 도착 쪽에 출발점에서 5.5 m·7.5 m 표시(마지막 2 m 가 정속 구간).
- motor_control 을 `-p base_pwm:=1400` / `1360` / `1300` 으로 재시작하며 `/desired_angle 80.0` 직진, PWM 당 2회 = 6런.
```bash
ros2 run motor_control motor_control --ros-args --params-file ~/ros2_ws/src/motor_control/config/motor_control.yaml -p base_pwm:=1400
```
```bash
ros2 topic pub -r10 /desired_angle std_msgs/msg/Float32 "{data: 80.0}"
```
- 옆에서 폰 촬영(벽에 1 m 테이프 있으면 좋음).
- 계산: 5.5 m → 7.5 m 통과 시간 t, `v = 2 / t` [m/s]. 보고서엔 "수조 대각선 8.5 m, 담수" 조건.
- 런마다 메모: 정지 거리(모터 끈 뒤 미끄러진 거리), 좌우 쏠림, 시작·끝 전압.
- 보낼 것: 영상 6개(파일명에 배·PWM), 전압.
