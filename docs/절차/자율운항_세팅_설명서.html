1. 안전을 위한 주의사항 (반드시 먼저 읽으십시오)

  1. 🚨 모드 전환(수동 ↔ 자율)은 조종기(RC)로만 합니다. 노트북에서 /boat_mode 를 바꾸지 마십시오.
  2. 🚨 프로펠러가 물 밖일 때만 벤치 시험을 합니다. 비상정지를 눌러 ESC 전원을 끈 상태가 기본입니다.
  3. 🚨 조향 부호(steer_invert)와 IMU 방향(invert_yaw)을 확인하기 전에는 자율로 출발하지 마십시오. 가장 흔한 사고입니다(배가 정반대로 감).
  4. 🚨 설정 파일을 고친 뒤에는 launch 를 다시 시작합니다. ros2 param set 은 효과가 없습니다(노드가 시작할 때 한 번만 읽습니다).
  5. 🚨 배 노트북에서 고친 값은 git 에 커밋하지 않습니다. 현장 기록은 docs/절차/현장_조정표_20261106.md §4 기록표에 적습니다.
  6. 🚨 NTRIP(GPS 보정) 접속 정보는 ~/.ssf/ 에만 둡니다. 저장소·채팅에 올리지 마십시오.

4. 처음 한 번만 하는 설정 — 배마다 다른 실측값

이 장의 값은 배마다 다르고, 한 번 재면 대회 내내 유지합니다. 재는 순서대로 적었습니다.

4-1. 헤딩(IMU) — ssf_heading_A.yaml / ssf_heading_B.yaml

파라미터 지금 값 역할 넣을 값 재는 법
mount_offset_deg 0.0 ⚠️ IMU 를 배에 단 방향 보정. /imu/yaw 가 진북 기준 뱃머리 방위가 되도록 더하는 각 실측값 (예 37.0) 배를 나침반으로 정북에 맞춘 뒤 ros2 topic echo /imu/yaw 가 약 352(한국 편각 −8°, 자북→진북)가 되게 조정
invert_yaw false ⚠️ IMU 회전 방향이 반대로 달렸을 때 뒤집기 true/false 뱃머리를 시계방향으로 90° 돌렸을 때 값이 늘어나야 정상. 줄면 true

🚨 mount_offset_deg 는 반드시 소수점(37.0). 37 로 적으면 yaw_mux 가 부팅 즉시 죽고 /imu/yaw 가 끊깁니다. 🚨 이 두 키는 배별 파일에만 둡니다. 공통 ssf_heading.yaml 에 적으면 배별 값에 덮여 반영되지 않습니다. 🚨 launch 첫 줄 boat=…, 파일=… 로 내 배 파일이 맞는지 확인하십시오.

4-2. 추진·조향 — motor_control.yaml

파라미터 지금 값 역할 넣을 값 재는 법
steer_invert false ⚠️ 모터 배선이 좌우 반대일 때 조향·제자리 선회를 함께 뒤집습니다 true/false /desired_angle 5000 을 보내면 오른쪽(시계)으로 제자리 회전해야 정상. 왼쪽이면 true (실해역 2-1)
base_pwm 1360 ⚠️ 순항 전진 PWM. 1500=정지, 1500보다 작을수록 빠른 전진 실측 순항값 수조 직진 속도
max_diff 100 ⚠️ 조향 최대 좌우 차이. 클수록 급회전 실측값 선회 반경
reverse_pwm 1590 ⚠️ 후진 PWM (1500보다 클수록 빠른 후진) 실측값 후진 속도
spin_forward_pwm 1500 제자리 선회 때 가운데 PWM. 1500 이면 진짜 제자리 물 위에서 제자리 회전이 안 되면 1360 쪽으로 낮춤 —
spin_diff 100 제자리 선회 세기 보통 그대로 —

🚨 base_pwm·max_diff·reverse_pwm 을 1360 / 100 / 1590 에서 바꾼 배는 토너먼트 DWA 를 끕니다(ship_direction_tournament.yaml 의 dwa_enabled: false). DWA 가 속에 1360/100/1590 기준 배 모델을 갖고 있어 어긋나도 경고가 안 납니다. 참고: ROS 쪽은 1500보다 작으면 전진이고, 실물 시리얼은 반대입니다. 뒤집기는 ssf_bridge 의 invert_thrust_direction(기본 true) 한 곳이 합니다. 스러스터 배선을 다시 뒤집었을 때만 false 로 바꿉니다.

4-3. 선체·센서 위치 — ship_direction.yaml

파라미터 지금 값 역할 넣을 값
half_width 0.29 ✅🔒 회피할 때 쓰는 배 반폭(m). 1번배 실측 폭 0.57 m ÷ 2, 2번배 0.535 m 도 이 값으로 충분 그대로. 폭이 바뀌면 네 곳(yaml·코드 기본값·테스트·tools/sim/ssf_sim.py)을 함께
dwa_lidar_x_m 0.0 ⚠️ LiDAR 가 선체 중심보다 앞(+)·뒤(−)로 떨어진 거리(m). DWA 가 선체 모서리를 계산할 때 씀 줄자로 잰 값, 소수점 (예 0.35)
dwa_model_agility 1.0 ⚠️ DWA 속 배 모델의 예민도(감쇠 ÷a, 추력 ×a). 실제 배가 모델보다 둔하면 줄이고 예민하면 키움 1360 직진 속도·1286/1434 선회율을 재서 정함. 모르면 1.2~1.4. 0.5~2.0 밖이면 1.0 으로 되돌아감
dwa_hull 자동 DWA 가 쓸 선체 치수(A 1.66×0.55 m / B 1.77×0.522 m) 손대지 않습니다. launch 가 boat:= 로 넣습니다. 시작 로그 DWA 켬: 선체 <내 배> 로 확인

5. 대회마다 하는 설정

5-1. 웨이포인트(GPS 좌표) — north_goal_angle/config/waypoints.yaml (종합임무)

형식: - {구역: "설명", lat: 위도, lon: 경도, mode: 미션번호, dwell: 머무는초}

바꾸는 것 바꾸지 않는 것
각 줄의 lat·lon (대회장 실측) mode, dwell, 줄 순서 (이것이 미션 순서입니다)
  • 도킹 네 줄(도킹 접근 10m ~ WP9 도킹 이탈, ⚠️ 현장 교체 표시)은 손으로 좌표만 고치지 않습니다. 목표 칸이 공지되면 tools/dock_wp.py 가 찍어 주는 네 줄로 통째로 바꿉니다(docs/절차/도킹_칸별_웨이포인트.md).
  • 녹화 방법: docs/절차/웨이포인트_녹화절차.md.
  • 위도·경도를 바꿔 넣거나 오타가 있으면 배가 출발하지 않고 "몇 번째 줄이 왜 틀렸는지" 로그를 냅니다. 정상입니다(틀린 좌표로 달리지 않도록).
  • 로그의 WP 번호는 0부터 센 순번입니다. 도킹 접근 두 줄이 끼어 있어 WP8 입구 = 10, WP9 이탈 = 11, WP10 = 12 로 찍힙니다.

5-2. 토너먼트 웨이포인트 — 노트북 녹화본

  • 레인별로 녹화해 노트북에만 둡니다: ~/ssf_logs/waypoints_tournament_<배>_<레인>.yaml (웨이포인트_녹화절차.md §3a).
  • 🚨 모든 줄이 mode: 8 이어야 합니다. 다른 mode 가 섞이면 north_goal_angle 이 ERROR 를 내고 멈춥니다(배가 출발하지 않음).
  • 마지막 줄 = 결승선 너머 약 3 m, dwell: 0.5. 마지막 WP 를 지나면 즉시 정지(50000)합니다.
  • 저장소의 config/waypoints_tournament.yaml 은 자리표시 템플릿입니다. 녹화본을 거기에 복사하지 말고 launch 의 waypoints_file:= 로 넘깁니다.

5-3. 경기장 경계(지오펜스) — 코스별 north 파일

파일 파라미터 넣을 값
north_goal_angle_main.yaml (종합임무) geofence_polygon [lat1, lon1, lat2, lon2, …] 평탄 배열, 최소 3점(숫자 6개)
north_goal_angle_tournament.yaml (토너먼트) geofence_polygon 같은 형식. 결승선 너머까지 포함
  • 역할: 경계를 "가짜 LiDAR 벽"으로 만들어 회피가 경계를 장애물처럼 피하게 합니다. 경계 이탈은 실격입니다.
  • 🚨 실제 경계를 그대로 찍습니다. 안쪽으로 줄이지 마십시오. 배가 줄인 선을 넘는 순간 경계 정보가 꺼져 오히려 더 나갈 수 있습니다(11-09 시뮬).
  • 비어 있으면([]) 경계 방어가 꺼집니다. 토너먼트에서는 시작 WARN 이 뜹니다. 시작 로그에 geofence ON(n점) 이 보여야 합니다.
  • ⚠️ 경계를 피하는 반응은 약 3 m 앞부터입니다. 경계 쪽으로 크게 꺾인 채 순항하면 다 못 돌 수 있습니다(시뮬 경기 중 이탈 약 1~2 %). 실해역 4-5c 에서 확인합니다.
  • 결승선 뒤 이탈은 감점이 아닙니다(11-09 확인).

6. 실행하기 — launch 명령

종합임무 · 수조 · 실해역 시험

ros2 launch launch_files launch_files.launch.py boat:=A course:=main

토너먼트

ros2 launch launch_files launch_files.launch.py boat:=A course:=tournament waypoints_file:=$HOME/ssf_logs/waypoints_tournament_A_1.yaml

(2번배는 boat:=B, 파일 이름의 A 도 B 로)

인자 필수 기본값 역할
boat 🚨 필수 — A 또는 B. 배별 IMU 값 파일과 DWA 선체를 고릅니다
course 🚨 필수 — main(종합임무) 또는 tournament. 코스별 덮어쓰기 파일을 고릅니다. 빠지거나 Main 처럼 틀리면 launch 가 거부합니다
waypoints_file — (비움) 웨이포인트 파일 경로. 비우면 코스 기본 파일(main=waypoints.yaml, tournament=템플릿)
gps_config — zed_f9p_rover.yaml GPS 설정. 두 배 모두 ZED-F9P 라 그대로
search_behavior — hold 탐색(mode 3): hold=부표 앞 위치유지(2026 안내문). orbit=부표 돌기(옵션)
record — true 블랙박스 CSV(~/ssf_logs) 기록
  • 🚨 판(경기) 사이에는 launch 를 다시 띄웁니다. 웨이포인트 순번이 처음으로 되돌아가지 않습니다.
  • 🚨 RC 가 AUTO(/boat_mode 2)여야 미션이 진행됩니다(require_boat_mode_auto: true). 벤치에서 아두이노가 없으면 ros2 topic pub /boat_mode std_msgs/msg/Int32 "{data: 2}".

10. 문제 해결

증상 가능한 원인 조치
launch 가 바로 거부됨 boat·course 빠짐 또는 오타(Main) boat:=A course:=main
노드가 뜨자마자 죽음 (InvalidParameterTypeException) 소수 자리에 정수 9장 형식대로
배가 출발하지 않음, north ERROR "웨이포인트 내용 오류" 좌표 오타·위경도 뒤바뀜, 토너먼트에 mode 8 아닌 줄 로그가 알려 주는 줄 수정
배가 출발하지 않음, 로그 이상 없음 RC 가 AUTO 아님(/boat_mode ≠ 2) 조종기 AUTO
출발했는데 계속 정지(50000) + 5 초마다 ERROR /yaw_error 를 한 번도 못 받음 (GPS fix 없음 → 목표 방위 없음) GPS fix·RTK 확인
목표와 반대쪽으로 감 invert_yaw 또는 mount_offset_deg 틀림 4-1 다시
조향이 반대로 꺾임 / 5000 에 왼쪽으로 돎 steer_invert 4-2
시작 WARN "geofence_polygon 이 비어 있다" 토너먼트 경계 미입력 5-3
로그 "DWA 가능한 후보 없음"(폴백)이 잦음 물보라·가까운 장애물. DWA 가 기존 회피로 넘김 잦으면 dwa_enabled: false
도킹 중 갑자기 정지 + '🚧🛑' 경계 2 m 안 하드 정지(정상 동작) 도크가 경계 가까우면 폴리곤 확인
탐색 부표를 못 찾음 turn_color_mode3 가 공지 색과 다름, HSV 범위 5-4
두 배가 서로 토픽을 받음 ROS_LOCALHOST_ONLY 없음 3장 ②
yaml 을 고쳤는데 그대로 launch 재시작 안 함 / 설치 폴더가 symlink 아님 재시작, 3장 ③
